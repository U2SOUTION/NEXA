## 🔍 대안 라이브러리 비교

### 1. **D2** ⭐⭐⭐⭐⭐ (최고 대안, 하지만 제약 있음)

**특징:**

- Go로 작성된 모던 다이어그램 라이브러리
- 마크다운 스타일 문법 (Mermaid와 유사)
- 레이아웃 엔진이 강력하고 안정적

**장점:**

- ✅ 마크다운 스타일 문법 (Mermaid와 유사)
- ✅ 레이아웃 엔진이 안정적 (컨테이너 크기 문제 없음)
- ✅ 다양한 다이어그램 타입 지원
- ✅ 무료, 오픈소스
- ✅ 성능 좋음

**단점:**

- ❌ **JavaScript 클라이언트 라이브러리가 없음** (서버 렌더링 필요)
- ❌ Vue 통합이 복잡함
- ❌ Mermaid만큼 널리 사용되지 않음

**결론:** 브라우저에서 직접 실행이 불가능하여 현재 프로젝트에는 부적합

### 2. **PlantUML** ⭐⭐⭐

**특징:**

- UML 다이어그램에 특화
- 텍스트 기반 다이어그램 작성

**장점:**

- ✅ 다양한 UML 다이어그램 타입
- ✅ 문법이 명확하고 강력함
- ✅ 무료, 오픈소스

**단점:**

- ❌ 브라우저에서 직접 실행 불가 (서버 필요)
- ❌ Mermaid 문법과 다름 (마이그레이션 필요)
- ❌ Vue 통합이 복잡함

**결론:** 서버 설정이 필요하여 클라이언트 사이드만으로는 사용 어려움

### 3. **nomnoml** ⭐⭐

**특징:**

- JavaScript 라이브러리
- UML 다이어그램에 특화

**장점:**

- ✅ 브라우저에서 직접 실행 가능
- ✅ 가볍고 간단함
- ✅ JavaScript 라이브러리

**단점:**

- ❌ **UML 다이어그램 위주** (플로우차트, 시퀀스 등 제한적)
- ❌ Mermaid만큼 다양한 타입 지원 안 함
- ❌ 커뮤니티가 작음

**결론:** 다이어그램 타입이 제한적

### 5. **Mermaid 유지 + 문제 해결** ⭐⭐⭐⭐ (권장)

**현재 문제:**

- Pie 차트의 viewBox 오류
- 새로고침 시 렌더링 타이밍 문제

**해결 방안:**

#### 방안 A: Pie 차트만 제외하고 사용

- 다른 차트 타입은 정상 작동
- Pie 차트는 Chart.js나 다른 라이브러리 사용

#### 방안 B: IntersectionObserver 사용

- 실제로 보일 때만 렌더링
- 컨테이너 크기가 확정된 후 렌더링

#### 방안 C: Mermaid 버전 다운그레이드

- 이전 버전이 더 안정적일 수 있음
- 하지만 최신 기능을 놓칠 수 있음

**장점:**

- ✅ 이미 구현되어 있음
- ✅ 마크다운 파서와 통합 완료
- ✅ 대부분의 차트가 정상 작동
- ✅ 널리 사용되는 라이브러리

**단점:**

- ⚠️ Pie 차트 문제 지속 가능성
- ⚠️ 렌더링 타이밍 문제

**결론:** 문제를 해결할 수 있다면 가장 현실적인 선택

## 🎯 추천 방안

### 1순위: **Mermaid 유지 + Pie 차트 제외** ⭐⭐⭐⭐⭐

**이유:**

- 이미 구현되어 있음
- 대부분의 차트 타입이 정상 작동
- Pie 차트만 제외하고 다른 차트 사용
- Pie 차트가 필요하면 Chart.js로 별도 구현

**구현 방법:**

```javascript
// useMermaid.js에서
if (chartType.includes('pie')) {
  // Pie 차트는 Chart.js로 렌더링하거나 에러 메시지 표시
  block.innerHTML = '<div class="mermaid-pie-notice">Pie 차트는 Chart.js를 사용하세요</div>'
  continue
}
```

---

### 2순위: **Mermaid + IntersectionObserver** ⭐⭐⭐⭐

**이유:**

- 실제로 보일 때만 렌더링하여 타이밍 문제 해결
- 컨테이너 크기가 확정된 후 렌더링

**구현 방법:**

```javascript
// IntersectionObserver로 실제로 보일 때만 렌더링
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      renderMermaidBlock(entry.target)
      observer.unobserve(entry.target)
    }
  })
})
```
