## 현재 문제점 분석

### 검색 결과 정렬 미작동

- **원인**: `filteredSearchResults`가 `matchCount` 순으로만 정렬되어 표시됨
- **해결**: `sortedSearchResults` computed를 생성하여 사용자 정렬 기준 적용

### 검색 결과 드래그 앤 드롭 미작동

- **원인**: 검색 결과 항목에 드래그 앤 드롭 이벤트가 연결되지 않음
- **해결**: 검색 결과 항목에 드래그 앤 드롭 이벤트 추가

### 정렬 모드별 순서 변경 미작동

- **원인**: 현재는 우선순위만 조정하고, 다른 정렬 기준은 조정하지 않음
- **해결**: 각 정렬 모드에 맞는 값 조정 로직 구현

## 구현 세부사항

### 수정일 조정 로직

```javascript
// 타겟 파일의 수정일 확인
const targetDate = new Date(targetFile.modifiedDate)

// 드롭 위치에 따라 조정
if (sourceIndex < finalTargetIndex) {
  // 아래로 이동: 타겟보다 1초 뒤
  newDate = new Date(targetDate.getTime() + 1000)
} else {
  // 위로 이동: 타겟보다 1초 앞
  newDate = new Date(targetDate.getTime() - 1000)
}
```

### 사용 빈도 조정 로직

```javascript
// 타겟 파일의 사용 빈도 확인
const targetUsage = fileUsageCounts.value[targetFileName] || 0

// 드롭 위치에 따라 조정
if (sourceIndex < finalTargetIndex) {
  // 아래로 이동: 타겟보다 1 낮게
  newUsage = Math.max(0, targetUsage - 1)
} else {
  // 위로 이동: 타겟보다 1 높게
  newUsage = targetUsage + 1
}

// 사용 빈도 설정 (새 함수 필요)
setFileUsage(sourceFileName, newUsage, fileUsageCounts)
```

### 즐겨찾기 조정 로직

```javascript
// 타겟 파일의 즐겨찾기 상태 확인
const targetFavorite = favoriteStates.value[targetFileName] === true

// 타겟이 즐겨찾기면 소스도 즐겨찾기로, 아니면 해제
if (targetFavorite && !favoriteStates.value[sourceFileName]) {
  toggleFavorite(sourceFileName, favoriteStates)
} else if (!targetFavorite && favoriteStates.value[sourceFileName]) {
  toggleFavorite(sourceFileName, favoriteStates)
}
```
