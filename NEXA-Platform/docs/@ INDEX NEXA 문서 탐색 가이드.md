## 2. 접두어로 문서 찾기

### 2-A. Context 접두어 (파일명 맨 앞)

| 접두어       | 성격                                   | 찾는 곳        |
| :----------- | :------------------------------------- | :------------- |
| `N-MAP`      | N-MAP 프로토콜 (정의·실행·문법·예외)   | 루트           |
| `SYS`        | 시스템 인프라·아키텍처·가이드          | 루트           |
| `NIXIE`      | 닉시 시각화 엔진 (설계·스키마·컨셉)    | 루트           |
| `NEXU`       | 넥슈 캔버스·가이드 에이전트            | 루트           |
| `AIS`        | AI 워크스페이스 (협업·에디터·탐색기)   | 루트           |
| `NOD`        | 노드·하드웨어 (ESP32·Jetson·펌웨어)    | 루트           |
| `_KNOWLEDGE` | 지식 운영체제 (아키텍처·DDL·규약·CRUD) | 루트           |
| `__NEXA`     | 오케스트레이션 DB 명세·DDL             | 루트           |
| `DDL`        | DB 스키마·물리 설계                    | `database/`    |
| `NEXA`       | 플랫폼 정체성·비전·마스터 디자인       | 루트           |
| `[NXN]`      | Nexion 도메인 전용                     | `NEXA Nexion/` |
| `[NEXA]`     | NEXA-OS 아키텍처 (Nexion 폴더 내)      | `NEXA Nexion/` |

### 2-B. DocType 접두어 (Context 뒤)

| 접두어            | 성격                | 용도                               |
| :---------------- | :------------------ | :--------------------------------- |
| `ARCH`            | 아키텍처 설계       | 구조·계층·흐름 정의                |
| `SPEC`            | 기술 규격           | 프로토콜·알고리즘·데이터 포맷 상세 |
| `DESIGN`          | UI/UX·시스템 디자인 | 화면 설계·인터랙션·레이아웃        |
| `RFC`             | 기획 초안           | 아직 확정되지 않은 제안·검토 문서  |
| `REF`             | 참조 자료           | 코드표·레퍼런스·매트릭스           |
| `GUIDE`           | 가이드·로드맵       | 구축 순서·운영 방법                |
| `CONCEPT`         | 개념·철학           | 비전·원칙·사유의 토대              |
| `VISION`          | 비전 선언           | 플랫폼 방향성·장기 목표            |
| `REQ`             | 요구사항            | 하드웨어·기능 요구 명세            |
| `SCHEMA` / `SCHM` | 스키마 명세         | DB 테이블·필드 정의                |
| `DDL`             | 물리 스키마         | SQL DDL, 마이그레이션              |
| `API`             | API 통신 규약       | REST 엔드포인트·페이로드           |
| `PRD`             | 제품 기능 정의      | 기능 목록·작업 순서·우선순위       |
| `CNCP`            | 설계 철학           | 개념 정의·전략 문서                |
| `UIUX`            | 인터페이스 기획     | 레이아웃·시각 규약·카드 디자인     |
| `RULE`            | 규약·계약           | 표준 규칙·정책                     |
| `INF`             | 인프라              | MQTT·오디오·네트워크 설정          |

### 2-C. 특수 접두어

| 접두어 | 의미                              |
| :----- | :-------------------------------- |
| `@`    | 수정 금지·상단 고정 (시스템 문서) |

## 4. 탐색 규칙 요약

1. **개념(What)을 모르겠으면** → 용어집 (`N-MAP 00 NEXA-OS GLOSSARY`) 참조
2. **파일을 찾으려면** → Context 접두어 + DocType 접두어로 파일명 검색
3. **Nexion 관련이면** → `NEXA Nexion/` 폴더에서 `[NXN]` 접두어로 검색
4. **DB 관련이면** → `database/` 폴더 또는 루트의 `_KNOWLEDGE DDL`, `__NEXA` 접두어 검색
5. **AI/하드웨어 관련이면** → `AI/` 폴더에서 `NEXA AIS` 접두어로 검색
6. **시각화 관련이면** → 루트에서 `NIXIE` 또는 `NEXU` 접두어로 검색
