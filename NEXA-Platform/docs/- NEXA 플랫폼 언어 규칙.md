**IoT 플랫폼에서 자주 등장하는 기술 용어들을 최대한 많이 뽑아서 하나의 기준 테이블 초안**.

---

# IoT 플랫폼 용어 정리 (초안)

| 기존 용어         | 우리 용어            | 이유                          | 용어 정의                                                       |
| ----------------- | -------------------- | ----------------------------- | --------------------------------------------------------------- |
| Lifecycle         | 흐름                 | 생애주기라는 과장된 표현 제거 | 어떤 데이터나 장치가 생성되어 사용되고 종료되기까지의 전체 흐름 |
| Data Lifecycle    | 데이터 흐름          | 직관적인 표현                 | 데이터가 생성되고 저장되고 사용되는 과정                        |
| Device Lifecycle  | 장치 상태            | 사용자 이해도 높음            | 장치가 등록되고 연결되고 사용되는 상태 변화                     |
| Provisioning      | 장치 등록            | 어려운 IT 용어                | 새 장치를 시스템에 등록하는 과정                                |
| Device            | 장치                 | 일반 사용자도 이해            | 시스템에 연결되는 물리적 장비                                   |
| Sensor            | 센서                 | 이미 일반화된 용어            | 환경 데이터를 측정하는 장치                                     |
| Actuator          | 제어장치             | 사용자 이해도 향상            | 전기적 신호로 실제 동작을 수행하는 장치                         |
| Gateway           | 연결장치             | 기술 용어 완화                | 장치와 서버 사이에서 데이터를 전달하는 장비                     |
| Endpoint          | 연결지점             | 직관적 표현                   | 데이터가 들어오거나 나가는 시스템 위치                          |
| Node              | 장치노드             | 의미 유지                     | 네트워크에 연결된 하나의 장치 단위                              |
| Telemetry         | 센서데이터           | 전문 용어 제거                | 장치에서 전송되는 측정 데이터                                   |
| Ingest            | 데이터 수집          | 이해 쉬움                     | 외부 장치에서 데이터를 받아오는 과정                            |
| Data Pipeline     | 데이터 흐름 경로     | 파이프라인 은유 제거          | 데이터가 이동하고 처리되는 경로                                 |
| Stream Processing | 실시간 처리          | 직관적                        | 들어오는 데이터를 바로 처리하는 방식                            |
| Batch Processing  | 일괄 처리            | 일반 용어                     | 데이터를 모아서 한 번에 처리하는 방식                           |
| Data Storage      | 데이터 저장          | 직관적                        | 데이터를 저장하는 공간                                          |
| Database          | 데이터 저장소        | 기술 단어 완화                | 데이터를 구조적으로 보관하는 시스템                             |
| Data Lake         | 대용량 데이터 저장소 | 이해도 향상                   | 원본 데이터를 대량으로 저장하는 공간                            |
| Cache             | 임시 저장            | 직관적                        | 빠른 처리를 위해 잠시 보관하는 데이터                           |
| Firmware          | 장치 소프트웨어      | 사용자 친화                   | 장치 내부에서 동작하는 프로그램                                 |
| Firmware Update   | 장치 업데이트        | 쉬운 표현                     | 장치 내부 프로그램을 최신 상태로 바꾸는 작업                    |
| OTA Update        | 원격 업데이트        | 기술 용어 완화                | 네트워크를 통해 장치를 업데이트하는 방식                        |
| Authentication    | 사용자 확인          | 기술 용어 완화                | 사용자가 누구인지 확인하는 과정                                 |
| Authorization     | 권한 확인            | 이해 쉬움                     | 사용자가 어떤 기능을 사용할 수 있는지 확인                      |
| Token             | 접근 열쇠            | 직관적 표현                   | 시스템 접근을 허용하는 인증 정보                                |
| API               | 연결 규칙            | 비개발자 친화                 | 시스템 간 데이터를 주고받는 방법                                |
| REST API          | 웹 연결 규칙         | 이해도 향상                   | 웹 기반 시스템 연결 방식                                        |
| Webhook           | 자동 알림            | 사용자 친화                   | 특정 이벤트 발생 시 자동으로 전송되는 알림                      |
| Event             | 발생 신호            | 직관적                        | 시스템에서 발생한 특정 상황                                     |
| Event Trigger     | 실행 조건            | 이해 쉬움                     | 특정 조건이 만족되면 실행되는 기능                              |
| Rule Engine       | 자동 규칙            | 사용자 중심                   | 설정한 조건에 따라 자동 동작하는 기능                           |
| Automation        | 자동 동작            | 쉬운 표현                     | 설정된 조건에 따라 시스템이 자동으로 동작                       |
| Dashboard         | 상황판               | 직관적 표현                   | 시스템 상태를 한눈에 보여주는 화면                              |
| Monitoring        | 상태 확인            | 직관적                        | 시스템 상태를 계속 확인하는 작업                                |
| Logging           | 기록                 | 쉬운 표현                     | 시스템 동작 기록을 남기는 것                                    |
| Alert             | 경고 알림            | 직관적                        | 문제가 발생했을 때 전달되는 알림                                |
| Notification      | 알림                 | 쉬운 표현                     | 사용자에게 전달되는 메시지                                      |
| Edge Computing    | 현장 처리            | 기술 용어 완화                | 장치 가까운 곳에서 데이터를 처리하는 방식                       |
| Cloud             | 서버 시스템          | 사용자 이해도 향상            | 인터넷 기반 데이터 처리 시스템                                  |
| IoT Platform      | 장치 관리 시스템     | 직관적                        | 여러 장치를 연결하고 관리하는 시스템                            |
| Integration       | 시스템 연결          | 이해 쉬움                     | 서로 다른 시스템을 연결하는 과정                                |
| Deployment        | 시스템 적용          | 쉬운 표현                     | 프로그램을 실제 환경에 설치하는 과정                            |
