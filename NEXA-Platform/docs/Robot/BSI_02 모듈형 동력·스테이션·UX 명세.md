# BSI_02 모듈형 동력·스테이션·UX 명세

BSI를 **고토크 회전 동력**(전동 공구 계열)에서 **모듈형 레일·포트 플랫폼**으로 확장했을 때의 전자·UX 개요이다. 브러시 단순 제어([[BSI_01 팩 내 제어·하이브리드 회로]])와 다른 층이므로 같은 BSI 패밀리 안에서 선택 적용한다.

## 1. 엔코더·FOC

드릴의 회전 동력을 정밀 가공 또는 주행 피드백으로 쓸 때의 핵심 경로이다.

- **센서**: MT6701 자기식, 14-bit(한 회전당 16384 분해능).
- **설치**: 감속기 **이후 최종 출력축** 직결. 출력축 끝 **자석 반매립 홀**(선반·동심 가공).
- **제어**: FOC(Field Oriented Control), SimpleFOC 등.
- **보정**: 자석 편향, 감속기 백래시를 소프트웨어로 실시간 보완.
- **슬립**: 휠–레일 마찰 구동 시 슬립을 엔코더 기준과 비교해 위치 편차 보정.

## 2. 스테이션 ID (무전원 소켓 식별)

10m 레일 등에 다수 포트를 두되 **별도 유선 버스 최소화**를 목표로 한다.

- **방식**: 전압 분배 **Voltage Divider ID** — 소켓에 고유 저항 \(R_{id}\), 장비 단에 기준 저항 \(R_{ref}\).
- **기계**: 클램프 체결 시 닿는 **3핀 슬라이딩 접점**(세척·마모 고려).
- **흐름**  
  1. 체결 시 MCU(예: XIAO) ADC로 전압 측정 → \(R_{id}\) 역산  
  2. 중앙 DB에서 해당 ID의 좌표·작업 정보 조회  
  3. 미등록 ID는 **최초 등록 모드**로 DB 갱신·동기화  
- **확장**: 저항 조합·핀 추가로 포트 수 이론상 대량까지 확대 가능.

## 3. 웨어러블 인터페이스

고글 탑재 시 상태 인지 채널.

- **입력**: XIAO nRF52840 + 손가락 마디 터치 3×3, IMU 제스처.
- **출력(햅틱)**: 장갑 진동 모터.  
  - 짧게 1회: 스테이션 인식·동기 성공  
  - 짧게 3회: 접촉 불량·위치 경고  
  - 연속: 가공 가동 또는 긴급 정지

## 4. 동력 전달·슬립·기계 잠금

### 4-1. 트라이앵글 벨트·마찰

- Y형: 구동 풀리 1 + 아이들러 2로 텐션·감김 각 확보.
- 타이밍 벨트 **백사이드**를 구동 휠에 넓게 밀착(백사이드 마찰 구동). 고인장·내마모·필요 시 뒷면 코팅.
- 미세 슬립은 출력축 MT6701으로 보정(SSWT·벨트 선정은 [[BSI_03 SSWT·벨트·구동 용어·실험]]).

### 4-2. 웜기어 자가 잠금

동력 차단 즉시 **웜 기어 역전 저항**(self-locking)으로 브레이크 없이도 위치 유지. 경사·외충격 시에도 유리.

### 4-3. 스테이션 매핑(요약)

체결 순간 저항 인식 → DB 위치 정보 → 진동 패턴과 UI 동기화.

## 마스터 요약표 (중복 블록 통합)

| 구분 | 적용 요소 | 효과·비고 |
| --- | --- | --- |
| 동력 제어 | BLDC + MT6701 + FOC(SimpleFOC) | 저속 정밀, 슬립 보정 가능 |
| 기계 구동 | Y자 벨트 + 웜 기어 | 텐션·백사이드 접지·전원 차단 시 고정 |
| 위치 피드백 | 최종축 자기 엔코더 + SW 보정 | 백래시·미세 슬립 완화 |
| 포트 인식 | \(R_{id}\) + 접점 → ADC → DB | 저비용, 무전원 스테이션 쪽 단순 |
| 사용자 UX | 고글·햅틱 장갑 | 상태·안전 피드백 |

정밀도 목표 예(문서 초안값): 출력축 기준 미세 슬립에도 약 **0.1mm급** UI 정합을 노릴 경우 SW·기계 세부를 [[BSI_03 SSWT·벨트·구동 용어·실험]]와 맞출 것.

## 작업 시나리오 요약

1. 사용자가 원하는 스테이션에 공구 편도체를 거치·클램프한다.  
2. 접점 ADC로 스테이션 ID 확인, 햅틱으로 성공/실패를 즉시 알린다.  
3. IMU 또는 버튼으로 이동 명령, 웜·벨트로 전달 후 정지 시 기계 고정.  
4. 벨트 슬립은 엔코더로 보정해 고글/UI 좌표를 유지한다.
