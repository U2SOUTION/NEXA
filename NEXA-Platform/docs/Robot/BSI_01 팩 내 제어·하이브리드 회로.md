# BSI_01 팩 내 제어·하이브리드 회로

BSI 레이어의 **동력 차단·속도 방향 제어**를 다룬다.

- **전반**: 브러시류·좁은 **팩 내부** 우선 회로 (릴레이+MOSFET).
- **후반**: **본체–팩 브리지(BLDC)** — 순정 회로 차단 후 어댑터 **외부 BLDC 드라이버**가 모터 **U·V·W**에 직접 연결되는 **외장 샌드위치 컨트롤러** 계열.

상위 원칙: [[BSI_00 플랫폼 원칙 및 용어]].

## 전동 공구 방향·속도 제어 방식 비교 (공간 우선 한정)

| 구분 | 1. 하이브리드 (릴레이+MOSFET) | 2. 4-MOSFET (H-브릿지) | 3. 3-MOSFET (대안 검토용) |
| --- | --- | --- | --- |
| 핵심 부품 | 2회로 릴레이(1) + MOSFET(1) | MOSFET(4) + 드라이버 IC(1) | MOSFET(3) + 복잡 구동 |
| 공간 효율 | 가장 좋음 | 보통 | 낮음 |
| 속도 제어 | PWM 가능 | 매우 정밀 | 가능(난이도 높음) |
| 장점 | 회로 단순, 소량 제작에 유리 | 무소음에 가깝고 내구 높음 | 이론적 부품 축소 |
| 단점 | 릴레이 소음·수명 | 면적·발열 관리 필요 | 고측 구동·배선 |
| 우선 순위 권장 | 1위 (좁은 팩) | 2위 (전문 PCB) | 3위 |

## 최종 권장: 하이브리드 (릴레이 + 단일 저측 MOSFET)

좁은 팩 내부에는 소형 릴레이 1 + MOSFET 1 조합이 현실적인 균형이다.

1. **공간**: H-브릿지+PWM·드라이버·방열 대비 면적이 작다.
2. **제어선**: MCU에서 방향 1선 + PWM 1선 수준으로 단순화 가능.
3. **역기전력**: 브러시·리프트류에서 정지 시 서지 처리가 4-MOSFET 전부 설계보다 단순해지는 경우가 많다.

## 부품 사양 (초안)

- **릴레이**: 24V 20~30A급·자동차/산업 소형, **DPDT 2회로** (방향 스왑).
- **MOSFET**: IRFB7430 등, **Low-side**에서 온오프·PWM.
- **MCU**: ESP32-C3 초소형 모듈 등 (핀·전력 예산에 맞게 선정).

팩 내부 여유가 있으면 외부 전원 인터페이스는 XT60 등으로만 노출하는 구성이 가능하다.

## 하이브리드 제어 개념도 (텍스트)

```
[배터리 +] ----+-----------+----------------------------------+
               |           |                                  |
         [Buck → MCU VIN] [릴레이 코일]                    [릴레이 COM]
               |           |                                  /
               |     [NPN] ← GPIO1 (방향)                      /
               +---------------------------------- [모터 단자 A]
                                                            /
[배터리 GND] ------------------------------------ [모터 단자 B]
               |
         [MOSFET D] … [MOSFET S] ---- GND (공통)
         [MOSFET G] ← 드라이버 ← GPIO2 (PWM/ON-OFF)
```

## 결선·안전

1. **릴레이 (DPDT)**  
   - NC/NO에 (+)(-)를 교차 배선하고 COM을 모터 양단에 연결하는 전형적 역전 구성.  
   - **가동 중 방향 전환 금지**: 반드시 PWM 0 → 짧은 대기 → 릴레이 토글 → PWM 적용 순서.

2. **MOSFET (Low-side)**  
   - 모터 (-) 경로와 배터리 GND 사이.  
   - **게이트 드라이버 필수**: 3.3V 직접 구동은 부적합. TC4427급 또는 푸시풀로 **10V 이상** 게이트 구동.

3. **MCU 전원**  
   - 팩 전압(예: 18~20V대) 직결 금지. Buck으로 5V(또는 보드 규격) 후 VIN.

4. **보호**  
   - 릴레이 코일·모터단 **역기전력용 다이오드**.  
   - 선택: ACS712 등으로 과전류 시 차단.

## ESP32 계열 의사 코드 (방향 안전 순서 포함)

방향 논리(`RELAY_HIGH`/`LOW`가 실제 회로에서 어느 쪽 회전인지는 배선에 맞게 반전 가능).

```cpp
static void motorOffAndSettle() {
  ledcWrite(PWM_CHANNEL, 0);
  delay(100);
}

void liftUp(int speed) {
  motorOffAndSettle();
  digitalWrite(RELAY_PIN, HIGH);
  delay(50);
  ledcWrite(PWM_CHANNEL, speed);
}

void liftDown(int speed) {
  motorOffAndSettle();
  digitalWrite(RELAY_PIN, LOW);
  delay(50);
  ledcWrite(PWM_CHANNEL, speed);
}

void stopMotor() {
  motorOffAndSettle();
  digitalWrite(RELAY_PIN, LOW);
}
```

## 오픈 이슈·검증 항목

- 릴레이 코일 전압(5V 논리 vs 배터리 직계)에 따른 **구동단**(트랜지스터/레벨) 확인.
- MOSFET·릴레이 접점 전류 여유·열, **패킹 재질** 내 내연·단락 대책.
- 실제 패킹에서 **MCU·고전압 간 거리·크리프** 거리.

## 본체–팩 브리지: 샌드위치형 BLDC 디렉트 (팩 바깥·중간층)

**결합 순서**(슬라이딩 형): `[본체 드릴]` – `[어댑터 PCB·구동층]` – `[정품 배터리 팩]`  
정품 패킹 단독으로 본체에 끼울 때는 **가능한 한 OEM 형상·체결 리듬**을 유지하는 것이 플랫폼 규격이다([[BSI_00]]).

### 전원 급전(초안)

- 패킹 **외부 노출 접점**(브랜드별 핀 번호만 상이함) 예: 특정 패밀리에서 **`+`/`-`(문서 초안에서는 1·5번 계열 참조만)** 에서 패킹 전압을 컨트롤러 **BLDC 드라이버**로 인입.
- 패킹 셀·BMS 규격·접점 내구는 반드시 **해당 패킹 전기·기계 사양과 정합 검증**(전류 피크, 역주입 방지 포함).

### 물리적 마스터 인터록(예시 개념)

- 본체 측 **배터리 슬라이더 중앙 공간**(또는 빈 블레이드)에 들어오는 어댑터 **밀림 핀**(돌기).
- 순정 상태(어댑터 미삽입): 밀림 핀이 내부 스위치에 가해지지 않아 **3PDT(또는 동등 순정 스위치)** 가 OEM 모터 회로측 연결 유지.
- 어댑터 장착: 핀이 스위치를 물리 밀어 **순정 경로 차단**, 모터 단자 **U·V·W** 가 어댑터 **외부 BLDC 드라이버**로만 연결.
- 패킹·본체 간 **케이블 패싱**(스프링 접점 등) 허용치·**내부 클리어런스**는 **SKU별 검증 목록**으로 분리 관리한다.

> 브랜드·모델마다 빈 슬롯 깊이·내부 스위치 위치가 다르므로(예: **Worx** 무브러시 일부 SKU), 기능 개념은 본 챕터에 두고 **핀 깊이·밀림 행정** 등은 SKU별 **실측 치수 시트**로만 관리하는 것을 권장한다.

### 제어·연동(MCU 초안 ESP32 계열)

- **ESP-NOW** 등 근거리 메시형으로 AP 없이 동일 동작 묶음(예: 수평 잭 4점 동시·지연 명령) 동기 검토 가능.
- **위치·각도 센서 없이 하는 말단 제한(센서리스 초안)**: BLDC 드라이버 **모터 전류·전압**(또는 DC 링크)을 감시해 **충격·말단에서의 과전류**를 감지하고 즉시 정지(**소프트 리미트**).
- 순정 트리거·방향 UI를 그대로 둘지, 어댑터가 전면 제어할지는 **SKU별 UX 계약**(동일 SKU는 같은 리듬 권장).

### 기구와의 연결(초안)

- 출력부 **웜기어 + 육각(각산) 볼트 지그**(잭·어닝 등 표준 입력축 통합 가능): 전원 차단 후에도 웜 특성상 **역전 성립(self-lock 근처)** 에서 미끄럼 저항 확보([[BSI_02]], [[BSI_03]] 참고).

### 이 탈착 패턴의 장점(요약)

- **교체 가능한 동력원**: 구동 헤드를 공구 교체처럼 갈아치우면 현장 교체 시간 단축.
- **구동부 무게 분산**: 곳곳에 대형 매립 모터 필요성 완화(탈거형 패밀리에 한함).
- **비상 조작**: 전원 또는 전자 장애 시 **드릴 본체를 분리 후 수공구(렌치)로 회전축 추진**(육각·지그 규격 맞춤).
- **원가 구조**: 양산 드라이브를 엔진으로 사용해 개발 속도 확보 전제.
