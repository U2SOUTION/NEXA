# BSI 문서 세트 개요

NEXA 플랫폼에서 무선 전동 공구 동력계를 표준 레이어로 통합하기 위한 규격·설계 노트 묶음이다. 접두 **`BSI_`** 로 정렬해 검색·버전 관리를 통일한다.

## 플랫폼 원칙

- **통합 방식**: 본체와 배터리 팩 사이에 **샌드위치 형태 어댑터**를 두어 제어·시스템 I/O를 끼워 넣는다. 외관·패킹만 사용할 때는 **가능한 한 OEM 형상과 동일한 결합·사용 리듬**(배터리 장착감 등)을 유지한다.
- **내부 가변 허용**: 내부 회로·펌웨어는 브랜드·모델에 따라 달라질 수 있으며, 형상 호환 스택 레이어만 규격의 기준점으로 삼는다.
- **적용 범위**: 장비 라인별로 브러시 단순 제어부터 BLDC·FOC·스테이션 연동까지 다층이다. 가능한 기능은 동일 패밀리(스택 레이어)로 맞추고, 불가능한 경우에만 예외 모듈로 분리한다.

## 레이아웃 형태 (둘 다 BSI 패밀리)

| 형태 | 위치 | 대표 회로 |
| --- | --- | --- |
| **팩 내 최소형** | 배터리 팩 챔버 내부 | 브러시류 **릴레이 + 저측 MOSFET**(공간 우선)·[[BSI_01 팩 내 제어·하이브리드 회로]] |
| **본체–팩 브리지** | **[본체] – [어댑터] – [정품 패킹]** 순으로 슬라이딩 체결 | 내부 **BLDC 구동**(순정 전자 차단·모터 단자 브리지)·같음 [[BSI_01 팩 내 제어·하이브리드 회로]] 후반 |

외형 목표는 동일하게 **패킹만 단독 사용 시 OEM과 동등한 결합감**(가능 영역까지) 유지다.

### 응용 시나리오(초안·참고)

탈착형 동력으로 **잭·어닝·리프트**(웜기어·육각 지그), **중앙 Y-벨트 주행**(SSWT·[[BSI_03]]), 그리고 레일 계열까지 한 공구 패밀리로 묶을 수 있다는 초안 블록을 둔다. 상세 과제별 문서와 분리해 유지한다.

## 용어 (짧은 정리 표준)

| 용도 | 권장 용어 | 비고 |
| --- | --- | --- |
| 내부·문서 표준명 | **배터리 스택 인터페이스**, **BSI** | 본 세트 접두와 대응 |
| 역할·아키텍처 설명 | **본체–배터리 브리지 모듈** | 본체–팩 중간 레이어 |
| 샌드위치 역할 강조 | **샌드위치 파워 허브** | 전원·통합 집결부 |
| OEM 체험 유지 강조 | **형상 호환 스택 어댑터** | 외관·패킹 시 정품류 UX |

영문 병기 예: Battery Stack Interface (BSI).
