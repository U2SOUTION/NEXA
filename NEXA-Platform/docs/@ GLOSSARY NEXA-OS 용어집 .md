이 용어들은 NEXA 플랫폼이 단순한 관리를 넘어 **사용자의 의도를 분석하고, 시각적으로 공감하며, 지능적으로 자원을 합성**하는 구체적인 과정을 설명하는 핵심 개념들입니다. 추가로 특정 도메인(예: 마켓의 수익 모델 등)에 집중된 용어가 필요하시면 말씀해 주세요.

제공해주신 통합 서사 원장 및 마켓 규격서, 그리고 Nexnap 프로토콜 문서들을 종합하여 **시스템 아키텍처, AI 오케스트레이션, 거버넌스 및 시각화** 레이어에서 추출한 더 상세하고 전문적인 용어들을 정리해 드립니다.

### **1. AI 오케스트레이션 및 언어적 로직 (AI Orchestration & Logic)**

시스템의 '두뇌'가 자연어를 처리하고 실행 사슬로 변환하는 과정에서 사용되는 핵심 기술 용어입니다.

| 용어 (영문)                          | 한글 표기             | 정의 및 역할                                                                                    |
| :----------------------------------- | :-------------------- | :---------------------------------------------------------------------------------------------- |
| **Linguistic Routing**               | **언어적 라우팅**     | 자연어 의도를 분석하여 기기, 서비스, 에이전트로 배정하는 지능형 스위치 엔진입니다.              |
| **English Kernel**                   | **영어 커널**         | 내부 엔진이 소통하는 '표준 영문 악보'로, 높은 논리성과 토큰 효율을 위해 채택된 원칙입니다.      |
| **Pruning**                          | **프루닝 (가지치기)** | HEXAGON 토큰을 인덱스로 활용해 무관한 데이터의 90%를 1ms 내에 사전 필터링하는 기술입니다.       |
| **Intermediate Representation (IR)** | **중간 표현**         | 멀티모달 입력을 영어 커널이 이해할 수 있도록 정규화한 5W1H 기반의 데이터 규격입니다.            |
| **Reverse Decomposition**            | **역방향 분해**       | 추상적 명령(예: 외출 모드)을 원자적 실행 스텝(창문 닫기, 가스 차단 등)으로 분해하는 로직입니다. |
| **Meaning Lock**                     | **의미론적 잠금**     | 시뮬레이션(`is_virtual=true`) 중 실물 장치가 작동하지 않도록 보호하는 안전장치입니다.           |
| **Semantic Cache**                   | **시맨틱 캐시**       | 과거 질문-답변 쌍을 벡터로 비교해 즉시 응답함으로써 LLM 부하를 줄이는 Redis 기반 방어막입니다.  |

### **2. 데이터 아키텍처 및 정체성 (Data & Identity)**

지식 운영체제(K-OS) 내에서 데이터의 정체성과 저장 구조를 정의하는 용어입니다.

| 용어 (영문)                     | 한글 표기                   | 정의 및 역할                                                                                 |
| :------------------------------ | :-------------------------- | :------------------------------------------------------------------------------------------- |
| **nexa_identities**             | **영혼 원장**               | 시스템 내 모든 객체의 불변하는 정체성과 탄생 유래를 기록하는 최상위 커널 테이블입니다.       |
| **Dual-Layer ID**               | **이중 ID 체계**            | 자산의 원본을 가리키는 `cap.*` ID와 사용자의 실행본인 `usr.*` ID를 분리 관리하는 체계입니다. |
| **Inode Indexing**              | **Inode식 인덱싱**          | 물리적 파일 위치가 바뀌어도 `doc_anchor`를 통해 지능적 사슬을 유지하는 추적 방식입니다.      |
| **Late Anchoring**              | **후행 연결**               | 설계 노드에 실제 파일이나 자산을 사후에 연결하여 지능 자산화하는 핵심 메커니즘입니다.        |
| **Narrative File System (NFS)** | **지능형 서사 파일 시스템** | 물리적 폴더 구조를 시스템의 논리적 족보(Traceability)와 일체화하여 관리하는 방식입니다.      |
| **TurboQuant**                  | **터보퀀트**                | 압축된 메모리 공간 내에 더 많은 지식 쌍을 적재하여 추론 정확도를 극대화하는 가속 기술입니다. |

### **3. 실행 상태 및 생애주기 (Lifecycle & Governance)**

지식이 성숙하고 소멸하거나, 실행 사슬이 전이되는 단계를 설명하는 용어입니다.

| 용어 (영문)             | 한글 표기              | 정의 및 역할                                                                                 |
| :---------------------- | :--------------------- | :------------------------------------------------------------------------------------------- |
| **FLOW / STUCK / VOID** | **유동 / 고착 / 여백** | 실행 흐름의 3대 상태로, 정상 작동, 막힘, 잠재적 잠침 상태를 의미합니다.                      |
| **ASK / GOVERN / ERA**  | **검토 / 운영 / 헌법** | 지식의 3단계 성숙도로, ERA는 시스템의 영혼(Soul)으로 보존되는 절대 원칙입니다.               |
| **MOMENT / DURATION**   | **모먼트 / 듀레이션**  | 지식 맥락이 단기적으로 유지되는 구간과 장기 지식화로 넘어가는 시간축 구간입니다.             |
| **Confidence Score**    | **신뢰도 점수**        | 실행 및 판단의 확신도(0~100)로, 임계값(95) 미만 시 `ASK`를 강제하고 `Jitter`를 발생시킵니다. |
| **Shadow Project**      | **그림자 프로젝트**    | TRIAL 등 비회원 체험 단계의 데이터를 임시 관리하고 승격시키는 특례 관리 방침입니다.          |

| 용어 (영문)             | 한글 표기               | 정의 및 역할                                                                                |
| :---------------------- | :---------------------- | :------------------------------------------------------------------------------------------ |

| **Passive Elicitation** | **수동적 유도**         | 질문지 대신 사용자의 클릭이나 행동 1회에서 시스템 재구성을 위한 의도를 추출하는 기법입니다. |

### **6. 넥사라(Nexara) 유통 자산 (Nexara Assets)**

마켓 도메인 **Nexara**에서 공유되고 거래되는 지능형 자산들의 세부 명칭입니다.

- **Nexet UI:** 지능 상태를 투영하는 시각적 인터페이스 패키지.
- **Nexet Template:** 검증된 지능 세포(Nexel)의 조합 및 표준 논리 구조(UCL 패키지).
- **Nexet Map:** 특정 도메인에 최적화된 노드 배치 및 연결망 정보(토폴로지 지도).
- **Nexet Workflow:** 복합 태스크 해결을 위한 원자적 실행 사슬(Execution Chain) 규격.
- **Nexet Extension:** 외부 API를 시스템 자격으로 연결하는 지능형 드라이버 모듈.
- **Persona Packs:** 에이전트의 인격, 말투, 6-Coils 가중치 프리셋.
- **Prompt Recipes:** 특정 LLM에 최적화된 고정 Nexnap 및 실행 지시문 레시피.
- **Intelligence Seeds:** 특정 환경 감지를 위한 비식별화된 행동 패턴 데이터셋.
- **Knowledge Atoms:** 5W1H로 정규화된 전문 지식 번들(RAG 원천 데이터).

이 용어들은 NEXA 플랫폼이 지향하는 **"기술은 배경으로 숨기고 지능은 유연하게 표현한다"**는 철학을 기술적으로 뒷받침하는 핵심 제원들입니다.
