# 테마 관리 시스템 문서

## 목표

- `/dev` 페이지에서 테마 관리 기능 제공
- 설정 페이지의 ThemeSettings UI를 메인 컨텐츠로 표시
- 왼쪽 사이드바: 색상 리스트 관리 (최근 사용, 즐겨찾기, 통계)
- 오른쪽 사이드바: 선택한 색상 상세 편집 + **칼라 템플릿 패널** (별도 문서 참고: `칼라_템플릿_패널.md`)
- 오른쪽 사이드바: 선택한 색상의 상세 편집 패널 (범용 색상 기능)
- **핵심 기능**: 테마 사용 통계 분석, 색상 단속, 파일별 사용 현황

## 핵심 기능

### 1. 테마 사용 통계 분석

- 분석 버튼: 왼쪽 헤더에 "통계 분석" 버튼
- 분석 대상: 전체 코드베이스에서 `--nexa-*` 변수 사용 현황
- 통계 데이터:
  - 색상 변수별 사용 횟수
  - 사용 파일 목록 (파일 경로, 라인 번호)
  - 파일별 사용 빈도
- 표시 방식: 왼쪽 사이드바의 "통계" 탭에 표시
- 파일 클릭: 파일 경로 클릭 시 해당 페이지로 이동하여 직접 확인

### 2. 색상 삭제 기능

- 삭제 대상: 선택한 색상 변수
- 삭제 범위: `dark.scss`와 `light.scss`에서 동일한 변수 모두 삭제
- 삭제 전 확인: 사용 중인 파일 목록 표시 및 확인
- 백엔드 API: SCSS 파일 수정을 위한 API 호출

### 3. 테마 변경 시 팔레트 표시

- 테마 토글: 다크/라이트 모드 전환
- 팔레트 업데이트: 테마 변경 시 해당 테마의 색상만 표시
- 실시간 반영: `extractThemeColors()` 함수로 현재 활성 테마 색상 추출

### 4. 정렬 기능

- 정렬 기준:
  - 카테고리별 (기본)
  - 사용 횟수별 (내림차순/오름차순)
  - 변수명 알파벳 순
  - 색상 값별 (HEX 값 기준)
- 정렬 UI: 메인 컨텐츠 헤더에 정렬 드롭다운
- 재렌더링: 정렬 기준 변경 시 즉시 재렌더링

### 5. 색상 단속 및 틀 정리

- 목적: 규모가 커지기 전에 색상을 단속하고 틀을 점진적으로 정리
- 도구:
  - 사용 통계로 미사용 색상 파악
  - 중복 색상 값 검출
  - 유사 색상 그룹화
  - 색상 삭제 기능으로 정리

## 데이터 흐름

```
DevMenuSlider (activeMenu: 'theme-manager')
  ↓ emit('update:activeMenu') 또는 store
  ↓
MainLayout / DevelopmentPage
  ├─ DevSidebar (:active-menu="activeMenu")
  │   ├─ activeMenu === 'document-manager' → DocumentManagerHeader + DocumentManagerList
  │   └─ activeMenu === 'theme-manager' → ThemeManagerHeader + ThemeManagerList
  │       ├─ 통계 분석 버튼 클릭
  │       │   ↓ themeUsageAnalyzer.js
  │       │   ↓ 코드베이스 스캔
  │       │   ↓ 통계 데이터 표시
  │       └─ 색상 선택 → 선택 색상 상태 업데이트
  ├─ DevelopmentPage (:active-menu="activeMenu")
  │   ├─ activeMenu === 'document-manager' → 문서 컨텐츠
  │   └─ activeMenu === 'theme-manager' → ThemeManagerContent
  │       ├─ 테마 토글 → 해당 테마 팔레트 표시
  │       ├─ 정렬 기준 변경 → 재렌더링
  │       └─ 색상 클릭 → 선택 색상 상태 업데이트
  └─ DevToolsPanel (:active-menu="activeMenu")
      ├─ activeMenu === 'document-manager' → PanelTOC + PanelMermaidStyle
      └─ activeMenu === 'theme-manager' → ThemeColorPanel
          ├─ 선택 색상 표시 및 편집
          ├─ 사용 통계 표시
          └─ 색상 삭제 → themeVariableManager.js → 백엔드 API
```
