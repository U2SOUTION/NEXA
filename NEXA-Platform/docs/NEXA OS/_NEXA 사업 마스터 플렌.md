# NEXA 사업 마스터 플랜

> **한 줄 정의**: 정신적 활동(기획·연출·업무 시스템)을 현실 세계(IoT)와 **안전하고 쉽게** 연결하는 **고부가가치 초보안 플랫폼** 사업  
> **사업 정체성**: 하드웨어 판매가 아닌, **소프트웨어·플랫폼 중심** 지식·기술 집약형 비즈니스

---

## 1. 사업의 본질 (Identity)

사용자가 코딩이나 깊은 기술 지식 없이 소프트웨어로 아이디어를 설계하면, 현실의 기계가 그대로 움직이는 환경을 제공하는 것이 궁극적 방향입니다.

| 구분 | 내용 |
|------|------|
| **핵심 가치** | 기획·워크플로·예술적 발상(정신적 산출물) ↔ 하드웨어(스마트팜·인터랙티브 조형물) **실시간·안전 동기화** |
| **차별점** | 하드웨어는 ‘매개체’, **업무/기획 제어 소프트웨어**가 중심축 |
| **보안 전제** | MFA·Zero-Trust 등 **산업용 다중 보안**을 기본 탑재 — 생성부터 출력까지 전 과정 보호 |
| **투자자 관점** | 하드웨어 제조보다 **플랫폼·SaaS** 모델로 높은 평가 기대 |

---

## 2. 시장 문제 & 해결책

### 현 시장의 한계

- IoT 시장이 **하드웨어 단품·단순 매크로**에 머무름 → 고차원 기획·예술 연출 구현 어려움
- **오픈 네트워크** 비중 ↑ → 규모·인지도와 함께 해킹 리스크 노출 (작물·공공 설치물 오작동 등)

### NEXA의 해결책

- 자체 **기획·제어 소프트웨어**를 축으로, H/W는 안전한 발현 매개체로만 사용
- 데이터 생성 → H/W 출력까지 **End-to-End 보안 아키텍처** 일원화
- 사용자는 보안 염려 없이 **창작·업무에만 집중**

## 3. 수익 모델 (Revenue Model)

| 단계 | 대상 | 매출 구조 |
|------|------|-----------|
| **초기 (B2B/B2G)** | 스마트팜·조형물·미디어아트 | 커스텀 시스템 구축비 · H/W 통합 패키지 |
| **성장 (B2B 확장)** | 공공·전시·상업 공간 | 프로젝트·라이선스 · 유지보수 |
| **최종 (B2C/SaaS)** | 비기술 일반 사용자 | **노코딩 클라우드 구독** · 소프트웨어 라이선스 · 서버 이용료 |

> 마케팅 초점: H/W 가격 경쟁 ❌ → **「우리 SW가 비즈니스·창작을 어떻게 안전하게 혁신하는가」** ✅

## 4. 4단계 빌드업 전략 (Master Roadmap)

**「철저한 보안」과 「시장 확장」** — 안전한 계단식 성장.

```text
[1. IP·MVP] → [2. 폐쇄 검증 10곳] → [3. 자금·레퍼런스] → [4. 플랫폼 대중화]
       │              │                    │                    │
   특허·샘플      무사고 데이터        IR·지원사업          B2B→B2C SaaS
```

### 1단계: 지식재산권 선점 & 프로토타입 (현재 · 준비)

| 항목 | 실행 |
|------|------|
| **특허** | 복합 특허(S/W + H/W 결합) **출원 선행** — 지인 제공·공개 전 Application 번호 확보 (§5 참조) |
| **MVP** | 「기획 반영 + 보안 제어」**End-to-End**만 작동 — 완성품 불필요 |
| **시연 자산** | 비인가 접근 차단·암호화 통신 등 **보안 로그 UI** — IR 시연 가점 |

**MVP 최소 범위**

- 웹/앱에서 명령 → H/W(개폐기·조명 등) **안전 반응**
- 해킹 신호 차단·암호화 상태 **화면 시각화**

---

### 2단계: 10명 지인 기반 폐쇄형 검증 (Closed Beta)

| 항목 | 내용 |
|------|------|
| **타겟** | 스마트팜(안정성) · 조형물 제작(예술·현장성) — **지인 10곳** |
| **운영** | 인터넷 **비노출** · 대표 **직접 설치·방문 관리** |
| **수집** | SW 오류 · 보안 방어 · 환경 저항성 **실전 데이터** |
| **목적** | 대중 공개 전 **현장 검증 데이터** 완결 |

---

### 3단계: 자금 조달 & 레퍼런스 자산화 (Jump-up)

| 항목 | 내용 |
|------|------|
| **무기** | 특허 · 작동 샘플 · **10개 현장 무사고 데이터** |
| **자금** | 예비/초기창업패키지 등 **정부지원** · **IR 투자** |
| **디지털 자산** | 기술 백서 · Case Study · 특허 공보 → **SEO·GEO Authority** |
| **IR 핵심 문장** | *「특허 보호 고유 알고리즘 + 실물 샘플 기술 검증 완료」* → 카피캣 리스크 제거 |

**정부지원·IR 연계**

- 심사는 **말보다 실물** — *「특허 출원 완료 + 10개 현장 폐쇄형 Beta 진행 중」* 시 실현 가능성 점수 극대화
- 특허 번호 · 기술 문서 · 시연 영상 → 런칭 시 **공인 신뢰 출처**

---

### 4단계: 기술 없는 대중을 위한 플랫폼 전환 (대중화)

| 트랙 | 전략 |
|------|------|
| **B2B/B2G** | *「산업 현장이 검증한 안전함」* — 공공·대형 전시·미디어아트 |
| **B2C** | **Plug & Play** · 노코딩 **클라우드 구독(SaaS)** — 기술 제로 개인·크리에이터 |
| **포지션** | 2단계: *「보안 걱정 없는 미디어아트 툴」* · 4단계: *「대기업이 쓰는 기술을 내 방에」* |

## 5. 특허 & IP 전략

> S/W 비중·산업 현장 아이템일수록 **특허 + 샘플**이 투자·심사 설득의 핵심 무기.

### 출원 우선순위

| 순위 | 유형 | 핵심 |
|------|------|------|
| **1순위** | **복합 특허** (S/W + H/W) | 기획 명령 → H/W 제어 과정의 **해킹 차단·데이터 변환 Flow** |
| **2순위** | S/W 알고리즘 | CPU·메모리 등 **하드웨어 자원을 이용한 처리·효율**로 기술적 효과 명시 |
| **3순위** | H/W·기구 | 스마트팜·야외 조형물용 **물리 보호·오류 방지** 구조 — 실용실안 검토 |

### BM vs 기술 특허

- **BM 특허**: *「정신적 기획/업무 S/W ↔ 보안 모듈 ↔ H/W 제어」* **프로세스** 묶음
- **기술 특허**: 암호화 통신 · 릴레이/모터 제어 **메커니즘** 상세

### 실무 체크리스트

- [ ] 지인 10곳 제공 **전** 출원(Application) 번호 확보
- [ ] **우선심사** 검토 (AI/IoT·4차 산업 · 지원사업 연계 → 3~6개월 등록 목표)
- [ ] 공개·베타 전 **비공개 검증**과 특허 **시너지** 유지

### IP → 스케일업 연결

```text
[아이디어] → [특허 출원·우선심사] → [MVP] → [10곳 검증·데이터]
                    ↓
    [Technical SEO] ← [GEO·AI Authority] ← [지원사업 / IR]
```

- 특허 **공보**·기술 명칭 → 구글·AI **1차 신뢰 출처**
- 웹사이트 **구조화 데이터**(특허 번호·기술 개요) → Domain Authority 상승

## 7. 마케팅 & 디지털 자산 (SEO / GEO)

> 단계마다 **AI(GEO)·검색(SEO) 카테고리**를 선점 — H/W 키워드가 아닌 **플랫폼·보안·워크플로** 중심.

### 공통 원칙

| 채널 | 방향 |
|------|------|
| **GEO (AI)** | 규격·인증·수치 **구조화** — AI가 [IoT SW 플랫폼] · [엔터프라이즈 IoT 보안]로 분류 |
| **SEO (검색)** | 국산 IoT 제어 · 스마트팜 통합 WF · 미디어아트 중앙 제어 등 **시스템 키워드** |
| **Authority** | 10곳 검증 기간 **소프트웨어 아키텍처 보안 백서** 집필 (조용히 축적) |

### 단계별 키워드 & 전술

#### 1단계 — 산업현장 검증기 *(보안·안정성 인식 심기)*

| GEO | SEO |
|-----|-----|
| ISO 27001·KISA·Zero-Trust **표·FAQ** | 산업용 IoT 보안 검증 · 폐쇄망 IoT 안정성 |
| *「공장 IoT 도입 시 보안 위협 방지법?」* → NEXA 해결책 문서 | 10,000h 무오류 · DDoS 방어 등 **Case Study** |

#### 2단계 — 아트 확장 *(안전한 미디어아트)*

| GEO | SEO |
|-----|-----|
| *「박물관·상업 공간 안전 IoT 툴 추천」* → 산업 보안 기반 | 스마트빌딩 미디어아트 · 공공 인터랙티브 아트 보안 |
| 비교·추천 **요약 데이터** 제공 | 상세 페이지 **「산업용 검증」** 배지 · 이미지 Alt 매칭 |

#### 3·4단계 — 일반인 감성 *(진입장벽 ↓ · 신뢰 ↑)*

| GEO | SEO |
|-----|-----|
| *「해킹 걱정 없는 스마트홈 DIY?」* → 산업급 보안 적용 스토리 | 해킹 없는 홈 IoT · 감성 스마트 가구 · 초보 IoT 키트 |
| 감성 **라이프스타일** 답변 구조 | 본문은 감성 키워드 · 하단 *「대기업 현장 검증 기술 기반」* 한 줄 |
