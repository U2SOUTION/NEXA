## 핵심 시스템

### 1. NEXA BOARD (IoT 디바이스 관리 및 대시보드)

**개요**: IoT 디바이스를 관리하고 대시보드를 구성하는 핵심 시스템

#### 주요 기능

1. **보드 관리**

   - 그룹/보드 계층 구조 관리
   - 보드 생성, 수정, 삭제
   - 보드 복제 및 템플릿 기능

2. **레이아웃 관리**

   - 레이아웃 프리셋 선택 (single, split-lr, l-shape, split-tb)
   - 창 분할 및 병합
   - 패널 그리드 레이아웃 (드래그앤드롭, 리사이즈)

3. **디바이스 연결**

   - 등록된 디바이스를 보드에 적용
   - 보드-디바이스 N-N 관계 관리
   - 디바이스 연결 상태 모니터링

4. **패널 관리**
   - 패널 카탈로그에서 패널 선택 및 추가
   - 패널 설정 및 커스터마이징
   - 패널 위치 및 크기 조정

#### 요구사항

**기능 요구사항**

- [ ] 그룹/보드 트리 구조 UI
- [ ] 보드 생성/수정/삭제 기능
- [ ] 레이아웃 프리셋 선택 UI
- [ ] 창 분할/병합 기능 (splitpanes)
- [ ] 패널 그리드 레이아웃 (vue3-grid-layout-next)
- [ ] 패널 드래그앤드롭 기능
- [ ] 패널 리사이즈 기능
- [ ] 디바이스 선택 및 연결 UI
- [ ] 보드 설정 저장 및 불러오기
- [ ] 보드 데이터 표준화 (표준 계약 준수)

**비기능 요구사항**

- [ ] 반응형 레이아웃 지원 (모바일, 태블릿, 데스크톱)
- [ ] 실시간 데이터 업데이트 (WebSocket)
- [ ] 보드 데이터 로컬 스토리지 백업
- [ ] 보드 데이터 서버 동기화
- [ ] 성능 최적화 (대량 패널 렌더링)

**데이터 요구사항**

- [ ] 보드 메타데이터 (id, name, type, version, metadata)
- [ ] 레이아웃 프리셋 정보
- [ ] 패널 구성 정보 (위치, 크기, 타입, 설정)
- [ ] 디바이스 연결 정보 (N-N 관계)
- [ ] 보드 설정 JSON 저장

### 3. NEXA NODE (노드 기반 자동화 시스템)

**개요**: 블렌더 스타일의 노드 에디터를 통한 자동화 워크플로우 구성

#### 주요 기능

1. **노드 에디터**

   - 시각적 노드 그래프 편집
   - 노드 연결 (소켓 기반)
   - 노드 그룹화 및 정리

2. **노드 타입**

   - 트리거 노드 (시간, 이벤트, 조건 기반)
   - 처리 노드 (데이터 변환, 계산, 집계, 필터링, 조건 분기)
   - 액션 노드 (디바이스 제어, 알림, 데이터 저장)

3. **워크플로우 실행**

   - 워크플로우 실행 엔진
   - 실시간 실행 상태 모니터링
   - 실행 로그 및 디버깅

4. **전역 모듈**
   - 처리 노드를 다른 컴포넌트에서 재사용
   - 패널, 차트, 블럭에서 노드 활용

#### 요구사항

**기능 요구사항**

- [ ] 노드 에디터 UI (그래프 편집)

- [ ] 노드 그룹화 및 정리 기능
- [ ] 워크플로우 저장/불러오기
- [ ] 워크플로우 실행 엔진
- [ ] 실행 상태 모니터링 UI
- [ ] 실행 로그 뷰어
- [ ] 노드 디버깅 도구
- [ ] 노드 표준 계약 준수

**비기능 요구사항**

- [ ] 실시간 워크플로우 실행
- [ ] 워크플로우 버전 관리

## ERP 시스템

### 4. NEXA ERP (프로젝트 및 업무 관리)

**개요**: 프로젝트 중심의 유연한 관계형 업무 관리 시스템

#### 주요 기능

1. **프로젝트 관리**

   - 프로젝트 등록 및 관리
   - 프로젝트 타입 (개발, 연구, 유지보수, 인프라)
   - 프로젝트 상태 (계획, 진행중, 보류, 완료, 취소)
   - 프로젝트 분류 및 태그
   - 팀/담당자 관리
   - 예산 관리

2. **작업 문서 관리**

   - 작업 항목 등록 (제원, 수량, 작업 순서)
   - 제원 관리 (치수, 무게, 재질)
   - 작업 절차 문서화
   - NEXA NODE 워크플로우 변환
   - CNC 장비 연동

3. **일정 관리**

   - 일정 등록 및 관리
   - 마일스톤 관리
   - 반복 일정 설정
   - 캘린더 뷰 (월간, 주간, 일간)
   - 알림 및 리마인더

4. **실시간 협업**

   - WebSocket 기반 실시간 통신
   - 프로젝트별 채널 생성
   - 멀티미디어 메시지 (텍스트, 차트, 블록, 패널, 노드)
   - 공유 모듈 통합 (차트, 블록, 패널, 노드)
   - 히스토리 관리

5. **참고자료 관리**

   - 자료 등록 및 관리 (문서, 이미지, 링크, 아이디어)
   - 태그 시스템
   - 독립 관리 및 선택적 프로젝트 연결
   - 검색 기능

6. **로그북 관리**

   - 시간별 작업 기록
   - 관찰 기록 (상태, 변화, 측정값)
   - 이미지 첨부
   - 데이터 시각화 (그래프)
   - 프로젝트 연결

7. **부품관리**

   - 재고 관리
   - 입출고 관리
   - 부품 분류
   - 프로젝트 연동
   - 재고 알림

8. **재무 관리**
   - 회계 관리 (일반/총계정원장, 분개, 결산)
   - 예산 관리 (예산 계획, 집행, 분석)
   - 비용 관리 (비용 발생, 배분, 분석)
   - 매출/매입 관리
   - 자금 관리
   - 견적 관리

#### 요구사항

**기능 요구사항**

- [ ] 전용 에디터 개발 (Tiptap 기반 커스터마이징)
  - [ ] 프로젝트 문서 에디터
  - [ ] 작업 문서 에디터
  - [ ] 참고자료 에디터
  - [ ] 로그북 에디터
- [ ] 프로젝트 CRUD 기능
- [ ] 작업 문서 CRUD 기능
- [ ] 일정 관리 UI (캘린더)
- [ ] 실시간 협업 UI (채팅)
- [ ] 참고자료 관리 UI
- [ ] 로그북 관리 UI
- [ ] 부품관리 연동
- [ ] 재무 관리 UI
- [ ] 프로젝트-항목 관계 관리 (선택적 연결)

**비기능 요구사항**

   - 등록된 디바이스 목록 조회
