### [NEXA-UCL-06] 멀티모달 파싱 및 아톰화 규격서 (Draft)

**목적:** 음성, 영상 등 비정형 멀티모달 데이터를 **비식별화**하고, 이를 AI가 즉시 이해할 수 있는 **5W1H IR(중간 표현)**로 변환하여 UCL의 'Listen' 단계로 표준화된 입력을 제공함에 있다.
**범위:** 엣지(Sentinel)의 1차 요약 로직부터 인디케이터(Indicator/Vista)의 최종 아톰화 절차를 포함한다.

---

#### 1. 지능 위계별 처리 역할 (Intelligence Hierarchy)

NEXA의 3단계 지능 위계에 따라 멀티모달 데이터 처리 역량을 분산 배치한다.

- **Nano Sentinel (ESP32):** 텍스트/음성 키워드 감지 시 10ms 내 '즉각 반사(Reflex)' 수행 및 상위 계층 깨움(Wake-up).
- **Micro Sentinel (Edge PC/라즈베리 파이):** 영상/오디오 분석을 통한 객체 탐지 및 사건 식별. **로컬 비식별화**를 수행하여 5W1H 텍스트 요약본만 상향 전송한다.
- **Vista Indicator (AI Server):** 엣지에서 수신한 요약을 바탕으로 'Why(인과)'를 추론하고, 코일 밸런서를 적용하여 최종 **아톰(Atom)**으로 박제한다.

---

#### 2. 1단계: 엣지(Sentinel) 비식별화 및 1차 요약 로직

엣지 단에서는 개인정보가 포함된 로우 데이터를 폐기하고 지능적 서사로 변환하는 '보안 게이트' 역할을 수행한다.

1.  **입력 채널별 처리 (Micro Sentinel):**
    - **Audio (Whisper-tiny):** 사용자의 음성을 텍스트로 변환(STT)하되, 고유 명사나 민감 정보를 일반 명사로 치환하여 **5W1H 텍스트**로 요약한다.
    - **Video (YOLOv10 / VideoLLaMA):** 특정 인물의 얼굴 대신 '사용자(Who)', '장비(What)', '이동 궤적(Where)' 등 객체와 행동 패턴만을 추출하여 사실(Fact)로 정의한다.
2.  **비식별 5W1H 패키징:**
    - 원본 파일은 로컬에서 즉시 파기하거나 별도 보안 저장소(ref_id만 유지)에 두고, 플랫폼으로는 **HEXAGON 토큰**과 **비식별 요약문**만 전송한다.

---

#### 3. 2단계: 인디케이터(Vista) 아톰화 절차 (Atomization)

인디케이터는 엣지로부터 받은 사실에 '의미'를 부여하여 지능적 최소 단위인 아톰을 완성한다.

1.  **서사적 구조화 (Parsing):** 수신된 5W1H 데이터를 UCL의 `ucl_header` 규격에 맞게 정수 토큰으로 매핑한다.
2.  **판단의 무게 부여 (Why & Summary):**
    - 현재 설정된 **코일 밸런서(6-Coils)** 가중치를 필터로 사용하여 사건의 동기(Why)를 도출한다.
    - 사용자와 소통할 부드러운 자연어 요약(Summary)을 생성한다.
3.  **지능적 족보 연결 (Why Chain):**
    - `ref_ids` 필드에 [실행(EFF) → 의도(IND) → 사실(SNT)]로 이어지는 참조 사슬을 기록하여 인과관계를 역추적 가능하게 한다.
4.  **벡터화 및 영구 박제:**
    - 완성된 아톰을 임베딩 모델(nomic-embed-text)을 통해 벡터화하고, `project_knowledge`에 `nature_tag`(INTENT, INCIDENT 등)와 함께 저장한다.

---

#### 4. 5W1H IR (중간 표현) 데이터 스키마

UCL 'Listen' 단계로 주입되는 데이터의 표준 JSONB 규격이다.

```json
{
  "ir_header": {
    "where_scope": "FIELD", // 엣지 위치/좌표
    "when_tempo": "MOMENT", // 발생 시점
    "who_pulse": "TICK", // 동력원 (TICK:디바이스)
    "what_intent": "FACT", // 데이터 본질
    "how_state": "FLOW", // 현재 상태
    "why_causality": "CAUSE" // 1차 원인 분석
  },
  "content_body": {
    "summary": "비식별화된 요약문",
    "raw_ref_id": "SNT-AUDIO-001", // 원본 참조 키
    "confidence_score": 98 // 신호 품질 기반 확신도
  },
  "extra_data": {
    "trajectory": "이동 벡터 데이터", // Where 궤적 정보
    "object_list": ["drill", "user_hand"] // 검출 객체
  }
}
```

---

#### 5. 예외 상태 처리: VOID와 불확실성

- **VOID 전환:** 입력 신호가 모호하거나 망설임 패턴(롤백, 체류 등)이 감지되면 `how_state = VOID`로 정의하고 넥슈를 '영감 모드'로 전환시킨다.
- **신뢰도 가드레일:** `confidence_score`가 95점 미만일 경우 `who_pulse`를 `ASK`로 전환하여 사용자의 최종 확인(WILL)을 유도한다.

---

#### 6. 기대 효과

- **토큰 절감:** 엣지에서의 선제 요약을 통해 인디케이터(LLM)의 연산 부하를 90% 이상 절감한다.
- **프라이버시 강화:** 로컬 비식별화 과정을 통해 민감 정보의 플랫폼 유입을 원천 차단한다.
- **지능의 자산화:** 모든 멀티모달 입력이 일관된 아톰으로 변환되어 시간이 흐를수록 정교한 RAG 검색과 페르소나 학습이 가능해진다.

---

**검토 결론:** 본 규격서는 엣지의 물리적 사실(Fact)을 플랫폼의 지혜(Why)로 연결하는 핵심 다리가 됩니다. 특히 **비식별화**와 **아톰화**를 명문화함으로써 NEXA는 보안과 지능을 동시에 확보한 유기체적 시스템으로 작동하게 될 것입니다.
