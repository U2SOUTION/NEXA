### 4. 사용자 경험(UX)의 포용성 및 확장 (Inclusivity & UX Expansion)

## 4.1 목적과 범위

본 문서는 NEXIA `7개 탭` 사용 경험을 직관적이고 접근 가능하며 확장 가능한 형태로 표준화한다.

## 4.2 UX 핵심 원칙

- 조종권 보장: 사용자는 항상 시스템의 최종 승인자다.
- 인지 부하 최소화: Focus 전환은 단순하고 예측 가능해야 한다.
- 상태 가시성: 시스템 상태는 실시간으로 명확히 표현되어야 한다.
- 포용성: 다양한 사용 환경과 접근성 요구를 기본 지원한다.

## 4.3 7개 탭 UX 규칙

- `0 Cockpit`: 통합 지휘/승인/상태 대시보드.
- `1~6 전문 탭`: 목적 기반 실행 인터페이스.
- 탭 간 이동 시 현재 작업 맥락(Context)과 최근 이벤트를 유지한다.

## 4.4 접근성 기준

| 항목 | 기준 |
| --- | --- |
| 키보드 조작 | 주요 기능 100% 지원 |
| 스크린리더 | 핵심 컴포넌트 ARIA 레이블 제공 |
| 색상 대비 | WCAG AA 이상 |
| 모션 제어 | 애니메이션 축소 모드 제공 |
| 대체 정보 | 음성/파형 피드백 대체 텍스트 제공 |

## 4.5 디바이스 확장 전략

- 데스크톱: 전체 기능 제공(멀티윈도우/고급 편집).
- 태블릿: 모니터링 + 승인 중심.
- 모바일: 경량 Cockpit(알림/승인/상태 조회) 중심.

## 4.6 피드백 시스템 규칙

- 파형 UI는 상태 레벨(정상/주의/위험)을 색상과 패턴으로 구분.
- 고위험 이벤트는 시각 + 텍스트 + 알림 채널을 동시 사용.
- 장시간 작업은 진행률, 대기열 위치, 예상 시간 표시를 기본 제공.

## 4.7 KPI

- 주요 태스크 완료율 95% 이상.
- 접근성 이슈 고심각도 0건.
- 사용자 승인 누락 0건.
