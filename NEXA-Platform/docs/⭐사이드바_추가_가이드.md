# 사이드바 추가 가이드

## 📋 개요

각 페이지별로 좌측, 우측 사이드바를 쉽게 추가할 수 있습니다. `sidebarRegistry.js`에만 등록하면 자동으로 적용됩니다.

---

## 🗂️ 현재 구조

```
src/components/sidebars/
├── left/                    # 왼쪽 사이드바
│   ├── NexaBoardSidebar.vue
│   └── PartsManagementSidebar.vue
└── right/                   # 오른쪽 사이드바
    ├── NexaBoardToolsPanel.vue
    └── DefaultRightPanel.vue
```

---

## ➕ 새 사이드바 추가 방법

### 1단계: 사이드바 컴포넌트 생성

#### 왼쪽 사이드바 예시

```bash
# 파일 생성
src/components/sidebars/left/PortfolioSidebar.vue
```

```vue
<!-- PortfolioSidebar.vue -->
<template>
  <div class="portfolio-sidebar">
    <q-list>
      <q-item>
        <q-item-section>
          <q-item-label>포트폴리오 사이드바</q-item-label>
        </q-item-section>
      </q-item>
      <!-- 사이드바 내용 -->
    </q-list>
  </div>
</template>

<script setup>
// 사이드바 로직
</script>

<style lang="scss" scoped>
.portfolio-sidebar {
  height: 100%;
}
</style>
```

#### 오른쪽 사이드바 예시

```bash
# 파일 생성
src/components/sidebars/right/PortfolioToolsPanel.vue
```

```vue
<!-- PortfolioToolsPanel.vue -->
<template>
  <div class="portfolio-tools-panel">
    <div class="q-pa-md">
      <div class="text-h6">포트폴리오 도구</div>
      <!-- 도구 패널 내용 -->
    </div>
  </div>
</template>

<script setup>
// 도구 패널 로직
</script>

<style lang="scss" scoped>
.portfolio-tools-panel {
  height: 100%;
}
</style>
```

### 2단계: sidebarRegistry.js에 등록

#### 왼쪽 사이드바 등록

```javascript
// src/config/sidebarRegistry.js

const leftSidebarConfigs = {
  // 기존 등록...
  'nexa-board': { ... },
  'parts-management': { ... },
  
  // 새 사이드바 추가
  'portfolio': {
    component: () => import('src/components/sidebars/left/PortfolioSidebar.vue'),
    behavior: {
      autoOpen: false,              // 수동으로만 열기
      showMessage: false,           // 안내 메시지 없음
      respectMobileHidden: true,    // 모바일에서 숨김 상태 유지
      defaultOpen: true,            // 최초 진입 시 열림
      saveState: true,              // 상태 저장
      message: null,
    },
  },
}
```

#### 오른쪽 사이드바 등록

```javascript
// src/config/sidebarRegistry.js

const rightSidebarConfigs = {
  // 기존 등록...
  'nexa-board': { ... },
  
  // 새 사이드바 추가
  'portfolio': {
    component: () => import('src/components/sidebars/right/PortfolioToolsPanel.vue'),
    behavior: {
      autoOpen: false,
      showMessage: false,
      respectMobileHidden: true,
      defaultOpen: false,
      saveState: true,
      message: null,
    },
  },
  
  // 기본 패널 (등록되지 않은 메뉴용)
  default: { ... },
}
```

### 3단계: 메뉴 이름 확인

`sidebarRegistry.js`에 등록할 때 사용하는 메뉴 이름은 `MainLayout.vue`의 `currentMenu` computed에서 결정됩니다.

```javascript
// src/layouts/MainLayout.vue의 currentMenu 로직 참고
const currentMenu = computed({
  get: () => {
    const path = router.currentRoute.value.path
    if (path.startsWith('/portfolio')) return 'portfolio'
    // ...
  },
})
```

**메뉴 이름 규칙:**
- 라우트 경로 기반으로 자동 결정
- `/portfolio` → `'portfolio'`
- `/parts-management` → `'parts-management'`
- `/nexa-board` → `'nexa-board'`

```javascript
const leftSidebarConfigs = {
```

## ⚙️ 동작 설정 옵션

### `autoOpen: true`
컨텐츠 상태에 따라 자동으로 사이드바를 엽니다.

```javascript
'dev': {
  behavior: {
    autoOpen: true,  // 문서가 없을 때 자동으로 열기
    // ...
  },
}
```

### `showMessage: true`
안내 메시지만 표시합니다 (컴포넌트는 렌더링하지 않음).

```javascript
'dev': {
  behavior: {
    showMessage: true,
    message: '문서를 선택하거나 새로 만드세요.',
    // ...
  },
}
```

### `defaultOpen: true`
최초 진입 시 사이드바를 열어둡니다.

```javascript
'parts-management': {
  behavior: {
    defaultOpen: true,  // 처음 방문 시 열림
    // ...
  },
}
```

### `saveState: true`
사이드바 열림/닫힘 상태를 저장하여 다음 방문 시 유지합니다.

```javascript
'parts-management': {
  behavior: {
    saveState: true,  // 상태 저장
    // ...
  },
}
```

## 🔍 현재 등록 현황

### 왼쪽 사이드바
- ✅ `nexa-board` → `NexaBoardSidebar.vue`
- ✅ `parts-management` → `PartsManagementSidebar.vue`

### 오른쪽 사이드바
- ✅ `nexa-board` → `NexaBoardToolsPanel.vue`
- ✅ `default` → `DefaultRightPanel.vue` (등록되지 않은 메뉴용)

---

## 💡 팁

1. **한쪽만 추가 가능**: 왼쪽만 또는 오른쪽만 추가해도 됩니다.
2. **기본 패널 사용**: 오른쪽 사이드바를 등록하지 않으면 `DefaultRightPanel`이 표시됩니다.
3. **동적 로딩**: 모든 사이드바는 lazy loading으로 로드되어 성능에 영향이 없습니다.
4. **캐싱**: 한 번 로드된 사이드바는 캐시되어 재사용됩니다.
