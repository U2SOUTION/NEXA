|------------|------------|---------|

| Layer 4 근우주 | ISS·위성·NASA·Space-Track | 근우주 자산 현황 |
| Layer 5 태양계 | JPL·NOAA 우주기상·SDO | 태양 활동·행성 위치 |
| Layer 6 항성·은하 | Hubble·JWST·SIMBAD | 우주 이벤트·천문 |

## 14. 우선순위 구현 순서

### 1순위 — 즉시 실용적 (NEXA 플랫폼 핵심)

```
기상청 API          → 날씨 예보·실황
에어코리아          → 미세먼지·대기질
기상청 지진 정보    → 지진 실시간
NOAA Space Weather  → 태양풍·Kp (우주 연결)
Open-Meteo          → 전 세계 날씨
OpenSky Network     → 항공기 실시간 (NEXA NIXIE 시각화)
USGS Earthquake     → 전 세계 지진
NASA FIRMS          → 산불 실시간
공공데이터 포털     → 한국 공공 API 허브
```

### 2순위 — NEXU 캔버스 풍부화


## API 통합 전략

```
수집 레이어 (서버):
  각 API 폴링 주기 관리
  데이터 정규화 → HEXAGON 패킷으로 변환
  변화분만 SSE로 브라우저 푸시

캐싱 전략:
  실시간 (1분 미만): 메모리 캐시
  단기 (1시간 미만): Redis
  중기 (1일 미만): PostgreSQL
  장기 (이미지·정적): CDN + IndexedDB

브라우저 수신:
  변화 있을 때만 SSE 푸시
  브라우저 AI로 중요도 판단
  NEXA NIXIE 도트 업데이트
```
