# INF RFC 닉시 JAB5 멀티앰프 스피커 지능 선택 설계

> 앰프 출력단 셀렉터 없이 JAB5 데이지체인 구성으로 스피커를 지능적으로 선택·제어하는 설계안

---

## 설계 변경 이력

| 버전 | 변경 내용 |
|------|----------|
| v0.1 | 최초 작성. LC7821 + op-amp 버퍼 + JAB5 병렬 구성 |
| v0.2 | MCP4131 볼륨 제어로 LC7821 역할 대체 → LC7821 제거 |
| v0.3 | JAB5 I2S 데이지체인 확인 → op-amp 버퍼 불필요 → 제거. 구성 단순화 |

## 배경 및 발상

### 기존 방식 (출력단 셀렉터)

```
앰프 1대 → 릴레이/셀렉터 → 스피커 A / B / C

문제점
  출력 전력 신호를 직접 스위칭해야 함
  릴레이 회로 복잡, 임피던스 관리 필요
  앰프 과부하 위험
```

### 새로운 발상 (입력단 제어 + JAB5 데이지체인)

```
핵심 전환
  출력단(전력) 스위칭 → 입력단(저전력 신호) 제어
  MCP4131 볼륨 0 = 사실상 음소거 = 스피커 선택 효과
  JAB5 I2S 데이지체인으로 op-amp 버퍼 없이 신호 분배
```

---

## JAB5 데이지체인 구조

JAB5는 I2S 출력 포트(J7)를 통해 다른 JAB5와 연결 가능하다.
한 대는 마스터, 나머지는 슬레이브로 SW1 스위치로 설정.

```
마스터 JAB5 ─── I2S (J7) ──→ 슬레이브 JAB5-A → 스피커 A
             └── I2S (J7) ──→ 슬레이브 JAB5-B → 스피커 B
```

I2S는 디지털 신호 전송이므로 아날로그 신호 분기 레벨 저하 문제 없음.
op-amp 버퍼 불필요.

---

## 전체 시스템 구성

```
음원
  ↓
마스터 JAB5 ─── I2S ──→ 슬레이브 JAB5-A → 스피커 A
             └── I2S ──→ 슬레이브 JAB5-B → 스피커 B

ESP32
  ├── SPI → MCP4131 → 마스터 JAB5 POT4      전체 볼륨
  ├── SPI → MCP4131 → 슬레이브 JAB5-A POT4  스피커 A 볼륨
  ├── SPI → MCP4131 → 슬레이브 JAB5-B POT4  스피커 B 볼륨
  ├── GPIO → 마스터 JAB5 J11                스탠바이 제어
  ├── GPIO → 슬레이브 JAB5-A J11            스탠바이 제어
  └── GPIO → 슬레이브 JAB5-B J11            스탠바이 제어
  ↑
NEXA NIXIE / NEXA
  기분, 목적, 시간대, 음원 장르에 따라 지능적 선택
```

## 멀티앰프 방식의 장점

```
출력단 스위칭 불필요    전력 릴레이 없이 구성 가능
모든 앰프 동시 가동     스피커 전체를 동시에 울리기도 가능
개별 볼륨 독립 제어     스피커별 음량 자유롭게 조정
개별 전원 제어          미사용 앰프 자동 절전
확장 용이               스피커 추가 시 JAB5 한 대 + I2S 연결만으로 해결
```

## 부품 구성

### JAB5 (ONDOM JAB5)

```
현재 보유    2대 (1대 사용 중)
역할         마스터 1대 + 슬레이브 N대 구성
데이지체인   I2S 출력 포트(J7)로 연결
             마스터/슬레이브 설정: SW1 스위치
스탠바이     J11 포트를 ESP32 GPIO로 제어
             단락 시 스탠바이 / 해제 시 정상 동작
```

### MCP4131 (디지털 포텐셔미터)

```
역할         JAB5 물리적 포텐셔미터 케이블 대체
             JAB5 POT4 포트에 연결 → 볼륨 디지털 제어
인터페이스   SPI (ESP32에서 직접 제어)
분해능       0~255 단계
음질         아날로그 신호를 직접 건드리지 않으므로 음질 손상 없음
수량         JAB5 1대당 MCP4131 1개 필요
선택 효과    볼륨 0으로 내리면 사실상 음소거 = LC7821 없이 선택 효과
```

### LC7821 — 제거됨

```
MCP4131 볼륨 제어로 동일한 선택 효과를 낼 수 있어 불필요
```

### 버퍼 앰프 (op-amp) — 제거됨

```
JAB5 I2S 데이지체인이 디지털 신호로 분배하므로 불필요
```

## 볼륨 제어 상세

### MCP4131 선택 이유

| 방법 | 음질 | 복잡도 | 비용 |
|------|------|--------|------|
| MCP4131 디지털 포텐셔미터 | 손상 없음 | 낮음 | 낮음 |
| DSP + ICP5 | 최상 | 높음 | 높음 |
| ESP32 PWM + RC 필터 | 저하 가능 | 낮음 | 없음 |

MCP4131이 음질·복잡도·비용 모두 균형이 맞음

### 현재 물리 포텐셔미터와의 교체 방법

```
현재   JAB5 POT 포트 ←── 물리적 포텐셔미터 케이블 (손으로 돌림)
교체   JAB5 POT 포트 ←── MCP4131 ←── ESP32 SPI 명령

JAB5 입장에서 저항값 변화로 동일하게 인식
물리 케이블 뽑고 MCP4131 연결만 하면 됨
```

## 자동화 로직

### 음원 감지 → 앰프 자동 전원 제어

```
음원 입력 감지
  └→ 마스터 JAB5 스탠바이 해제 (J11)
     필요한 슬레이브 JAB5 스탠바이 해제

음원 없음 + 일정 시간 경과
  └→ 슬레이브 JAB5 스탠바이 전환
     마스터 JAB5 스탠바이 전환 (절전)
```

### NEXA NIXIE 지능 선택 시나리오 예시

```
"집중 작업 모드"   슬레이브-A(서재) 볼륨 40%, 슬레이브-B 볼륨 0
"전체 재생"        마스터 + 슬레이브 전체 ON, 각 볼륨 독립 설정
"취침 모드"        전체 스탠바이 전환
"장르: 클래식"     특정 슬레이브 조합 + 볼륨 프리셋 적용
```

```
NEXA NIXIE 소프트웨어 UI
```

### NEXA NIXIE ↔ ESP32 통신 — ESP-NOW 확정

```
ESP-NOW 선택 이유

  레이턴시 매우 낮음 (수 ms)
  볼륨·스탠바이 제어 명령 전송에 최적
  구현 단순

통신 흐름
  NEXA NIXIE → ESP-NOW → ESP32 → SPI → MCP4131 → JAB5 볼륨
                          → GPIO → J11 → 스탠바이
```

### 자동화 확장 가능성

```
시간대별 자동화
  기상 시간  →  볼륨 서서히 올라오며 음악 시작 (반수면 효과)
  취침 시간  →  볼륨 서서히 낮아지며 전체 스탠바이
  집중 시간  →  특정 스피커만 낮은 볼륨

감지 연동
  음원 장르 감지  →  스피커 조합 자동 선택
  목소리 감지     →  볼륨 자동 조절
  자리 비움 감지  →  스탠바이 전환

아트 프로젝트 연동
  공간별 스피커 독립 제어
  음향 연출 프리셋 (전시, 퍼포먼스, 인스톨레이션)
  실시간 음향 공간 변환
```

### JAB5 추가 구매 결정

```
기존 방식 (회로 기반 셀렉터)
  릴레이, op-amp, LC7821 등 다수 부품 필요
  설계·제작·디버깅 공수 높음

JAB5 추가 구매 방식
  부품 단순화
  데이지체인으로 즉시 확장
  모든 스피커 동시 가동이라는 부가 기능 확보
  아트 프로젝트 음향 연출까지 확장 가능
  → 비용 대비 효과 압도적으로 유리
```

## v0.5 추가 — 라즈베리 파이 + 고음질 HAT + Louder ESP32 구성

### 전체 구성 업그레이드 방향

```
라즈베리 파이 5
  Node.js + Ollama + NEXA 서버
  음원 스트리밍, AI 판단, 자동화 로직
  ↓ I2S
Louder Raspberry Hat (TAS5825M)
  고음질 DAC + 클래스 D 앰프
  ALSA / I2C로 볼륨 및 DSP 직접 제어
  AI DSP 처리 (EQ, DRC, 보정)
  ↓ I2S 데이지체인
JAB5 슬레이브 × N
  각 스피커 전용 앰프 (멀티룸 확장)
  MCP4131로 독립 볼륨 제어

닉시 하드웨어 (별도 유닛)
  Louder ESP32 내장 (TAS5805M + ESP32 일체형)
  닉시 전면 내장 스피커 또는 근거리 스피커 구동
  ESP-NOW로 전체 시스템 제어 명령 송수신
```

### 역할 분담

| 유닛 | 역할 |
|------|------|
| 라즈베리 파이 5 | NEXA 서버, Ollama AI, 음원 스트리밍, 자동화 |
| Louder Raspberry Hat | 메인 고음질 앰프, DSP 보정, I2S 마스터 |
| JAB5 슬레이브 | 멀티룸 확장, 스피커별 독립 볼륨 |
| Louder ESP32 (닉시 내장) | 닉시 로컬 제어, ESP-NOW 허브 |

### Louder Raspberry Hat 선택 이유

```
TAS5825M 기반      TAS5805M(Louder ESP32)보다 상위 칩
ALSA 완전 지원     라즈베리 파이 OS에서 바로 볼륨·DSP 제어
Sonocotta 제품군   Louder ESP32와 동일 생태계 → 드라이버·문서 일관성
Volumio 호환       필요 시 전용 오디오 OS로 전환 가능
```

### JAB5 대비 음질 향상 포인트

```
JAB5 (현재)
  ADAU1701 DSP + 클래스 D
  MCP4131 외부 포텐셔미터로 볼륨 제어
  충분히 좋은 음질

Louder Raspberry Hat (업그레이드)
  TAS5825M — 더 현대적인 TI 클래스 D 칩
  라즈베리 파이 AI 처리 → 실시간 음장 보정 가능
  I2C 직접 볼륨 제어 → MCP4131 불필요
  고해상도 오디오 (192kHz/24bit) 지원
```

### 단계적 구현 계획

```
1단계 (현재)
  JAB5 × 2 + MCP4131 + ESP32 + ESP-NOW
  기본 멀티룸 + 지능 선택 완성

2단계 (업그레이드)
  라즈베리 파이 5 + Louder Raspberry Hat 추가
  JAB5는 슬레이브로 유지
  Louder Raspberry Hat이 마스터 역할

3단계 (닉시 통합)
  닉시 하드웨어에 Louder ESP32 내장
  전체 시스템 ESP-NOW로 통합 제어
```

## v0.6 수정 — AI 보드 명칭 정정 및 구성 단순화

### 오해 수정

```
이전 표현  "라즈베리 파이 + 인공지능 증폭보드 + Louder ESP32"
정확한 명칭 "라즈베리 파이 5 + Raspberry Pi AI HAT+ 2 + Louder ESP32"

"증폭보드"는 오디오 증폭이 아닌 AI 추론 가속 보드를 의미
```

### 확정된 닉시 AI 오디오 구성

```
라즈베리 파이 5 (8GB)
  NEXA 서버, Node.js, Ollama
  ↓ PCIe
Raspberry Pi AI HAT+ 2 (Hailo-10H)
  40 TOPS, 8GB 전용 RAM
  hailo-ollama (Ollama 호환 API)
  SLM 로컬 실행 (DeepSeek, Llama 등)
  비전 AI, 음성 인식(Whisper) 가속
  소비전력 3.5W 이하
  ↓ I2S
Louder ESP32 (닉시 내장)
  TAS5805M + ESP32 일체형
  2×25W 스테레오 출력
  I2C 직접 볼륨 제어
  ESP-NOW로 JAB5 멀티룸 시스템 제어
```

### AI HAT+ 2 주요 스펙

| 항목 | 내용 |
|------|------|
| 칩 | Hailo-10H NPU |
| 성능 | 40 TOPS (INT4) |
| 전용 RAM | 8GB 온보드 |
| Ollama 호환 | hailo-ollama API |
| 가격 | 약 $130 |
| 인터페이스 | PCIe (라즈베리 파이 5 전용) |

### 현실적인 LLM 성능 체크

```
AI HAT+ 2 LLM 속도   약 6.5~6.7 tokens/s
라즈베리 파이 5 CPU   약 9 tokens/s (소형 모델)

AI HAT+ 2가 진가를 발휘하는 영역
  비전 AI (객체 인식, 포즈 추정)
  음성 인식 (Whisper 가속)
  VLM (비전-언어 모델)
  → NEXA 카메라, 음성 명령 기능과 연계 시 효과적
```

### 오디오 담당 단순화

```
기존 논의 (Louder Raspberry Hat 추가)
  라즈베리 파이 → Louder Raspberry Hat → JAB5

최종 확정 (단순화)
  라즈베리 파이 5 + AI HAT+ 2   AI/서버 전담
  Louder ESP32 (닉시 내장)      오디오 전담
  JAB5 × N                      멀티룸 확장

Louder Raspberry Hat 불필요
  → 역할 분리가 명확해지고 구성이 단순해짐
```

## v0.8 추가 — HiFi ESP32 + LC7821 범용 확장 시나리오

### 핵심 발견

```
HiFi ESP32 (DAC 라인 출력)
  ↓ 아날로그 라인 출력
LC7821 (채널 분배 제어)
  ├── 일반 앰프 A → 스피커 A
  ├── 일반 앰프 B → 스피커 B
  └── 진공관 앰프 → 스피커 C

= JAB5 I2S 데이지체인과 동일한 멀티앰프 효과
  단, 어떤 앰프든 연결 가능
```

### JAB5 전용 vs 범용 구성 비교

| 항목 | JAB5 I2S 데이지체인 | HiFi ESP32 + LC7821 |
|------|-------------------|---------------------|
| 호환 앰프 | JAB5끼리만 | 어떤 앰프든 가능 |
| 신호 방식 | 디지털 I2S | 아날로그 라인 |
| 노이즈 | 없음 | 그라운드 루프 주의 |
| 볼륨 제어 | MCP4131 각 JAB5 | 각 앰프 자체 또는 MCP4131 추가 |
| 확장 비용 | JAB5 추가 구매 | 기존 보유 앰프 활용 |

### 확장 시나리오

**대형 아트 프로젝트**
```
지인 앰프 + 스피커 여러 대 동원
  HiFi ESP32 → LC7821 → 각 앰프 분배
  NEXA가 채널 온오프, 타이밍, 음향 연출 제어
  공간 전체를 음향으로 디자인 가능
  앰프 기종·브랜드 무관
```

**일반 사용자 환경**
```
기존 보유 앰프 그대로 활용
  HiFi ESP32 + LC7821만 추가하면
  NEXA 지능 제어 시스템에 편입 가능
  새 앰프 구매 없이 스마트 오디오 구현
```

**진공관 앰프 활용**
```
NEXA 자동화 시나리오 예시
  "클래식 감상 모드" → 진공관 앰프 채널 자동 ON
  "취침 모드"        → 진공관 앰프 채널 OFF
  "전체 재생"        → 모든 앰프 동시 구동
```

### NEXA 플랫폼 오디오 확장 구조 전체

```
닉시 하드웨어
  Louder ESP32 내장
  패시브 스피커 직결 또는 헤드폰 또는 라인 출력

로컬 멀티룸 (JAB5 전용)
  마스터 JAB5 → I2S → 슬레이브 JAB5 × N
  MCP4131 개별 볼륨 제어

범용 멀티앰프 (어떤 앰프든)
  HiFi ESP32 → LC7821 → 일반 앰프 × N
  진공관, 트랜지스터, Class D 모두 가능

전체 제어
  ESP-NOW → ESP32 → MCP4131 / LC7821 / J11
  NEXA AI → 기분·목적·시간대·장르별 자동 연출
```
