# _ NOTE 인천 폐철도 나무 아트 프로젝트

> 개인 프로젝트 — 숙성 중인 아이디어 메모
> NEXA 플랫폼 + NIXIE Canvas + NEXU를 활용한 몰입형 설치 예술

---

## 소재

```
인천 뒷골목 폐철도
  현재 관계자 외 출입 금지 구역
  사용하지 않는 철도 선
  인천의 역사와 함께한 쓰러진 나무
  → 시간이 멈춘 장소의 기억
```

## 전시 구조 — 세 개의 레이어

### 레이어 1 — 진입 공간 (준비)

```
나무를 소재로 그린 그림
비디오 아트
스마트폰 연동 작품
→ 관람객이 나무의 맥락을 먼저 경험
→ 감정적 준비 단계
```

### 레이어 2 — 나무 공간 (현재)

```
실물 나무 + 프로젝터 투사
실물과 시뮬레이션의 경계

프로젝터 투사 특성
  나무 실물과 일치하기도 하고
  살짝 벗어나기도 함 → 가상의 느낌 극대화

관람객 모션 연동
  모션 감지 → 투사 떨림 발생
  스마트폰 미세 진동
  이동 시   투사 살짝 벗어남
  정지 시   투사 다시 일치로 수렴
  집단 정지 → 트리거 발동
```

### 레이어 3 — 우주 공간 (확장)

```
트리거 발동 후
  나무 생명력 표현 (물올림, 광합성)
  몸통 전체에 꽃 배열
  꽃 하나 = 나이테 한 해

꽃 → 도트 전환
  꽃잎이 NIXIE Canvas 도트로 픽셀화
  처음엔 꽃 형태 유지 → 점점 도트로 분해

도트 확산
  전시장 전면으로 확산
  관람객 모션으로 줌아웃
  우주로 여행

NIXIE Canvas + NEXU 협연
  나무의 GPS 좌표 → 우주 지도 위에 펼쳐짐
  관람객 위치도 도트 하나로 천장에 표시
  나무와 관람객이 함께 우주로 여행
  NEXU가 실제 우주 전파 소리 재생
```

## 트리거 후보

```
집단 모션 기반 (유력)
  여러 관람객이 동시에 정지했을 때
  = 집중의 순간

기타 후보
  시간 기반    일정 시간 경과 후 자동 발동
  소리 기반    전시장이 일정 수준 이상 조용해졌을 때
  랜덤         예측 불가능한 순간 → 경이감 극대화
```

## 기술 구성

### 프로젝터 + 어안렌즈

```
프로젝터 1대 + 어안렌즈 어댑터
  나무 + 바닥 투사 담당
  어안렌즈로 최대한 넓은 화각 확보

DIY 어안렌즈 어댑터 검토
  보유 중인 LED 확산 렌즈 (지름 70mm 이상)
  일반 프로젝터 렌즈 구경 커버 가능
  각도 확인 후 테스트 예정

왜곡 처리
  NIXIE Canvas Pre-warping으로 역방향 왜곡 적용
  원하는 부분 보정 / 의도적 왜곡 살림
  → 우주로 빨려가는 효과 활용 가능
```

### 나머지 공간 처리

```
4벽면
  WS2812B LED 매트릭스 (ESP32 직접 제어)
  도트 확산 표현

천장
  실 + 발광 구슬
  3D 도트 공간감 표현
  나무 중심으로 사방 배치
```

### NEXA 연동

```
ESP32 + 센서
  관람객 모션 감지 (카메라 또는 PIR 센서)
  스마트폰 진동 신호 송출 (ESP-NOW)

NEXU
  오디오 연동 (우주 전파 소리)
  트리거 제어

NIXIE Canvas
  구면 좌표 기반 도트 배치
  어안렌즈 Pre-warping 적용
  관람객 모션 반응 도트
```

## 스마트폰 인터랙티브 자원

QR 스캔으로 입장 → 웹앱 접속 → 허가 요청 한 번으로 모든 기능 활성화

| 자원 | iOS | Android | 이 전시에서의 역할 |
|------|-----|---------|-----------------|
| 진동 (Web Vibration API) | 미지원 | 지원 | 나무 맥박 전달 |
| 화면 밝기·색상 변화 | 지원 | 지원 | iOS 진동 폴백 |
| Web Audio API | 지원 | 지원 | 우주 전파 소리 (이어폰) |
| 터치 이벤트 | 지원 | 지원 | 화면 터치 → 꽃 피우기 |
| 가속도계·자이로스코프 | 허가 필요 | 자동 | 폰 기울기 → 도트 방향 반응 |
| GPS 위치 | 허가 필요 | 허가 필요 | 관람객 좌표 → 우주 도트 |
| 마이크 | 허가 필요 | 허가 필요 | 집단 침묵 감지 → 트리거 |
| 카메라 | 허가 필요 | 허가 필요 | AR 오버레이 |
| WebSocket | 지원 | 지원 | NEXU 실시간 연동 |

### 브라우저에서 불가능한 것

```
NFC               iOS 완전 차단, Android도 브라우저 미지원
근접 센서          브라우저 API 없음
진동 (iOS)         Apple 정책으로 전면 차단
OS 진동 강제       사용자가 진동 off 시 앱도 불가 (OS 레벨 차단)
백그라운드 실행    탭 닫히면 모든 기능 중단
```

### iOS 진동 폴백 전략

```
Android   진동 (Web Vibration API)
iOS       화면 깜빡임 + Web Audio 저음 펄스 (이어폰)

안내 문구 예시
  "진동을 켜면 나무의 맥박을 손으로 느낄 수 있어요"
  → 강요 아닌 유도
```

### 가장 강렬한 인터랙티브 흐름

```
QR 스캔 → 웹앱 접속 → 탭 한 번 (사용자 제스처) → 이후 자동 작동

관람 중
  가속도계      폰 기울기 → 도트 방향 반응
  마이크        집단 침묵 감지 → 트리거 판단
  WebSocket     NEXU와 실시간 연동

트리거 발동 후
  진동 / 화면 색상 변화   나무 맥박 전달 (기기별 폴백)
  Web Audio               우주 전파 소리 (이어폰)

줌아웃 시
  GPS 좌표    관람객 도트 → 우주 지도에 표시
  WebSocket   전체 관람객 도트 실시간 동기화
```

## 동기화 감각 — 엇박자 깜박임

### 결론: 엇박자가 동기화를 더 강하게 느끼게 함

```
동시 깜박임
  폰과 캔버스가 같은 순간 반응
  → 같은 신호를 두 번 보는 느낌
  → 인지적으로 이해하고 끝남
  → 화음 (Chord) — 두 소리가 합쳐져 하나로 들림

엇박자 깜박임
  폰 깜박임 → 0.1초 후 캔버스 도트 깜박임
  → 신호가 폰에서 캔버스로 전달되는 느낌
  → "내 폰이 저 도트를 건드렸다"
  → 인과관계를 몸으로 느낌
  → 메아리 (Echo) / 도미노 (Cascade)
```

### 최적 엇박자 타이밍

```
10ms 이하    동시처럼 느껴짐
80~150ms     인과관계를 가장 강하게 느끼는 지연 시간  ← 최적
500ms 이상   연결감이 끊어짐
```

### 이 전시에서의 적용

```
관람객이 나무에 손을 댐
  → 폰 진동 / 화면 깜박임 (즉시)
    → 80ms 후 나무 위 도트 깜박임
      → 80ms 후 주변 도트로 전파
        → 도미노처럼 확산

"내 손이 나무를 깨웠다"는 느낌
```

## 전체 신호 흐름

```
나무
  터치 센서 (정전식)
  진동 센서 (나무 내부 울림)
  나이테 데이터 (나무의 시간)
    ↓
관람객 동작
  나무에 손을 댐 / 앞에 섬 / 집단 침묵
    ↓
스마트폰 (브라우저 웹앱)
  가속도계, 마이크, GPS, 터치 감지
  WebSocket으로 신호 송신
  진동 / 화면 깜박임 수신 (피드백)
    ↓
NEXU
  신호 수신 및 트리거 판단
  오디오 출력 (폐철도 소리 → 수액 소리 → 우주 전파)
  80~150ms 타이밍 제어
    ↓
NIXIE Canvas
  도트 반응 및 확산
  어안렌즈 Pre-warping 적용
  6면 투사

역할 분리
  나무        물리적 기억, 최초 신호 발생지
  스마트폰    입력 수집 + 피드백 수신
  NEXU       판단 + 오디오 + 타이밍
  NIXIE      시각 출력
```

나무는 단순한 소재가 아니라 시스템의 첫 번째 노드다.
인천의 역사적 기억이 관람객을 통해 우주로 전달되는 통로.

## 프로젝트 핵심 철학

### 비어 있음이 연결의 조건이다

```
원자와 원자 사이     99.9%가 빈 공간
별과 별 사이         광막하게 비어 있음
사람과 사람 사이     보이지 않는 간격

그 빈 공간을 통해
  중력이 전달되고
  전자기파가 흐르고
  감정이 오간다

꽉 차 있으면 아무것도 통과하지 못한다
비어 있기 때문에 연결이 가능하다
```

### 연결과 홀로됨의 역설

```
우리는 연결을 갈망하면서도 홀로됨을 갈망한다
이것은 모순이 아니라 같은 뿌리에서 나온다

연결을 통해 비로소 홀로 있음의 의미를 알고
홀로 있음을 통해 비로소 연결의 의미를 안다

엇박자 깜박임처럼
동시에 합쳐지면 구분이 없어지고
사이(간격)가 있어야 각자가 살아있다
```

### 나무의 여정이 이 역설을 담는다

```
폐철도에서 홀로 서 있었고   (홀로됨)
쓰러졌고                     (단절)
전시장으로 옮겨졌고          (탈장소)
관람객이 손을 대고           (연결 시도)
우주로 확산됐다가            (극한의 연결)
다시 도트 하나로 남는다      (홀로됨으로 귀환)
```

연결과 홀로됨이 순환하는 여정.

## 철학적 메모 — 축퇴압과 홀로됨

### 전자들의 축퇴압

```
파울리 배타 원리
  두 개의 동일한 전자는
  같은 양자 상태를 동시에 점유할 수 없다
  → 아무리 강하게 압축해도 서로 자리를 내어주지 않는다
  → 이것이 축퇴압 (Degeneracy Pressure)

백색왜성이 중력에 짓눌리면서도 붕괴하지 않는 이유
```

### 홀로됨은 물리적 본성일 수 있다

```
우리가 홀로됨을 갈망하는 것은
  전자처럼
  나라는 양자 상태는 오직 하나만 존재 가능하고
  그것을 지키려는 압력이 내부에서 작용하기 때문

그런데 역설
  전자는 축퇴압으로 자리를 지키면서
  동시에 다른 전자와 결합하여
  원자를 이루고 분자를 이루고 물질을 이룬다

홀로 있음을 지키는 힘이
동시에 연결의 조건이 된다
```

### 이 프로젝트로 이어지면

```
나무의 세포 하나하나가
  자기 자리를 지키면서 (축퇴압)
  나무라는 전체를 이루듯

관람객 한 명 한 명이
  자기 존재를 지키면서 (홀로됨)
  집단 침묵이라는 하나의 트리거를 만들고
  우주로 연결된다

홀로됨이 연결을 가능하게 하는 것은
물리 법칙에 이미 새겨져 있다
```
