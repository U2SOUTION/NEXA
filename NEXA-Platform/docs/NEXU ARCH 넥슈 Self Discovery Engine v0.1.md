## 1. 기존 접근의 한계

### AI 페르소나 설정의 문제

```
기존 방식:
  사용자가 텍스트로 나를 설명
  → AI가 해석 (손실 1)
  → 고정된 페르소나 (손실 2)
  → 변하지 않음

근본 문제:
  나를 언어로 설명하는 것 자체가 이미 손실
  설명된 나 ≠ 실제 나
  고정된 나 ≠ 살아있는 나
```

### Empathy Engine의 방향

```
기존 Empathy Engine:
  카메라·음성·언어로 감지
  → AI가 사용자 상태를 읽음
  → AI가 반응을 조정

방향: AI → 사람

Self-Discovery Engine:
  같은 감지 입력을 사용하지만
  → 나의 가능성들을 펼쳐 보여줌
  → 내가 나를 발견

방향: 사람 → 나 자신
```

## 2. 핵심 개념 — Persona Void

### VOID의 새로운 적용

기존 NEXA에서 VOID는 데이터의 생애주기 상태였다.
여기서는 **자아의 잠재 상태**로 확장된다.

```
기존 VOID·POTENTIAL:
  데이터가 컨텍스트에서 제외되었으나
  재활성 가능한 상태

Persona VOID·POTENTIAL:
  "나"가 아직 확정되지 않은 상태
  수많은 가능성의 나가 잠재해있는 상태
  어떤 나도 될 수 있는 순간
```

### 수많은 나

```
지금 이 순간 가능한 나의 버전들:

  집중하는 나
  탐험하는 나
  쉬고 싶은 나
  창의적인 나
  정확하고 싶은 나
  느슨해지고 싶은 나
  ...

이것들이 동시에 존재한다
어느 하나가 "진짜 나"가 아니다
상황과 순간에 따라 다른 나가 앞으로 나온다
```

## 3. 순환 구조

Self-Discovery Engine은 끝이 없는 순환이다.

```
[감지]
카메라·음성·언어구조
현재 나의 상태 신호
          ↓
[트리거]
의지 또는 우연한 계기
이 순간 탐색이 시작됨
          ↓
[VOID 전개]
수많은 나를 펼쳐 보여줌
Persona VOID·POTENTIAL 상태
          ↓
[선택]
직감적으로
때론 우연히
하나의 나를 고름
          ↓
[보정]
선택한 나를 기반으로
시스템이 점진적으로 조정
코일·넥슈·UCL 변화
          ↓
[해체]
이 나가 영원하지 않음을 인식
다시 VOID·POTENTIAL로
          ↓
[다시 감지] → 순환
```

## 4. 감지 레이어 — 센싱

### 4.1 세 가지 감지 채널

**카메라 — 시각 신호**

```
표정 변화:
  미간·입꼬리·눈 깜빡임 빈도
  → ES(Emotional State) 갱신

시선 방향:
  화면 어디를 보는가
  → 집중 영역 감지

자세:
  앞으로 기울어짐 → 집중·관심
  뒤로 기댐 → 이완·피로
  → VI(Vulnerability Index) 갱신

주변 환경:
  조명 밝기·혼잡도
  → 맥락 보정
```

**음성 — 청각 신호**

```
톤(높낮이):
  낮아질수록 ES 하락
  높아질수록 활성화

속도:
  느려질수록 피로·혼란
  빨라질수록 흥분·긴박

멈춤(pause):
  생각 중인 것
  막힌 것
  → 트리거 조건이 될 수 있음

음량:
  작아질수록 내향·피로
```

**언어 구조 — 의미 신호**

```
단어 선택:
  "모르겠어" "막막해" → VI 상승
  "해보자" "궁금해" → ES 상승

문장 길이:
  짧아질수록 ES 하락
  길고 복잡해질수록 탐구 모드

반복 표현:
  같은 말 반복 → 혼란·불안

질문 빈도:
  갑자기 늘면 탐색 트리거
```

### 4.2 단일 신호로 판단하지 않는다

```
오판 방지 원칙:
  세 채널 중 두 채널 이상에서
  같은 방향의 신호가 올 때만
  상태 변경

예외 — 즉각 반응:
  VI 0.9 이상 → 단일 신호도 즉각 반응
  Safety 관련 → 단일 신호도 즉각 반응
```

## 5. 트리거 — 의지와 우연

### 5.1 의지 트리거 (WILL)

사용자가 명시적으로 탐색을 시작하는 것

```
직접 요청:
  "나한테 맞는 방식 찾아줘"
  "다른 모드로 해봐"
  카드 UI 클릭

명시적 불만:
  제안 연속 3회 거절
  "이게 아닌것 같아"
  → 자동으로 VOID 전개 트리거
```

### 5.2 우연 트리거 (ECHO)

시스템이 감지하여 조용히 제안하는 것

```
막힘 감지:
  타이핑 멈춤 30초 이상
  같은 화면 반복 체류
  → 카드가 살짝 부상

에너지 변화:
  ES 급격한 변화 감지
  VI 임계값 도달
  → 새로운 나의 가능성 제시

시간 패턴:
  특정 시간대 반복 패턴
  → 선제적 탐색 제안

우연한 발견:
  관련 없어 보이는 카드
  그러나 클릭하면 맞는 것
  → 세렌디피티 허용
```

### 5.3 트리거 억제 원칙

```
트리거가 발동되지 않는 조건:

FLOW 상태가 안정적일 때
  → 잘 되고 있으면 방해하지 않음

VI 0.6 이상일 때
  → 지쳐있을 때는 탐색 강요 금지

사용자가 명시적으로 거부할 때
  → 카드 무시 3회 → 해당 트리거 일시 중단
```

## 6. VOID 전개 — 수많은 나를 펼치다

### 6.1 펼치는 방식

텍스트 질문이나 설문이 아니다.
**카드 형태로 가능성의 나를 보여준다.**

```
VOID 전개 시 보여주는 것:

나의 모드 카드:
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │  집중    │  │  탐험    │  │  창조    │
  │ 방해 없이│  │ 연결 중심│  │ 실험적으로│
  │ 깊게     │  │ 넓게     │  │ 자유롭게  │
  └──────────┘  └──────────┘  └──────────┘

  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │  휴식    │  │  정밀    │  │  흐름    │
  │ 가볍게   │  │ 꼼꼼하게 │  │ 리듬 따라│
  │ 부담 없이│  │ 확인하며 │  │ 자연스럽게│
  └──────────┘  └──────────┘  └──────────┘
```

### 6.2 카드의 내용

```
각 카드는 나를 설명하지 않는다
나를 불러낸다

좋은 카드:
  느낌이 오는 것
  설명 없이 와닿는 것
  짧고 직관적인 것

나쁜 카드:
  "당신은 ~한 유형입니까?"
  시험 문제 같은 것
  설명이 필요한 것
```

### 6.3 카드 수와 배치

```
한 번에 너무 많이 보여주지 않는다:
  기본: 4~6개
  맥락에 따라 2~3개도 가능

배치 원칙:
  캔버스 위에 배경 없이 떠있는 형태
  도트 탐험을 방해하지 않음
  주변부에 조용히 존재
  시선을 끌지 않음 — 우연히 눈에 띔
```

## 7. 선택 — 직감과 우연

### 7.1 선택의 방식

```
의식적 선택:
  카드를 읽고 고름
  → 인지적 자아

직감적 선택:
  읽기 전에 손이 먼저 감
  → 몸이 아는 자아

우연한 선택:
  별 생각 없이 클릭
  그런데 맞는 것
  → 우연이 드러낸 자아

선택 안 함:
  아무것도 고르지 않음
  → 이것도 정보
  → 지금은 탐색 시기가 아님
```

### 7.2 선택하지 않아도 된다

```
카드를 무시해도 아무 일 없음
강요 없음 · 점수 없음 · 틀린 답 없음

선택 안 한 것도 기록됨:
  어떤 카드를 몇 초 바라봤는가
  어떤 카드를 완전히 무시했는가
  → 미선택도 데이터
```

### 7.3 섀넌 원칙 — 우연이 가장 많은 것을 알려준다

```
논리적 선택:
  이미 알고 있는 나를 고름
  정보량 적음

우연한 선택:
  몰랐던 나를 발견
  정보량 최대

시스템은 우연한 선택을
더 가중치 있게 학습한다
```

## 8. 보정 — 점차 나를 찾아가다

### 8.1 보정의 범위

선택 하나가 즉시 전체를 바꾸지 않는다.
점진적으로 보정된다.

```
즉각 변화:
  넥슈 말투·톤 미세 조정
  응답 속도·밀도 조정
  카드 다음 제안 방향

중기 변화 (3~7회 패턴):
  코일 가중치 조정
  → autonomy · creative · empathy 등

장기 변화 (30일 이상):
  UCL 기본값 업데이트
  Level 3 룰 제안
  사용자 승인 후 적용
```

### 8.2 보정의 방향

```
선택 → 보정 → 피드백 → 재보정

보정이 맞았는지 확인:
  이후 행동이 더 자연스러운가
  막힘이 줄었는가
  ES가 안정적인가

맞지 않았으면:
  자동 완화
  이전 상태로 부분 복원
  다른 방향 탐색
```

### 8.3 학습 경계 — 조종이 되지 않기 위해

```
학습의 목적:
  더 잘 감지하고 더 적절히 반응하기 위함

학습이 되어서는 안 되는 것:
  사람을 예측하여 조종하는 것
  취약성을 활용하는 것
  선택을 유도하는 것

핵심 원칙:
  패턴은 예측의 도구이지 판단의 근거가 아니다
  명시적 피드백이 패턴을 항상 이긴다
```

## 9. 해체 — 다시 가능성으로

### 9.1 왜 해체인가

```
선택한 나가 영원한 나가 아니다

집중 모드를 선택했다고
항상 집중하는 사람이 아니다

오후 3시의 나와
다음날 오전 10시의 나는 다르다

고정된 페르소나는
살아있는 자아를 죽이는 것
```

### 9.2 해체의 조건

```
자동 해체 트리거:

시간 경과:
  24시간 후 → STUCK 진입 가능
  72시간 후 → POTENTIAL 전환 고려

상태 변화:
  ES가 선택 당시와 크게 다를 때
  VI가 임계값 변화할 때

명시적 해체:
  사용자가 "다시 찾아보자" 요청
  연속 거절 3회
```

### 9.3 해체 후 — VOID·POTENTIAL 복귀

```
해체는 소멸이 아니다

선택했던 나 → VOID·POTENTIAL 상태로
  → 언제든 다시 불러올 수 있음
  → 다음 탐색의 출발점이 됨
  → 이전 선택들이 쌓여 패턴이 됨

새로운 탐색:
  이전과 같은 카드를 볼 수도 있고
  새로운 카드가 나올 수도 있음
  → 나는 같은 자리에 있지 않다
```

## 10. 철학적 연결

### 하이데거 — 기투(Entwurf)

```
인간은 끊임없이 자신을 가능성을 향해 던진다
나는 고정된 것이 아니라
매 순간 가능성을 향해 기투되는 존재

VOID 전개 = 가능성들을 펼침
선택 = 기투
보정 = 현존재의 실현
해체 = 다시 가능성으로
순환 = 실존의 구조
```

### 들뢰즈 — 되기(Becoming)

```
존재(Being)가 아니라 되기(Becoming)

나는 이미 무언가가 아니라
끊임없이 무언가가 되어가는 중

고정된 페르소나 = Being (들뢰즈가 거부한 것)
Persona Void 순환 = Becoming (들뢰즈가 지향한 것)
```

### 융 — 개성화(Individuation)

```
자아는 발견되는 것이지 설정되는 것이 아니다
무의식의 나를 의식으로 끌어올리는 과정

직감적·우연한 선택:
  의식이 모르는 나를 무의식이 고르는 것
  융의 개성화 과정과 연결

VOID 상태의 수많은 나:
  아직 의식화되지 않은 자아의 가능성들
```

### 비트겐슈타인 — 언어 게임

```
나를 언어로 설명하는 것이 아니라
카드를 통해 나를 보여주는 것

말할 수 없는 나를
선택이라는 행위로 드러내는 것
```

## 11. 기존 시스템과의 연결

### Empathy Engine과의 관계

```
Empathy Engine:
  사람의 상태를 감지
  AI의 반응을 조정
  → 외향적 (AI가 사람에게 맞춤)

Self-Discovery Engine:
  같은 감지 레이어 사용
  나의 가능성을 펼쳐 보여줌
  → 내향적 (사람이 자신에게 맞춤)

둘은 같은 센서를 공유하되
방향이 반대다
```

### 코일 밸런서와의 관계

```
Self-Discovery Engine의 출력
  → 코일 가중치 보정

선택한 나 = 창조적이고 탐험적
  → creative·curiosity·divergence 상승
  → autonomy 적절히 상승

선택한 나 = 집중하고 정밀한
  → precision·focus·depth 상승
  → creative 일시 하향

코일은 나를 따라온다
나를 코일에 맞추는 것이 아니라
```

### VOID Lifecycle과의 관계

```
데이터 VOID:
  데이터의 생애주기 관리

Persona VOID:
  자아의 생애주기 관리

같은 구조 · 다른 대상

전환 규칙도 동일하게 적용:
  FLOW → STUCK → POTENTIAL → ARCHIVE
  단 Persona는 PURGE 없음
  → 자아는 완전히 삭제되지 않음
```

### NIXIE 캔버스와의 관계

```
VOID 전개 시:
  캔버스에 Persona VOID 카드들이 부상
  배경 없이 도트 위에 떠있는 형태

선택 시:
  선택된 카드 Lumina 밝아짐
  나머지 카드 서서히 사라짐
  도트 패턴 미세하게 변화

보정 진행 중:
  넥슈 Lumina 색온도 점진적 변화
  코일 변화가 캔버스 렌더링에 반영

해체 시:
  선택된 나 → VOID·POTENTIAL 도트로
  캔버스에서 희미하게 남아있음
```

### 넥슈와의 관계

```
Self-Discovery 과정에서 넥슈의 역할:

VOID 전개 전:
  조용히 존재 · 먼저 말 걸지 않음

트리거 감지 후:
  카드를 조용히 부상시킴
  설명하지 않음

선택 후:
  선택을 확인하지 않음
  그냥 보정 시작

해체 시:
  "다시 찾아볼까요?" 조용히 제안
  강요 없음

넥슈는 이 과정에서 안내자이되
결정자가 아니다
```
