## 4. 아키텍처 설계

- [ ] `{Context} ARCH` 작성

      → 장애 대응 및 복구 전략
      → 확장성 고려사항

## 5. 상세 설계 및 명세

- [ ] `{Context} DESIGN` 작성
      → 내부 모듈 구조
      → 핵심 알고리즘 또는 로직 흐름
      → 설정값 및 파라미터 정의
- [ ] `{Context} SPEC` 작성
      → 인터페이스 명세 (API, 이벤트, 메시지)
      → 입출력 데이터 형식
      → 오류 코드 및 처리 방식
      → 보안 고려사항 (인증, 암호화, 감사 로그)
