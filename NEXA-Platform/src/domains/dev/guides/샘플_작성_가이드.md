# 샘플 작성 가이드

## 📋 개요

개발 가이드의 샘플 파일을 작성할 때 따라야 할 원칙과 가이드라인입니다.

---

## 🎨 핵심 원칙

### 1. 배경색/테마 전환 테스트 가능성

- ❌ 고정 배경색 사용 금지
- ✅ 테두리(`border`)와 패딩(`padding`)만으로 섹션 구분
- ✅ 배경색이 필요하면 `var(--nexa-surface)` 같은 테마 변수 사용

```scss
// ❌ 나쁜 예
.sample-section {
  background-color: #f5f5f5; // 테마 전환 테스트 불가
}

// ✅ 좋은 예
.sample-section {
  border: 1px solid var(--nexa-border-color);
  border-radius: 8px;
  padding: 24px;
}
```

### 2. 중첩 구조 최소화

- ❌ 불필요한 래퍼 `div` 요소 사용 금지
- ✅ 직접적인 부모-자식 관계 유지
- ✅ CSS로 해결 가능한 경우 래퍼 추가 금지

```vue
<!-- ❌ 나쁜 예 -->
<div class="sample-container">
  <div class="wrapper">
    <div class="content">
      <q-btn>버튼</q-btn>
    </div>
  </div>
</div>

<!-- ✅ 좋은 예 -->
<div class="sample-container">
  <q-btn>버튼</q-btn>
</div>
```

## 📐 구조 가이드

### 기본 구조

```vue
<template>
  <div class="sample-container">
    <div class="sample-section">
      <h4 class="section-title">섹션 제목</h4>
      <div class="section-content">
        <!-- 샘플 콘텐츠 -->
      </div>
    </div>
  </div>
</template>
```

### 스타일 가이드

```scss
.sample-container {
  display: flex;
  flex-direction: column;
  gap: 24px;
}

.sample-section {
  border: 1px solid var(--nexa-border-color);
  border-radius: 8px;
  padding: 24px;
}
```

## 🖼️ 썸네일 전략

### 개요

- **썸네일**: 리스트 카드에서 보이는 작은 미리보기 (제한된 높이)
- **미리보기**: 상세 페이지에서 보이는 전체 미리보기

### 썸네일 최적화 전략

#### 1. 중요 내용 우선 배치

가장 중요한 예제나 핵심 내용을 맨 위에 배치합니다.

```vue
<div class="sample-container">
  <!-- ✅ 핵심 예제를 맨 위에 -->
  <div class="sample-section">
    <h4>버튼 내부 사용 (일반 button)</h4>
    <!-- 실제 사용 예제 -->
  </div>

  <!-- 기본 예제들 -->
  <div class="sample-section">
    <h4>기본 스피너</h4>
  </div>

  <!-- 비교용은 하단에 -->
  <div class="sample-section">
    <h4>비교: Quasar 버튼</h4>
  </div>
</div>
```

#### 2. 섹션 순서 전략

1. **실용적인 예제** (최우선) - 실제 프로젝트에서 자주 사용하는 패턴
2. **기본 예제들** - 기본 사용법, 다양한 옵션
3. **고급 예제** - 복잡한 사용 사례
4. **비교용 예제** (하단) - 다른 방식과의 비교

#### 3. 섹션 크기 최적화

- 각 섹션은 2-3개의 예제로 구성
- 너무 많은 예제는 여러 섹션으로 분리

## 🔄 재사용 가능한 컴포넌트 자동 감지

시스템이 자동으로 재사용 가능성을 감지하여 "사용 예제" 섹션을 표시합니다.

### 자동 감지 기준

1. **실제 프로젝트 컴포넌트 참조**

   ```javascript
   import NexaChart from 'src/charts/NexaChart.vue'
   ```

2. **Props/Emits 정의**

   ```vue
   const props = defineProps({ data: Array }) const emit = defineEmits(['update'])
   ```

3. **실제 로직 존재**
   ```vue
   const data = ref([]) const processedData = computed(() => { /* 로직 */ })
   ```

### 주의사항

- 명시적 플래그 불필요 (`@reusable: true` 같은 것)
- 자동 감지로 판단
- 재사용 가능한 컴포넌트는 실제 프로젝트 컴포넌트를 참조하거나 Props/Emits를 정의
