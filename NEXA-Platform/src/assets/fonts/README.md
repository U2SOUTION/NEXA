# 한글 폰트 파일

PDF 내보내기에서 한글을 표시하기 위한 폰트 파일을 이 폴더에 추가하세요.

## 권장 폰트

- **Noto Sans KR** (Google Fonts)
- **Nanum Gothic** (네이버 한글나눔글꼴)

## 폰트 파일 준비 방법

1. TTF 형식의 한글 폰트 파일을 다운로드합니다.
2. 파일을 `src/assets/fonts/` 폴더에 `NotoSansKR-Regular.ttf` 이름으로 저장합니다.
3. 또는 작은 subset 폰트를 사용하여 파일 크기를 최소화할 수 있습니다.

## 폰트 다운로드 링크

- Noto Sans KR: https://fonts.google.com/noto/specimen/Noto+Sans+KR
- Nanum Gothic: https://hangeul.naver.com/font

## 참고

폰트 파일이 없으면 PDF에서 한글이 깨질 수 있습니다.
