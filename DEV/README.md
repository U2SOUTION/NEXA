# Explorer Accordion Mode Extension

VS Code 탐색기에서 아코디언 모드(클릭한 폴더만 열고 나머지는 모두 닫기)를 구현하는 확장 프로그램입니다.

## 프로젝트 상태

- [x] 1단계: Yeoman 및 generator-code 설치 ✅
- [x] 2단계: 프로젝트 생성 ✅
- [x] 3단계: 의존성 설치 (`npm install`) ✅
- [x] 4단계: 코드 작성 ✅
- [x] 5단계: 빌드 (`npm run compile`) ✅
- [ ] 6단계: 테스트 (F5)

## 시작하기

`설치-체크리스트.md` 파일을 참고하여 단계별로 진행하세요.

각 단계마다 확인을 받고 진행합니다.
