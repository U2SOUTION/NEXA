# NEXA-App (모바일 애플리케이션)

**상태**: 계획 단계  
**개발 예정 시기**: NEXA-Platform 완성 후  
**목적**: NEXA 시스템의 모바일 클라이언트 제공

---

## 폴더 역할

이 폴더는 NEXA 시스템의 **모바일 애플리케이션**을 담을 예정입니다.

### 현재 상태

-   **개발 전 단계**: 아직 개발을 시작하지 않았습니다
-   **개발 시기**: NEXA-Platform (Quasar 기반 웹 플랫폼)이 어느 정도 완성된 후 구체적인 개발 방법을 검토할 예정입니다

---

## NEXA 시스템 구조

NEXA 시스템은 4개의 주요 컴포넌트로 구성되며, 모두 연동되어 동작합니다:

```
NEXA/
├── NEXA-Platform/    (웹 플랫폼) - Quasar/Vue 3 기반
├── NEXA-Desktop/     (PC 데스크톱 프로그램) - Python/PySide6 기반
├── NEXA-Edge/        (ESP32 엣지 디바이스) - PlatformIO 기반
└── NEXA-App/         (모바일 앱) - 이 폴더 (개발 예정)
```

### 시스템 간 연동

모든 시스템은 다음 기능을 공유하고 연동되어야 합니다:

-   **IoT 디바이스 관리**: ESP32 디바이스 등록, 모니터링, 제어
-   **대시보드 연동**: NEXA BOARD 데이터 동기화
-   **실시간 통신**: WebSocket을 통한 실시간 데이터 업데이트
-   **부품 관리**: 재고 현황, 입출고 기록 조회
-   **프로젝트 관리**: ERP 시스템 연동
-   **인증 및 권한**: 통합 사용자 인증 시스템

---

## 예상 기능 (향후 계획)

### 핵심 기능

1. **디바이스 모니터링**

    - ESP32 디바이스 상태 실시간 확인
    - 센서 데이터 시각화
    - 알림 및 경고 수신

2. **대시보드 뷰어**

    - NEXA BOARD 대시보드 모바일 최적화 뷰
    - 패널 기반 데이터 표시

3. **원격 제어**

    - 디바이스 제어 (버튼, 스위치, 슬라이더)
    - 명령어 전송

4. **부품 관리**

    - 재고 현황 조회
    - 입출고 기록 확인
    - QR 코드 스캔 (향후)

5. **프로젝트 관리**
    - 프로젝트 정보 조회
    - 작업 문서 확인
    - 일정 관리

### 기술 스택 (예상)

-   **프레임워크**: React Native, Flutter, 또는 Quasar Mobile 중 선택 예정
-   **상태 관리**: Redux, MobX, 또는 Pinia (Platform과 일관성 고려)
-   **통신**: WebSocket, REST API
-   **인증**: JWT 기반 인증

## 참고 사항

### NEXA-Platform과의 연동

-   NEXA-Platform의 API 엔드포인트를 활용
-   WebSocket 연결을 통한 실시간 데이터 동기화
-   인증 토큰 공유

### 표준 계약 준수

모바일 앱도 NEXA 시스템의 표준 계약을 준수해야 합니다:

-   모든 데이터 구조는 `id`, `type`, `version`, `metadata` 필드를 포함
-   API 통신 시 표준 형식 준수
