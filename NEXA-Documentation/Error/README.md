# 에러 분석 문서 저장소

이 폴더는 NEXA 프로젝트 전체의 에러 분석 문서를 저장하는 위치입니다.

## 구조

각 프로젝트별로 별도의 폴더를 가지고 있습니다:

```
Error/
├── Platform/    # NEXA Platform 프로젝트 에러 분석 문서
├── Desktop/     # NEXA Desktop 프로젝트 에러 분석 문서
├── Edge/        # NEXA Edge 프로젝트 에러 분석 문서
└── Mobile/      # NEXA Mobile 프로젝트 에러 분석 문서
```

## 문서 형식

각 문서는 마크다운 형식으로 저장되며, YAML 프론트매터를 포함합니다:

```yaml
---
errorId: "에러_고유_ID"
errorMessage: "에러 메시지"
errorFile: "파일 경로"
errorLine: 라인_번호
errorColumn: 컬럼_번호
project: "Platform"  # 또는 "Desktop", "Edge", "Mobile"
createdAt: "2024-12-20T10:30:00Z"
tags: ["태그1", "태그2"]
---
```

## 파일명 규칙

-   의미 있는 이름을 사용합니다 (에러 ID는 파일명에 포함하지 않음).
-   예시:
    -   `Vue_ref_초기화_에러_분석.md`
    -   `ESP32_초기화_에러_분석.md`
    -   `React_Native_네비게이션_에러_분석.md`

## 인덱스 시스템

각 프로젝트 폴더에는 `.error-analysis-index.json` 파일이 자동으로 생성되어 관리됩니다.

-   빠른 검색을 위한 인덱스 파일
-   에러 ID로 문서를 즉시 찾을 수 있음
-   메타데이터 캐싱

## 사용 방법

1. **에러 발생 시**: Cursor AI를 통해 에러 분석 문서 작성
2. **문서 저장**: 해당 프로젝트 폴더에 저장 (예: `Error/Platform/`)
3. **자동 인덱싱**: 인덱스 시스템이 자동으로 문서를 인덱싱
4. **에러 트래킹에서 확인**: 에러 트래킹 시스템에서 자동으로 문서 검색 및 표시

## 참고

-   에러 트래킹 시스템에서 자동으로 문서를 검색하여 표시합니다.
-   문서 뷰어에서도 일반 문서처럼 볼 수 있습니다.
-   각 프로젝트 폴더의 README.md에서 프로젝트별 상세 정보를 확인할 수 있습니다.
