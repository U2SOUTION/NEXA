# 에러 분석 문서 저장소

이 폴더는 NEXA Mobile 프로젝트의 에러 분석 문서를 저장하는 위치입니다.

## 구조

-   각 에러 분석 문서는 마크다운 형식으로 저장됩니다.
-   파일명은 의미 있는 이름을 사용합니다 (에러 ID는 파일명에 포함하지 않음).
-   에러 ID는 문서의 프론트매터에 포함됩니다.

## 문서 형식

각 문서는 다음 형식의 프론트매터를 포함합니다:

```yaml
---
errorId: "에러_고유_ID"
errorMessage: "에러 메시지"
errorFile: "파일 경로"
errorLine: 라인_번호
errorColumn: 컬럼_번호
project: "Mobile"
createdAt: "2024-12-20T10:30:00Z"
tags: ["태그1", "태그2"]
---
```

## 예시 파일명

-   `React_Native_네비게이션_에러_분석.md`
-   `네이티브_모듈_연동_에러_분석.md`
-   `앱_상태_관리_에러_분석.md`

## 참고

-   에러 트래킹 시스템에서 자동으로 이 폴더의 문서를 검색하여 표시합니다.
-   문서 뷰어에서도 일반 문서처럼 볼 수 있습니다.
