# 데이터베이스 뷰어 구현 가이드

**작성일**: 2024년 12월  
**목적**: 데이터베이스 스키마 시각화 기능 구현 가이드

---

## 📋 개요

데이터베이스 구조 파악을 위한 뷰어 기능 구현 가이드입니다.

**주요 기능:**

-   데이터베이스 테이블 목록 조회
-   테이블 구조 상세 정보 표시
-   외래키 관계 시각화 (ERD 다이어그램)
-   테이블 간 관계 탐색

**기술 스택:**

-   **백엔드**: Express.js, MySQL (INFORMATION_SCHEMA)
-   **프론트엔드**: Vue 3, D3.js, dagre-d3-es
-   **스타일링**: NEXA 테마 변수 (`--nexa-*`)

---

## 🎯 구현 기능 목록

### 1. 데이터베이스 개요

**기능:**

-   데이터베이스 목록 조회
-   현재 데이터베이스 정보 표시
-   테이블 개수 및 통계
-   데이터베이스 크기 정보

**표시 정보:**

-   데이터베이스 이름
-   테이블 개수
-   총 데이터 크기
-   인덱스 크기
-   엔진 정보

**API 엔드포인트:**

-   `GET /api/db/info` - 데이터베이스 정보 조회

---

### 2. 테이블 구조 조회

**기능:**

-   테이블 목록 조회 (트리뷰 또는 리스트)
-   테이블 상세 정보 표시
-   컬럼 정보 조회
-   인덱스 정보 조회
-   제약조건 정보 조회

**테이블 목록 (`TableList.vue`):**

-   테이블 이름 목록
-   행 수 표시
-   테이블 크기 표시
-   검색/필터링 기능
-   카테고리별 그룹화 (선택)
-   테이블 선택 기능

**테이블 상세 정보 (`TableDetail.vue`):**

-   **컬럼 정보:**
    -   컬럼 이름
    -   데이터 타입
    -   NULL 허용 여부
    -   기본값
    -   자동 증가 여부
    -   컬럼 코멘트
-   **인덱스 정보:**
    -   인덱스 이름
    -   인덱스 타입 (PRIMARY, UNIQUE, INDEX)
    -   인덱스 컬럼
    -   정렬 순서 (ASC/DESC)
-   **제약조건:**
    -   PRIMARY KEY
    -   UNIQUE 제약조건
    -   CHECK 제약조건
    -   FOREIGN KEY (외래키)
-   **테이블 메타데이터:**
    -   테이블 코멘트/설명
    -   엔진 타입 (InnoDB, MyISAM 등)
    -   문자셋 및 콜레이션
    -   생성일/수정일

**API 엔드포인트:**

-   `GET /api/db/tables` - 테이블 목록 조회
-   `GET /api/db/tables/:tableName/structure` - 테이블 구조 조회
-   `GET /api/db/tables/:tableName/columns` - 컬럼 정보 조회
-   `GET /api/db/tables/:tableName/indexes` - 인덱스 정보 조회
-   `GET /api/db/tables/:tableName/constraints` - 제약조건 조회

---

### 3. 릴레이션 관계 시각화 (핵심 기능)

**기능:**

-   외래키 관계 다이어그램 (ERD)
-   테이블 간 연결 관계 시각화
-   관계 타입 표시 (1:1, 1:N, N:N)
-   테이블 선택 시 관련 테이블 하이라이트

**ERD 다이어그램 (`SchemaDiagram.vue`):**

-   **노드 (테이블):**
    -   테이블 이름 표시
    -   테이블 카테고리별 색상 구분
    -   노드 클릭 시 상세 정보 표시
    -   노드 호버 시 툴팁 표시
-   **엣지 (관계):**
    -   외래키 관계 표시
    -   관계 방향 표시 (화살표)
    -   관계 컬럼 정보 표시 (`fromColumn → toColumn`)
    -   관계 타입 표시 (1:1, 1:N)
-   **인터랙션:**
    -   줌/팬 기능
    -   노드 드래그 (dagre-d3-es는 자동 레이아웃이지만, 수동 조정 가능)
    -   노드 클릭 시 관련 테이블 하이라이트
    -   노드 호버 시 관련 엣지 강조
    -   전체/부분 뷰 전환

**API 엔드포인트:**

-   `GET /api/db/relationships` - 외래키 관계 조회
-   `GET /api/db/relationships/:tableName` - 특정 테이블의 관계만 조회

## 🔧 기술 스택 결정

### 선택된 기술: **D3.js + dagre-d3-es**

**이유:**

1. ✅ **이미 설치되어 있음** - 추가 의존성 없음 (`dagre-d3-es` v7.0.13)
2. ✅ **ERD 시각화에 최적화** - 계층적 구조 표현
3. ✅ **기존 시스템 통합** - 차트 테마 재사용 가능
4. ✅ **학습 가치** - D3.js 실전 경험
5. ✅ **가장 빠른 구현 시간** - 8-12시간

**설치된 패키지:**

-   ✅ **d3** (v7.9.0) - 메인 라이브러리
-   ✅ **d3-force** (v3.0.0) - 네트워크 그래프 레이아웃
-   ✅ **dagre-d3-es** (v7.0.13) - ERD 레이아웃 (Dagre 알고리즘)

**기존 사용 사례:**

-   차트 시스템 (`src/charts/`)
    -   BarChart, LineChart, AreaChart, PieChart, ScatterChart
    -   차트 테마 시스템 (`chartTheme.js`)
    -   스케일 유틸리티 (`chartScales.js`)

## 🔌 백엔드 API 설계

### 라우터 파일 구조

**파일:** `server/routes/databaseSchema.js`

**구조:**

```javascript
import express from "express";

const router = express.Router();

// 데이터베이스 연결을 파라미터로 받음
export default function createDatabaseSchemaRouter(dbConnection) {
    // GET /api/db/tables - 테이블 목록 조회
    router.get("/tables", async (req, res) => {
        // ...
    });

    // GET /api/db/tables/:tableName/structure - 테이블 구조 조회
    router.get("/tables/:tableName/structure", async (req, res) => {
        // ...
    });

    // GET /api/db/relationships - 외래키 관계 조회
    router.get("/relationships", async (req, res) => {
        // ...
    });

    // GET /api/db/schema - 전체 스키마 정보 조회
    router.get("/schema", async (req, res) => {
        // ...
    });

    return router;
}
```

**api.js에 등록:**

```javascript
import createDatabaseSchemaRouter from "./routes/databaseSchema.js";

// 데이터베이스 연결 후 라우터 등록
const databaseSchemaRouter = createDatabaseSchemaRouter(dbConnection);
app.use("/api/db", databaseSchemaRouter);
```

```javascript
import * as d3 from "d3";
import dagreD3 from "dagre-d3-es";

// 1. Dagre 그래프 생성
const g = new dagreD3.graphlib.Graph().setGraph({ rankdir: "LR", nodesep: 50, ranksep: 80 }).setDefaultEdgeLabel(() => ({}));

// 2. 노드 추가 (테이블)
tables.forEach((table) => {
    g.setNode(table.name, {
        label: table.name,
        shape: "rect",
        style: "fill: var(--nexa-surface); stroke: var(--nexa-border-color);",
    });
});

// 3. 엣지 추가 (외래키 관계)
relationships.forEach((rel) => {
    g.setEdge(rel.fromTable, rel.toTable, {
        label: `${rel.fromColumn} → ${rel.toColumn}`,
        arrowhead: "vee",
        style: "stroke: var(--nexa-primary);",
    });
});

// 4. D3.js로 렌더링
const svg = d3.select(diagramContainer.value).append("svg").attr("width", "100%").attr("height", "600px");

const svgGroup = svg.append("g");
const render = new dagreD3.render();
render(svgGroup, g);

// 5. 줌/팬 기능
const zoom = d3
    .zoom()
    .scaleExtent([0.1, 3])
    .on("zoom", (event) => {
        svgGroup.attr("transform", event.transform);
    });
svg.call(zoom);
```
