## 개요

### 목적

GraphDoc 기능을 더욱 강력하고 사용자 친화적으로 만들기 위한 고급 기능 추가

### 핵심 가치

-   **탐색성 향상**: 히스토리, 즐겨찾기, 최근 사용으로 빠른 재접근
-   **커스터마이징**: 노드별 속성, 렌더링 제어로 개인화된 다이어그램
-   **확장성**: 다이어그램 타입 자동 인식 및 호환성 관리
-   **사용성**: 뒤로가기/앞으로가기로 탐색 흐름 개선

## 기본 기능

### 1. 네비게이션 컨트롤

#### 1-1. 뒤로가기 / 앞으로가기 버튼

-   **위치**: 입력폼 왼쪽 (아이콘 버튼)
-   **기능**:
    -   뒤로가기: 이전 분석 결과로 이동
    -   앞으로가기: 다음 분석 결과로 이동 (뒤로가기 후에만 활성화)
-   **상태 관리**:
    -   히스토리 스택 관리 (최대 50개)
    -   현재 위치 인덱스 추적
    -   브라우저 히스토리와 독립적 (GraphDoc 내부 히스토리)

#### 1-2. 현재 위치 표시

-   **표시 내용**: "3 / 15" (현재 위치 / 전체 히스토리)
-   **위치**: 뒤로가기/앞으로가기 버튼 사이 또는 아래

#### 1-3. 검색 기능 통합

##### 자동완성 검색

-   **기능**: URL 입력창에 자동완성 드롭다운 추가
-   **데이터 소스**:
    -   히스토리 (최근 분석 결과)
    -   최근 사용 (자주 사용하는 경로)그래
    -   즐겨찾기 (저장된 경로)
    -   프로젝트 파일 목록 (파일 경로 자동완성)
-   **필터링**: 입력한 텍스트와 일치하는 항목만 표시
-   **표시 정보**:
    -   히스토리: 경로, 분석 시간, 노드/엣지 수
    -   최근 사용: 경로, 사용 횟수
    -   즐겨찾기: 사용자 지정 이름, 경로
    -   파일 목록: 파일 경로, 파일 타입 아이콘

##### 실시간 검색 제안

-   **동작**: 입력 중 실시간으로 히스토리/최근/즐겨찾기에서 일치 항목 필터링
-   **제한**: 각 카테고리별 최대 5개 표시
-   **정렬**: 최신순, 사용 빈도순

##### 파일 경로 자동완성

-   **기능**: 프로젝트 파일 목록을 스캔하여 입력과 일치하는 파일 경로 제안
-   **스캔 범위**: `src/` 디렉토리 내 모든 파일
-   **필터링**: 파일명 또는 경로에 입력 텍스트가 포함된 파일만 표시
-   **제한**: 최대 10개 표시

##### 키보드 단축키

-   **`Ctrl + K`** 또는 **`/`**: 입력창 포커스
-   **`↑/↓`**: 제안 목록 네비게이션
-   **`Enter`**: 선택된 제안 적용 또는 분석 실행
-   **`Esc`**: 제안 목록 닫기
-   **`Tab`**: 첫 번째 제안 자동 완성

##### 검색 모드 토글 (향후)

-   **분석 모드**: 기본 모드, 분석 대상 입력
-   **검색 모드**: 코드 검색 기능과 통합
-   **토글 버튼**: 입력창 오른쪽에 모드 전환 버튼

##### 구현 로직

```javascript
// 필터링 로직
const filteredHistory = computed(() => {
    if (!analysisTarget.value) return history.value.slice(0, 5);
    return history.value.filter((item) => item.target.toLowerCase().includes(analysisTarget.value.toLowerCase())).slice(0, 5);
});

const filteredRecent = computed(() => {
    if (!analysisTarget.value) return recent.value.slice(0, 5);
    return recent.value.filter((item) => item.target.toLowerCase().includes(analysisTarget.value.toLowerCase())).slice(0, 5);
});

const filteredFavorites = computed(() => {
    if (!analysisTarget.value) return favorites.value.slice(0, 5);
    return favorites.value.filter((item) => item.target.toLowerCase().includes(analysisTarget.value.toLowerCase()) || (item.name && item.name.toLowerCase().includes(analysisTarget.value.toLowerCase()))).slice(0, 5);
});

const filteredFiles = computed(() => {
    if (!analysisTarget.value || analysisTarget.value.length < 2) return [];
    const query = analysisTarget.value.toLowerCase();
    return allFiles.value.filter((file) => file.toLowerCase().includes(query)).slice(0, 10);
});

// 제안 선택
function selectSuggestion(target) {
    analysisTarget.value = target;
    showSuggestions.value = false;
    handleAnalyze();
}

// 키보드 네비게이션
let selectedIndex = ref(-1);
function navigateSuggestions(direction) {
    const allSuggestions = [...filteredHistory.value, ...filteredRecent.value, ...filteredFavorites.value, ...filteredFiles.value];
    selectedIndex.value = Math.max(0, Math.min(allSuggestions.length - 1, selectedIndex.value + direction));
}
```

## 우측 사이드바 패널 구조

### 전체 구조

```
우측 사이드바 (DevToolsPanel)
└── GraphDoc 패널 (아코디언)
    ├── 0. 렌더링 제어 패널
    ├── 1. 통계 패널
    ├── 2. 히스토리/최근/즐겨찾기 패널 (탭 구조)
    │   ├── 히스토리 탭
    │   ├── 최근 탭
    │   └── 즐겨찾기 탭
    ├── 3. 노드 속성 패널
    └── 4. 다이어그램 타입 셀렉터
```

### 패널 공통 사항

-   각 패널은 `q-expansion-item`으로 구성
-   패널 간 독립적 (단일/다중 열림 모드 지원)
-   패널 상태는 `localStorage`에 저장
-   패널 순서는 드래그 앤 드롭으로 변경 가능 (향후)

## 상세 기능 명세

### 0. 렌더링 제어 패널

#### 0-1. 기본 렌더링 설정

-   **노드 크기**:
    -   기본 크기 (width, height)
    -   자동 크기 조정 (텍스트 길이에 따라)
    -   최소/최대 크기 제한
-   **레이아웃**:
    -   방향 (LR, TB, RL, BT)
    -   노드 간격 (nodesep, ranksep)
    -   마진 (marginx, marginy)
-   **줌/팬**:
    -   초기 줌 레벨
    -   최소/최대 줌 레벨
    -   자동 맞춤 (autoFit)

#### 0-2. 색상 및 스타일

-   **노드 색상**:
    -   기본 배경색
    -   테두리 색상
    -   파일 타입별 색상 (vue, js, ts, scss 등)
-   **엣지 스타일**:
    -   선 색상
    -   선 두께
    -   선 스타일 (직선, 곡선, 베지어)
-   **라벨**:
    -   라벨 표시 여부
    -   라벨 색상
    -   라벨 폰트 크기
    -   라벨 위치 (노드 내부/외부)

#### 0-3. 효과

-   **호버 효과**:
    -   노드 호버 시 확대
    -   연결된 엣지 강조
    -   연결된 노드 강조
-   **선택 효과**:
    -   선택된 노드 강조 색상
    -   선택된 노드 테두리 두께
-   **애니메이션**:
    -   레이아웃 전환 애니메이션
    -   노드 드래그 애니메이션
    -   줌/팬 애니메이션

#### 0-4. 인터랙티브

-   **노드 상호작용**:
    -   노드 클릭 동작 (선택/분석 재실행)
    -   노드 더블클릭 동작 (파일 열기/상세 정보)
    -   노드 드래그 활성화/비활성화
-   **엣지 상호작용**:
    -   엣지 클릭 동작 (의존성 정보 표시)
    -   엣지 호버 시 정보 툴팁
-   **키보드 단축키**:
    -   `Ctrl + Z`: 뒤로가기
    -   `Ctrl + Y`: 앞으로가기
    -   `Ctrl + F`: 검색
    -   `Esc`: 선택 해제

#### 0-5. 고급 옵션

-   **성능 최적화**:
    -   노드 수 제한 (대용량 그래프 처리)
    -   레이아웃 알고리즘 선택 (Force-Directed, Hierarchical 등)
    -   렌더링 품질 (고품질/표준/빠름)
-   **필터링**:
    -   파일 타입 필터 (vue만, js만 등)
    -   디렉토리 필터 (특정 경로 포함/제외)
    -   의존성 깊이 제한

### 1. 히스토리/최근/즐겨찾기 패널 (탭 구조)

#### 1-1. 패널 구조

-   **탭 구성**: `q-tabs`를 사용하여 3개의 탭으로 구성
    -   히스토리 탭
    -   최근 탭
    -   즐겨찾기 탭
-   **탭 전환**: 탭 클릭 시 해당 목록 표시
-   **활성 탭 저장**: `localStorage`에 마지막 활성 탭 저장

#### 1-2. 히스토리 탭

##### 표시 정보

-   분석 대상 (경로 또는 URL)
-   분석 시간
-   노드 수 / 엣지 수
-   썸네일 (작은 다이어그램 미리보기, 선택적)

##### 정렬 옵션

-   최신순 (기본)
-   오래된순
-   노드 수 순
-   이름순

##### 항목 동작

-   **클릭**: 해당 분석 결과로 재렌더링
-   **우클릭 메뉴**:
    -   즐겨찾기 추가/제거
    -   삭제
    -   복사 (분석 대상 경로)
    -   새 탭에서 열기 (향후)

##### 관리 기능

-   **자동 저장**: 분석 실행 시마다 자동으로 히스토리에 추가
-   **수동 저장**: 사용자가 명시적으로 저장 가능
-   **히스토리 제한**: 최대 100개 (초과 시 오래된 것부터 삭제)
-   **히스토리 검색**: 분석 대상 경로로 검색
-   **일괄 삭제**: 선택한 항목 일괄 삭제

##### 데이터 구조

```javascript
{
  id: 'unique-id',
  target: '/dev',
  timestamp: 1234567890,
  nodeCount: 103,
  edgeCount: 127,
  thumbnail: 'data:image/png;base64,...', // 선택적
  graphData: { nodes: [], edges: [] }, // 전체 데이터 (선택적, 큰 데이터는 제외)
  settings: { ... }, // 렌더링 설정 스냅샷
}
```

#### 1-3. 최근 탭

##### 표시 정보

-   경로 또는 URL
-   마지막 사용 시간
-   사용 횟수

##### 관리 기능

-   **자동 추가**: 분석 실행 시 자동으로 최근 목록에 추가
-   **중복 제거**: 같은 경로는 최신 것으로 업데이트
-   **제한**: 최대 20개
-   **정렬**: 최신순 (기본), 사용 횟수순, 이름순
-   **검색**: 경로로 검색
-   **삭제**: 개별 삭제 또는 일괄 삭제

##### 항목 동작

-   **클릭**: 즉시 분석 실행
-   **우클릭 메뉴**:
    -   즐겨찾기 추가/제거
    -   삭제
    -   복사 (분석 대상 경로)

##### 데이터 구조

```javascript
{
  target: '/dev',
  lastUsed: 1234567890,
  useCount: 5,
}
```

#### 1-4. 즐겨찾기 탭

##### 표시 정보

-   사용자 지정 이름 (없으면 경로 표시)
-   경로 또는 URL
-   생성 시간
-   즐겨찾기 아이콘 (⭐)

##### 관리 기능

-   **수동 추가**: 사용자가 명시적으로 추가
-   **이름 편집**: 사용자 지정 이름 변경
-   **제한**: 제한 없음
-   **정렬**: 이름순 (기본), 생성 시간순, 사용 횟수순
-   **검색**: 이름 또는 경로로 검색
-   **폴더 기능**: 즐겨찾기를 폴더로 그룹화 (향후)
-   **태그**: 태그 추가/제거 (향후)

##### 항목 동작

-   **클릭**: 즉시 분석 실행
-   **우클릭 메뉴**:
    -   이름 변경
    -   즐겨찾기 제거
    -   복사 (분석 대상 경로)
    -   폴더로 이동 (향후)

##### 데이터 구조

```javascript
{
  id: 'unique-id',
  target: '/dev',
  name: '개발 페이지', // 사용자 지정 이름
  createdAt: 1234567890,
  tags: ['dev', 'main'], // 태그 (향후)
  folder: 'work', // 폴더 (향후)
}
```

#### 1-5. 공통 기능

-   **빠른 접근**: 모든 탭에서 클릭 시 즉시 분석 실행
-   **드래그 앤 드롭**: 순서 변경 (향후)
-   **공유 검색**: 탭 전환 없이 모든 목록에서 검색 (향후)

### 3. 노드 속성 패널

#### 3-1. 노드 선택 시 표시

-   **선택된 노드 정보**:
    -   파일 경로
    -   파일명
    -   파일 타입

#### 4-1. 타입 자동 인식

-   **메타데이터 기반**:
    -   각 다이어그램 타입은 메타데이터를 가짐
    -   데이터 구조를 분석하여 호환 가능한 타입 자동 감지
-   **호환성 체크**:
    -   데이터에 필요한 필드 존재 여부 확인
    -   데이터 형식 검증
    -   자동 변환 가능 여부 확인

#### 4-2. 타입 목록

-   **기본 타입**:
    -   Dependency Analysis (Force-Directed Graph)
    -   Dependency Graph (Hierarchical)
    -   File Tree (Tree Layout)
    -   ERD (Entity Relationship Diagram)
-   **확장 타입** (향후):
    -   Flow Chart
    -   Network Diagram
    -   Sankey Diagram
    -   등등...

#### 4-3. 타입 전환

-   **자동 변환**: 호환 가능한 경우 자동으로 데이터 변환
-   **수동 변환**: 사용자가 명시적으로 변환
-   **변환 실패 처리**: 변환 불가능한 경우 경고 표시

#### 4-4. 타입별 설정

-   **타입별 렌더링 옵션**: 각 타입에 맞는 설정만 표시
-   **타입별 기본값**: 타입에 따라 적절한 기본 설정 적용
-   **타입별 기능**: 타입에 따라 사용 가능한 기능 다름

#### 4-5. 메타데이터 구조

```javascript
// diagramMetadata.js에 추가

  type: 'dependency-analysis',
  name: 'Dependency Analysis',
  label: '의존성 분석',
  description: 'Force-Directed Graph를 사용한 의존성 분석',
  icon: 'hub',
  requiredFields: ['packages', 'dependencies'],
  dataValidator: (data) => {
    return Array.isArray(data.packages) && Array.isArray(data.dependencies)
  },
  dataConverter: {
    from: {
      'dependency': (data) => {
        // dependency 타입에서 변환
        return {
          packages: data.nodes.map(n => ({ id: n.path, name: n.name })),
          dependencies: data.edges.map(e => ({ from: e.from, to: e.to }))
        }
      }
    }
  },
  supportedFeatures: ['zoom', 'pan', 'node-drag', 'export', 'node-hover'],
}
```

## 추가 아이디어

### 1. 검색 및 필터링

-   **전역 검색**: 노드 이름, 경로, 설명, 메모에서 검색

-   **이미지 내보내기**: PNG, SVG, PDF
-   **데이터 내보내기**: JSON, CSV
-   **설정 내보내기**: 렌더링 설정, 노드 속성 등
-   **가져오기**: 다른 사용자와 설정 공유

### 3. 협업 기능 (향후)

-   **공유 링크**: 특정 분석 결과를 링크로 공유
-   **댓글**: 노드에 댓글 추가
-   **협업 메모**: 팀원과 메모 공유

### 4. 성능 최적화

-   **가상화**: 대용량 그래프에서 보이는 노드만 렌더링
-   **레이지 로딩**: 필요할 때만 데이터 로드
-   **캐싱**: 분석 결과 캐싱으로 재렌더링 속도 향상

### 5. 접근성

-   **키보드 네비게이션**: 모든 기능을 키보드로 사용 가능
-   **스크린 리더 지원**: ARIA 레이블 추가
-   **고대비 모드**: 색상 대비 향상

### 6. 분석 도구

-   **순환 의존성 감지**: 순환 참조 자동 감지 및 표시
-   **의존성 깊이 분석**: 의존성 체인의 깊이 분석
-   **사용되지 않는 파일 감지**: import되지 않는 파일 표시
-   **의존성 통계**: 노드별 의존성 수, 평균 깊이 등

### 7. 시각화 개선

-   **클러스터링**: 관련 노드를 그룹으로 묶어 표시
-   **미니맵**: 전체 그래프를 작게 보여주는 미니맵
-   **레전드**: 파일 타입별 색상, 노드 타입별 아이콘 등
-   **그리드/스냅**: 노드를 그리드에 맞춰 정렬
