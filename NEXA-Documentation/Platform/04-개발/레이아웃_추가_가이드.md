# 레이아웃 추가 가이드

다른 플랫폼(IoT, 컨트롤러 등)에 대한 새로운 레이아웃을 추가하는 방법을 설명합니다.

## 📋 단계별 가이드

### 1단계: 레이아웃 파일 생성

`NEXA-Platform/src/layouts/` 폴더에 새로운 레이아웃 파일을 생성합니다.

**예시: `IotLayout.vue`**

```vue
<!-- IoT 전용 레이아웃 -->
<template>
    <q-layout view="hHh Lpr fFf">
        <q-page-container class="iot-layout-container">
            <router-view />
        </q-page-container>
    </q-layout>
</template>

<script setup>
import { onMounted } from "vue";
import { useUserSettingsStore } from "src/stores/userSettingsStore";

// IoT 전용 레이아웃 - 필요한 구조만 포함

// 테마 초기화 (Quasar 다크 모드 상속)
const userSettings = useUserSettingsStore();

onMounted(() => {
    // 테마 초기화 (사용자 설정에서 다크 모드 상태 로드)
    userSettings.initializeTheme();
});
</script>

<style lang="scss" scoped>
.iot-layout-container {
    padding: 0 !important;
    margin: 0 !important;
    min-height: 100vh !important;
    max-height: 100vh !important;
    height: 100vh !important;
    overflow: hidden !important;
}
</style>
```

### 2단계: 레이아웃 레지스트리에 추가

`NEXA-Platform/src/config/layoutRegistry.js` 파일을 수정합니다.

```javascript
export const layoutRegistry = {
    // 기본 레이아웃 (MainLayout)
    default: () => import("layouts/MainLayout.vue"),

    // U2BEE 전용 레이아웃 (크롬 확장 프로그램용)
    u2bee: () => import("layouts/U2BeeLayout.vue"),

    // IoT 전용 레이아웃 (새로 추가)
    iot: () => import("layouts/IotLayout.vue"),

    // 컨트롤러 전용 레이아웃 (예시)
    controller: () => import("layouts/ControllerLayout.vue"),
};
```

### 3단계: 라우터에 라우트 추가

`NEXA-Platform/src/router/routes.js` 파일에 새로운 라우트를 추가합니다.

#### 옵션 A: 직접 라우트 추가 (간단한 방법)

```javascript
// IoT 경로: IoT 전용 레이아웃
{
  path: '/iot',
  component: () => import('layouts/IotLayout.vue'),
  children: [
    {
      path: '',
      name: 'IotMain',
      component: () => import('pages/IotPage.vue'),
    },
    {
      path: ':deviceId',
      name: 'IotDevice',
      component: () => import('pages/IotDevicePage.vue'),
    },
  ],
},
```

#### 옵션 B: 동적 레이아웃 선택 (확장 가능한 방법)

```javascript
// IoT 경로: 동적 레이아웃 선택
{
  path: '/iot',
  component: (to) => {
    // layoutRegistry의 getLayoutComponent 함수 사용
    const { getLayoutComponent } = require('src/config/layoutRegistry')
    return getLayoutComponent(to)
  },
  children: [
    {
      path: '',
      name: 'IotMain',
      component: () => import('pages/IotPage.vue'),
      meta: { layout: 'iot' }, // 레이아웃 지정
    },
  ],
},
```

#### 옵션 C: 조건부 라우트 (U2BEE 방식)

```javascript
// IoT 경로: 조건부 레이아웃 선택
{
  path: '/iot',
  name: 'Iot',
  component: () => import('pages/IotPage.vue'),
  beforeEnter: (to, from, next) => {
    // IoT 레이아웃을 사용할 조건 확인
    const isIotMode = to.query.mode === 'embed' && to.query.platform === 'iot'

    if (isIotMode) {
      // IoT 레이아웃으로 리다이렉트
      next({ name: 'IotEmbedded', query: to.query, params: to.params })
    } else {
      // 일반 IoT 페이지 표시
      next()
    }
  },
},
// IoT 임베드 경로: IoT 전용 레이아웃
{
  path: '/iot',
  component: () => import('layouts/IotLayout.vue'),
  children: [
    {
      path: '',
      name: 'IotEmbedded',
      component: () => import('pages/IotPage.vue'),
    },
  ],
},
```

## 📝 체크리스트

새로운 레이아웃을 추가할 때 확인할 사항:

-   [ ] `layouts/` 폴더에 레이아웃 파일 생성
-   [ ] 레이아웃에 테마 초기화 코드 추가 (`userSettings.initializeTheme()`)
-   [ ] `layoutRegistry.js`에 레이아웃 등록
-   [ ] `routes.js`에 라우트 추가
-   [ ] 필요한 경우 `beforeEnter` 가드 추가
-   [ ] 테스트: 일반 접근 및 iframe/embed 모드 접근 확인

## 🔍 현재 구조

### 레이아웃 파일 위치

```
NEXA-Platform/src/layouts/
├── MainLayout.vue      # 기본 레이아웃
└── U2BeeLayout.vue     # U2BEE 전용 레이아웃
```

### 레이아웃 레지스트리

```
NEXA-Platform/src/config/layoutRegistry.js
```

### 라우터 설정

```
NEXA-Platform/src/router/routes.js
```

## 💡 권장 사항

1. **레이아웃 레지스트리 사용**: 수백 개의 레이아웃을 관리할 때 유리
2. **일관된 네이밍**: `{Platform}Layout.vue` 형식 사용
3. **테마 초기화 필수**: 모든 레이아웃에서 `userSettings.initializeTheme()` 호출
4. **문서화**: 각 레이아웃의 용도와 사용 조건을 주석으로 명시

## 🚀 빠른 시작 템플릿

새로운 레이아웃을 빠르게 생성하려면 `U2BeeLayout.vue`를 복사하여 수정하세요:

```bash
# 레이아웃 파일 복사
cp NEXA-Platform/src/layouts/U2BeeLayout.vue NEXA-Platform/src/layouts/IotLayout.vue

# 파일 내용 수정:
# 1. 클래스명 변경 (u2bee-layout-container → iot-layout-container)
# 2. 주석 수정
# 3. 필요한 구조 추가/제거
```
