# 컴포넌트 라이브러리 가이드

**작성일**: 2024년 12월  
**목적**: NEXA 플랫폼의 컴포넌트 구조를 파악하고, 시스템 리팩토링 및 기능 추가 시 중요한 단서를 제공하는 개발 도구  
**버전**: 1.0 (진행 중)

---

## 📋 문서 개요

컴포넌트 라이브러리는 NEXA 플랫폼의 전체 컴포넌트 구조를 시각화하고 분석하는 개발 도구입니다. 이 도구는 **전체적인 구조 파악**에 주안점을 두며, 특히 **파일 구조 파악**을 통해 차후 기능 추가나 시스템 리팩토링 시 중요한 단서를 제공합니다.

### 핵심 목표

1. **전체 구조 파악**: 프로젝트의 컴포넌트 구조를 한눈에 파악
2. **파일 구조 시각화**: 디렉토리 계층 구조와 파일 관계를 명확히 표시
3. **의존성 분석**: 컴포넌트 간 의존성 관계를 파악하여 리팩토링 시 영향도 분석
4. **리팩토링 지원**: 시스템 리팩토링 및 기능 추가 시 중요한 단서 제공

### 사용 목적

-   **시스템 리팩토링**: 컴포넌트 구조와 의존성을 파악하여 안전한 리팩토링 계획 수립
-   **기능 추가**: 새로운 기능 추가 시 기존 컴포넌트 구조를 참고하여 일관성 유지
-   **코드 탐색**: 특정 컴포넌트를 빠르게 찾고 관련 파일을 탐색
-   **문서화**: 컴포넌트 구조와 관계를 문서화하여 팀과 공유

## 🎯 프로그램 목적

### 1. 전체 구조 파악 (주안점)

컴포넌트 라이브러리의 가장 중요한 목적은 **전체적인 구조를 파악**하는 것입니다.

-   **디렉토리 구조**: `src/components/`, `src/block/`, `src/charts/`, `src/panel/` 등 독립 디렉토리 구조 파악
-   **카테고리 분류**: UI, 폼, 부품 관리, 사이드바, 설정, 사이드 패널 등 컴포넌트 카테고리별 분류
-   **파일 관계**: 같은 디렉토리의 다른 파일, 관련 파일 (`.vue`, `.js`, `.scss`) 관계 파악

### 2. 파일 구조 파악 (특별 강조)

**특히 파일 구조를 파악할 수 있으면 더욱 좋습니다.**

-   **디렉토리 계층 구조**: 폴더별 컴포넌트 개수와 계층 구조 시각화
-   **파일 타입별 분류**: `.vue`, `.js`, `.scss` 등 파일 타입별 분류 및 관계
-   **트리 뷰**: 접기/펼치기 기능을 통한 직관적인 구조 탐색

### 3. 리팩토링 및 기능 추가 지원

차후 시스템에 기능을 추가하거나 시스템 리팩토링 등을 하고자 할 때 **중요한 단서가 되도록** 설계되었습니다.

-   **의존성 분석**: 어떤 컴포넌트가 어떤 컴포넌트를 사용하는지 파악
-   **영향도 분석**: 특정 컴포넌트 수정 시 영향을 받는 컴포넌트 목록 확인
-   **구조 일관성**: 새로운 기능 추가 시 기존 구조와의 일관성 유지

## 🏗️ 프로그램 구성

### 전체 레이아웃

컴포넌트 라이브러리는 **3단계 계층 구조**로 구성됩니다.

```
┌─────────────────────────────────────────────────────────┐
│                    툴바 (상단)                          │
├──────────────┬──────────────────────┬───────────────────┤
│              │                      │                   │
│  왼쪽 사이드바 │   중간 컨텐츠 영역    │  오른쪽 사이드바   │
│  (뼈대/구조)  │   (상세 정보)         │  (추가정보/기능)   │
│              │                      │                   │
│  - 카테고리   │  - 컴포넌트 상세 정보  │  - Props/Emits    │
│  - 컴포넌트   │  - 코드 미리보기      │  - Slots          │
│    목록       │  - 디렉토리 구조     │  - 빠른 액션       │
│  - 파일 구조  │  - 파일 구조 상세    │  - 관련 문서       │
│    (하위메뉴) │  - 의존성 관계       │  - 기능/설정       │
│              │  - 사용 위치         │                   │
│              │  - 파일 관계         │                   │
│              │                      │                   │
└──────────────┴──────────────────────┴───────────────────┘
```

### 3단계 계층 구조

1. **왼쪽 사이드바**: 뼈대, 구조 선택
    - 왼쪽에서 항목 선택 → 중간에 상세 정보 표시
2. **중간 컨텐츠 영역**: 선택한 항목의 상세 정보
    - 중간에서 아이템 선택 → 오른쪽에 추가 정보 표시
3. **오른쪽 사이드바**: 추가 정보, 기능, 액션
    - 중간에서 선택한 아이템의 세부 정보 및 기능 제공

### 왼쪽 사이드바: 뼈대/구조

왼쪽 사이드바는 **뼈대와 구조**를 표시하여 전체 구조 파악에 중점을 둡니다.

#### 1. 카테고리 목록 (메인)

-   **카테고리별 분류**
    -   UI 컴포넌트
    -   폼 컴포넌트
    -   부품 관리
    -   사이드바
    -   설정
    -   사이드 패널
    -   기타
-   **카테고리 선택**: 카테고리 클릭 시 해당 카테고리의 컴포넌트 목록 표시

#### 2. 컴포넌트 목록 (메인)

-   **선택된 카테고리의 컴포넌트 목록**
    -   컴포넌트 이름 표시
    -   컴포넌트 아이콘 표시
    -   파일 경로 미리보기
-   **검색 필터링**: 컴포넌트 이름, 경로로 검색
-   **선택 상태 표시**: 선택된 컴포넌트 하이라이트
-   **컴포넌트 클릭**: 중간 컨텐츠 영역에 상세 정보 표시

#### 3. 파일 구조/디렉토리 (하위 메뉴)

-   **하위 메뉴 버튼**: "파일 구조 보기" 또는 "디렉토리 탐색" 버튼
-   **클릭 시 동작**: 중간 컨텐츠 영역에 디렉토리 구조와 파일 구조 상세 표시
-   **표시 정보**
    -   디렉토리 계층 구조 (D3 tree layout)
    -   `src/components/` 하위 구조
    -   `src/block/`, `src/charts/`, `src/panel/` 등 독립 디렉토리
    -   폴더별 컴포넌트 개수 표시
    -   파일 타입별 아이콘 (`.vue`, `.js`, `.scss`)
    -   접기/펼치기 기능

### 중간 컨텐츠 영역: 상세 정보

중간 컨텐츠 영역은 **왼쪽에서 선택한 항목의 상세 정보**를 표시합니다.

#### 1. 컴포넌트 상세 정보 (컴포넌트 선택 시)

-   **기본 정보**
    -   컴포넌트 이름 (displayName)
    -   파일 경로 (path)
    -   카테고리 (category)
    -   아이콘 (icon)
    -   설명/주석 (description) - 파일 상단 주석에서 추출

#### 2. 디렉토리 구조 및 파일 구조 상세 (파일 구조 메뉴 클릭 시)

-   **디렉토리 계층 구조**
    -   D3 tree layout을 사용한 트리 시각화
    -   `src/components/` 하위 구조
    -   `src/block/`, `src/charts/`, `src/panel/` 등 독립 디렉토리
    -   폴더별 컴포넌트 개수 표시
    -   접기/펼치기 기능
-   **파일 구조 상세**
    -   선택한 디렉토리의 파일 목록
    -   파일 타입별 아이콘 (`.vue`, `.js`, `.scss`)
    -   파일 크기, 수정일 등 메타데이터
    -   파일 클릭 시 상세 정보 표시

#### 3. 코드 미리보기 (컴포넌트 선택 시)

-   **템플릿 코드**: HTML 구조 미리보기
-   **스크립트 코드**: 로직 및 로직 흐름 미리보기
-   **스타일 코드**: SCSS/CSS 스타일 미리보기
-   **코드 하이라이팅**: 구문 강조 표시

#### 4. 의존성 관계 (컴포넌트 선택 시)

-   **이 컴포넌트가 사용하는 컴포넌트 (Dependencies)**
    -   직접 import하는 컴포넌트 목록
    -   중첩 깊이 표시
-   **이 컴포넌트를 사용하는 컴포넌트 (Dependents)**
    -   사용 위치 목록
    -   사용 횟수 표시

#### 5. 파일 관계 (컴포넌트 선택 시)

-   같은 디렉토리의 다른 파일 목록
-   관련 파일 (`.vue`, `.js`, `.scss`) 관계 표시
-   컴포넌트와 스타일 파일 매칭

#### 6. 사용 위치 목록 (컴포넌트 선택 시)

-   어디서 사용되는지 목록
-   사용 횟수
-   사용 컨텍스트

### 오른쪽 사이드바: 추가 정보/기능/액션

오른쪽 사이드바는 **중간에서 선택한 아이템의 추가 정보, 기능, 액션**을 제공합니다.

#### 1. 컴포넌트 구조 정보

-   **Props 목록**
    -   이름, 타입, 기본값, 필수 여부, validator
    -   설명 (주석에서 추출)
-   **Emits 목록**
    -   이벤트 이름, 파라미터 타입, 설명
-   **Slots 목록**
    -   슬롯 이름, 설명, 스코프 변수

#### 2. 빠른 액션

-   **파일 경로 복사**: 클립보드에 경로 복사
-   **VS Code에서 열기**: VS Code에서 해당 파일 열기
-   **파일 탐색기에서 열기**: 파일 탐색기에서 해당 파일 위치 열기
-   **Git 히스토리**: Git 커밋 히스토리 확인

#### 3. 관련 문서 링크

-   컴포넌트 관련 문서 링크
-   사용 예제 링크
-   API 문서 링크

#### 4. 기능 및 설정

-   컴포넌트 설정 옵션
-   사용 예제 생성
-   테스트 코드 생성
-   리팩토링 제안

## 🔍 주요 기능

### 1. 컴포넌트 탐색

-   **카테고리별 분류**: UI, 폼, 부품 관리, 사이드바, 설정, 사이드 패널 등
-   **검색 기능**: 컴포넌트 이름, 경로로 검색
-   **필터링**: 카테고리, 파일 타입별 필터링

### 2. 구조 시각화

-   **파일 구조 트리**: 디렉토리 계층 구조 시각화 (D3 tree layout 활용 가능)
-   **의존성 그래프**: 컴포넌트 간 의존성 관계 시각화 (D3.js + dagre-d3-es 활용, 데이터베이스 뷰어 ERD 참고)
-   **파일 관계도**: 파일 간 관계 시각화 (D3.js force-directed graph 활용 가능)

### 3. 상세 정보 표시

-   **컴포넌트 인터페이스**: Props, Emits, Slots 정보
-   **코드 미리보기**: 템플릿, 스크립트, 스타일 코드
-   **사용 통계**: 어디서 사용되는지, 사용 횟수

### 4. 개발 지원 기능

-   **빠른 액션**: 파일 경로 복사, VS Code에서 열기
-   **관련 문서 링크**: 컴포넌트 관련 문서 연결
-   **검색 및 필터링**: 빠른 컴포넌트 탐색

## 🎨 D3.js 시각화 활용 방안

### 데이터베이스 뷰어 ERD 다이어그램 참고

데이터베이스 뷰어의 ERD 다이어그램 구현(`NEXA-Platform/src/diagram/erd/ERDDiagram.js`)을 참고하여 컴포넌트 라이브러리에서 다양한 구조를 시각화할 수 있습니다.

**기존 구현 기술 스택:**

-   **D3.js**: SVG 기반 시각화
-   **dagre-d3-es**: 그래프 레이아웃 알고리즘 (계층형, 원형 등)
-   **NexaDiagram**: 범용 다이어그램 래퍼 컴포넌트

### 활용 가능한 시각화 유형

#### 1. 의존성 그래프 (D3.js + dagre-d3-es)

**목적**: 컴포넌트 간 의존성 관계를 노드-엣지 그래프로 시각화

**구현 방법:**

-   **노드 (Node)**: 컴포넌트
    -   컴포넌트 이름 표시
    -   카테고리별 색상 구분
    -   노드 클릭 시 상세 정보 표시
-   **엣지 (Edge)**: 의존성 관계
    -   import 관계 표시
    -   관계 방향 표시 (화살표)
    -   관계 타입 표시 (직접 import, 간접 import)

**데이터베이스 뷰어 참고:**

```javascript
// ERDDiagram.js 패턴 활용
import { renderERD } from "@/diagram/erd/ERDDiagram.js";

// 컴포넌트 의존성 데이터 변환
const componentData = {
    components: [
        { name: "BaseModal", category: "ui" },
        { name: "ContextMenu", category: "ui" },
        // ...
    ],
    dependencies: [
        { fromComponent: "BaseModal", toComponent: "ContextMenu" },
        // ...
    ],
};

// 다이어그램 렌더링
await renderERD(container, componentData, {
    selectedNode: selectedComponent.value,
    layoutType: "hierarchical",
    onNodeClick: handleComponentClick,
});
```

**활용 위치:**

-   **중간 컨텐츠 영역**: 선택한 컴포넌트의 의존성 관계를 그래프로 표시
-   **오른쪽 사이드바**: 전체 의존성 그래프 미니맵

#### 2. 파일 구조 트리 (D3.js tree layout)

**목적**: 디렉토리 계층 구조를 트리 형태로 시각화

**구현 방법:**

-   **D3 tree layout** 사용
-   디렉토리 노드: 폴더 아이콘
-   파일 노드: 파일 타입별 아이콘 (`.vue`, `.js`, `.scss`)
-   접기/펼치기 기능
-   노드 클릭 시 해당 파일 정보 표시

**활용 위치:**

-   **중간 컨텐츠 영역**: 파일 구조 메뉴 클릭 시 디렉토리 구조 트리 뷰 표시

#### 3. 컴포넌트 관계도 (D3.js force-directed graph)

**목적**: 컴포넌트 간 사용 관계를 시각화

**구현 방법:**

-   **D3 force simulation** 사용
-   노드: 컴포넌트
-   엣지: 사용 관계 (어떤 컴포넌트가 어떤 컴포넌트를 사용하는지)
-   노드 드래그 가능
-   노드 클릭 시 관련 컴포넌트 하이라이트

**활용 위치:**

-   **중간 컨텐츠 영역**: 전체 컴포넌트 관계도 표시
-   **오른쪽 사이드바**: 선택한 컴포넌트 중심 관계도

#### 4. 카테고리별 그룹화 (D3.js cluster layout)

**목적**: 컴포넌트를 카테고리별로 그룹화하여 표시

**구현 방법:**

-   **D3 cluster layout** 사용
-   카테고리별 그룹 노드
-   그룹 내 컴포넌트 노드
-   그룹 접기/펼치기 기능

**활용 위치:**

-   **중간 컨텐츠 영역**: 카테고리별 컴포넌트 그룹 뷰 및 관계도

### 기존 다이어그램 인프라 활용

**NexaDiagram 컴포넌트:**

-   위치: `NEXA-Platform/src/diagram/NexaDiagram.vue`
-   범용 다이어그램 래퍼 컴포넌트
-   ERD, Flow, Network 등 다양한 다이어그램 타입 지원

**다이어그램 유틸리티:**

-   `diagramLayout.js`: 레이아웃 옵션 관리
-   `diagramZoom.js`: 줌/팬 기능
-   `diagramTheme.js`: 테마 관리
-   `diagramEvents.js`: 이벤트 처리

**활용 예시:**

```vue
<template>
    <NexaDiagram type="component-dependency" :data="componentDependencyData" :options="diagramOptions" @node-click="handleComponentClick" @node-hover="handleComponentHover" />
</template>
```

    - 컴포넌트 사용 통계 시각화

### 시나리오 1: 컴포넌트 구조 파악

1. **왼쪽 사이드바**에서 카테고리를 선택하여 컴포넌트 목록 확인
2. 특정 컴포넌트를 선택하여 **중간 컨텐츠 영역**에 상세 정보 표시
3. 중간에서 의존성 관계를 확인하여 컴포넌트 간 관계 파악
4. 필요시 **오른쪽 사이드바**에서 Props/Emits/Slots 등 추가 정보 확인

### 시나리오 1-1: 파일 구조 파악

1. **왼쪽 사이드바**에서 "파일 구조 보기" 하위 메뉴 클릭
2. **중간 컨텐츠 영역**에 디렉토리 구조와 파일 구조 상세 표시
3. D3 tree layout을 사용한 트리 시각화로 전체 구조 파악
4. 특정 디렉토리/파일 클릭 시 상세 정보 확인

### 시나리오 2: 리팩토링 계획 수립

1. **왼쪽 사이드바**에서 수정할 컴포넌트 선택
2. **중간 컨텐츠 영역**에서 코드 미리보기 및 의존성 관계 확인
3. **오른쪽 사이드바**에서 Props/Emits/Slots 확인
4. 중간에서 Dependents 목록 확인하여 영향받는 컴포넌트 파악
5. 오른쪽에서 빠른 액션으로 관련 파일 열기

### 시나리오 3: 새 기능 추가

1. **왼쪽 사이드바**에서 관련 컴포넌트 탐색
2. **중간 컨텐츠 영역**에서 기존 컴포넌트 구조를 참고하여 일관성 유지
3. 중간에서 의존성 관계를 확인하여 새로운 컴포넌트 배치 위치 결정
4. **오른쪽 사이드바**에서 사용 예제 생성 또는 관련 문서 확인
