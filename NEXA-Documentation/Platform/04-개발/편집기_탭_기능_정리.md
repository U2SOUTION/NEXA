# 편집기 탭 기능 정리

**작성일**: 2024년 12월  
**목적**: 데이터베이스 편집기 탭에서 제공하는 기능 목록 및 초보 개발자를 위한 가이드

---

## 📋 개요

편집기 탭은 데이터베이스 테이블을 시각적으로 관리하고 편집할 수 있는 기능을 제공합니다. 특히 초보 개발자가 데이터베이스 구조를 이해하고 쉽게 작업할 수 있도록 설계되었습니다.

---

## ✅ 현재 구현된 기능

### 1. 테이블 읽기 (읽기 모드)

**기능 설명:**

-   왼쪽 사이드바에서 테이블을 선택하면 테이블 구조를 읽기 전용으로 확인할 수 있습니다.
-   테이블명, 행 수량, 컬럼 수량을 한눈에 확인할 수 있습니다.

**표시 정보:**

-   테이블명 (큰 글씨)
-   행 수량 및 컬럼 수량 (세컨더리 컬러)
-   컬럼 상세 정보:
    -   컬럼명
    -   데이터 타입
    -   NULL 허용 여부
    -   키 타입 (PK, UNIQUE, INDEX)
    -   기본값
    -   코멘트

**초보자를 위한 장점:**

-   복잡한 SQL 명령어 없이 테이블 구조를 시각적으로 확인
-   각 컬럼의 역할과 속성을 쉽게 이해

---

### 2. 테이블 생성 (UI 구현 완료, 저장 기능 미구현)

**기능 설명:**

-   "새 테이블" 버튼을 클릭하여 새로운 테이블을 생성할 수 있습니다.
-   테이블명, 코멘트, 컬럼 정보를 입력할 수 있습니다.

**제공 기능:**

-   테이블명 입력
-   테이블 코멘트 입력
-   컬럼 추가/삭제
-   각 컬럼의 속성 설정:
    -   컬럼명
    -   데이터 타입 (셀렉트 박스로 선택)
    -   NULL 허용 여부 (체크박스)
    -   키 타입 (PK, UNIQUE, INDEX)
    -   기본값 (셀렉트 박스 + 직접 입력 가능)
    -   코멘트

**초보자를 위한 장점:**

-   데이터 타입을 셀렉트 박스로 선택하여 오타 방지
-   일반적인 기본값을 미리 제공하여 선택 용이
-   실시간으로 컬럼을 추가/삭제하여 유연한 테이블 설계

**미구현 기능:**

-   실제 데이터베이스에 테이블 생성 (저장 버튼 클릭 시)
-   유효성 검사 및 오류 메시지
-   테이블 생성 전 미리보기

---

### 3. 테이블 편집 (UI 구현 완료, 저장 기능 미구현)

**기능 설명:**

-   읽기 모드에서 "편집" 버튼을 클릭하면 테이블 구조를 수정할 수 있습니다.
-   컬럼 추가, 수정, 삭제가 가능합니다.

**제공 기능:**

-   기존 컬럼 정보 수정
-   새 컬럼 추가
-   컬럼 삭제
-   테이블 코멘트 수정

**초보자를 위한 장점:**

-   SQL `ALTER TABLE` 명령어를 몰라도 시각적으로 편집 가능
-   변경 사항을 취소할 수 있어 안전하게 실험 가능

**미구현 기능:**

-   실제 데이터베이스에 변경사항 저장 (저장 버튼 클릭 시)
-   컬럼 순서 변경
-   컬럼 타입 변경 시 데이터 손실 경고
-   변경 이력 및 되돌리기

---

### 4. 테이블 삭제 (다이얼로그만 구현, 실제 삭제 미구현)

**기능 설명:**

-   "삭제" 버튼을 클릭하면 테이블 삭제 확인 다이얼로그가 표시됩니다.
-   확인 시 테이블이 삭제됩니다.

**초보자를 위한 장점:**

-   삭제 전 확인 다이얼로그로 실수 방지
-   명확한 경고 메시지

**미구현 기능:**

-   실제 데이터베이스에서 테이블 삭제
-   외래키 관계 확인 및 경고
-   삭제 전 백업 옵션

---

### 5. 컬럼 관리

**제공 기능:**

-   컬럼 추가 (헤더 툴바 또는 테이블 하단 버튼)
-   컬럼 삭제 (각 컬럼 행의 삭제 버튼)
-   컬럼 속성 수정

**초보자를 위한 장점:**

-   직관적인 UI로 컬럼 추가/삭제
-   각 속성을 개별적으로 수정 가능

---

### 6. 데이터 타입 선택

**제공 기능:**

-   MySQL 데이터 타입을 셀렉트 박스로 선택
-   검색 기능으로 원하는 타입 빠르게 찾기
-   일반적인 데이터 타입 미리 제공:
    -   정수형: `INT`, `BIGINT`, `SMALLINT`, `TINYINT`
    -   실수형: `DECIMAL`, `FLOAT`, `DOUBLE`
    -   문자열: `VARCHAR`, `CHAR`, `TEXT`, `LONGTEXT`
    -   날짜/시간: `DATE`, `DATETIME`, `TIMESTAMP`, `TIME`
    -   기타: `BOOLEAN`, `JSON`, `BLOB`

**초보자를 위한 장점:**

-   데이터 타입 이름을 정확히 입력할 필요 없음
-   각 데이터 타입의 용도를 쉽게 파악
-   오타로 인한 오류 방지

---

### 7. 기본값 설정

**제공 기능:**

-   일반적인 기본값을 셀렉트 박스로 선택:
    -   `NULL`
    -   `0`, `''` (빈 문자열)
    -   `CURRENT_TIMESTAMP`
    -   기타 일반적인 값
-   직접 입력 가능 (셀렉트 박스에서 검색 또는 새 값 입력)

**초보자를 위한 장점:**

-   일반적인 기본값을 빠르게 선택
-   필요시 커스텀 값 입력 가능
-   SQL 문법을 몰라도 쉽게 설정

---

## 🚀 향후 구현 예정 기능 (초보 개발자 중심)

### 1. 유효성 검사 및 오류 메시지

**필요성:**

-   테이블명 중복 확인
-   컬럼명 중복 확인
-   필수 필드 검증
-   데이터 타입별 제약조건 검증

**초보자를 위한 장점:**

-   실수로 인한 오류를 사전에 방지
-   명확한 오류 메시지로 문제 해결 용이

---

### 2. 테이블 구조 미리보기

**기능:**

-   저장 전 테이블 구조를 SQL 문으로 미리보기
-   생성될 `CREATE TABLE` 문 표시

**초보자를 위한 장점:**

-   실제로 생성될 SQL을 확인하여 학습
-   저장 전 최종 확인 가능

---

### 3. 테이블 복사

**기능:**

-   기존 테이블을 복사하여 새 테이블 생성
-   구조만 복사 또는 데이터 포함 복사 옵션

**초보자를 위한 장점:**

-   비슷한 테이블을 빠르게 생성
-   기존 테이블을 템플릿으로 활용

---

### 4. 컬럼 순서 변경

**기능:**

-   드래그 앤 드롭으로 컬럼 순서 변경
-   또는 위/아래 화살표 버튼으로 순서 변경

**초보자를 위한 장점:**

-   직관적인 방법으로 컬럼 순서 조정
-   테이블 구조를 논리적으로 정리

---

### 5. 인덱스 관리

**기능:**

-   인덱스 추가/수정/삭제
-   인덱스 타입 선택 (PRIMARY, UNIQUE, INDEX)
-   인덱스 컬럼 선택

**초보자를 위한 장점:**

-   인덱스의 역할을 시각적으로 이해
-   성능 최적화를 위한 인덱스 관리 용이

---

### 6. 외래키 관계 관리

**기능:**

-   외래키 추가/수정/삭제
-   참조할 테이블 및 컬럼 선택
-   CASCADE 옵션 설정

**초보자를 위한 장점:**

-   테이블 간 관계를 시각적으로 설정
-   데이터 무결성 유지 방법 학습

---

### 7. 테이블 코멘트 관리

**기능:**

-   테이블 코멘트 추가/수정
-   각 컬럼의 코멘트 관리

**초보자를 위한 장점:**

-   테이블과 컬럼의 용도를 문서화
-   나중에 구조를 이해하기 쉬움

---

### 8. 변경 이력 및 되돌리기

**기능:**

-   편집 중 변경 이력 저장
-   이전 상태로 되돌리기
-   변경사항 비교

**초보자를 위한 장점:**

-   실수로 인한 손실 방지
-   안전하게 실험 가능

---

### 9. 도움말 및 툴팁

**기능:**

-   각 필드에 대한 설명 툴팁
-   데이터 타입별 가이드
-   제약조건 설명
-   예제 및 베스트 프랙티스

**초보자를 위한 장점:**

-   컨텍스트에 맞는 도움말 제공
-   학습 자료에 쉽게 접근

---

### 10. 테이블 내보내기/가져오기

**기능:**

-   테이블 구조를 SQL 파일로 내보내기
-   SQL 파일에서 테이블 구조 가져오기
-   JSON 형식으로 내보내기/가져오기

**초보자를 위한 장점:**

-   백업 및 공유 용이
-   다른 프로젝트에서 재사용 가능

---

### 11. 데이터 미리보기

**기능:**

-   테이블의 실제 데이터 미리보기 (읽기 전용)
-   행 수 제한 (예: 최대 100행)
-   간단한 필터링

**초보자를 위한 장점:**

-   테이블 구조와 실제 데이터를 함께 확인
-   데이터 타입과 실제 값의 관계 이해

---

### 12. SQL 쿼리 예제 생성

**기능:**

-   선택한 테이블에 대한 일반적인 SQL 쿼리 예제 생성:
    -   `SELECT * FROM table_name`
    -   `INSERT INTO table_name ...`
    -   `UPDATE table_name SET ...`
    -   `DELETE FROM table_name ...`

**초보자를 위한 장점:**

-   SQL 문법 학습
-   실제 사용 예제 확인

---

### 13. 테이블 비교

**기능:**

-   두 테이블의 구조 비교
-   차이점 하이라이트
-   동기화 옵션

**초보자를 위한 장점:**

-   테이블 간 차이를 쉽게 파악
-   마이그레이션 계획 수립 용이

---

### 14. 테이블 검색 및 필터링

**기능:**

-   테이블명으로 검색
-   컬럼명으로 검색
-   데이터 타입별 필터링

**초보자를 위한 장점:**

-   많은 테이블 중 원하는 테이블 빠르게 찾기
-   특정 속성을 가진 컬럼 찾기

### 15. 테이블 통계

**기능:**

-   테이블 크기
-   행 수

-   외래키 수
-   최근 수정일

**초보자를 위한 장점:**

## 🎯 초보 개발자를 위한 사용 시나리오

### 시나리오 1: 첫 번째 테이블 만들기

1. "새 테이블" 버튼 클릭
2. 테이블명 입력 (예: `users`)
3. 컬럼 추가:
    - `id`: INT, PK, 자동 증가
    - `name`: VARCHAR(100), NOT NULL
    - `email`: VARCHAR(255), UNIQUE
    - `created_at`: TIMESTAMP, 기본값 CURRENT_TIMESTAMP
4. 코멘트 입력
5. "저장" 버튼 클릭

### 시나리오 2: 기존 테이블 구조 확인

1. 왼쪽 사이드바에서 테이블 선택
2. 읽기 모드에서 테이블 구조 확인
3. 각 컬럼의 속성 확인
4. 필요시 "편집" 버튼으로 수정

### 시나리오 3: 테이블에 컬럼 추가

1. 테이블 선택 후 "편집" 버튼 클릭
2. "컬럼 추가" 버튼 클릭
3. 새 컬럼 정보 입력
4. "저장" 버튼 클릭

### 시나리오 4: 테이블 복사하여 새 테이블 만들기

1. 기존 테이블 선택
2. "테이블 복사" 기능 사용 (향후 구현)
3. 새 테이블명 입력
4. 필요시 컬럼 수정
5. "저장" 버튼 클릭
