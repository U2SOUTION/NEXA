# NEXA UI 샘플 개발 가이드

**작성일**: 2024년  
**목적**: Quasar 프레임워크와의 타협점을 찾아 UI 개발 시 시간을 절약하기 위한 가이드  
**버전**: 1.0 (진행 중 - 지속적으로 업데이트)

---

## 📋 문서 개요

이 문서는 **프론트엔드 UI 개발 시 Quasar 문법과 싸우느라 시간을 허비하지 않도록** 적절한 선을 지키면서 모든 UI 구성 시 참고할 **1번째 문서**가 되도록 정리한 가이드입니다.

### 핵심 목표

1. **Quasar 오버라이딩 최소화**: Quasar의 기본 기능을 최대한 활용하여 오버라이딩 시간 절약
2. **타협점 찾기**: Quasar 프레임워크의 기본 기능을 유지하면서 NEXA 테마의 일관성을 유지하는 적절한 타협점 제시
3. **실전 가이드**: 실제 UI 샘플을 통해 검증된 패턴 제공
4. **지속적 업데이트**: 진행하면서 발견한 타협점을 문서에 업데이트하여 누적

### 현재 상태

⚠️ **진행 중**: 몇 가지 UI 샘플을 만들었지만 아직 적절한 타협점은 완전히 찾지 못한 상태입니다. 진행해보면서 더 다듬고 이 문서에 업데이트할 예정입니다.

### 이 문서의 활용 방법

- **UI 개발 시작 전**: 이 문서를 먼저 참고하여 Quasar와의 타협점 확인
- **새로운 UI 구성 시**: 이 문서의 샘플과 패턴을 참고하여 개발
- **문제 발생 시**: 이 문서에 해결 방법을 추가하여 누적
- **타협점 발견 시**: 이 문서를 업데이트하여 팀과 공유

---

## 🎯 핵심 원칙

### Quasar와의 타협점

1. **Quasar 기본 기능 우선 활용**: 가능한 한 Quasar의 기본 기능과 스타일을 그대로 사용
2. **최소한의 오버라이딩**: 전역 CSS를 통한 최소한의 오버라이딩만 허용
3. **타협점 문서화**: 오버라이딩이 필요한 경우, 그 이유와 방법을 명확히 문서화
4. **일관성 유지**: NEXA 테마의 일관성을 유지하면서도 Quasar의 장점 활용

### 스타일링 원칙

- **전역 CSS 우선**: 모든 스타일은 전역 CSS로 해결 (`src/css/nexa-system/` 등)
- **컴포넌트별 스타일 금지**: 샘플 파일에 컴포넌트별 스타일을 넣지 않음
- **전역 해결책 검증**: 샘플은 문제를 발견하고 전역 해결책을 검증하는 용도
- **CSS 변수 활용**: 색상 등은 CSS 변수(`var(--nexa-*)`)를 사용하여 일관성 유지

## 📚 Quasar 오버라이딩 가이드

### 오버라이딩이 필요한 경우

다음과 같은 경우에만 Quasar를 오버라이딩합니다:

1. **NEXA 브랜딩**: NEXA 고유의 색상, 폰트 등 브랜딩 요소
2. **일관성 유지**: 프로젝트 전반에 걸친 일관된 스타일
3. **기능 확장**: Quasar 기본 기능으로 해결할 수 없는 특수한 요구사항

### 오버라이딩 방법

#### 1. 전역 CSS를 통한 오버라이딩

**위치**: `src/css/nexa-system/` 디렉토리

**원칙**:
- 색상 값 직접 정의 금지 (CSS 변수 사용: `var(--nexa-primary)` 등)
- 특정 모듈에 종속된 스타일 금지
- 전역적으로 적용 가능한 스타일만 정의

**파일 구조**:
- `nexa-system.scss` (메인 파일)
- `_form.scss`, `_item.scss`, `_card.scss`, `_table.scss`, `_list.scss`, `_chart.scss` (부분 파일)

#### 2. CSS 변수를 통한 테마 커스터마이징

Quasar의 CSS 변수를 활용하여 테마를 커스터마이징합니다:

```scss
// Quasar 변수 오버라이드
:root {
  --q-primary: var(--nexa-primary);
  --q-secondary: var(--nexa-secondary);
  // ...
}
```

### 오버라이딩 시 주의사항

1. **최소한의 오버라이딩**: 가능한 한 Quasar 기본 기능 활용
2. **문서화**: 오버라이딩한 이유와 방법을 이 문서에 기록
3. **일관성 유지**: 동일한 패턴을 반복 사용
4. **성능 고려**: 불필요한 CSS 오버라이딩은 성능에 영향을 줄 수 있음
