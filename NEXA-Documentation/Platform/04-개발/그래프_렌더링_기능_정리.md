# 그래프 렌더링 기능 정리

그래프 다이어그램 렌더링 관련 모든 기능을 정리한 문서입니다.

## 기능 목록

| 체크 | 항목명                                    | 기능 특징                                                  | 구현 상태 | 우선순위 | 비고                                      |
| :--: | :---------------------------------------- | :--------------------------------------------------------- | :-------: | :------: | :---------------------------------------- |
|  ☑   | **줌/팬 기본 기능**                       | 마우스 드래그로 그래프 이동, 마우스 휠로 줌 인/아웃        | ✅ 구현됨 |    -     | D3.js zoom 기본 기능                      |
|  ☑   | **관성 효과 (Inertia)**                   | 드래그 속도에 따라 마우스를 놓은 후에도 관성으로 이동      | ✅ 구현됨 |    -     | 드래그 속도 추적 및 애니메이션            |
|  ☑   | **화면 맞춤 (fitToScreen)**               | 그래프 전체가 화면에 맞도록 자동 스케일 및 중앙 정렬       | ✅ 구현됨 |    -     | 초기 렌더링 시 자동 적용                  |
|  ☑   | **수동 줌 설정 (setOptimalZoom)**         | 사용자가 직접 스케일과 위치를 지정하여 줌 설정             | ✅ 구현됨 |    -     | 자동 중앙정렬 옵션 포함                   |
|  ☑   | **줌 인/아웃 (zoomTo)**                   | 지정된 스케일 배율로 줌 인/아웃                            | ✅ 구현됨 |    -     | scaleBy 사용                              |
|  ☑   | **줌 리셋 (resetZoom)**                   | 줌 상태를 초기 상태로 리셋                                 | ✅ 구현됨 |    -     | zoomIdentity 적용                         |
|  ☑   | **현재 줌 상태 조회 (getCurrentZoom)**    | 현재 스케일, translateX, translateY 값 조회                | ✅ 구현됨 |    -     | 상태 저장/복원에 사용                     |
|  ☐   | **특정 영역으로 줌 (zoomToBounds)**       | 지정된 사각형 영역이 화면에 맞도록 줌                      | ❌ 미구현 |   높음   | 특정 노드/영역 포커스에 유용              |
|  ☐   | **특정 포인트 중심으로 줌 (zoomToPoint)** | 특정 좌표를 중심으로 줌 인/아웃                            | ❌ 미구현 |   중간   | 노드 클릭 시 해당 노드 중심으로 줌        |
|  ☐   | **줌 히스토리 (Undo/Redo)**               | 줌 상태 히스토리 관리 및 이전/다음 상태로 이동             | ❌ 미구현 |   높음   | 사용자 편의성 향상                        |
|  ☐   | **경계 제한 (Constrain Bounds)**          | 그래프가 화면 밖으로 나가지 않도록 제한                    | ❌ 미구현 |   중간   | 빈 공간 표시 방지                         |
|  ☐   | **더블클릭 줌**                           | 더블클릭으로 줌 인/아웃                                    | ❌ 미구현 |   낮음   | 빠른 줌 전환                              |
|  ☐   | **줌 레벨 프리셋**                        | 미리 정의된 줌 레벨로 빠르게 이동 (50%, 100%, 200% 등)     | ❌ 미구현 |   중간   | 빠른 줌 레벨 전환                         |
|  ☐   | **줌 애니메이션 제어**                    | 애니메이션 일시정지/재개/취소                              | ❌ 미구현 |   낮음   | 디버깅 및 성능 최적화                     |
|  ☐   | **마그네틱 스냅**                         | 특정 위치로 자동 정렬 (예: 노드 중심, 그리드)              | ❌ 미구현 |   낮음   | 정확한 위치 정렬                          |
|  ☐   | **줌 속도 제어**                          | 마우스 휠 줌 속도 조절                                     | ❌ 미구현 |   낮음   | 사용자 선호도에 맞춤                      |
|  ☐   | **터치 제스처 지원**                      | 모바일 터치 제스처 (핀치 줌, 두 손가락 팬)                 | ❌ 미구현 |   낮음   | 모바일 지원                               |
|  ☐   | **미니맵 (작은 창 네비게이션)**           | 전체 그래프를 축소하여 보여주는 미니맵, 클릭으로 이동      | ❌ 미구현 |   높음   | 큰 그래프에서 현재 위치 파악 및 빠른 이동 |
|  ☐   | **렌더링 대상 필터링**                    | 노드/엣지 타입, 속성에 따른 필터링 및 동적 표시/숨김       | ❌ 미구현 |   높음   | 복잡한 그래프에서 특정 요소만 표시        |
|  ☐   | **URL 프리셋**                            | 자주 사용하는 분석 대상 URL을 프리셋으로 저장 및 빠른 선택 | ❌ 미구현 |   중간   | 반복 작업 효율화                          |
|  ☐   | **즐겨찾기**                              | 자주 사용하는 그래프 설정/상태를 즐겨찾기로 저장           | ❌ 미구현 |   중간   | 빠른 접근                                 |
|  ☐   | **노드 검색**                             | 렌더링된 노드 중에서 이름/속성으로 검색                    | ❌ 미구현 |   높음   | 큰 그래프에서 특정 노드 찾기              |
|  ☐   | **노드 하일라이팅**                       | 검색된 노드 또는 선택된 노드를 하일라이팅하여 강조 표시    | ❌ 미구현 |   높음   | 검색 결과 시각화                          |
|  ☐   | **노드 클릭 이벤트**                      | 노드 클릭 시 상세 정보 표시 또는 액션 실행                 | ✅ 구현됨 |    -     | 이벤트 핸들러 지원                        |
|  ☐   | **노드 호버 이벤트**                      | 노드에 마우스 오버 시 정보 표시 또는 스타일 변경           | ✅ 구현됨 |    -     | 툴팁 또는 하일라이팅                      |
|  ☐   | **노드 드래그**                           | 노드를 드래그하여 위치 이동 (Force-Directed Graph)         | ✅ 구현됨 |    -     | Force 시뮬레이션과 연동                   |
|  ☐   | **엣지 클릭 이벤트**                      | 엣지(연결선) 클릭 시 정보 표시                             | ❌ 미구현 |   낮음   | 의존성 관계 상세 정보                     |
|  ☐   | **노드 선택 상태 관리**                   | 선택된 노드 표시 및 상태 유지                              | ✅ 구현됨 |    -     | selectedNode 옵션                         |
|  ☐   | **노드 고정 (Fixed Nodes)**               | 노드 위치를 고정하여 Force 시뮬레이션에서 이동 방지        | ✅ 구현됨 |    -     | Force-Directed Graph 전용                 |
|  ☐   | **다중 노드 선택**                        | 여러 노드를 동시에 선택                                    | ❌ 미구현 |   중간   | Ctrl/Cmd 클릭으로 다중 선택               |
|  ☐   | **노드 그룹화**                           | 관련 노드를 그룹으로 묶어서 표시                           | ❌ 미구현 |   낮음   | 복잡한 그래프 단순화                      |
|  ☐   | **노드 확장/축소**                        | 트리 구조에서 노드의 자식 노드 표시/숨김                   | ❌ 미구현 |   중간   | FileTree 다이어그램에 유용                |
|  ☐   | **노드 라벨 표시/숨김**                   | 노드 라벨 표시 여부 토글                                   | ✅ 구현됨 |    -     | showLabels 옵션                           |
|  ☐   | **엣지 라벨 표시/숨김**                   | 엣지 라벨 표시 여부 토글                                   | ❌ 미구현 |   낮음   | 의존성 관계 라벨                          |
|  ☐   | **노드 크기 조절**                        | 노드 크기 동적 조절 (노드 중요도, 연결 수 등에 따라)       | ✅ 구현됨 |    -     | nodeSize 설정                             |
|  ☐   | **노드 색상 커스터마이징**                | 노드 타입/속성에 따른 색상 지정                            | ✅ 구현됨 |    -     | 파일 타입별 색상                          |
|  ☐   | **엣지 스타일 커스터마이징**              | 엣지 스타일 (직선, 곡선, 베지어) 선택                      | ✅ 구현됨 |    -     | edgeStyle 옵션                            |
|  ☐   | **레이아웃 방향 변경**                    | 그래프 방향 변경 (LR, TB, RL, BT)                          | ✅ 구현됨 |    -     | rankdir 옵션                              |
|  ☐   | **노드 간격 조절**                        | 노드 간 가로/세로 간격 조절                                | ✅ 구현됨 |    -     | nodesep, ranksep 옵션                     |
|  ☐   | **그래프 마진 조절**                      | 그래프 전체의 여백 조절                                    | ✅ 구현됨 |    -     | marginx, marginy 옵션                     |
|  ☐   | **Force 시뮬레이션 파라미터**             | 반발력, 링크 거리, 링크 강도 등 조절                       | ✅ 구현됨 |    -     | Force-Directed Graph 전용                 |
|  ☐   | **설정 저장/로드**                        | 다이어그램 설정을 localStorage에 저장 및 로드              | ✅ 구현됨 |    -     | 타입별 독립 설정                          |
|  ☐   | **설정 초기화**                           | 설정을 기본값으로 리셋                                     | ✅ 구현됨 |    -     | resetDiagramSettings                      |
|  ☐   | **설정 검증**                             | 설정값이 유효 범위 내에 있는지 검증                        | ✅ 구현됨 |    -     | validateDiagramSettings                   |
|  ☐   | **애니메이션 이징**                       | 줌/팬 애니메이션 이징 함수 선택                            | ✅ 구현됨 |    -     | easing 옵션                               |
|  ☐   | **애니메이션 지속 시간**                  | 애니메이션 지속 시간 조절                                  | ✅ 구현됨 |    -     | duration 옵션                             |
|  ☐   | **폰트 크기 제한**                        | 줌 레벨에 관계없이 폰트 크기 고정                          | ✅ 구현됨 |    -     | Force-Directed Graph 전용                 |
|  ☐   | **다이어그램 타입별 렌더러**              | 타입에 따라 적절한 렌더러 자동 선택                        | ✅ 구현됨 |    -     | ERD, Flow, Network, Dependency, FileTree  |
|  ☐   | **에러 처리**                             | 렌더링 실패 시 에러 메시지 표시                            | ✅ 구현됨 |    -     | 에러 상태 관리                            |
|  ☐   | **로딩 상태 표시**                        | 렌더링 중 로딩 스피너 표시                                 | ✅ 구현됨 |    -     | isLoading 상태                            |
|  ☐   | **히스토리 관리**                         | 분석 이력 저장 및 뒤로가기/앞으로가기                      | ✅ 구현됨 |    -     | GraphDoc 히스토리 시스템                  |
|  ☐   | **VS Code 통합**                          | 노드 더블클릭으로 VS Code에서 파일 열기                    | ❌ 미구현 |   중간   | 개발 편의성 향상                          |
|  ☐   | **그래프 내보내기**                       | 그래프를 이미지(PNG, SVG) 또는 JSON으로 내보내기           | ❌ 미구현 |   중간   | 공유 및 문서화                            |
|  ☐   | **그래프 인쇄**                           | 그래프를 인쇄용으로 최적화하여 출력                        | ❌ 미구현 |   낮음   | 문서화 지원                               |
|  ☐   | **그래프 비교**                           | 두 그래프를 나란히 비교하여 표시                           | ❌ 미구현 |   낮음   | 변경 사항 분석                            |
|  ☐   | **실시간 업데이트**                       | 데이터 변경 시 그래프 자동 업데이트                        | ❌ 미구현 |   중간   | 동적 데이터 반영                          |
|  ☐   | **성능 모니터링**                         | 렌더링 성능 지표 표시 (FPS, 노드 수 등)                    | ❌ 미구현 |   낮음   | 최적화 지원                               |
|  ☐   | **접근성 지원**                           | 키보드 네비게이션, 스크린 리더 지원                        | ❌ 미구현 |   낮음   | 접근성 향상                               |
|  ☐   | **다국어 지원**                           | 라벨 및 메시지 다국어 지원                                 | ❌ 미구현 |   낮음   | 국제화                                    |
