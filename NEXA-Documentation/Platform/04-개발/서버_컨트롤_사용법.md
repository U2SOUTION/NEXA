# 서버 제어 가이드

백엔드 API 서버와 프론트엔드 개발 서버를 한 번에 제어하는 방법입니다.

> **용어 정리:**
>
> - **백엔드 서버**: Express API 서버 (포트 3000) - 데이터베이스와 통신하는 서버
> - **프론트엔드 개발 서버**: Quasar/Vite 개발 서버 (포트 9000) - 개발 중 프론트엔드를 제공하는 서버

## 방법 1: npm 스크립트 사용 (권장)

### 설치

```bash
npm install
```

### 사용법

#### 두 서버 동시 시작 (개발 모드)

```bash
npm run dev:all
```

#### 두 서버 동시 시작 (프로덕션 모드)

```bash
npm run start:all
```

#### 프론트엔드만 시작

```bash
npm run dev
```

#### 백엔드만 시작

```bash
npm run dev:server
```

### 중지 방법

- `Ctrl + C`를 눌러 두 서버를 모두 중지합니다.

---

## 방법 2: PowerShell 스크립트 사용 (선택 사항)

> **참고**: `npm run dev:all`만으로도 충분합니다. 이 방법은 서버 상태 확인이나 재시작이 필요할 때만 사용하세요.

### 사용법

#### 서버 시작

```powershell
.\server-control.ps1 start
```

#### 서버 중지

```powershell
.\server-control.ps1 stop
```

#### 서버 재시작

```powershell
.\server-control.ps1 restart
```

#### 서버 상태 확인

```powershell
.\server-control.ps1 status
```

### 실행 정책 설정 (최초 1회만)

PowerShell 스크립트를 실행하려면 실행 정책을 설정해야 할 수 있습니다:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## 포트 정보

- **프론트엔드 (Quasar)**: http://localhost:9000
- **백엔드 API**: http://localhost:3000

## 문제 해결

### 포트가 이미 사용 중인 경우

1. PowerShell 스크립트로 상태 확인: `.\server-control.ps1 status` (선택 사항)
2. 해당 포트를 사용하는 프로세스 종료: `.\server-control.ps1 stop` (선택 사항)
3. 또는 수동으로 프로세스 종료:

   ```powershell
   # 포트 3000 사용 프로세스 찾기
   Get-NetTCPConnection -LocalPort 3000 | Select-Object -ExpandProperty OwningProcess

   # 프로세스 종료 (PID를 위 명령어 결과로 대체)
   Stop-Process -Id <PID> -Force
   ```

### concurrently가 작동하지 않는 경우

```bash
npm install concurrently --save-dev
```
