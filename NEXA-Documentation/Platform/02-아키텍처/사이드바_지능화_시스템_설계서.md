# 사이드바 지능화 시스템 설계서

## 📋 개요

사이드바의 아코디언 섹션과 기능들을 지능적으로 자동화하여 사용자 경험을 향상시키는 시스템입니다.

## 🎯 목표

1. **맥락 기반 자동화**: 현재 상황에 맞는 섹션 자동 표시/숨김
2. **사용자 히스토리 학습**: 사용 패턴을 학습하여 개인화된 자동화
3. **사용자 설정 통합**: 사용자 선호도와 자동화의 균형
4. **AI 통합**: 향후 AI 기반 예측 및 추천 기능

## 🔍 왼쪽 사이드바 vs 오른쪽 사이드바

### 왼쪽 사이드바 (Left Sidebar)

**역할**: 네비게이션 및 목록 관리

**지능화 대상**:
- 파일 검색 제안 (히스토리 기반)
- 자주 사용하는 파일 우선 표시
- 검색어 자동완성
- 필터 자동 적용
- 파일 정렬 순서 최적화

**맥락 요소**:
- 파일 목록
- 검색 히스토리
- 파일 사용 빈도
- 작업 시간대
- 최근 작업 파일

### 오른쪽 사이드바 (Right Sidebar)

**역할**: 도구 및 설정 패널

**지능화 대상**:
- 아코디언 섹션 자동 표시/숨김
- 아코디언 자동 펼치기 우선순위
- 섹션 표시 조건 평가
- 사용자 작업 흐름에 따른 섹션 추천
- 섹션 간 충돌 방지

**맥락 요소**:
- 문서 내용 (Mermaid, 목차 등)
- 현재 작업 컨텍스트
- 사용자 액션 (헤더 아이콘 클릭 등)
- 섹션 사용 빈도
- 시간대별 사용 패턴

## 🧠 지능화 시스템 구성 요소

### 1. 공통 엔진 (intelligenceEngine.js)

**역할**: 기본 알고리즘 프레임워크

**기능**:
- 가중치 계산
- 우선순위 결정
- 설정 병합 (사용자 설정 + 기본값 + 맥락)
- 점수 기반 의사결정

**알고리즘**:
- 가중 평균 점수 계산
- 우선순위 정렬
- 임계값 기반 필터링

### 2. 맥락 분석기 (contextAnalyzer.js)

**역할**: 현재 상태 분석

**분석 대상**:
- 현재 파일/페이지
- 사용자 액션 (클릭, 스크롤 등)
- 시간대 (오전/오후/저녁)
- 작업 패턴 (읽기/편집/검색)
- 문서 내용 (Mermaid, 목차, 체크리스트 등)

**출력**:
- 컨텍스트 점수 (0-100)
- 컨텍스트 태그 (예: "mermaid-editing", "toc-browsing")
- 우선순위 힌트

### 3. 사용자 히스토리 추적 (userHistoryTracker.js)

**역할**: 사용 패턴 기록 및 분석

**추적 데이터**:
- 섹션 사용 빈도
- 섹션 사용 시간대
- 섹션 조합 패턴
- 파일별 섹션 사용 패턴
- 사용자 액션 시퀀스

**저장 위치**: localStorage (`NEXA-sidebar-intelligence-history`)

**분석 기능**:
- 빈도 분석
- 패턴 인식
- 선호도 계산
- 예측 점수 생성

### 4. AI 통합 (aiIntegration.js)

**역할**: AI 기반 예측 및 추천 (향후)

**기능**:
- 사용자 행동 예측
- 개인화된 추천
- 패턴 학습
- 적응형 자동화

## ⚙️ 오른쪽 사이드바 아코디언 자동화

### 섹션 레지스트리 패턴

**섹션 설정 객체 구조**:

```javascript
{
  id: 'mermaid-style',
  component: MermaidStyleSection,
  icon: 'palette',
  label: 'Mermaid 차트 스타일',
  priority: 1, // 낮을수록 우선순위 높음
  
  // 표시 조건
  visibilityCondition: (context) => {
    return context.hasMermaidBlocks
  },
  
  // 자동 펼치기 조건
  autoExpandCondition: (context) => {
    return context.mermaidIconClicked || 
           (context.hasMermaidBlocks && context.firstLoad)
  },
  
  // 자동 펼치기 우선순위
  expandPriority: 1
}
```

### 자동화 정책

**1. 조건 기반 표시**
- 각 섹션은 `visibilityCondition` 함수 제공
- 문서 내용, 파일 상태, 사용자 설정 등을 확인
- 조건이 true일 때만 아코디언 표시

**2. 우선순위 기반 자동 펼치기**
- 여러 섹션이 동시에 펼치기를 요청할 때 우선순위 적용
- 기본 정책: 한 번에 하나만 자동 펼치기 (최우선순위)
- 사용자 설정: "동시에 여러 개 펼치기" 옵션
- 수동 펼치기 시 자동 펼치기 취소

**3. 자동 펼치기 트리거**
- 문서 로드 시: 조건 만족 시 자동 펼치기
- 헤더 아이콘 클릭: 해당 섹션 자동 펼치기
- 외부 이벤트: 전역 이벤트로 특정 섹션 펼치기 요청
- 사용자 액션: 특정 작업 후 관련 섹션 자동 펼치기

### 섹션 상태 관리

**중앙 집중식 상태 관리**:
- Store에 섹션 상태 통합 관리
- 각 섹션의 표시/숨김, 펼침/접힘 상태 추적
- 파일별 섹션 상태 저장/복원
- 전역 설정: 자동 펼치기 활성화 여부

## 📊 데이터 저장 구조

### 사용자 히스토리

**localStorage 키**: `NEXA-sidebar-intelligence-history`

**구조**:
```javascript
{
  left: {
    fileUsage: {
      'file1.md': { count: 10, lastUsed: '2025-01-15T10:00:00' },
      'file2.md': { count: 5, lastUsed: '2025-01-14T15:00:00' }
    },
    searchHistory: ['검색어1', '검색어2'],
    filterPatterns: { ... }
  },
  right: {
    sectionUsage: {
      'mermaid-style': { count: 20, lastUsed: '2025-01-15T11:00:00' },
      'toc': { count: 15, lastUsed: '2025-01-15T09:00:00' }
    },
    expandPatterns: { ... },
    contextPatterns: { ... }
  },
  lastUpdated: '2025-01-15T12:00:00'
}
```

### 사용자 설정

**localStorage 키**: `NEXA-sidebar-intelligence-settings`

**구조**:
```javascript
{
  enabled: true,
  left: {
    autoSuggest: true,
    autoSort: true,
    historyBasedRecommendation: true
  },
  right: {
    autoExpand: true,
    autoExpandLevel: 'balanced', // 'conservative' | 'balanced' | 'aggressive'
    allowMultipleExpand: false,
    learnFromUsage: true
  },
  aiIntegration: {
    enabled: false, // 향후
    model: null
  }
}
```

## 📝 참고사항

### 확장성

- 새 섹션 추가 시 레지스트리에 등록만 하면 자동화 적용
- 기존 코드 수정 최소화
- 섹션 간 의존성 최소화

### 성능 최적화

- 조건 함수는 computed로 캐싱
- 섹션 컴포넌트는 lazy loading
- 불필요한 리렌더링 방지
- 히스토리 데이터는 주기적으로 정리

### 사용자 경험

- 자동화는 기본적으로 활성화
- 사용자가 언제든 수동으로 제어 가능
- 설정은 직관적으로 접근 가능
- 학습 데이터는 투명하게 관리
