# 칼라 템플릿 패널 시스템 문서

## 목표

- UI 구성 시 재사용 가능한 색상 템플릿을 관리하는 패널 시스템
- 보드, 패널, 노드 등 모든 UI 컴포넌트에서 호환되는 색상 템플릿 제공
- 최근 사용 색상과 템플릿을 동시에 보면서 템플릿 구성 및 관리
- SCSS 기본 색상과 병행하여 일관성 있게 오버라이딩 적용

---

## 핵심 개념

### 템플릿의 역할

**템플릿**: 특정 UI 구성 컨텍스트에서 재사용 가능한 색상 그룹

- 보드/패널 생성 시 빠른 색상 적용
- 프로젝트 간 일관된 디자인 유지
- SCSS 기본 색상 대비 특정 UI에 맞춘 커스터마이징

**호환성**: 템플릿이 적용 가능한 컴포넌트 타입

- 예: 게이지 패널 전용, 차트 패널 전용, 보드 전체 등

---

## 데이터 구조

### 템플릿 스키마

```typescript
interface ColorTemplate {
  // 기본 정보
  id: string // 고유 ID
  name: string // 템플릿 이름
  description?: string // 설명
  category?: string // 카테고리 (예: "보드", "패널", "노드")

  // 호환성 정보
  compatibleTypes: string[] // 호환 가능한 컴포넌트 타입
  // 예: ['panel:gauge', 'panel:chart', 'board:default']

  // 태그 (검색/필터링용)
  tags: string[] // 예: ['dashboard', 'monitoring', 'light-theme']

  // 색상 목록
  colors: ColorItem[] // 색상 배열

  // 메타데이터
  createdAt: number // 생성일시 (timestamp)
  updatedAt: number // 수정일시 (timestamp)
  isDefault?: boolean // 기본 템플릿 여부
  isFavorite?: boolean // 즐겨찾기 여부
}

interface ColorItem {
  variableName: string // CSS 변수명 (예: --nexa-primary)
  colorValue: string // 색상 값 (예: #00ff5e)
  order: number // 템플릿 내 순서
  description?: string // 색상 설명 (선택사항)
}
```

### 호환성 타입 정의

**패널 타입:**

- `panel:gauge` - 게이지 패널
- `panel:chart` - 차트 패널
- `panel:button` - 버튼 제어 패널
- `panel:text-note` - 텍스트 노트 패널
- `panel:device-status` - 디바이스 상태 패널
- `panel:*` - 모든 패널 (와일드카드)

**보드 타입:**

- `board:default` - 기본 보드
- `board:dashboard` - 대시보드 보드
- `board:monitoring` - 모니터링 보드

**노드 타입:**

- `node:default` - 기본 노드
- `node:automation` - 자동화 노드
- `node:*` - 모든 노드

## UI 구조

### 오른쪽 사이드바: 칼라 템플릿 패널

**위치:** `src/components/sidebars/right/dev-tools/ColorTemplatePanel.vue`

**구성 요소:**

1. **템플릿 리스트 섹션**

   - 호환성 필터 (현재 컨텍스트에 맞는 템플릿만 표시)
   - 템플릿 카드 리스트 (이름, 미리보기, 호환 타입 표시)
   - 템플릿 검색/필터링

2. **템플릿 상세 섹션 (선택된 템플릿)**

   - 템플릿 색상 리스트 (최근 탭과 유사한 UI)
   - 색상 추가/삭제/순서 변경 (드래그 앤 드롭)
   - 템플릿 편집 (이름, 설명, 호환 타입, 태그)

3. **템플릿 생성 섹션**
   - 최근 색상에서 선택하여 새 템플릿 생성
   - 빈 템플릿 생성 후 수동 추가

### 왼쪽 사이드바: 최근 탭과의 통합

- 최근 탭에서 색상을 선택
- 오른쪽 템플릿 패널로 드래그하여 추가
- 또는 템플릿 패널에서 "최근에서 추가" 버튼 클릭

## 통합 시나리오

### 시나리오 1: 보드에서 패널 생성 시 템플릿 적용

**플로우:**

1. 사용자가 보드에서 새 패널 추가
2. 패널 타입 선택 (예: 게이지 패널)
3. 패널 생성 다이얼로그에 "색상 템플릿 적용" 옵션 표시
4. 칼라 템플릿 패널에서 호환 템플릿 필터링 (`panel:gauge` 호환)
5. 사용자가 템플릿 선택
6. 템플릿의 색상들을 패널 설정에 자동 적용
7. 패널 생성 완료

**기술적 구현:**

- `NexaPanelDialog.vue` 또는 패널 생성 모달에 템플릿 선택 UI 추가
- 선택된 템플릿의 색상을 패널 `content` 설정에 매핑
- SCSS 기본 색상보다 우선 적용 (CSS 변수 오버라이딩)

### 시나리오 2: 노드 생성 시 템플릿 적용

**플로우:**

1. 노드 에디터에서 새 노드 생성
2. 노드 타입 선택
3. 노드 설정 다이얼로그에서 호환 템플릿 표시
4. 템플릿 선택 → 노드 색상 설정 자동 구성

**기술적 구현:**

- 노드 생성 컴포넌트와 템플릿 패널 통신
- 노드 타입별 호환 템플릿 필터링

### 시나리오 3: SCSS 기본 색상과 오버라이딩 병행

**개념:**

- SCSS (`dark.scss`, `light.scss`): 전역 기본 색상 정의
- 템플릿: 특정 UI 컴포넌트에만 적용되는 오버라이드

**적용 방식:**

1. 컴포넌트에 템플릿 적용 시
2. 템플릿 색상을 CSS 변수로 런타임 오버라이드
3. 전역 SCSS는 유지, 해당 컴포넌트만 커스텀 색상 적용
4. 일관성 유지하면서 특정 UI만 디자인 커스터마이징

**예시:**

```css
/* 전역 SCSS */
--nexa-primary: #00ff5e;

/* 템플릿 적용 시 (컴포넌트 레벨) */
.panel-gauge {
  --nexa-primary: #ff8400; /* 오렌지 테마로 오버라이드 */
}
```

## 기능 명세

### 1. 템플릿 관리

#### 템플릿 생성

- 최근 색상에서 선택하여 생성
- 현재 활성 색상들을 템플릿으로 저장
- 빈 템플릿 생성 후 수동 추가
- 기존 템플릿 복제하여 수정

#### 템플릿 편집

- 이름, 설명 수정
- 호환 타입 추가/제거
- 태그 추가/제거
- 색상 추가/삭제/순서 변경

#### 템플릿 삭제

- 사용자 생성 템플릿만 삭제 가능
- 기본 템플릿은 삭제 불가
- 삭제 확인 다이얼로그

### 2. 호환성 필터링

#### 자동 필터링

- 현재 작업 컨텍스트 감지 (보드 생성, 패널 추가 등)
- 해당 컨텍스트와 호환되는 템플릿만 표시
- 와일드카드 타입 (`panel:*`) 지원

#### 수동 필터링

- 사용자가 필터 옵션 선택
- 호환 타입별 필터링
- 태그별 필터링
- 카테고리별 필터링

### 3. 템플릿 적용

#### 자동 적용

- 컴포넌트 생성 시 템플릿 선택
- 선택한 템플릿의 색상을 컴포넌트 설정에 자동 매핑
- CSS 변수 오버라이드로 런타임 적용

#### 수동 적용

- 기존 컴포넌트에 템플릿 적용
- 컴포넌트 설정에서 템플릿 선택
- 일부 색상만 선택적으로 적용 가능

### 4. 템플릿 미리보기

- 색상 스왑 시각화
- 각 색상의 변수명과 값 표시
- 실제 UI 컴포넌트에서의 적용 미리보기 (향후)

## 호환성 규칙

### 호환 타입 매칭 규칙

1. **정확 일치**

   - `panel:gauge` → `panel:gauge` 템플릿만 표시

2. **와일드카드**

   - `panel:*` → 모든 패널 타입에 호환
   - `*` → 모든 컴포넌트 타입에 호환

3. **다중 타입**
   - 템플릿이 여러 타입에 호환 가능
   - 예: `['panel:gauge', 'panel:chart']`

### 우선순위

1. 정확 일치 템플릿
2. 와일드카드 템플릿
3. 기본 템플릿 (fallback)

## 참고사항

- 템플릿은 SCSS 기본 색상을 대체하지 않고 오버라이드
- 템플릿 적용은 런타임 CSS 변수 오버라이딩으로 처리
- 영구 저장은 컴포넌트 설정에 포함 (JSON)
