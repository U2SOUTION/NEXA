# 개발자 중심의 전문 테마 색상 관리툴

## 개요

현재 `/settings` 페이지에 구현된 테마 색상 표시 기능을 `/dev` 페이지로 이동하여 개발자 중심의 전문적인 테마 색상 관리 도구로 발전시킵니다.

## 현재 구현 상태

### 기존 기능 (Settings 페이지)
- 활성 테마의 모든 CSS 색상 변수 자동 추출
- 변수명 패턴 기반 자동 카테고리 분류
- 카테고리별 색상 그리드 표시
- 색상 박스 클릭 시 변수명 복사
- 테마 전환 (라이트/다크)
- 번역 기능 (영문 카테고리명 → 한글)

### 기술 스택
- `src/utils/themeColorParser.js`: CSS 변수 추출 및 분류
- `src/components/settings/ThemeSettings.vue`: UI 컴포넌트

## 개발자 중심 기능 제안

### 핵심 기능 (우선순위 높음)

#### 1. 색상 수정 및 지정
- **실시간 색상 편집**
  - 색상 박스 클릭 → 색상 피커 열기
  - HEX, RGB, HSL 입력 지원
  - 실시간 미리보기 (변경 즉시 반영)
  - 변경 사항 임시 저장 (브라우저 새로고침 전까지 유지)

- **색상 값 직접 편집**
  - 색상 값 텍스트 클릭 → 인라인 편집
  - 유효성 검증 (색상 형식 체크)
  - 자동 완성 (기존 색상 값 제안)

- **일괄 변경**
  - 여러 변수 선택 → 일괄 색상 조정
  - 밝기/채도 조정 슬라이더
  - 색상 팔레트에서 일괄 적용

#### 2. 정렬 기능
- **카테고리 정렬**
  - 알파벳 순 (기본)
  - 사용 빈도 순 (코드베이스 분석)
  - 수동 정렬 순 (드래그 앤 드롭)
  - 변수 개수 순

- **카테고리 내부 정렬**
  - 변수명 알파벳 순 (기본)
  - 사용 빈도 순
  - 수동 정렬 순 (드래그 앤 드롭)
  - 색상 값 순 (밝기, 색상 계열)
  - CSS 파일 정의 순서

#### 3. 사용 빈도 분석
- **코드베이스 전체 스캔**
  - 버튼 클릭 시에만 실행 (부하 최소화)
  - `.vue`, `.scss`, `.css`, `.js`, `.ts` 파일 스캔
  - `var(--nexa-{변수명})` 패턴 검색
  - 인라인 스타일, CSS 클래스 내부 사용 추적

- **통계 데이터**
  - 변수별 사용 횟수
  - 파일별 사용 위치
  - 사용 빈도 기반 정렬

### 고급 기능 (우선순위 중간)

#### 4. CSS 파일 직접 수정
- 변경사항을 SCSS 파일에 자동 반영
- 변경 이력 관리
- 롤백 기능

#### 5. 색상 테마 관리
- 현재 변경사항을 새 테마로 저장
- 테마 복사/이름 변경/삭제
- 테마 간 비교 (diff)

#### 6. 색상 검색 및 필터
- 색상 값으로 검색 (HEX, RGB)
- 색상 범위 필터 (밝기, 채도, 색상)
- 사용되지 않는 변수 표시

#### 7. 실시간 미리보기
- 변경 즉시 전체 UI에 반영
- 다크/라이트 모드 전환 테스트
- 컴포넌트별 미리보기 패널

### 전문 기능 (우선순위 낮음)

#### 8. 색상 관계 시각화
- 색상 팔레트 맵 (색상 공간에서의 위치)
- 유사 색상 그룹화
- 대비 분석 (접근성 체크)

#### 9. 색상 분석 및 제안
- 접근성 점수 (WCAG 준수 여부)
- 색상 조화 분석
- 대체 색상 제안

#### 10. 색상 가져오기/내보내기
- JSON/SCSS 형식으로 내보내기
- 다른 프로젝트에서 가져오기
- 색상 팔레트 파일 (Adobe Swatch 등) 지원

## UI/UX 제안

### 레이아웃 구조

```
[DEV 페이지]
├─ 왼쪽: 문서 목록 (기존)
├─ 중앙: 문서 내용 (기존)
└─ 우측 사이드바: 개발 도구
   ├─ Mermaid 편집 (기존)
   └─ 테마 색상 관리 (신규)
      ├─ 헤더: 테마 전환 + 정렬 옵션
      ├─ 색상 목록 (카테고리별)
      ├─ 색상 편집 패널 (우측 확장)
      └─ 사용 빈도 분석 버튼
```

### 색상 편집 UI

- **색상 박스 클릭** → 우측에 편집 패널 표시
  - 색상 피커 (시각적 선택)
  - HEX/RGB/HSL 입력 필드
  - 실시간 미리보기
  - 저장/취소 버튼

- **색상 값 텍스트 클릭** → 인라인 편집 모드
  - 직접 입력 가능
  - 유효성 검증
  - Enter로 저장, ESC로 취소

### 주요 기능별 구현

#### 색상 편집
- Quasar `q-color` 컴포넌트 활용
- 또는 커스텀 색상 피커 구현
- 변경사항은 로컬 스토리지에 임시 저장

#### 사용 빈도 분석
- Vite의 `import.meta.glob`로 파일 스캔
- 정규식으로 CSS 변수 사용 패턴 검색
- 비동기 처리로 성능 최적화

#### 정렬 기능
- Vue Draggable 또는 HTML5 Drag & Drop API
- 로컬 스토리지에 정렬 순서 저장
- 정렬 옵션별 computed 속성으로 필터링

## 참고사항

- 현재 `/settings` 페이지의 기능은 그대로 유지
- `/dev` 페이지로 이동 후 개발자 중심 기능 추가
- 레이아웃 변경 최소화 (기존 구조 유지)
- 성능 최적화 (버튼 클릭 시에만 분석 실행)
