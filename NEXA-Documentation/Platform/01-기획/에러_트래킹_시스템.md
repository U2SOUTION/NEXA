# 에러 트래킹 시스템

## 목적

-   애플리케이션 실행 중 발생하는 모든 에러를 자동으로 수집, 분석, 추적
-   에러 발생 패턴 파악 및 빠른 디버깅 지원
-   에러 통계 및 트렌드 분석을 통한 코드 품질 개선
-   프로덕션 환경에서의 에러 모니터링 및 알림
-   **에러 패턴을 AI 컨텍스트로 제공하여 동일한 실수 방지 및 코드 품질 향상**
-   **시스템 전체 구조의 취약점을 사전에 파악하여 예방적 개선 지원**

## 목표

1. **자동 에러 수집**: 전역 에러 핸들러를 통한 자동 에러 캡처
2. **에러 분석**: 에러 유형, 발생 위치, 빈도 등 상세 분석
3. **빠른 디버깅**: 스택 트레이스, 컨텍스트 정보 제공
4. **통계 및 시각화**: 에러 발생 추이, 유형별 분포 차트 제공
5. **에러 그룹화**: 유사한 에러를 자동으로 그룹화하여 중복 제거
6. **AI 컨텍스트 제공**: 에러 패턴을 AI에게 제공하여 동일한 실수 방지 및 안전한 코드 생성 지원
7. **시스템 취약성 파악**: 에러 패턴 분석을 통해 시스템 전체의 취약점을 식별하고 개선 우선순위 제시

## 주요 기능

### 1. 자동 에러 수집

-   **전역 에러 핸들러**

    -   `window.onerror`: JavaScript 에러 캡처
    -   `unhandledrejection`: Promise rejection 캡처
    -   Vue 에러 핸들러: Vue 컴포넌트 에러 캡처
    -   네트워크 에러: fetch/XHR 에러 캡처

-   **에러 정보 수집**
    -   에러 메시지
    -   스택 트레이스
    -   발생 파일 및 라인 번호
    -   발생 시간
    -   사용자 컨텍스트 (URL, User Agent 등)
    -   브라우저 정보

### 2. 에러 그룹화

-   **유사 에러 자동 그룹화**

    -   에러 메시지 유사도 기반
    -   스택 트레이스 유사도 기반
    -   발생 위치 기반
    -   같은 에러의 반복 발생을 하나로 묶음

-   **그룹 정보**
    -   그룹 내 에러 발생 횟수
    -   첫 발생 시간 및 마지막 발생 시간
    -   발생 빈도 통계

### 3. 에러 필터링 및 검색

-   **필터 옵션**

    -   에러 레벨 (Error, Warning)
    -   발생 시간 범위
    -   에러 상태 (새 에러, 해결됨, 무시됨)
    -   에러 유형
    -   발생 파일/컴포넌트

-   **검색 기능**
    -   에러 메시지 검색
    -   파일명 검색
    -   스택 트레이스 검색
    -   정규식 검색 지원

### 4. 에러 상세 정보

-   **스택 트레이스 표시**

    -   클릭 가능한 파일명/라인 번호
    -   코드 스니펫 표시
    -   스택 프레임별 상세 정보

-   **컨텍스트 정보**

    -   발생 시점의 URL
    -   사용자 에이전트
    -   화면 정보
    -   상태 정보 (가능한 경우)

-   **발생 이력**
    -   같은 에러의 발생 이력 타임라인
    -   각 발생 시점의 컨텍스트

### 5. 통계 및 시각화

-   **에러 발생 추이 차트** (NexaChart - 라인 차트)

    -   시간별 에러 발생 추이
    -   일별/주별/월별 선택 가능
    -   에러 레벨별 색상 구분

-   **에러 유형별 분포 차트** (NexaChart - 파이/도넛 차트)

    -   에러 유형별 비율
    -   발생 횟수 표시

-   **에러 발생 위치 히트맵**

    -   파일별 에러 발생 빈도
    -   컴포넌트별 에러 발생 빈도
    -   시각적 강조 표시

-   **에러 의존성 다이어그램** (NexaDiagram)
    -   에러 간 연관성 시각화
    -   에러 체인 다이어그램
    -   원인-결과 관계 표시

### 6. 에러 관리

-   **에러 상태 관리**

    -   새 에러: 최근 발생한 에러
    -   해결됨: 개발자가 해결 표시한 에러
    -   무시됨: 무시하도록 표시한 에러

-   **에러 액션**
    -   에러 해결 표시
    -   에러 무시
    -   에러 삭제
    -   에러 내보내기

### 7. 알림 및 모니터링

-   **에러 발생 알림**

    -   중요 에러 발생 시 알림 표시
    -   알림 사운드 설정
    -   알림 빈도 제한

-   **실시간 모니터링**
    -   새 에러 발생 시 자동 업데이트
    -   에러 통계 실시간 갱신

### 8. 에러 패턴 분석 및 AI 컨텍스트 제공

-   **에러 패턴 추출**

    -   자주 발생하는 에러 패턴 식별
    -   에러 메시지 유사도 분석
    -   발생 위치 기반 패턴 그룹화
    -   시간대별 패턴 분석

-   **개발자 실수 패턴 분석**

    -   반복적으로 발생하는 개발자 실수 식별
    -   실수 유형별 분류 (props 기본값 누락, null 체크 누락 등)
    -   실수 발생 위치 및 빈도 추적
    -   예방 방법 제시

-   **AI 컨텍스트 자동 생성**

    -   에러 패턴을 마크다운 형식으로 변환

    -   예방적 코드 리뷰 (코드 작성 전 잠재적 에러 감지)

### 9. 시스템 취약성 파악

-   **파일/컴포넌트 취약점 분석**

## AI 컨텍스트 활용 및 시스템 취약성 파악

### 핵심 가치

에러 트래킹 시스템의 가장 중요한 가치 중 하나는 **에러 패턴을 학습하여 미래의 실수를 방지**하고, **시스템 전체의 취약점을 사전에 파악**하는 것입니다.

### 1. AI 컨텍스트 활용

#### 1.1 에러 패턴 → AI 컨텍스트 변환

에러 패턴 분석 결과를 AI가 이해할 수 있는 구조화된 컨텍스트로 변환합니다:

```javascript
// AI 컨텍스트 데이터 구조
{
  frequentErrors: [
    {
      message: "TypeError: Cannot read property 'x' of undefined",
      frequency: 45,
      commonCause: "비동기 데이터 로딩 전 접근",
      preventionTip: "옵셔널 체이닝(?.) 또는 null 체크 추가"
    }
  ],
  commonMistakes: [
    {
      mistake: "props 기본값 누락",
      occurrences: 23,
      solution: "props 정의 시 항상 default 값 제공"
    }
  ],
  codingGuidelines: [
    "비동기 데이터는 항상 로딩 상태 확인 후 접근",
    "props 정의 시 기본값 필수 제공"
  ]
}
```

#### 1.2 실시간 AI 지원

코드 작성 요청 시 자동으로 에러 패턴 컨텍스트를 포함하여 AI에게 제공:

```
사용자: "새로운 컴포넌트를 만들어줘"

AI가 자동으로 포함하는 컨텍스트:
- 이 프로젝트에서 자주 발생하는 에러: props 기본값 누락 (23회)
- 주의사항: 비동기 데이터 접근 시 null 체크 필수
- 권장 패턴: 옵셔널 체이닝 사용
```

#### 1.3 예방적 코드 리뷰

코드 작성 전 잠재적 에러 패턴을 감지하여 경고:

```javascript
// 코드 작성 전 자동 체크
if (matchesErrorPattern(newCode, errorPatterns)) {
    warnings.push({
        type: "POTENTIAL_ERROR",
        pattern: errorPattern.message,
        suggestion: errorPattern.preventionTip,
    });
}
```

### 2. 시스템 취약성 파악

#### 2.1 취약점 분석 알고리즘

-   **파일별 에러 집중도**: 에러가 10회 이상 발생한 파일 식별
-   **컴포넌트별 에러율**: 컴포넌트의 에러율이 10% 이상인 경우 취약점으로 분류
-   **에러 체인 분석**: 5초 이내 연속 발생하는 에러를 연쇄 에러로 감지
-   **의존성 취약점**: 같은 파일/컴포넌트에서 발생하는 연관 에러 분석

#### 2.2 취약점 시각화

취약점을 다이어그램으로 시각화하여 시스템 구조의 문제점을 한눈에 파악:

```javascript
// 취약점 다이어그램 데이터
{
  nodes: [
    { id: 'file-1', label: 'ComponentA.vue', risk: 'HIGH', errorCount: 15 },
    { id: 'component-1', label: 'ComponentB', risk: 'MEDIUM', errorRate: 0.12 }
  ],
  edges: [
    { from: 'file-1', to: 'component-1', type: 'contains', risk: 'HIGH' }
  ]
}
```

#### 2.3 취약점 리포트

주간/월간 취약점 리포트를 자동 생성하여 시스템 건강도를 추적:

```javascript
{
  period: "2024-12-01 ~ 2024-12-07",
  summary: {
    totalErrors: 156,
    newVulnerabilities: 3,
    resolvedVulnerabilities: 1,
    overallRisk: "MEDIUM"
  },
  criticalIssues: [
    {
      area: "비동기 처리",
      affectedFiles: 12,
      recommendation: "전역 에러 바운더리 추가 필요"
    }
  ]
}
```

### 3. 기대 효과

#### 3.1 AI 컨텍스트 활용 효과

-   **실수 방지**: 자주 발생하는 에러 패턴을 사전에 피하여 코드 품질 향상
-   **학습 효과**: 에러 패턴을 학습하여 프로젝트 특성에 맞는 코드 생성
-   **개발 효율성**: AI가 프로젝트의 취약점을 이해하여 더 정확한 코드 생성

#### 3.2 시스템 취약성 파악 효과

-   **예방적 개선**: 취약한 부분을 사전에 파악하여 문제 발생 전 개선
-   **우선순위 결정**: 에러율이 높은 부분부터 개선하여 효율적인 리팩토링
-   **구조적 문제 발견**: 아키텍처 레벨의 문제를 발견하여 근본적인 개선

### 4. 구현 예시

#### 4.1 AI 컨텍스트 생성

```javascript
// src/utils/error-tracking/errorContextGenerator.js
export function generateErrorContextForAI(errorPatterns) {
    return `
# 에러 패턴 분석 결과 (AI 컨텍스트)

## 자주 발생하는 에러 패턴
${errorPatterns.frequentErrors
    .map(
        (e) => `
### ${e.message}
- 발생 횟수: ${e.frequency}회
- 주요 원인: ${e.commonCause}
- 예방 방법: ${e.preventionTip}
`
    )
    .join("\n")}

## 개발자 실수 패턴
${errorPatterns.commonMistakes
    .map(
        (m) => `
- **${m.mistake}**: ${m.solution}
`
    )
    .join("\n")}
  `.trim();
}
```

#### 4.2 취약점 분석

```javascript
// src/utils/error-tracking/vulnerabilityAnalyzer.js
export function analyzeSystemVulnerabilities(errors) {
    // 파일별 에러 집중도
    const fileErrorMap = groupErrorsByFile(errors);
    const highErrorFiles = Object.entries(fileErrorMap)
        .filter(([file, count]) => count > 10)
        .map(([file, count]) => ({
            file,
            errorCount: count,
            risk: "HIGH",
            type: "ERROR_PRONE_FILE",
        }));

    // 에러 체인 분석
    const errorChains = detectErrorChains(errors);

    return {
        fileLevel: highErrorFiles,
        errorChains: errorChains,
        overallRisk: calculateOverallRisk(highErrorFiles, errorChains),
    };
}
```
