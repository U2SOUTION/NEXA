## 시스템 개요

NEXA는 **스마트 IoT 플랫폼**으로, ESP32 기반 디바이스를 관리하고 시각화하는 통합 시스템입니다.

### 핵심 개념

-   **Monorepo 구조**: 모든 프로젝트를 하나의 저장소에서 통합 관리
-   **중앙 집중식 데이터 관리**: NEXA-Platform이 모든 데이터의 중계소 역할
-   **멀티 플랫폼 지원**: Web, Desktop, Mobile, Edge 디바이스 지원

---

## 시스템 구조

```
NEXA/
├── NEXA-Platform/        # 🌐 웹 플랫폼 (중계소/데이터 관리)
├── NEXA-Desktop/         # 💻 데스크톱 애플리케이션
├── NEXA-Edeg/            # 🔌 엣지 디바이스 (ESP32)
├── NEXA-App/             # 📱 모바일 애플리케이션
├── NEXA-Documentation/   # 📚 통합 문서
└── DEV/                  # 🛠️ 개발 도구 (VS Code 확장)
```

### 각 프로젝트의 역할

| 프로젝트          | 역할                               | 기술 스택               |
| ----------------- | ---------------------------------- | ----------------------- |
| **NEXA-Platform** | 중계소, 데이터 관리, 웹 인터페이스 | Vue 3, Quasar, Node.js  |
| **NEXA-Desktop**  | 데스크톱 클라이언트                | Python, PyQt            |
| **NEXA-Edge**     | IoT 디바이스 펌웨어                | C++, PlatformIO, ESP32  |
| **NEXA-App**      | 모바일 클라이언트                  | (계획 중)               |
| **DEV**           | 개발 도구                          | TypeScript, VS Code API |

## 핵심 플랫폼 구성

### 1. NEXA-Platform (중계소)

**역할:**

-   모든 데이터의 중앙 관리
-   다른 플랫폼 간 데이터 중계
-   웹 기반 관리 인터페이스 제공
-   API 서버 역할

**주요 기능:**

-   ESP32 디바이스 등록 및 관리
-   실시간 데이터 수집 및 저장
-   대시보드 시각화
-   부품 관리 시스템
-   문서 관리 시스템

### 2. NEXA-Desktop (데스크톱 클라이언트)

**역할:**

-   로컬 데스크톱 환경에서의 작업 지원
-   화면 그리기 도구 (ScreenDraw)
-   작업 관리 도구

**주요 기능:**

-   화면 캡처 및 주석 도구
-   작업 시간 관리
-   로컬 파일 관리

### 3. NEXA-Edge (엣지 디바이스)

**역할:**

-   IoT 디바이스 펌웨어
-   센서 데이터 수집
-   NEXA-Platform과 통신

**주요 기능:**

-   OTA (Over-The-Air) 업데이트
-   센서 데이터 전송
-   디바이스 제어

### 4. NEXA-App (모바일 클라이언트)

**역할:**

-   모바일 환경에서의 접근
-   휴대성 있는 모니터링 및 제어

**상태:** 계획 중

## 데이터 흐름

### 데이터 흐름도

```
┌─────────────┐
│ NEXA-Edge   │ (ESP32 디바이스)
│  (센서)     │
└──────┬──────┘
       │ 센서 데이터 전송
       ▼
┌─────────────────┐
│ NEXA-Platform   │ ◄──┐
│  (중계소/DB)    │    │
└──────┬──────────┘    │
       │               │ 데이터 조회
       │               │
       ▼               │
┌─────────────┐        │
│ NEXA-Desktop│        │
└─────────────┘        │
                        │
┌─────────────┐        │
│  NEXA-App   │ ───────┘
└─────────────┘
```

### 데이터 관리 원칙

1. **단일 소스 원칙**: 모든 데이터는 NEXA-Platform에서 관리
2. **실시간 동기화**: 변경사항은 즉시 다른 클라이언트에 반영
3. **중앙 집중식 저장**: 데이터베이스는 NEXA-Platform에 위치

## 통신 아키텍처

### 통신 프로토콜

| 통신 경로          | 프로토콜       | 용도                            |
| ------------------ | -------------- | ------------------------------- |
| Edge → Platform    | HTTP/WebSocket | 센서 데이터 전송, 디바이스 제어 |
| Desktop → Platform | HTTP/WebSocket | 데이터 조회, 설정 동기화        |
| App → Platform     | HTTP/WebSocket | 모바일 접근 (계획)              |

### API 구조

```
NEXA-Platform (API Server)
├── /api/devices      # 디바이스 관리
├── /api/data         # 데이터 조회
├── /api/parts        # 부품 관리
└── /api/documents    # 문서 관리
```

## 개발 환경

### Monorepo 구조

-   **단일 Git 저장소**: 모든 프로젝트 통합 관리
-   **공통 설정**: `.gitignore`, `.editorconfig` 등 공유
-   **통합 문서**: `NEXA-Documentation/`에서 모든 문서 관리

### 개발 워크플로우

1. **로컬 개발**: 각 프로젝트별 독립 개발 환경
2. **통합 테스트**: NEXA-Platform을 통한 통합 테스트
3. **버전 관리**: 단일 저장소에서 버전 관리

### 빌드 및 배포

-   각 프로젝트는 독립적으로 빌드 가능
-   NEXA-Platform이 배포의 중심점
-   Edge 디바이스는 OTA를 통한 원격 업데이트
