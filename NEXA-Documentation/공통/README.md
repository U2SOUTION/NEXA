# 공통 문서

레이어 간 공통 문서 및 전체 시스템 문서를 관리합니다.

## 문서 분류 기준

### 이 폴더에 넣을 문서

- **2개 이상 레이어에 공통으로 적용되는 문서**
  - 통신 프로토콜
  - 인증 시스템
  - 데이터 동기화 전략

- **레이어 간 통신/연동 문서**
  - Platform ↔ Desktop 통신
  - Platform ↔ Edge 통신
  - 전체 레이어 간 통신 프로토콜

- **전체 시스템 표준/규약**
  - API 표준 규약
  - 데이터 형식 표준
  - 네이밍 컨벤션

### 레이어별 폴더에 넣을 문서

- 특정 레이어에만 적용되는 문서
- 레이어 내부 구현 상세
- 레이어 전용 기능 명세

## 폴더 구조

- **01-기획/**: 공통 기획 문서
