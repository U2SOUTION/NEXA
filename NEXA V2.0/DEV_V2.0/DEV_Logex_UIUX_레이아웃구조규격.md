## [설계서] React Flow 디지털 트윈 관제 "LOGEX" 마스터플랜

> 단순히 상자들을 선으로 잇는 '개발자용 로직 편집기'의 한계를 넘어, [로직 + 시뮬레이션 + 상황판 + 컨트롤러 + 디지털 트윈]을 하나의 무한 캔버스에 통합한 공간·인프라 제어 플랫폼 설계도입니다.

---

> [!abstract] 플랫폼 핵심 4대 레이어
> 
> - 로직 (Logic): 사용자가 노드 간 인과관계를 선으로 연결하여 비즈니스 규칙과 인프라 흐름을 시각적으로 코딩하는 뇌의 역할입니다.
> - 시뮬레이션 (Simulation): 구성된 노드 환경을 가상 샌드박스에서 검증하고 부하 및 오작동을 예측하여 토폴로지를 안전하게 재구성합니다.
> - 상황판 (Status Board): 완성된 노드 구성 자체를 실시간 모니터링 뷰로 전환하고, 3D Map 바탕의 가상 인프라와 매핑하여 디지털 트윈을 시각화합니다.
> - 컨트롤러 (Controller): 운영 목적에 맞춰 필요한 만큼의 제어(Control) 노드를 유연하게 배치하여 실제 물리 하드웨어 인프라에 실시간 명령을 하향 전달합니다.

> [!info] 글로벌 시그널 버스 (Global Signal Bus)
> - **Phase 1 (MVP):** 마스터 JSON의 핵심 노드 상태값(Status) 동기화 및 수동 배치.
> - **Phase 2 (Adv):** 가상 연결선(Virtual Link) 및 논리적 흐름 시각화.
> - **Phase 3 (Full):** 1ms급 초정밀 동기화 및 물리적 지연 기반 패킷 애니메이션.

> [!gear] 백본 JSON 구조 및 결정론적 ID 발급
> 
> - 통합 백본 마스터 관리: 전체 시스템의 토폴로지는 하나의 거대한 마스터 JSON 파일로 중앙 관리됩니다.
> - 결정론적 UUID v5 발급: 노드 생성 시 `프로젝트ID + 탭ID + 노드타입 + 순서번호(order)`를 조합한 네임스페이스 기반 UUID v5를 부여하여, 새로고침이나 서브 그래프 재구성 시에도 물리 장비와 1:1 매핑 정체성을 유지합니다.

> [!activity] 추상화 가상 엣지(Virtual Edge) 및 런타임 동기화
> - **경로 간소화:** 실시간 알고리즘 대신, 사용자가 버스에 배치한 노드 간의 **직접적인 부모-자식 관계**를 우선적으로 표현하여 연산 부하 최소화.
> - **상태 중심 동기화:** 패킷의 이동 속도보다는 **노드 테두리 색상 및 아이콘 상태 변화**를 통해 직관적인 이상 탐지 우선 구현.

> [!lock] 대용량 미디어 압축 및 안전 샌드박스
> 
> - 메타데이터 패킷 고속 유통: ComfyUI나 Rivet 기반의 무거운 바이너리(영상, 사운드, 대형 텍스트)를 시그널 버스에 직접 태우지 않고, 데이터가 보관된 스토리지 주소와 해시값이 담긴 경량 JSON 패킷만 고속 유통합니다.
> - 실행 샌드박스 인터셉터: 시뮬레이션 모드 활성화 시, 제어 신호가 실제 하드웨어로 전송되지 않도록 글로벌 버스 라우터가 물리 인프라 경로를 가상 시뮬레이터 수신처로 자동 우회(Mutation)시켜 관제 안정성을 확보합니다.
