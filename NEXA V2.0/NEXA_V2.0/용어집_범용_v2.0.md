### 아키텍처 다이어그램 및 주석 용어 사전 (Technical Glossary)

| Term               | Meaning (뜻) | Context (사용처)                   |
| :----------------- | :---------- | :------------------------------ |
| **Anchor**         | 앵커 / 고정점    | 지식이 고착되는 최종 지점 (`ontex`)        |
| **Array**          | 어레이 / 배열    | 여러 엔진이 나열된 구조적 집합               |
| **Bus**            | 버스          | 데이터나 상태가 흐르는 공유 통로 (`stateBus`) |
| **Cold Path**      | 콜드 패스       | 비실시간 지식 저장 및 고착 경로              |
| **Constitutional** | 규범적 / 헌법적   | 시스템의 근간이 되는 규칙 및 규범 스타일         |
| **Content**        | 내용 / 콘텐츠    | 문서나 데이터의 실제 내용물                 |
| **Context**        | 맥락 / 컨텍스트   | 상황 파악을 위한 주변 정보 및 환경            |
| **Data**           | 데이터         | 정제되지 않은 기초 정보 (Raw Data)        |
| **Direction**      | 방향          | 다이어그램의 흐름 방향 (TB, LR 등)         |
| **Distillation**   | 정제          | 데이터를 지식으로 승화시키는 프로세스            |
| **Draft**          | 초안          | 아직 확정되지 않은 문서 상태                |
| **Engine**         | 엔진          | 특정 기능을 수행하는 독립적 실행 주체           |
| **Event**          | 이벤트         | 시스템 내에서 발생하는 동적인 사건             |
| **Facet**          | 패싯 / 단면     | 지능의 특정 측면이나 개별 엔진 모듈            |
| **Flow**           | 흐름          | 데이터나 로직의 진행 방향                  |
| **Governance**     | 거버넌스        | 시스템의 관리 및 통제 체계                 |
| **Hot Path**       | 핫 패스        | 즉각적인 제어 및 실행이 일어나는 경로           |
| **Intent**         | 의도          | 사용자의 목적이나 명령의 근본 취지             |
| **Loop**           | 루프 / 순환     | 반복적으로 수행되는 지능 운영 과정             |
| **Note over**      | ~위의 주석      | 다이어그램 특정 지점에 표기하는 설명            |
| **Orchestrator**   | 오케스트레이터     | 여러 구성 요소를 조율하는 지휘자 (`Nexaon`)   |
| **Participant**    | 참여자         | 시퀀스 다이어그램에서 상호작용하는 주체           |
| **Path**           | 경로          | 데이터나 로직이 이동하는 통로                |
| **Platform**       | 플랫폼         | 시스템이 구동되는 기반 환경                 |
| **Promotion**      | 상신 / 승격     | 정제된 지식을 상위 계층으로 올리는 행위          |
| **Raw**            | 가공 전의       | 처리되지 않은 원시 데이터 상태               |
| **Rect**           | 사각형 범위      | 다이어그램 내 특정 영역을 강조하는 블록          |
| **Runtime**        | 런타임         | 시스템이 실제로 동작하고 있는 시점             |
| **Shell**          | 셸 / 외피      | 내부 엔진을 감싸고 있는 실행 환경             |
| **State**          | 상태          | 특정 시점의 데이터 값이나 시스템 조건           |
| **Style**          | 스타일         | 다이어그램 요소의 시각적 정의                |
| **Subgraph**       | 하위 그래프      | 큰 흐름 내의 독립된 하위 논리 그룹            |
