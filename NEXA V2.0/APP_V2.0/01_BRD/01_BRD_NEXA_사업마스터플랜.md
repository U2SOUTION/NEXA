# NEXA 사업 마스터 플랜

> **한 줄 정의**: 정신적 활동 (기획·연출·업무 시스템) 을 현실 세계 (IoT) 와 **안전하고 쉽게** 연결하는 **고부가가치 초보안 플랫폼** 사업
> **사업 정체성**: 하드웨어 판매가 아닌, **소프트웨어·플랫폼 중심** 지식·기술 집약형 비즈니스

---

## 비전

인간의 기획·AI 오케스트레이션·물리 기기 (로봇·IoT) 가 **인터넷 위에서 공존**하는 **Physical AI Ops** 생태계를 목표로 한다. 하드웨어는 **발현 매개체**, **기획·제어 소프트웨어**가 중심축이다.
**확장 방향 (도메인 진화 축):** NEXA 는 **산업 → 아트 → 일상** 순으로 발전한다. 산업 현장에서 **안전·신뢰·온톨로지**를 검증하고, 아트·미디어아트로 **감성·표현**을 확장한 뒤, 검증된 기술을 **일상 (스마트홈·웰니스)** 으로 일반화한다. (상세 §「인문 ➡️ 산업 ➡️ 아트 ➡️ 일상」)
**포지션:** 단순 H/W 개발 도구가 아니라, AI 가 **어떤 논리·프롬프트 체인**으로 산출물을 만들었는지 **투명하게 공개 (Transparent Orchestration)** 하고, 사용자가 **검증·개입**할 수 있는 **화이트박스** 플랫폼.

---

## 물리적인 IoT 하드웨어와 결합하여 [인문 ➡️ 산업 ➡️ 아트 ➡️ 일상] 으로 확장하는 온톨로지 기반 웹 플랫폼

물리적인 IoT 하드웨어와 결합하여 **[안뮨 ➡️ 산업 ➡️ 아트 ➡️ 일상]** 으로 확장하는 온톨로지 기반 웹 플랫폼으로서, 기술과 인문·예술이 융합된 비전입니다.
이 메가 프로젝트에서 데이터 레이크, 코퍼스, 온톨로지가 하드웨어와 어떻게 결합되어 작동해야 하는지 구조를 정의해보겠습니다.

---

### 1. 하드웨어 (IoT) 중심의 데이터 흐름 구조

물리적 장치 (센서, 액추에이터 등) 가 개입되면 데이터는 다음과 같은 흐름을 가집니다.

[IoT 디바이스] ➡️ [데이터 레이크] ➡️ [코퍼스 (컨텍스트화)] ➡️ [온톨로지 (지식 표현)]
(센서값, 로그) (시계열 데이터 적재) (데이터의 시각적/언어적 해석) (산업·아트·일상의 관계 매핑)

#### ① 데이터 레이크 (IoT 센서 데이터의 바다)

- 하드웨어에서 초단위로 쏟아지는 전류량, 진동, 온도, 가속도, GPS, RGB 카메라 값 등 가공되지 않은 시계열 (Time-series) 데이터를 그대로 받아내는 거대한 그릇입니다.

#### ② 코퍼스 (AI 가 이해할 수 있는 ' 상황 ' 묘사 데이터)

- IoT 환경에서 코퍼스의 정의가 확장됩니다. 숫자로 된 센서값만으로는 AI 가 맥락을 알 수 없습니다.
- 센서 로그 데이터에 " 현재 장비가 과열되어 비정상 작동 중임 ", " 미술관 A 존에 관객 5 명이 진입함 " 같은 문맥 (Context) 과 텍스트 설명을 결합하여 1 차 가공한 데이터셋을 만듭니다. 이것이 플랫폼의 핵심 학습용 코퍼스가 됩니다.

#### ③ 온톨로지 (하드웨어 제어와 의미적 연결의 핵심)

- 최종적으로 [산업/아트/일상] 이라는 서로 다른 세계를 연결하는 ' 공통 언어 규격 ' 이 됩니다.
- 예를 들어, [산업] 의 진동 센서가 [아트] 에서는 미디어아트의 움직임으로 변환되고, [일상] 에서는 스마트홈의 가전 제어로 이어지도록 개념과 규칙을 정의합니다.

---

### 2. [지식 ➡️ 산업 ➡️ 아트 ➡️ 일상] 확장을 위한 온톨로지 설계 전략

광범위한 도메인을 아우르기 위해서는 ' 코어 온톨로지 (Core Ontology)' 를 먼저 단단하게 짜고, 그 위에 도메인별 온톨로지를 얹는 구조로 가야 합니다.

    [ 1단계: 지식 온톨로지 ] ➡️ 가치, 분류, 규범, 기획, 설계, 교육
    [ 2단계: 산업 온톨로지 ] ➡️ 공장 설비, 물류, 센서 스펙, 물리적 보안
    [ 3단계: 아트 온톨로지 ] ➡️ 미디어아트, 인터랙티브, 감성, 공간 연출
    [ 4단계: 일상 온톨로지 ] ➡️ 스마트홈, 웰니스, 웨어러블, 사용자 경험

─────────────────────────────────────────────────────────────────────────────
[ 하드웨어 코어 온톨로지 ] ➡️ 디바이스 ID, 센서 종류, 액추에이터, 통신 상태 (공통)

#### 1 단계: 인문 (Humanities & Origin)

- 데이터 특징: 정의적, 철학적, 규범적 지식.
- 온톨로지 역할: 시스템이 ' 안전 ' 과 ' 가치 ' 를 판단하는 최상위 규범을 정의합니다. 모든 데이터와 제어 논리의 근거가 되는 시맨틱 (Semantic) 베이스라인입니다
#### 2 단계: 산업 (Industrial IoT)

- 데이터 특징: 신뢰성, 안전성, 정밀함이 최우선인 수치 데이터 위주.
- 온톨로지 역할: "A 센서의 온도가 80 도를 넘으면 장비를 정지한다 " 같은 물리적 기계의 관계와 인과관계를 엄격하게 정의 (예: SSN/SOSA 표준 온톨로지 활용).

#### 3 단계: 아트 (Interactive / Media Art)

- 데이터 특징: 산업용 센서 데이터를 시각, 청각, 촉각 등 ' 감성적 미디어 ' 로 치환한 비정형 데이터.
- 온톨로지 역할: 산업용 센서의 ' 진동 주파수 ' 개념을 미디어아트의 ' 조명 밝기 ' 나 ' 사운드 피치 ' 노드와 연결 (Mapping). 물리적 수치를 예술적 표현 언어 (텍스트/코퍼스) 로 매끄럽게 번역해 줍니다.

#### 3 단계: 일상 (Everyday Life / Smart Living)

- 데이터 특징: 인간의 행동 패턴, 라이프스타일, 주거 환경 등 가장 복잡하고 주관적인 데이터.
- 온톨로지 역할: 예술 전시에서 검증된 인터랙티브 기술을 집 안으로 가져옵니다. " 사용자의 심박수 (하드웨어) 가 높아지면, 거실 조명을 차분하게 바꾸고 (아트), 휴식을 권고하는 메시지를 띄운다 (일상)" 를 기계가 스스로 추론하게 만듭니다.

### 💡 아키텍트로서의 조언: 'GraphRAG' 와 디지털 트윈

이 플랫폼을 웹으로 구현하실 때 최근 가장 주목받는 기술인 GraphRAG(지식 그래프 + 생성형 AI) 개념을 접목하시면 강력해집니다.

- 하드웨어의 상태 (데이터 레이크) 를 AI 가 인식하여 지식 그래프 (온톨로지) 로 변환해 두면, 사용자는 웹 화면에서 복잡한 코딩 없이 " 지금 2 층 전시장 조명을 좀 더 몽환적인 분위기로 바꿔줘 " 라고 자연어로 명령할 수 있습니다. 시스템이 온톨로지를 해석해 실제 하드웨어를 제어 (Actuation) 하게 되는 것이죠.

| 구분         | 블랙박스형 「원클릭」 AI          | 화이트박스형 NEXA 방향                                              |
| ---------- | ----------------------- | ----------------------------------------------------------- |
| **산출**     | 결과만 제공                  | **설계·실행 과정** 공개 (Rivet 그래프·로그)                              |
| **물리 도메인** | 핀·레이트 오류 시 **현장 사고** 위험 | 설계 단계 **검증·Human CP** 후 실행                                  |
| **실행**     | 범용 API·텍스트 위주           | **자체 프로토콜** 기반 초정밀 제어 (§TODO Protocol)                      |
| **키워드**    | —                       | **White-Box Determinism** · **Protocol-Driven Physical AI** |

**가치 제안 (Value Proposition):** 설계 단계의 **투명한 검증**을 통해, 실행 단계에서 **프로토콜 기반** Physical AI Ops 의 **정확성·유연성**을 확보한다.

## 1. 사업의 본질 (Identity)

사용자가 깊은 코딩 없이 소프트웨어로 아이디어를 설계하면, 현실 기계가 **안전하게** 반응하는 환경을 제공하는 것이 궁극적 방향이다.

| 구분            | 내용                                                                                |
| --------------- | ----------------------------------------------------------------------------------- |
| **핵심 가치**   | 기획·워크플로·예술적 발상 ↔ H/W(스마트팜·인터랙티브 조형물) **실시간·안전 동기화** |
| **차별점**      | H/W 는 매개체, **업무·기획 제어 SW**가 중심                                          |
| **보안 전제**   | MFA·Zero-Trust 등 **산업용 다중 보안** — 생성부터 출력까지                          |
| **투자자 관점** | H/W 제조보다 **플랫폼·SaaS** 모델                                                   |

## 2. 시장 문제와 해결책

### 현 시장의 한계

- IoT 가 **H/W 단품·단순 매크로**에 머무름 → 고차원 기획·연출 구현 어려움
- **오픈 네트워크** 비중 증가 → 해킹·오작동 리스크 (작물·공공 설치물)

### NEXA 해결책

- **기획·제어 SW** 축 + H/W 는 안전한 발현 매개체
- 데이터 생성 → H/W 출력 **End-to-End 보안** 일원화
- 사용자는 보안 염려 없이 **창작·업무**에 집중

## 5. 특허 · IP 전략

S/W 비중·산업 현장일수록 **특허 + 샘플**이 투자·심사 설득의 핵심이다.

### 출원 우선순위

| 순위  | 유형             | 핵심                                         |
| ----- | ---------------- | -------------------------------------------- |
| **1** | 복합 (S/W + H/W) | 기획 명령 → H/W 제어 **해킹 차단·변환 Flow** |
| **2** | S/W 알고리즘     | H/W 자원 활용 **처리·효율**                  |
| **3** | H/W·기구         | 야외·팜용 **물리 보호·오류 방지**            |

### BM vs 기술

- **BM:** 정신적 기획 SW ↔ 보안 ↔ H/W 제어 **프로세스**
- **기술:** 암호화 · 릴레이/모터 제어 **메커니즘**

### 실무 체크리스트

- [ ] 지인 10 곳 제공 **전** 출원 번호
- [ ] **우선심사** (AI/IoT · 3~6 개월 등록 목표)
- [ ] 공개·베타 전 비공개 검증과 특허 시너지

### IP → 스케일업

```text
[아이디어] → [특허] → [MVP] → [10곳 검증]
                ↓
        [SEO] ← [GEO] ← [지원사업 / IR]
```

### 2. [인문 ➡️ 산업 ➡️ 아트 ➡️ 일상] 확장을 위한 온톨로지 설계 전략

광범위한 도메인을 아우르기 위해서는 ' 코어 온톨로지 (Core Ontology)' 를 먼저 단단하게 짜고, 그 위에 도메인별 온톨로지를 얹는 구조로 가야 합니다.

    [ 0단계: 인문 온톨로지 ] ➡️ 가치 정의, 존재론적 분류, 관계의 근거 (Origin)
    [ 1단계: 산업 온톨로지 ] ➡️ 공장 설비, 물류, 센서 스펙, 물리적 보안
    [ 2단계: 아트 온톨로지 ] ➡️ 미디어아트, 인터랙티브, 감성, 공간 연출
    [ 3단계: 일상 온톨로지 ] ➡️ 스마트홈, 웰니스, 웨어러블, 사용자 경험

─────────────────────────────────────────────────────────────────────────────
[ 하드웨어 코어 온톨로지 ] ➡️ 디바이스 ID, 센서 종류, 액추에이터, 통신 상태 (공통)

### 0 단계: 인문 (Humanities & Origin)

- 데이터 특징: 정의적, 철학적, 규범적 지식.
- 온톨로지 역할: 시스템이 ' 안전 ' 과 ' 가치 ' 를 판단하는 최상위 규범을 정의합니다. 모든 데이터와 제어 논리의 근거가 되는 시맨틱 (Semantic) 베이스라인입니다.
