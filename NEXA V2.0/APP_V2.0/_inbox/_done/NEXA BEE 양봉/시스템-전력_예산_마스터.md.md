# 자원 구성과 인프라 용량

## 1. 소초광 및 단일 봉군 (1 군) 규모 비교
사용자 분의 커스텀 소초광은 면적 기준으로 표준 랑스트로스 소초광보다 3.21 배 더 크다.

| 비교 항목       | 사용자 커스텀 시스템       | 표준 양봉 시스템 (계상 기준)    | 비고 및 특징                  |
| ----------- | ----------------- | -------------------- | ------------------------ |
| 소초광 규격 (mm) | 730 × 457 × 35    | 448 × 232 × 35 (표준)  | 가로·세로 모두 약 1.6~2 배 확장    |
| 단일 소초광 면적   | 333,610 $mm^2$    | 103,936 $mm^2$       | 표준 대비 약 3.21 배 면적        |
| 1 군 (봉군) 구성 | 8 장 (육아 4 + 저밀 4) | 20 장 (단상 10 + 계상 10) | 단일 면적이 커서 효율적 공간 배치      |
| 1 군 총 벌집 면적 | 2,668,880 $mm^2$  | 2,078,720 $mm^2$     | 표준 계상 (2 단) 대비 1.28 배 용적 |

## 2. 전체 시스템 구조 및 세력 규모 비교 (1 양봉카 기준)
단일 소초광의 압도적인 면적과 1 개 양봉카당 총 64 마리의 여왕벌이 이끄는 다왕복합군 세력을 표준 벌통 (단상 기준) 개수로 치환하고, 성수기 최대 벌 수량을 재산정.

| 시스템 단위      | 사용자 시스템 구성                | 표준 벌통 환산 규모 (단상 기준)  | 최성수기 예측 벌 수량 (최대)   |
| ----------- | ------------------------- | -------------------- | ------------------- |
| 1 복합군       | 4 군 (여왕 4 마리)               | 표준 단상 벌통 약 10.3 통 분량  | 약 24 만 ~ 32 만 마리      |
| 1 셀 블록 (복층) | 8 복합군 (총 32 군 / 여왕 32 마리)   | 표준 단상 벌통 약 82.2 통 분량  | 약 192 만 ~ 256 만 마리    |
| 1 양봉카 전체    | 2 개 셀 블록 (총 64 군 / 여왕 64 마리) | 표준 단상 벌통 약 164.5 통 분량 | 최대 약 384 만 ~ 512 만 마리 |

* ※ 벌 수량 산정 근거: 다왕복합군 최성수기 강군 전환 시 1 군당 최대 6 만~8 만 마리까지 군집이 팽창하는 생태적 특징을 반영.

## 산정순 1. 메인 히트펌프 (50mm 우레탄)

### 1. 전제 (설계 안)

| 항목 | 값 | 근거 |
| :--- | :--- | :--- |
| 단열 | **우레탄 (PUR) 50mm**, \( \lambda \approx 0.024\,\mathrm{W/m·K} \) | 사용자 지정 |
| 열관류율 \( U \) | \( U=\lambda/d \approx 0.48\,\mathrm{W/m^2K} \) | |
| 외피 면적 (안) | 약 **59 m²** (L≈6m × W1.9 × H3.0, 바닥 제외 5 면) | 운송폭 1.9m·높이 3m 급 가정. 길이 확정 시 재계산 |
| 평시 세력 | 약 **250~260 만 마리** (최대의 ~50%, 시즌 평균·외역 분담) | §2 최대 384~512 만의 중간 운용 |
| 최대 세력 | **384~512 만 마리** (설계는 **512 만** 상한) | §2 |
| 대사열 (안) | 평시 **~1.4 mW/마리**, 최대 **~1.5 mW/마리** (군내 평균) | 기저~활성 대역. 군당 환산 시 평시~50W·최대~120W×64 군과 동급 |
| 내부 설정 | 냉방 목표 약 **27~29°C** (봉풍 억제) | 비상·미아 플랜과 정합 |
| HP COP (냉방, DC 인버터 안) | 평시 **~3.0~3.5**, 혹서·제습 가중 **~2.5~3.0** | 이동식·제습 동시 시 COP↓ |

※ 외피 전도만 보면 \( Q_\mathrm{env}=U A \Delta T \): \( \Delta T=6\,\mathrm{K} \) 일 때 **~0.17 kW**, \( \Delta T=20\,\mathrm{K} \)(솔에어) 일 때 **~0.57 kW**.
→ **50mm 우레탄이면 외피 부하는 전체의 소수**. 용량을 가르는 것은 **벌 대사열 + 잠열 (제습) + 환기**.

### 2. 냉방·제습 부하 (열량 kW)

| 부하 성분 | 평시 (안) | 최대 (안) | 산출 요지 |
| :--- | ---: | ---: | :--- |
| 벌 대사열 \( Q_\mathrm{bee} \) | **3.5~3.9 kW** | **7.2~7.7 kW** | 256 만×1.4 mW / 512 만×1.5 mW |
| 외피 + 솔에어 \( Q_\mathrm{env} \) | **0.15~0.25 kW** | **0.5~0.8 kW** | U·A·ΔT, 어닝·도장 시 하한 |
| 환기 현열 \( Q_\mathrm{vent} \) | **0.3~0.7 kW** | **1.0~2.0 kW** | 300~500 m³/h 급, ΔT·ERV 유무 |
| 잠열 (제습) \( Q_\mathrm{lat} \) | **0.8~1.2 kW** | **2.0~3.0 kW** | 일 40~70L 응축의 시간 가중 (야간 피크 큼) |
| **합계 필요 냉방능력 \( Q_\mathrm{cool} \)** | **약 5.0~6.0 kW** | **약 11~13 kW** (전부 동시 상한) | 실무는 시나리오 분리 |

**시나리오를 나누면 (권장 설계 포인트):**

| 시나리오 | 지배 부하 | \( Q_\mathrm{cool} \) (안) | BTU/h (대략) |
| :--- | :--- | ---: | ---: |
| **평시 주간 냉방** | 대사 + 약한 외피·환기 | **5~6 kW** | **17,000~20,000** |
| **최대 주간 냉방** (세력↑, 혹서) | 대사 + 환기 + 외피 | **9~11 kW** | **31,000~38,000** |
| **야간 제습 피크** (화밀 숙성) | 잠열 + 대사 | **8~10 kW** | **27,000~34,000** |
| **선정 정격 (여유 포함)** | 위 중 큰 쪽 ×1.1~1.2 | **약 7~10 kW** 실용 / 엄격 최대 **10~12 kW** | **24,000~34,000** |

기존 인프라 문서의 **24,000~28,000 BTU (7.0~8.2 kW)** 는
**ERV·환기 최소화·어닝이 있는 운용**에서는 타당.
환기 현열·잠열을 한낮에 동시에 최대로 보면 **한 단계 상향 (예: 30~36 kBTU)** 여유를 검토.

### 3. 전기 소비 (DC 48V 히트펌프)

\( P_\mathrm{el} \approx Q_\mathrm{cool} / \mathrm{COP} \) (압축기 + 실내외 팬 포함 시스템 COP 가정)

| 구분 | 냉방능력 (안) | COP (안) | **소비전력 (평시/연속)** | 비고 |
| :--- | ---: | ---: | ---: | :--- |
| **평시** | 5.0~6.0 kW | 3.0~3.5 | **약 1.5~2.0 kW** | 명세표 1 번 평시 |
| **최대 연속** | 8.2~11 kW | 2.5~3.0 | **약 2.8~4.0 kW** | 명세표 1 번 피크 |
| 압축기 기동 순간 | — | — | 연속의 **1.5~2.5 배** 가능 | BMS·케이블은 이 전류로 |

**48V 환산 전류 (대략):**
- 평시 2.0 kW → **~42 A**
- 최대 4.0 kW → **~83 A**
- 기동 피크는 **100 A+** 가능 → 배터리·버스바 여유 필요

### 4. 한 줄 결론

| | 열량 (냉방) | **전력 (DC 48V)** |
| :--- | :--- | :--- |
| **평시** | ~5~6 kW (≈18~20 kBTU 급 운전점) | **1.5~2.0 kW** |
| **최대** | ~8~11 kW 설계점 (엄격 동시부하 시 ~12 kW) | **2.8~4.0 kW** (기동은 더 큼) |

50mm 우레탄은 **외피 손실을 수백 W 대로 눌러** 주므로, 히트펌프 크기는 사실상 **512 만 마리 대사열 + 제습 잠열**이 결정한다.

### 산정 근거 요약 (검토)

일반 온실과 달리, 50mm 우레탄 단열이면 외피 전도는 수백 W 대에 머물고, 용량을 가르는 주 부하는 **벌 대사열**과 **화밀 숙성 제습 잠열**이다. 상세 수치는 위 산출과 동일하며, 아래는 검토용 요약이다.

### 1. 부하 성분별 검토

| 성분 | 평시 | 최대 | 검토 |
| :--- | ---: | ---: | :--- |
| 외피 + 솔에어 (Q_env) | 0.15~0.25 kW | 0.5~0.8 kW | U≈0.48 W/m²K, A≈59 m² 가정. 길이·창·솔에어 확정 시 재계산 |
| 벌 대사열 (Q_bee) | 3.5~3.9 kW | 7.2~7.7 kW | 256 만×1.4 mW / 512 만×1.5 mW. **지배 부하 (~70%+)** |
| 잠열 제습 (Q_lat) | 0.8~1.2 kW | 2.0~3.0 kW | 일 40~70 L 응축. 평균은 ~1~2 kW, 야간 집중 시 피크 2~3 kW |
| 환기 현열 (Q_vent) | 0.3~0.7 kW | 1.0~2.0 kW | CO2·환기량·ERV 유무에 민감. 동시 최대는 드묾 |

**산술 점검 (잠열):** 수증기 응축열 ≈ 0.68 kWh/L → 40~70 L/일 = 약 27~48 kWh/일 → 24 시간 평균 **1.1~2.0 kW**. 야간 8~12 시간에 몰리면 피크 **2~3 kW**대는 타당.

**주의:** 대사열 1.4~1.5 mW/마리는 군내 평균 가정값이다. 외역 분담·야간 저활동 시 실측이 낮을 수 있고, 봉풍·군집 밀집 시 국부 부하는 더 클 수 있다. 512 만은 **설계 상한**이지 상시 운전점이 아니다.

### 2. 시나리오별 냉방능력·전력 (DC 48V)

| 운용 시나리오 | 지배 부하 | 필요 냉방능력 (Q_cool) | 소비전력 (P_el) | 48V 전류 |
| :--- | :--- | ---: | ---: | ---: |
| 평시 주간 냉방 | 대사 (256 만)+ 외피/환기 | 5.0~6.0 kW (17~20 kBTU/h) | 1.5~2.0 kW | ~42 A |
| 최대 주간 냉방 | 대사 (512 만)+ 혹서 + 환기 | 9.0~11.0 kW (31~38 kBTU/h) | 2.8~4.0 kW | ~83 A |
| 야간 제습 피크 | 잠열 + 대사 | 8.0~10.0 kW (27~34 kBTU/h) | 2.5~3.5 kW | ~52~73 A |

P_el ≈ Q_cool / COP. 평시 COP 3.0~3.5, 혹서·제습 가중 시 2.5~3.0 가정. 기동 전류는 연속의 1.5~2.5 배 가능.

### 3. 정격 선정 결론 (수정)

| 구분 | 권장 | 이유 |
| :--- | :--- | :--- |
| **실용 정격** | **7~10 kW** (24~34 kBTU 급) | 평시 5~6 kW 를 인버터 부분부하로 돌리고, 야간 제습 8~10 kW 까지 대응 |
| **엄격 상한** | **10~12 kW** (또는 30~36 kBTU) | 512 만 + 혹서 + 환기를 **동시에** 최대로 잡을 때. ERV·어닝·환기 최소화면 7~8 kW 도 가능 |
| **기존 24~28 kBTU** | 운용 전제 충족 시 타당 | 환기 현열·잠열을 한낮에 동시에 최대로 보면 한 단계 상향 검토 |

1. **방향은 맞음** — 외피보다 대사 + 제습이 지배적이라는 프레임은 타당하다.
2. **“7~10 kW 면 9~11 kW 피크를 완벽 커버”는 과장** — 정격 7 kW 인버터가 연속 11 kW 를 내지는 못한다. 피크를 커버하려면 **정격 (또는 최대 연속 능력) 을 피크에 맞추거나**, 피크를 시나리오로 쪼개 동시부하를 줄여야 한다.
3. **전력 예산** — 평시 ~42 A, 연속 최대 ~83 A, 기동 100 A+ 는 계산상 일관. 다만 버스바·BMS·배터리 C-rate 는 별도 검증이 필요하다.
4. **남는 불확실성** — 외피 실면적, 대사열 실측, 일 응축량 (40~70 L), ERV 유무. 이 네 값이 바뀌면 Q_cool 이 가장 먼저 움직인다.

**한 줄:** 산정 구조와 평시 1.5~2.0 kW / 피크 2.8~4.0 kW 전력 대역은 **설계 가정 안에서 타당**. 다만 결론 문구는 “매우 적절·완벽 커버”보다 **실용 7~10 kW, 동시 최대 시 10~12 kW 여유**로 두는 것이 맞다.

## 산정순 2. 급배기 블로어 (총 8 대)

### 1. 구성 전제

| 항목 | 값 | 근거 |
| :--- | :--- | :--- |
| 대수 | **급기 4 + 배기 4 = 8** | 명세표 「좌우 더블」. 셀 블록당 급기 2·배기 2 (N+1) |
| 버스 | DC 48V BLDC, PWM+Tacho 4 선 | 인프라 문서·벌 소음 회피용 ~25 kHz PWM |
| 형태 | 급기: 양흡입 시로코 / 배기: 단흡입 시로코 | 기계실 ~200mm 매립, ㄹ자 관로·필터 정압 |
| 목표 양압 | +1~+2 Pa (평시) | 푸시 - 풀 사양서. 소문 역류 억제 |
| 유효 외기 교환 | **평시 300~500 m³/h** | 산정순 1 Q_vent. CO2·습기. **팬 프리에어 합 ≠ 유효 풍량** |
| 구문서 (2+4) 와의 관계 | 급기 2+ 배기 4 = 유효 운전점 | 본표 8 대는 **예비 포함**. 평시에는 급기 2 대만 정격급 또는 4 대 반속 |

### 2. 대당 스펙 (선정 안)

| 역할 | 수량 | 풍량 (프리에어, 대당) | 정압 목표 | 소모전력 (대당) | 하우징 **(대당, 1 대)** |
| :--- | ---: | :--- | :--- | :--- | :--- |
| 메인 급기 | 4 | **180~220 CFM** (≈306~374 m³/h) | ≥250 Pa (HEPA·ERV·관로) | **80~120 W** | **~210 × 150 × 130 mm / 대** |
| 메인 배기 | 4 | **90~125 CFM** (≈153~212 m³/h) | 100~200 Pa | **40~60 W** | **~160 × 150 × 65 mm / 대** |

※ 하우징 치수는 **합산이 아니라 단품 (1 대) 외형**. 8 대 전부 붙인 부피·점유면적이 아님.
기계실 배치 시 대략 점유 (여유·덕트 제외, 단순 합): 급기 4 대 ≈ 4×(0.21×0.15×0.13) ≈ **0.016 m³**, 배기 4 대 ≈ 4×(0.16×0.15×0.065) ≈ **0.006 m³**. 실제는 좌/우 셀·덕트·필터박스 레이아웃이 지배.

인프라 문서 급기 2·배기 4 단품 스펙을 **더블 (N+1) 로 확장**한 값. 실배관 정압에서 전달 풍량은 프리에어의 50~70% 로 보는 것이 안전.

### 3. 풍량·CO2 정합

| 점검 | 계산 | 판정 |
| :--- | :--- | :--- |
| 유효 OA 목표 | 300~500 m³/h (산정순 1) | 설계 포인트 |
| 평시 운전 (급기 2 대 정격급 + 배기 4 대 ~50%) | 급기 전달 ≈ 2×(200 CFM×0.6) ≈ 240 CFM ≈ **410 m³/h** | 목표 대역 안 |
| 최대 세력 CO2 (약식) | 대사열 ~7.5 kW → O2/CO2 ~0.3~0.4 L/s, ΔCO2 4000~5000 ppm → **~250~350 m³/h** | 300~500 m³/h 와 동급 |
| 피크 (8 대 고듀티) | 유효 OA 를 과다 키우기보다 **정압·필터 막힘·1 대 고장 백업**용 | 풍량 폭주 방지: PWM·차압 루프로 캡 |

### 4. 소비전력

| 모드 | 가동 | 전력 (합) | 48V 전류 |
| :--- | :--- | ---: | ---: |
| **평시 (24h)** | 급기 2 대@80~100 W + 배기 4 대@25~40 W  <br>(또는 급기 4 대@40~55 W 동등) | **260~400 W** | **~5.5~8.5 A** |
| **피크** | 8 대 고듀티·필터 막힘·N+1 100% | **480~720 W**  <br>(4×120 + 4×60) | **~10~15 A** |
| 미풍 건조 (세척 후) | 전대 ~10~15% PWM | **~40~80 W** | ~1~2 A |

**이름판 합산 상한:** 4×120 + 4×60 = **720 W**. 평시 연속은 그 **절반 이하**를 예산으로 잡는다.

### 5. 제어·백업 (전력과 직결)

| 조건 | 동작 | 전력 영향 |
| :--- | :--- | :--- |
| 배기 1 대 고장 | 동측 잔여 배기 PWM → 100% | 해당 측 피크 쪽으로 치우침 |
| 필터 막힘 | 동일 차압 유지 위해 급기 W↑ | 평시→피크 상단 이동 (교체 트리거) |
| 연기/산불 (Fail-Safe) | 급기 즉시 정지, 모드 전환 | 급기 0, 배기만 또는 전정지 (시나리오별) |
| 새벽 방제 인터록 | RPM 스케줄·댐퍼 연동 | 단시간 피크, HP 와 시분할 권장 |

### 6. 한 줄

- **스펙:** DC 48V 시로코 8 대 (급기 4×180~220 CFM·80~120 W / 배기 4×90~125 CFM·40~60 W).
- **전력:** 평시 **260~400 W**, 피크 **480~720 W** (HP 1.5~4 kW 대비 소수이나 **24h 기저부하**).
- **주의:** 유효 환기는 **300~500 m³/h**에 맞출 것. 8 대 풀가동 풍량·전력은 백업용이지 상시 운전점이 아님.

## 산정순 3. 실내 스핀 - 갠트리

사용자 확정·도식 (스핀 - 갠트리 멀티 플래너) 기준. 인출 횟수는 미확정이므로 **미션 유형별 W**로 잡고, 일일 Wh 는 출동 스케줄 확정 후 곱한다.

### 1. 기구·축 전제

| 항목 | 값 | 비고 |
| :--- | :--- | :--- |
| 형식 | 좌우 셀 사이 **U 형 요크** 스핀 - 갠트리 | 통로 폭 **860 mm**, 인체 스케일 |
| 주 이송 | **X 3000 mm**, **높이 (Z) 1800 mm** | NEMA17+ 감속기 |
| 자세 | X 캐리지 회전, Y 요크 회전 | 좌/우 랙 선택·면 정렬 |
| 암 내부 | 소형 NEMA17 다축 (포고·그리퍼·소문 링크 등) | 도식상 연두 요크 내부 |
| 페이로드 | 소초광 **~10 kg**/장 (인출 시) | 항상 인출하지 않음 |
| 홀딩 | **상시 홀딩 토크 불필요** | 정지·홈 ≈ **0 W** (구조 유지) |
| 구동 분담 (안) | 액추에이터 일 **전동 ~20% / 공압 ~80%** | 도식 하이브리드. 공압은 **산정순 5** 전력 |

### 2. 미션 유형 (인출 ≠ 매번)

| 미션 | 하는 일 | 전동 부하 | 공압 부하 |
| :--- | :--- | :--- | :--- |
| A. 포고 센싱 | 포고핀 → 소초광 내장 온도·피에조 | 위치·접촉 축 위주 | 접촉/클램프 펄스 |
| B. 열화상·비전 | 면 정렬 후 촬영 | 이송 + 자세 | 소 |
| C. 소문 개폐 | 암 링크로 소문 조작 | 소~중 | 중 (링크·실린더) |
| D. 정밀 센싱 | 메인컴 지령 좌표 출동 | A+B 혼합 | 소~중 |
| E. 소초광 인출/재삽입 | 10 kg 광 빼기·넣기 | 위치 제어 | **대** (행정·파지) |

출동 횟수·E 비율은 아직 산정 불가 → 아래 전력은 **가동 중 瞬时/평균**, 일일 kWh 는 아래 일일 에너지 공식으로 후기입.

### 3. 전동부 (NEMA17+ 드라이버) 전력

가정: 축 합계 **약 8~12× NEMA17 급**, 동시 구동은 보통 **2~4 축**. 버스 DC 48V(또는 48→드라이버). 감속기로 10 kg 급은 **공압이 주력**, 전동은 위치·동기.

| 모드 | 내용 | 전력 (전동만) | 48V 전류 |
| :--- | :--- | ---: | ---: |
| 정지/홈 | 홀딩 통전 없음 | **≈0~5 W** (제어기 대기) | ~0.1 A |
| **가동 중 평균** (A~D 순회) | X/Z 간헐 + 자세·암 | **80~200 W** | **~1.7~4.2 A** |
| **피크** (다축 가속·인출 보조) | 3~4 축 동시 + 암 | **250~450 W** | **~5~9.5 A** |
| 인출 (E) 전동분 | 위치만, 들어올림은 공압 | 피크 상단에 포함 | — |

NEMA17 단품 연속은 수십 W 대이나, 드라이버 손실·다축 가속·케이블 저항을 넣어 **가동 평균 80~200 W**로 보수 설정.

### 4. 공압부 (전력은 산정순 5 에 귀속)

| 항목 | 취급 |
| :--- | :--- |
| 실린더·행정 증폭 풀리·파지 | 기계일의 **~80%** (설계 안) |
| 폐에어 버퍼·리사이클 | 컴프레셔 듀티↓에 기여 (산정순 5 산정 시 반영) |
| 본 행 (산정순 3) 숫자 | **전동만** 기입. 공압 Wh 이중계산 금지 |

→ 갠트리가 “레일보다 수십 배 무겁다”는 감각의 상당 부분은 **공압·질량·출동 빈도**이며, 배터리에선 **산정순 3 전동 + 산정순 5 충전**을 합쳐 봐야 한다.

### 5. 일일 에너지 (출동 스케줄 확정용)

\[
E_{\mathrm{gantry,day}} \approx P_{\mathrm{avg,run}} \times T_{\mathrm{active}} + E_{\mathrm{comp,gantry}}
\]

| 기호 | 의미 | 현재 |
| :--- | :--- | :--- |
| \(P_{\mathrm{avg,run}}\) | 가동 중 전동 평균 | **80~200 W** |
| \(T_{\mathrm{active}}\) | 하루 순수 가동 시간 (h) | **미정** (사용자 스케줄) |
| \(E_{\mathrm{comp,gantry}}\) | 그날 갠트리 공압으로 쓴 컴프레셔 Wh | **산정순 5**에서 분배 |

참고 시나리오 (가정, 확정 아님): 주간 가동 3 h × 120 W → 전동 **~0.36 kWh/일**. 인출·소문 공압이 많으면 산정순 5 쪽이 이보다 커질 수 있음.

### 6. 한 줄

- **전동:** 가동 중 **80~200 W**, 피크 **250~450 W**, 정지 **≈0**.
- **공압:** 부하의 대부분 → **산정순 5**과 묶어서 볼 것.
- **다음:** 하루 \(T_{\mathrm{active}}\)·미션 A~E 비율만 주시면 일일 kWh 를 확정 수치로 갱신.

## 산정순 7. 채밀기 저속 회전 모터

커스텀 소초광 **2 매** 동시 (면적·질량상 표준 랑스트로스 **약 5 매** 상당).
고속 원심 (수백 RPM) 이 아니라 **최대 50 RPM 저속** — 소초 보호·중력/온열 채밀 보조에 맞춤.

### 1. 전제

| 항목 | 값 |
| :--- | :--- |
| 용량 | 커스텀 소초광 **2 매** ≈ 표준 **~5 매** |
| 회전 | **≤ 50 RPM** (상한). 기동·램프 업 필수 |
| 버스 | **DC 48V** (감속 BLDC 또는 기어드 모터) |
| 평시 | **정지 · ≈0 W** (배치 공정만) |
| 가동 | 채밀 배치·시즌. 연속 수 십 분~수 시간 가능 |

### 2. 모터 선정 (안)

| 항목 | 선정 |
| :--- | :--- |
| 형식 | **48V BLDC + 고감속** (행성/웜) 또는 정격 출력 **≤50 RPM** 기어드 |
| 드럼 속도 | 엔코더·감속으로 **하드캡 50 RPM** |
| 토크 | 젖은 2 매·편심 기동 여유 → 출력단 **수~십수 N·m** 급 (기종표로 확정) |
| 제어 | 소프트 스타트 · 과전류 · 언밸런스 감지 (진동) 시 감속/정지 |
| 기구 | 바스켓 밸런스·커버 인터록. (온열은 챔버/HP 측 — 본 행은 **회전 모터만**) |

역학 스케일: ω = 50 rpm ≈ 5.2 rad/s.
기계동력 P ≈ T·ω → 예: T=10 N·m 이면 ≈ **52 W**. 효율·기동 여유 넣어 전기 **40~100 W** 가동 / **80~150 W** 피크.

### 3. 전력

| 모드 | 내용 | 전력 |
| :--- | :--- | ---: |
| 대기 | 미사용 | **≈ 0 W** |
| **가동 (정속 ≤50 RPM)** | 정상 채밀 | **40~100 W** |
| **피크 (기동·고점도·편심)** | 수 초~수십 초 | **80~150 W** |

48V 전류: 가동 ~1~2 A, 피크 ~2~3 A.

### 4. 일일·시즌 (참고)

상시 부하 아님. 예: 가동 2 h/일 × 70 W ≈ **0.14 kWh/일** (채밀일만).
배터리 피크 합산 시 **HP·블로어와 시분할** 권장.

### 5. 한 줄

- **2 매 (≈표준 5 매) · ≤50 RPM · DC 48V 감속 모터.**
- **대기 0 · 가동 40~100 W · 피크 80~150 W.**

## 산정순 13. 복합군 급배기 댐퍼 서보

소문 입구가 아닌 **급·배기 덕트 플랩**. 벌 통과는 없으나 **기류 중 프로폴리스 미스트·증착** 가능 → 고착·토크 여유를 넣어 선정.

### 1. 전제 (사용자 확정)

| 항목 | 값 |
| :--- | :--- |
| 대수 | **32** (복합군 16 × 급기 1 + 배기 1) |
| 플랩 | **≤ 50 × 100 mm** |
| 버스 | **DC 24V** → 로컬 벅 **6.0~7.4V** 서보 레일 |
| 제어 | **순차** (동시 기동 1 대 기준; 뱅크 여유 시 최대 2) |
| 홀딩 | **무통전** (이동 후 PWM OFF · 기어 마찰 + 경부하) |
| 조작 횟수 | 댐퍼당 **최대 ≈ 50 회/일** (가정, 근거 없음 · 상한) |

### 2. 토크·기종 선정

풍압만 (예: ΔP 50 Pa, 면적 0.005 m²): F ≈ 0.25 N → 암 50 mm 기준 **≪ 1 kg·cm**.
지배 부하는 **프로폴리스 고착 파단** → 여유 배수 적용.

| 항목 | 선정 |
| :--- | :--- |
| 형식 | **디지털 메탈기어 서보** (플라스틱 기어 배제) |
| 정격 토크 | **≥ 15 kg·cm @ 6~7.4V** (권장 **20~25 kg·cm** 급) |
| 예 | waterproof 메탈기어 20 kg·cm 급 (DS3218 / 동급) |
| 각도 | 90° 개폐 (필요 시 120°) |
| 부가 | 혼·축 부트, 플랩 엣지 **PTFE/이형**, 일 1 회 Anti-Sticking Sweep |
| Fail-Open | 비상 시 슈퍼캡·순차 Open (안전 마스터플랜). 평시 피크와 동일 스케일 |

무통전 홀딩: 플랩이 작고 풍압 토크가 낮아 **메탈기어 비가역에 가깝게 유지** 가능. 장기 진동·강풍 덕트면 **스프링 바이어스 (Open 방향) 또는 기구 디텐트** 병행 권장.

### 3. 전력

| 모드 | 내용 | 전력 |
| :--- | :--- | ---: |
| 대기/홀딩 | PWM OFF ×32 | **≈ 0 W** |
| 1 대 주행 | 7.4V · ~1~2 A | **≈ 8~15 W** |
| 1 대 피크 (고착 파단·스톨 순간) | ~2.5~4.5 A · 0.2~0.5 s | **≈ 20~35 W** (서보 레일) |
| **버스 피크 (24V, η≈0.9, 순차 1 대)** | | **≈ 25~40 W** |
| 순차 2 대 (비권장·여유) | | **≈ 50~80 W** |

※ 32 대 동시 기동은 설계에서 배제. Fail-Open 도 **순차/뱅크**로 피크를 위 대역에 맞춤.

### 4. 일일 에너지 (상한 가정)

1 회 ≈ 평균 **10~15 W × 1 s** ≈ **10~15 J** (≈ 0.003~0.004 Wh). 고착 시 소폭↑.

| 가정 | 계산 | 결과 |
| :--- | :--- | ---: |
| 댐퍼당 50 회/일 ×32 | 32×50×0.004 Wh | **≈ 6~8 Wh/일** |
| 등가 연속 | 8 Wh / 24 h | **≈ 0.3 W** |

HVAC·블로어 대비 **무시 가능** 규모. 배터리 예산은 **피크 25~40 W** 만 보면 됨.

### 5. 한 줄

- **기종:** 24V 버스 · 로컬 7.4V · **메탈기어 디지털 ≥15(권장 20~25) kg·cm** ×32.
- **전력:** 홀딩 **0 W** · 순차 피크 **25~40 W** · 일 **≈ 6~8 Wh** (50 회/댐퍼·일 상한).
- **프로폴리스:** 토크 여유 + PTFE·일일 스윕 + 밀폐 혼. 소문 서보 (A8) 와 별개.

## 산정순 14. 고압 공압 솔레노이드 밸브

**평시 닫힘 (NC).** 코일 통전 시에만 열림. 용도는 **소초광 이격 (프로폴리스 격파 에어)** 과 **청소 (렌즈·바닥 블로우)** 단펄스에 한정.

### 1. 전제

| 항목 | 값 |
| :--- | :--- |
| 밸브 | **NC** (무통전 = 닫힘) · DC **24V** 코일 |
| 평시 | **닫힘 · ≈0 W** (누설·예열 없음) |
| 오픈 조건 | ① 소초광 **이격/격파** 에어 펄스 ② **청소** 에어 펄스 |
| 비오픈 | 상시 방제 분무·장시간 개방 없음 (구「새벽 방제 다채널 연속」안 폐기) |
| 동시 | **순차** 또는 최대 **1~2 코일** (피크 억제) |
| 에어·Wh | 압축기 부하는 **산정순 5**. 본 행은 **밸브 코일 전력**만 |

### 2. 코일·팩 선정 (안)

| 항목 | 선정 |
| :--- | :--- |
| 형식 | 24V DC · 고압 (≥7 bar) · NC 매니폴드 |

| 채널 | 격파 노즐·청소 노즐 등 필요 수 (개수는 배관 확정 시). 전력은 **동시 코일 수**가 지배 |
| 구동 | 단펄스 (예: **0.1~0.5 s** Open) 후 즉시 OFF → 닫힘 |

### 3. 전력

| 모드 | 내용 | 전력 |
| :--- | :--- | ---: |
| 평시 | 전 채널 NC · 코일 OFF | **≈ 0 W** |
| 1 코일 Open | 격파 또는 청소 펄스 | **≈ 5~12 W** |
| **피크 (1~2 코일)** | 짧은 동시/직후 펄스 | **≈ 10~25 W** |
| 다채널 장시간 | 설계 배제 | — |

### 4. 일일 에너지 (대략)

펄스 평균 8 W × 0.3 s ≈ 2.4 J/회.
이격·청소 합쳐 하루 **수백~수천 펄스**여도 일 **≪ 5 Wh** → HVAC 대비 무시.
예산은 **피크 10~25 W** + 압축기 (산정순 5) 쪽 에어량.

### 5. 한 줄

- **NC · 평시 0 W.** Open 은 **이격·청소 단펄스만**.
- **피크 10~25 W** (1~2 코일 @24V). 에어 에너지는 **컴프레셔 (5)**.

| 6 | 수평 잭 | 정박 시 단시간. 설계일 **≈0** (간헐) | **≈0~0.1** |
| 7 | 채밀기 | HVAC 피크 설계일 미가동 | **0** |
| 8 | 배터리 히팅 | 여름 피크 **0** | **0** |
| 9 | 제어반 RPi | **7~10 W** × 24 h | **0.17~0.24** |
| 10~12 | LED 군 | 주간 디밍 합 **~12~22 W** × ~14 h | **0.17~0.31** |
| 13 | 댐퍼 서보 | ≤50 회/댐퍼·일 상한 | **≈0.01** |
| 14 | 솔레노이드 | 이격·청소 단펄스 | **≪0.01** |
| | **합계 (버스 부하)** | | **≈ 48~69** |
| | **중앙값 (설계 기준)** | HP 중간 + 블로어·기타 중간 | **≈ 55~58** |

**HP 만 보면** 설계일의 **약 75~85%**. 블로어가 그다음 (~12~15%). 나머지 합 **≲ 5 kWh/일**.

### 시간대 스케치 (설계일 · 전력 W)

| 구간 | 시각 (예) | 주 부하 | 대략 연속 W (중간) |
| :--- | :--- | :--- | ---: |

| 새벽 전환 | 06~08 | 제습 말기·냉방 기동 | **≈ 2.0~3.0 kW** |

※ 순간 피크 (HP 기동·컴프레셔·잭) 는 **일 kWh 에 거의 안 타고**, 배터리 C-rate·버스 전류용.

### 등가·환산

| 지표 | 값 |
| :--- | :--- |
| 설계일 소비 | **≈ 48~69 kWh/일** (기준 **~55 kWh/일**) |

### 한 줄

- **여름 피크 설계일 ≈ 55 kWh/일** (대역 48~69). 겨울보다 **냉방 + 제습**이 피크.

## 태양광 패널 필요 용량 (한국 여름 평균 · kWp)

일 소비는 위 「일일 에너지 합산」 기준. **배치·장수·슬라이딩 기구는 다음 단계** — 여기선 **필요 어레이 와트 (kWp)** 만.

### 1. 입력

| 항목 | 값 | 근거 |
| :--- | :--- | :--- |
| 일 소비 \(E\) (버스) | **~55 kWh/일** (48~69) | 여름 피크 설계일 |
| 일 소비 \(E'\) (손실 포함) | **~60 kWh/일** (52~75) | DC-DC·배선 **+8%** |
| 한국 여름 평균 PSH | **4.5~5.5 h/일** (기준 **5.0**) | 6~8 월 일사 ≈ 피크썬아워. 내륙·남부 평균 대역 |
| 시스템 효율 \(\eta\) | **0.75~0.85** (기준 **0.80**) | 여름 패널 고온↓ · MPPT · 오염·배선 |

\[
P_{\mathrm{pv}}\,[\mathrm{kWp}] = \dfrac{E'}{\mathrm{PSH}\times\eta}
\]

(1 kWp ≈ STC 에서 1 kW. 필요 **와트수** = \(P_{\mathrm{pv}}\times1000\) W.)

### 2. 산출

| 케이스 | \(E'\) | PSH | \(\eta\) | **필요 용량** |
| :--- | ---: | ---: | ---: | ---: |
| 낙관 | 52 kWh | 5.5 h | 0.85 | **≈ 11.1 kWp** (**~11,100 W**) |
| **기준 (권장)** | **60 kWh** | **5.0 h** | **0.80** | **≈ 15.0 kWp** (**~15,000 W**) |
| 보수 | 75 kWh | 4.5 h | 0.75 | **≈ 22.2 kWp** (**~22,200 W**) |

| 설계 채택 (안) | 값 |
| :--- | :--- |
| **필요 어레이** | **14~16 kWp** (중앙 **15 kWp = 15,000 W**) |
| 여유 설계 | **18 kWp** (흐린 여름일·고온 추가 마진) |
| 구 인프라안 (4.0 kWp) | 현재 일부하 대비 **약 1/4** → **재상향 필수** |

검산 (기준): \(5.0\times0.80\times15\,\mathrm{kWp}=60\,\mathrm{kWh/일}\) → 손실 포함 설계일과 일치.

### 3. 참고 (와트만 · 장수 환산)

| 단장 정격 | 15 kWp 시 장수 (대략) |
| ---: | ---: |
| 400 W | **≈ 38 장** |
| 450 W | **≈ 34 장** |
| 500 W | **≈ 30 장** |

※ 루프·슬라이딩 **실면적 상한**이 이보다 작으면 → 패널을 줄이고 **그리드/발전기 보조** 또는 **부하 시나리오 하향**이 필요. 본 절은 **전기적 필요 와트**만 제시.

### 4. 한 줄

- 한국 **여름 평균 PSH ≈ 5.0 h**, 일부하 **~60 kWh** → 이론상 필요 태양광 **≈ 15,000 W (15 kWp)** (대역 ~11~22).
- **결론: 루프·슬라이딩만으로 전 부하를 태양광으로 소화하는 것은 현실적으로 불가** (구 4 kWp 는 일부하 대비 약 1/4).

### 5. 전력 공급 전략 (운용안)

| 단계 | 내용 |
| :--- | :--- |
| **버스** | 전 시스템 **DC 48V** 기준으로 통일 구성 |
| **1 차 전원** | **한전 농업용 전기** 접속 → 실운전 **전력·부하 데이터 축적** |
| **태양광** | 보조·부분 충전에 한정 (전량 자급 목표 아님) |
| **이후** | 데이터 확인 후 **발전기** 또는 **전원 전용 차량 1 대 추가** 등으로 보강 |

## 부록. 운영 중 부하 감지 → 업그레이드 전략 (히트펌프)

설계치는 가정값이다. **실운전 로그로 부족 유형을 나눈 뒤**, 소프트웨어·운용 → 열교환/풍량 → 압축기 순으로 올린다. 컴프레셔만 키우는 것은 최후 수단에 가깝다.

### 1. 최소 계측 (상시 로깅)

| 채널 | 무엇을 보나 | 부족 시 신호 |
| :--- | :--- | :--- |
| 내부 건구·상대습도 (구역별) | 현열 vs 잠열 | T↑만 / RH↑만 / 둘 다 |
| 응축수 유량·일적산 (L/h, L/일) | 실제 제습량 | 목표 미달 + RH 고착 |
| HP 소비전력·인버터 Hz | 능력 사용률 | 장시간 100% 고착 |
| 고·저압, 토출온도, 과열도/과냉각 | 루프 건강 | 고압↑·과열도↑ = 응축/증발 병목 |
| 실내외 풍량·필터 ΔP | 공기측 | 풍량↓·결빙·성능↓ |
| 외기 T·일사, 환기 m³/h | 외피·환기 부하 | 혹서·고환기일과 상관 |
| 48V 버스 전류·BMS | 전원 여유 | 케이블·배터리 한계 먼저 |

권장 판정 주기: **1 주 롤링** (평시) + **혹서·대유밀 주간은 일 단위**.

### 2. 부족 유형 판별 (먼저 진단)

| 유형 | 관찰 | 원인 후보 | 1 차 대응 (하드웨어 전) |
| :--- | :--- | :--- | :--- |
| **A. 현열 부족** | 주간 T 목표 미달, RH 는 보통 | 대사↑, 솔에어, 환기 현열, 응축기 불량 | 어닝·도장, 환기 스케줄, 외기 팬·응축기 청소 |
| **B. 잠열 부족** | RH·이슬점 고착, 응축 L/일↓ | 증발기 면적/풍량, 설정 이슬점, 드레인 | 풍량·설정점, 드레인·성에, 야간 전용 제습 모드 |
| **C. 동시 피크** | T·RH 동시 악화, Hz 100% | 세력 + 제습 + 환기 겹침 | 시나리오 분리: 주간 현열 / 야간 제습 우선 |
| **D. 국부 과열** | 일부 복합군만 고온 | 댐퍼·기류 불균일 | 댐퍼·팬 밸런스 (HP 용량 문제 아님) |
| **E. 전원 한계** | HP 는 여유인데 전류·전압 강하 | 버스바·BMS·배터리 | 전원 보강 후 HP 증설 |

업그레이드 트리거 예: **연속 3 일** 동일 시나리오에서 (1) 인버터 ≥95% × 2h+, 또는 (2) 구역 T/RH 가 목표 이탈 × 설정시간, 또는 (3) 일 응축량이 목표의 70% 미만.

### 3. 단계별 업그레이드 로드맵

```json
감지 → 진단(A~E) → Stage 0 운용 → Stage 1 공기/열교환
                 → Stage 2 팽창·충전 → Stage 3 압축기
                 → Stage 4 2차 유닛/전원
```

| Stage | 조치 | 기대 효과 | 비고 |
| :--- | :--- | :--- | :--- |
| **0. 운용·제어** | 설정점 분리 (주간 T / 야간 RH), 환기·ERV 스케줄, 댐퍼 밸런스, 필터·드레인 정비 | 체감 부하 10~30%↓ 가능 | 비용 최소. 먼저 소진 |
| **1. 공기측·열교환** | 실내 풍량↑, 증발기 코일 추가/병렬, 응축기 면적·외기팬↑, 어닝 | 능력·COP 동시 개선 | **A/B 유형의 본류** |
| **2. 팽창·냉매** | EEV 용량·PID, 적정 충전량, 드라이어 | Stage 1 효과를 루프에 전달 | 압축기 올리기 **직전** 필수 |
| **3. 압축기** | 동급 루프 내 1 단 상향 또는 동일 프레임 고출력 인버터 | 실효 **+10~30%** 수준이 현실적 | 증발/응축/EEV 미매칭 시 고압·효율↓·고장 |
| **4. 시스템 증설** | 제습 전용 소형 유닛 병렬, 또는 HP 2 호기 (주간/야간 분담), 48V 버스·배터리 증설 | 피크 시나리오 분리 | 컴프레셔 과대 1 대보다 **역할 분리**가 안전 |

### 4. “컴프레셔만” 규칙

- **하지 말 것:** 증발기·응축기·EEV·풍량 그대로 두고 압축기만 2 단 이상 점프.
- **해도 되는 경우:** Stage 1~2 후, 고·저압·과열도·토출온도가 여유이고, **공기측이 추가 질량유량을 받을 수 있을 때** 1 단 상향.
- **기대치:** 부품만 키워도 냉방/제습이 비례 (×1.5~2) 로 오르지 않는다. 병목이 코일이면 **거의 안 오르거나 악화**한다.

### 5. 시나리오별 우선 업그레이드

| 실측 패턴 | 우선 Stage | 목표 |
| :--- | :--- | :--- |
| 주간만 T↑, 야간 OK | 0 → 1(응축·어닝·환기) | 현열 여유 |
| 야간만 RH↑·응축↓ | 0 → 1(증발·풍량·제습모드) | 잠열 확보 |
| 대유밀 + 혹서에만 무너짐 | 0(시나리오 분리) → 4(제습 전용 병렬) | 동시부하 회피 |
| 전 구간 Hz 100%·압력 여유 | 2 → 3 | 압축기 1 단 |
| 전 구간 Hz 100%·고압 상시 | 1(응축) 먼저, 3 은 보류 | 응축 병목 해소 |
| HP OK, 48V 강하·트립 | 4(전원) | 열량 문제 아님 |

### 6. 운영 KPI (업그레이드 전후 비교)

| KPI | 합격 가이드 (안) |
| :--- | :--- |
| 주간 구역 T | 목표 27~29°C, 이탈 < 설정시간/일 |
| 야간 RH / 이슬점 | 숙성·봉풍 기준 이내 (운용값 확정 후 기입) |
| 일 응축량 | 설계 대역 (예: 40~70 L) 의 ≥80% |
| 인버터 100% 점유 | 연속 < 2 h/일 (피크일 제외 롤링) |
| 토출온도·고압 | 제조/설계 상한 대비 여유 마진 유지 |
| 48V 피크 전류 | 버스·BMS 연속 정격의 ≤80% 상시 |

### 7. 권장 도입 전략 (요약)

1. **초기:** 실용 7~10 kW 급 + **계측 풀세트** (업그레이드 판단용).
2. **1 시즌:** Stage 0~1 만으로 병목 유형 (A~E) 확정. 하드웨어 큰손 보류.
3. **부족 확정 시:** 유형별 Stage 표 순서. 압축기는 Stage 3.
4. **피크만 모자랄 때:** 단일 거대 압축기보다 **제습 전용 병렬 (Stage 4)** 검토.
5. **문서 피드백:** 실측 Q_bee·일 응축·외피를 산정순 1 가정과 대조해 다음 시즌 정격을 갱신. 상세 수치는 **산정순 1**과 대조.
