# 코드 — 스마트 온수 매트 해킹 제어

스펙은 [장비-스마트 온수 매트 해킹 제어](장비-스마트%20온수%20매트%20해킹%20제어.md).  
소스는 **`NEXA-Edeg/smart-water-mat/`** (PlatformIO).

## 원칙

- 로터 FW 매트 분기 없음 — 칸·노브만, 매트가 해석
- 침대 mmWave ≠ 로터 `PRESENCE`
- 무장 전 포토커플러 금지
- ESP-NOW 현장 > 포털/AI. 명령은 poll(구독 상시 금지)
- 펄스 중 MQTT 유예. 15분 데드타임. 노브 칸 ≠ 펄스 칸

## 기초에 들어 있는 것

`arm` · `optocoupler` · `pulse_scheduler` · `sensors`(자리) · `temp_control` · `schedule` · `presence_bed` · `sleep_fsm` · `feature_map` · `feedback` · `mqtt_portal`(스텁) · `main` 루프

## 아직 비어 있는 것

GPIO·센서 드라이버 · ESP-NOW 패킷 · TLS MQTT · 입실 만료 알림 · 건조 가온 · PC 음악 알림 · 존 전환 시 SW off 상세
