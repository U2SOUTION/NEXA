# Aero Profiler — 군별 풍량 프로파일링 (압력 샌드위치 방식)

Aero Profiler 는 Fanner(NB-HV-FAN) 조정 층에서 **군별·실별 풍량 배분**을 맡는 소프트웨어다.
배기 댐퍼 모터 없이, **실내와 배기 챔버의 압력을 고정**하고 **Tender Gantry 가 기계식 흡기 플랩을 조정**하며, **스캐닝 차압 센서 하나로 배기 유로 차이를 계속 보정**한다.
공조 제어 개념 문서의 §1 (공간·유로) 과 §6 (조정) 을 구현한다.

## 결정 요약

| 결정 | 내용 |
| :--- | :--- |
| **1. 배기 댐퍼 모터 없음** | 군·복합군 환기 배기 댐퍼 모터를 두지 않는다. 군별 독립 배기 라인 끝 (챔버 입구) 에 **가볍고 떨림 없는 역류 방지 플랩**만 둔다. 청소·방제 경로와 유닛 단위 댐퍼는 별도다 (§3) |
| **2. 압력 샌드위치** | 실내 (급기팬) 와 배기 챔버 (배기팬) 압력을 고정한다. 군은 두 압력 사이에 끼므로 **양압이 구조적으로 보장**된다. 군별 유량은 Tender Gantry 가 기계식 흡기 플랩 (육아실·저밀실 각각) 으로 정한다 |
| **3. 스캐닝 보정** | 군별 배기 라인의 그릴 뒤 압력을 **스캐닝 차압 센서 1 개**로 순차 측정한다. 흡기·배기 양쪽 유량 추정을 비교해 저항 DB 를 갱신하고 막힘을 판정한다 |
| **4. 급기구 배치** | 급기구는 **육아실 가장 아래 1 개, 저밀실 가장 아래 1 개**. 각각 같은 실 배기구의 **반대편 끝**에 두어 대각으로 훑는다. 형태는 소초광 끝면 쪽 벽의 **가로 슬릿 카세트** (두 실 공통 부품). 조정부는 갠트리 쪽 면에 둔다 |
| **5. 소문 = 세 번째 출구 (5 단계)** | 소문 (Hive Gate) 은 Tender Gantry 가 슬라이드 레버를 **톱니 턱 5 단계**로 조정한다 (§1.6). 공조는 소문 단계를 입력으로 받는다. 소문이 열려 있을 때 제어 목표는 군 압력이 아니라 **소문으로 나가는 최소 양압 바람 (소문 유출량)** 이다 (§2.5) |
| **6. 챔버 연결 — 평시 분리, 필요 시 연동** | 셀 블록 L·R 배기 챔버를 **연결 덕트 + 평시 닫힘 연결 댐퍼**로 잇는다. 평소에는 분리해 블록별로 압력을 조절하고, 팬 고장·정비·저부하·부하 쏠림 때만 연동한다. 방역 사유가 있으면 격리를 강제한다 (§1.7) |

## 1. 구조

### 1.1 유로 (셀 블록 하나 기준)

셀 블록 L·R 은 배기 계통이 기본적으로 분리되고, 두 챔버는 평시 닫힘 연결 댐퍼로만 이어진다 (§1.7). 실내 (가압 플레넘) 는 공통이다.

```text
외기 → 급기 블로어 → HEPA → ERV(급기 쪽) → 급기 코일 → 실내 (가압 플레넘, 공통)
     → 흡기 플랩 (군마다 저밀실·육아실 각각, 갠트리 기계식) → 군 (저밀실 · 육아실)
     → (소문 1~4 단계일 때) 소문 (Hive Gate) → 외기 : 약한 양압 페로몬풍, 환기량의 일부
     → 저밀실 상단 배기 라인 ┐
     → 육아실 하단 배기 라인 ┴→ 군별 독립 배기 라인 → 역류 방지 플랩 (챔버 입구)
     → 셀 블록 배기 챔버 → ERV(배기 쪽) → 배기 응축 코일 → 배기팬 2 대 (역풍 방지 댐퍼) → 외기
          ↕ 연결 덕트 + 연결 댐퍼 (평시 닫힘) ↔ 반대쪽 셀 블록 배기 챔버 (§1.7)
```

| 구성 | 셀 블록당 | 유닛 전체 | 비고 |
| :--- | :--- | :--- | :--- |
| 군 | 32 | 64 | |
| 흡기 플랩 (기계식·무전원) | 64 | 128 | 군마다 저밀실·육아실 각 1 |
| 독립 배기 라인 | 64 | 128 | 군마다 저밀실 상단·육아실 하단 |
| 역류 방지 플랩 (무전원) | 64 | 128 | 챔버 입구에 모아 배치, 카세트형 |
| 플랩 홀 센서 (아날로그) | 64 | 128 | 챔버 쪽 고정 프레임, 닫힘 감시 (§1.3) |
| 플랩 퍼지 라인 (Air Core) | 1 (구역별 솔밸브) | 2 | 정방향 흐름 중 약한 바람 (§1.3) |
| 배기 챔버 | 1 | 2 | |
| 챔버 연결 덕트 + 연결 댐퍼 | — | 1 | 평시 닫힘, 유닛 단위 Fanner 장치 (§1.7) |
| 배기팬 | 2 | 4 | 팬마다 역풍 방지 댐퍼 |
| 스캐닝 차압 센서 | 1 (측정점 64) | 2 | §2.3 |
| 소문 (Hive Gate, 5 단계 슬라이드) | 32 | 64 | 갠트리 기계식, 톱니 턱 고정 (§1.6) |
| **군·복합군 배기 댐퍼 모터** | **0** | **0** | |

### 1.2 압력 샌드위치 — 군을 실내 압력 (급기팬) 과 챔버 압력 (배기팬) 사이에 끼운다

```text
실내 +3~5 Pa (급기팬이 고정)  >  군 +1~4 Pa (결과값)  >  배기 챔버 +0.5~1 Pa (배기팬이 고정)  >  외기 0
```

| 공간 | 목표 차압 (외기 기준, 가정) | 누가 고정하나 |
| :--- | :--- | :--- |
| **실내 (플레넘)** | +3~5 Pa | 급기팬 PWM |
| **군 (벌 공간)** | +1~4 Pa (결과값). 소문이 열리면 외기보다 조금 높은 수준에 묶인다 | 고정하지 않는다. 실내와 챔버 사이에서 플랩 개도 (와 소문 단계) 에 따라 정해진다 |
| **배기 챔버** | 블록 안 소문이 모두 닫힘 (0 단계): 0 Pa 까지. 열린 군이 있으면: 소문 유출량 목표를 맞추는 값 (§2.5) | 배기팬 PWM |

- **흡기 (상류) 를 조이면 군 압력이 내려간다.** 배기를 강하게 당기면서 흡기 플랩으로 유량을 조이면 군이 음압이 되어 소문으로 외기가 빨려 든다. 따라서 배기 댐퍼 없이 양압을 지키려면 **챔버 압력을 군 목표 바로 아래에 고정**해야 한다.
- **소문이 닫혀 있으면** 군 압력은 항상 실내와 챔버 사이에 있으므로, 플랩을 어떤 개도로 두어도 군은 양압이다.
- **소문이 열려 있으면** 군에 외기로 통하는 출구가 하나 더 생긴다. 이때 양압 조건은 압력이 아니라 **유량 균형 (흡기 > 배기 라인)** 이다. 그 차이가 소문 유출량이 된다 (§2.5).
- 챔버 압력 목표는 시각 (낮·밤) 이 아니라 **블록 안 군들의 소문 단계**로 정한다. 열대야처럼 밤에도 열린 소문이 있을 수 있다.
- 실내와 챔버 압력이 모두 고정되어 있으므로 군별 유량은 **자기 흡기 플랩 개도로만** 정해진다. 군끼리 간섭하지 않아 간섭 상쇄 행렬이 필요 없다.
- 전체 압력 예산 (실내 − 챔버) 은 약 **2.5~4 Pa** 다. 흡기 플랩·급기구 그릴·배기 라인·역류 방지 플랩을 모두 이 예산 안에서 설계한다.

### 1.3 역류 방지 플랩 — 가볍고 떨림 없이

| 조건 | 내용 |
| :--- | :--- |
| **열림 압력** | 약 0.5 Pa 이하 (가정). 필름형 또는 자석 척력형 |
| **떨림 방지** | 열림 압력 근처에서 반쯤 열린 채 떨지 않도록, 평상 유량에서 **완전히 열린 상태**가 되게 크기·무게를 잡는다 |
| **소음 방지** | 닫힘 쪽에 부드러운 시트 (폼·실리콘), 약간의 기울기로 자중 닫힘 |
| **위치** | 군 쪽이 아니라 **챔버 입구 쪽**. 벌에게 진동이 전달되지 않고, 벌이 닿지 않아 프로폴리스가 붙지 않으며, 128 개를 한곳에서 점검·청소한다 |
| **고장** | 결로·밀랍 성분으로 고착될 수 있다. 아날로그 홀 센서 닫힘 감시와 스캐닝 측정으로 감지한다 (아래 닫힘 감시, §2.3) |

배기 댐퍼 모터를 없앴으므로 **섞임 방지와 압력 예산을 이 플랩이 혼자 책임진다.** 128 개가 모두 같은 성능을 내야 한다.

**리스크**

| 리스크 | 결과 |
| :--- | :--- |
| **열림 압력·개방 손실 과다** | 3 Pa 압력 예산을 잠식해 유량 부족 |
| **떨림 (채터링)** | 소음·진동, 힌지 마모, 유량 맥동으로 스캐닝 압력 측정에 잡음 |
| **닫힘 누설** | 배기팬 정지·청소 중 음압 때 챔버 공기가 군으로 역류 → 페로몬·질병 섞임 |
| **젖음 부착** | 결로수 막이 플랩과 시트를 붙여 열림 압력이 몇 배로 뛴다 (습한 유밀기 밤에 가장 위험) |
| **고착·결빙** | 밀랍·프로폴리스 미세 성분, 먼지, 겨울 결빙으로 열림 또는 닫힘 실패 |
| **재질 열화** | 습기·방제 잔류 가스·소독약·온도 사이클로 필름이 굳거나 휘어 닫힘 불량 (영구 변형) |
| **주행 진동·경사** | 관성으로 덜컹거림, 자중 닫힘 방식은 차량 기울기에 따라 열림 압력이 변함 |
| **품질 편차** | 128 개의 열림 압력이 제각각이면 군별 유량 편차가 커진다 |

**제작 팁**

1. **형식:** 경량 필름 플랩 (PET·실리콘 박막) + **약한 자석 보조 닫힘**을 기본 시제품으로 하고, 푸시 - 풀 사양서의 자석 척력형과 비교한다. 자석은 닫힘을 확실하게 하고 진동에 강하며, 자석 간격으로 열림 압력을 맞출 수 있다. 자석은 코팅품을 쓴다.
   - **밀폐 구간 — 자석에 다 붙지 않아도 밀폐:** 플랩이 시트에 닿기 몇 mm 전부터 부드러운 **겹침 립 (실리콘 스커트)** 이 먼저 닿게 한다. 이 구간 안이면 어디에 멈춰도 새지 않는다. 자석은 플랩을 밀폐 구간 안으로 끌어오는 역할이고, 끝까지 붙는 것은 여유다.
   - **역압 자기 밀폐:** 역압이 걸리면 그 압력이 플랩을 시트 쪽으로 누른다. 사고 상황일수록 더 단단히 닫힌다. 남는 위험은 이물 (프로폴리스·밀랍·먼지) 이 끼어 밀폐 구간 밖에 걸리는 경우이며, 홀 센서가 잡는다.
2. **열림 멈춤대:** 최소 운전 유량에서도 플랩이 **열림 멈춤대에 눌려 붙어 있게** 설계한다. 반쯤 열린 상태가 없으면 떨지 않는다.
3. **확대 하우징:** 플랩 부분만 덕트보다 넓게 해 풍속을 낮춘다. 열렸을 때 압력 손실이 작다.
4. **힌지:** 핀 힌지는 부식·밀랍으로 고착되므로 **리빙 힌지** (필름이나 PP 를 접어 쓰는 일체형 힌지) 를 쓴다. 굽힘 피로 수명을 확인한다.
5. **시트:** 부드러운 실리콘·EPDM 립으로 **선 접촉**하게 해 물막이 생길 면적을 줄인다. 시트와 플랩 면은 소수성 처리 (PTFE 필름 등) 한다.
6. **배수:** 덕트는 챔버 쪽으로 기울이고, 하우징 아래에 배수 구멍을 둬 플랩 앞에 결로수가 고이지 않게 한다.
7. **결빙 회피:** 챔버 입구는 따뜻한 실내 쪽에 두고 챔버를 단열한다.
8. **카세트화:** 챔버 입구 레일에 끼우는 카세트로 만들어 관리자가 공구 없이 교체하고 예비품을 둔다. 하우징은 **투명**하게 해 육안으로 점검한다 (아래 관리자 점검·교체).
9. **재질 선정:** 방제 약제·소독약 내성, 약 −20~60°C 를 만족하는지 본다. 공조 문서 §7.5 약품 선정 기준에 플랩 재질을 함께 넣는다.
10. **전수 시험:** 간이 지그 (소형 팬 + 차압 센서) 로 출고 전 128 개 모두 **열림 압력·개방 손실·닫힘 누설**을 측정해 편차를 걸러낸다. 시제품은 진동 시험, 습윤 부착 시험 (결로 환경), 한 시즌 내구 시험을 거친다.

**닫힘 감시 — 아날로그 홀 센서**

평상시 (정방향 흐름) 에는 플랩이 열려 있어야 정상이라, 덜 닫히는 고장은 역압 순간에만 드러난다. 갠트리로 돌며 재거나 미세한 틈의 차압을 감지하는 것은 어렵다. 따라서 **플랩마다 아날로그 (거리 출력형) 홀 센서**로 자석 위치를 직접 읽는다.

| 구역 | 판정 | 동작 |
| :--- | :--- | :--- |
| **안전** | 밀폐 구간 안 (여유 포함) | 정상 |
| **경계** | 밀폐 구간 끝 | 에어 퍼지 추가 실행, 그 블록의 역압 운전 제한, 관리자 알림 |
| **열림·이물** | 흐름이 없어야 할 때 밀폐 구간 밖 | **즉시 관리자 경보**, 해당 블록 역압 운전 금지 |

- **임계값은 플랩마다 실측한다.** 출고 시험 지그에서 위치별 홀 출력과 **역압 약 5 Pa 에서의 누설량**을 함께 재고, 누설 허용치 안에 드는 홀 출력 범위를 그 플랩의 안전 구역으로 정한다. 자석 세기·센서 위치 편차를 플랩별로 흡수한다.
- **온도 보정:** 네오디뮴 자석은 온도가 오르면 약해진다 (약 −0.1%/K). 챔버 온도로 보정한다.
- **추이 감시:** 같은 닫힘인데 값이 서서히 변하면 시트 변형·퇴적물이다. **허용 추이를 벗어나면 관리자에게 알린다** (Keeper). 관리자는 Keeper 진단 화면에서 언제든 플랩별 현재값·추이·마지막 닫힘 확인 결과·퍼지 이력을 조회한다.
- **닫힘 확인 시험:** 소문 0 단계일 때 배기팬을 몇 초 멈추면 흐름이 멎어 128 개 플랩이 동시에 닫힌다. 이때 홀 값을 한꺼번에 읽는다. 소문이 닫혀 있으면 챔버 압력은 군 압력까지만 올라 역압이 생기지 않으므로 시험 자체는 안전하다. 정기 실행 (주기 값 미정) 과 관리자 수동 실행 (Keeper 버튼) 을 모두 둔다. 청소·팬 정지 같은 자연 역압 순간에도 자동 기록한다.
- **덤 — 라인별 유량 지시:** 정방향 흐름일 때 홀 값은 플랩 열림 각도, 즉 그 라인의 유량에 대응한다. 스캐닝 이중 추정·막힘 판정을 보강한다 (§2.3).
- 센서는 카세트가 아니라 **챔버 쪽 고정 프레임**에 두고 비접촉으로 자석을 읽는다. 카세트를 바꿔도 배선을 건드리지 않는다.

**에어 퍼지 청소 — Air Core 라인 배정**

Air Core (NB-HV-AIR) 에서 셀 블록마다 **퍼지 전용 라인**을 배정하고, 챔버 입구 플랩 열 위에 노즐 매니폴드를 둔다. 이따금 정기적으로 **약한 바람**으로 플랩 면·시트·힌지의 물방울·먼지·벌 부스러기를 털어 낸다. 결로막·밀랍·프로폴리스는 공기로 잘 떨어지지 않으므로 퍼지는 고착 예방용이고, 홀 추이가 회복되지 않으면 관리자 점검으로 넘긴다.

| 항목 | 내용 |
| :--- | :--- |
| **흐름 상태** | **배기팬이 도는 정방향 흐름 중**에 한다. 플랩이 열린 상태에서 노즐이 시트·플랩 면을 **하류 방향 (배기팬 쪽)** 으로 쓸어, 털린 부스러기가 배기와 함께 챔버 출구 쪽으로 나간다. 퍼지 공기가 늘린 챔버 압력은 L1 이 배기팬으로 즉시 보상해 **챔버가 군보다 낮게 유지**된다. 플랩을 닫고 챔버 쪽에서 쏘면 퍼지 공기가 챔버를 가압해 새는 플랩으로 챔버 공기가 군에 넘어갈 수 있으므로 쓰지 않는다 |
| **세기** | 저압, 솔밸브를 **천천히 열고 닫는다** (수 초 램프). 충격파가 아니라 바람이다. 노즐 압력·풍량 값 미정 |
| **순서** | 구역 (플랩 여러 개 묶음) 별로 차례로. 한 구역 몇 초 |
| **조건** | 소문 0 단계, 배기팬·챔버 압력 제어 정상, 청소·방제·내검 중이 아닐 것 |
| **주기** | 기본 주기 (값 미정, 예: 주 1 회) + 습한 유밀기에 늘림 + 홀 값이 경계 구역이면 추가 실행 |
| **감시·중단** | 퍼지 중 스캐닝 측정점 압력 맥동과 선풍·스트레스 음향을 본다. 한계를 넘으면 즉시 중단하고 다음부터 세기를 낮춘다 |
| **효과 기록** | 퍼지 전후 홀 닫힘값·라인 저항 비교. 퍼지 후 닫힘 확인 시험을 이어서 한다 |
| **공기 질** | 기름 없는 건조 공기 (오일 필터·드라이어). 컴프레서 공기의 기름·수분은 플랩·시트를 오염시킨다 |
| **진동** | 배기 라인과 벌통 사이 고무 커플링으로 구조 진동을 끊는다. 벌은 소리보다 벽을 타고 오는 진동에 민감하다 |

- 채택 전 **목업 검증:** 퍼지 중 군 쪽 압력 맥동, 벌통 벽 가속도, 선풍 음향을 재 영향이 없음을 확인한다.

**관리자 점검·교체 — 설계 조건**

- **접근:** 챔버 입구 플랩 열은 관리자 통로 쪽에서 닿게 두고, 카세트 앞마다 **작은 개별 점검 도어**를 둔다. 챔버 전체를 열면 실내 공기가 챔버로 들어가 챔버 압력이 군보다 높아질 수 있기 때문이다.
- **육안:** 투명 하우징으로 플랩 닫힘·립 접촉·퇴적물을 바로 본다. 플랩에 색 표식을 붙여 위치를 쉽게 판단한다.
- **교체:** 레일 + 원터치 래치로 공구 없이 빼고 끼운다. 카세트 슬롯에는 **스프링 셔터**를 둬 카세트를 빼는 순간 라인이 자동으로 막힌다.
- **교체 모드 (Keeper):** 교체 중에는 해당 블록 배기팬을 조금 올려 챔버를 군보다 확실히 낮게 유지한다.
- **현장 시험:** 뺀 카세트는 휴대용 시험 지그 (출고 지그 소형판) 로 열림 압력·닫힘 누설을 바로 잰다. 장착 후 Keeper 에서 닫힘 확인 시험을 실행해 새 카세트의 홀 기준값을 등록한다.
- **이력:** 카세트마다 QR 코드로 출고 실측값 (밀폐 구간 위치·열림 압력) 과 교체·세척 이력을 연결한다.

### 1.4 급기구 배치 — 두 실 각 하단, 반대편 끝 대각

**배치**

| 실 | 급기구 | 배기구 | 흐름 |
| :--- | :--- | :--- | :--- |
| **저밀실** | 가장 아래, A 끝 | 상단, B 끝 | 아래에서 위로 대각 훑기. 꽃꿀 증발 수분을 싣고 상단으로 빠진다. **부력과 같은 방향**이라 적은 압력으로 흐른다 |
| **육아실** | 가장 아래 (바닥 띠), A 끝 | 바닥, B 끝 | 바닥을 따라 수평으로 흘러 가라앉은 CO₂를 밀어낸다. 육아권을 직접 때리지 않는다. 일부는 데워져 위로 올라 저밀실 배기로 합류한다 |

```text
        [저밀실]  급기 (하단, A 끝) ──↗── 배기 (상단, B 끝)
  ───── 격왕판 ───── (육아실에서 오르는 더운 공기도 합류)
        [육아실]  급기 (바닥, A 끝) ──→ 바닥을 따라 ──→ 배기 (바닥, B 끝)
```

- 아래로 들어와 데워진 공기가 위로 빠지는 구조라 자연 벌통 (아래 소문) 과 비슷하고, 벌의 선풍 방향과도 맞는다.
- 냉방 급기는 무거워 바닥에 머문다. 벌 위로 찬바람이 떨어지지 않는다 (구동 방식 검토 문서 §5 생태 원칙).

**배치 조건**

1. **같은 실의 급기구와 배기구는 수평으로 반대편 끝에** 둔다. 같은 끝이면 바닥에서 지름길로 빠진다.
2. **바닥에 붙이지 않고 약 20~30 mm 띄운다 (가정).** 죽은 벌·밀랍 부스러기·떨어진 응애가 그릴을 막지 않게 하고, 새벽 청소 흡입 경로 (바닥 플랩 F) 와 겹치지 않게 한다.
3. **소문 반대편 끝에 둔다.** 육아실 급기가 바닥을 훑으며 군 냄새를 싣고 소문으로 나가므로 양압 페로몬풍에도 유리하다.
4. **겨울에는 육아실 급기를 최소로** 둔다. 봉구가 주로 아래·가운데에 있어 바닥 흐름이 봉구를 식힐 수 있다. 갠트리가 저밀실 쪽으로 돌린다.
5. 저밀실 급기 일부는 격왕판을 지나 육아실 배기로 내려갈 수 있다. 주 흐름은 부력 때문에 위쪽이지만, 육아실 습도 하한 제약 (공조 문서 §4) 은 계속 지킨다.
6. **조정부와 출구를 분리한다.** 플랩 (조정부) 은 갠트리가 닿는 실내 쪽 면에, 출구는 내부 채널로 하단 위치에 둔다. 아래층 셀 블록 가장 아래까지 갠트리가 닿지 않을 때도 같은 방식으로 해결한다.

**급기구 형태 — 가로 슬릿 카세트 (두 실 공통)**

| 항목 | 내용 |
| :--- | :--- |
| **방향** | 소초광 **끝면과 마주 보는 벽**의 하단 띠, 실 폭 전체. 옆벽 (소초광 면과 나란한 벽) 에 두면 가장 바깥 틈 하나로만 들어가 효과가 없다 |
| **분배** | 폭 전체에서 들어와 **모든 소초광 사이 틈에 고르게** 나뉜다. 한 점 급기구는 앞쪽 몇 틈으로만 흐른다 |
| **분배 상자** | 슬릿 뒤 깊이 약 20~30 mm 의 얕은 상자. 흡기 채널이 한쪽 끝으로 들어와도 길이 방향 압력이 고르게 된다 |
| **벌 차단** | 슬릿 폭이 아니라 **망** (약 3~4 mm, 시제품 비교) 으로 막는다. 슬릿을 벌이 못 지나갈 만큼 좁히면 필요한 길이가 수 m 가 된다 |
| **프로폴리스** | 벌은 약 6 mm 이하 틈을 메우고 약 9~10 mm 보다 넓은 공간에는 집을 짓는다. 망은 **벽 안쪽 면과 같은 높이**로 붙여 틈·빈 공간을 만들지 않는다 |
| **탈착** | 망 카세트를 **실내 쪽에서 서랍처럼 빼내는 구조** (권장). 군을 열지 않고 청소한다 |
| **부품 통일** | 육아실·저밀실 같은 카세트. 길이만 실 폭에 맞춘다 |

| 크기 (추정, 저밀실 기준) | 값 |
| :--- | :--- |
| 급기 풍량 | 약 25 m³/h (육아실 약 15) |
| 망 앞 풍속 목표 | 약 0.3~0.5 m/s |
| 필요 전면적 | 약 140~230 cm² |
| 예 (실 폭 350 mm 가정) | 슬릿 높이 약 40~65 mm × 길이 350 mm |
| 망 압력 손실 | 약 0.5 Pa 이하 (압력 예산 안) |

- 틈별 조절 루버, 여러 줄 슬릿 개별 조절, 정류 날개는 두지 않는다 (과설계). 군 풍량은 흡기 플랩 하나로 정하고 슬릿은 **고정형 분배구**로만 쓴다.
- 상단·하단 배기 라인의 분배는 주로 라인 저항으로 정해진다. 분배 비율을 크게 바꿔야 하면 배기 라인 **고정 오리피스를 계절마다 교체**한다.

### 1.6 소문 (Hive Gate) — 5 단계, 세 번째 출구

소문은 Tender Gantry 가 실내 쪽에서 **슬라이드 레버를 상하로 밀어** 조정한다. 레버는 **톱니 턱**에 걸려 주행 진동에도 단계가 바뀌지 않는다. 연속식이 아니라 **5 단계**로 정의한다.

| 단계 | 상태 | 쓰임 |
| :---: | :--- | :--- |
| **0** | 닫힘 | 방제, 새벽 청소, 주행 |
| **1** | **통풍 망** (벌은 막고 공기만 통함) | 열대야, 주행 중 환기. 밤에 소문을 열어야 하는 상황을 벌 출입 없이 해결한다 |
| **2** | 최소 (벌 1~2 마리 통로) | 월동, 도봉·말벌 방어 |
| **3** | 축소 | 봄·가을 평시 |
| **4** | 전개 | 유밀기 강군, 여왕 귀소 지원 |

**계단식으로 정한 이유**

- **단계 번호가 곧 개구 면적이다.** 갠트리 지령이 곧 실제값이라 위치 센서가 필요 없다. 연속식은 레버 유격·밀림으로 실제 면적과 오차가 생긴다.
- **학습이 빠르다.** 군마다 단계별 통기 계수 하나씩 (§2.5 의 G_ 단계) 만 학습하면 된다. 같은 단계 데이터가 반복해서 쌓인다.
- **예측 계수 세트와 바로 대응된다** (§2.4). 소문 단계가 공기 경로를 정한다.
- **막힘 진단:** 같은 단계인데 추정 유출량이 줄면 소문 프로폴리스 막힘이다. 벌은 가을에 소문을 좁히므로 유용하다.
- 해상도는 필요 없다. 유량의 미세 조정은 흡기 플랩과 챔버 압력이 맡고, 소문은 거친 단계로 충분하다. 관행 양봉의 소문 축소판도 몇 단계짜리다.

**제작 팁**

- 상하 슬라이딩으로 **높이**를 바꾸면 높은 단계에서 말벌·쥐가 드나든다. 대신 **슬라이드 판에 단계별로 다른 구멍 패턴**을 낸다. 벌 통로 높이는 일정하게 두고 구멍 개수·폭으로 면적만 바꾼다. 통풍 망 (1 단계) 도 같은 판에 넣는다.
- 갠트리는 단계 번호로 지령하고, 톱니 걸림 감촉 (힘 피드백) 이나 카메라로 맞물림을 확인한다.

**공조와의 관계 — 소문 단계는 주로 조건 변수다**

- 소문 크기를 정하는 주체는 **벌**이다 (출입 교통량, 방어, 계절). 공조가 환기를 위해 소문을 바꾸면 출입을 방해한다.
- **기본:** Hive Gate 가 정한 단계를 입력으로 받고, 공조는 흡기 플랩과 챔버 압력을 그에 맞춘다.
- **예외 — 공조가 요청할 수 있는 경우:** 강풍 (바람받이 면 축소), 도봉, 월동, 열대야 (1 단계 통풍 망), 여왕 귀소 지원 (4 단계). 공조와 벌 보호의 방향이 같을 때만 요청하고, 결정은 Hive Gate 운영 규칙이 한다.

### 1.7 챔버 연결 — 평시 분리, 필요 시 연동

셀 블록 L·R 은 차량의 **반대쪽 면**을 보고 있어 바람·일사·소문 상태가 서로 다를 때가 많다. 그래서 두 배기 챔버를 항상 하나로 묶지 않고, **연결 덕트 + 평시 닫힘 연결 댐퍼**로 이어 필요할 때만 연동한다.

```text
[블록 L 챔버] ──── 연결 덕트 + 연결 댐퍼 (평시 닫힘) ──── [블록 R 챔버]
```

**연결로 얻는 것**

| 장점 | 내용 |
| :--- | :--- |
| **팬 이중화** | 블록별로는 팬 1 대 고장 시 그 블록만 크게 줄어든다. 연동하면 유닛 전체 팬이 나눠 맡아 손실이 고르게 퍼진다 |
| **부하 분담** | 양지 쪽 블록, 강군이 많은 블록처럼 필요량이 한쪽으로 쏠릴 때 반대쪽 여유 용량을 쓴다 |
| **저부하 효율** | 겨울·밤처럼 풍량이 적을 때 일부 팬만 효율 좋은 구간에서 돌리고 나머지는 쉰다. 수명·전력 이득 |
| **정비** | 한쪽 팬·ERV 정비 중 반대쪽이 (줄어든 용량으로) 받아 준다 |

**항상 연결하지 않는 이유**

| 단점 | 내용 |
| :--- | :--- |
| **블록별 압력 조절 상실** | 챔버 압력이 하나로 묶여 두 블록 중 더 빡빡한 쪽에 맞춰야 한다 (바람받이 면 대 바람 뒷면, 소문 열림 블록 대 닫힘 블록) |
| **방역 구획 확대** | 역압 사고 시 섞이는 범위가 32 군에서 64 군으로 늘어난다. 질병 의심 블록을 떼어 낼 수 없다 |
| **방제·청소 간섭** | 블록 방제의 잔류 가스, 청소 중 챔버 동반 감압이 반대쪽에 영향을 준다 |

- 평시 챔버끼리 공기가 오가는 것은 해가 없다. 둘 다 역류 방지 플랩 하류라 결국 밖으로 나가는 공기다. 위험은 역압 사고 때 섞이는 범위뿐이다.

**운전 모드**

| 모드 | 연결 댐퍼 | 쓰는 때 |
| :--- | :---: | :--- |
| **분리 (기본)** | 닫힘 | 평시. 블록마다 챔버 압력을 따로 조절한다 (소문 상태, 바람 면, 청소) |
| **연동** | 열림 | 한쪽 팬 고장, 한쪽 정비, 저부하 효율 운전, 한쪽 블록 부하 급증 |
| **격리 강제** | 닫힘 고정 | 질병 의심, 블록 방제, 블록 새벽 청소, 한쪽 강풍, 두 블록 소문 상태 차이가 클 때. **연동 요청보다 우선한다** |

**연동 제어 규칙**

1. **전환 순서:** 댐퍼를 열기 전에 두 챔버 압력을 비슷하게 맞추고 천천히 연다. 압력이 출렁이면 일부 군에 순간 역압이 걸릴 수 있다. 닫을 때도 천천히 닫고, 닫은 뒤 블록별 목표로 돌아간다.
2. **공통 목표:** 연동 중 챔버 목표 압력은 **두 블록 요구 중 더 낮은 (빡빡한) 쪽**이다. 소문 유출 기준 (§2.5) 과 육아실 우선 원칙은 두 블록 전체에 적용한다.
3. **팬 배분:** 연동 중에는 두 챔버 압력 센서의 평균이 아니라 **낮은 쪽 블록의 요구**를 만족하도록 유닛 전체 팬 출력을 정한다. 저부하 운전이면 효율 좋은 팬부터 돌리고 운전 시간을 고르게 돌려 쓴다.
4. **닫힘 확인:** 연결 댐퍼는 닫혔을 때 새지 않아야 한다 (방역 구획). 홀 센서·리밋 스위치로 닫힘을 확인하고, 분리 모드에서 두 챔버 압력 차이를 따로 움직여 교차 검증한다.
5. **격리 우선:** 격리 강제 사유가 생기면 연동 중이라도 즉시 닫힘 순서로 들어간다. 팬 고장으로 연동이 필요한데 격리 강제가 걸려 있으면, 고장 블록은 비상 운전 (소문 닫힘 요청, 급기 유지, Keeper 경보) 으로 버틴다.

**물리 구성**

- 연동 때 한쪽 블록 풍량의 약 절반을 옮길 수 있는 크기 (가정, 팬 실측 후 확정).
- 두 챔버가 양쪽으로 떨어져 있으므로 통로를 가로지른다. 천장 또는 바닥 공간을 쓰고 갠트리 동선과 겹치지 않게 한다.
- **연결 위치는 ERV 앞 (챔버끼리)** 을 권장한다. 팬과 ERV 를 모두 나눠 쓸 수 있다. ERV 를 블록마다 둘지 (§5 항목 11) 와 함께 정한다.
- 군·복합군 배기 댐퍼 모터 0 원칙과 충돌하지 않는다. 유닛 단위 장치다.

## 2. 제어 층

| 층 | 위치·주기 | 역할 |
| :--- | :--- | :--- |
| **L0 하드웨어** | — | 역류 방지 플랩, 급기구 대각 배치, 배기 라인 고정 오리피스, 배기팬 역풍 방지 댐퍼 |
| **L1 빠른 제어** | 모듈 MCU (ESP32), 약 10 Hz | 급기팬 → 실내 압력, 배기팬 → 챔버 압력 고정 (챔버 목표값은 소문 상태에 따라 L2 가 정한다, §2.5). 출입문 개방·내검 인출 보상. 팬 소프트 스타트 |
| **L2 배분** | Hive Mind, 분~시간 | 목표 풍량 → Aero 테이블 역산 → 플랩 개도 지령 → Tender Gantry 작업 큐. 육아실 예측 가드 (§2.4) 가 조절량과 다음 조절 시각을 정한다 |
| **L3 보정** | 스캐닝, 상시 순환 | 라인별 압력 → 유량 이중 추정 → 저항 DB 갱신·막힘 판정 |

### 2.1 전체 환기량 — 빠른 레버

- 군별 유량은 대략 **√(실내 − 챔버 압력차) × 플랩 개도 계수**에 비례한다. 전체 환기량은 이 압력차를 팬 PWM 으로 바꿔 모든 군을 한꺼번에 비례 조정한다.
- 유량을 2 배로 하려면 압력차가 약 4 배 필요하다. 따뜻한 날 최대 풍량에서는 실내 압력을 일시적으로 높인다 (상한 값 미정, 출입문 누설 증가).
- 챔버 압력 목표는 시각이 아니라 **블록의 소문 상태**로 정한다. 블록 안에 소문 1 단계 이상인 군이 하나라도 있으면 소문 유출 기준 (§2.5) 을 따르고, 모두 0 단계면 외기 기준 0 Pa 까지 허용한다 (가정).
- CO₂ 상한 같은 급한 제약은 이 레버로 먼저 대응한다. 갠트리 플랩 조정을 기다리지 않는다.
- 계획된 압력차 변경은 육아실 예측 가드 (§2.4) 의 전역 층 규칙에 따라 미리 예고한다. 팬 수량 × RPM 은 제어 목표가 아니라 진단용 결과값이다.

### 2.2 군별 배분 — Aero 테이블

| 항목 (플랩마다) | 내용 |
| :--- | :--- |
| 개도 - 유량 곡선 | 기준 압력차에서의 유량. 초기값은 목업·시운전 실측 |
| 배기 라인 저항 | 라인 길이·형상·오리피스로 정해지는 값. L3 가 갱신 |
| 위치 보정 | 층 (굴뚝 효과), 블록 내 위치 |
| 소문 통기 계수 G_ 단계 | 군별·단계별 (5 단계). 초기값은 설계 면적, 스캐닝으로 갱신 (§2.5) |
| 현재 개도 | 갠트리가 마지막으로 설정한 값 (플랩은 고정 홈으로 유지) |

- **역산:** 목표 풍량과 현재 압력차로 필요한 개도를 계산해 갠트리 작업 큐에 넣는다.
- **작업 순서:** 제약 위반 군 → 목표 편차가 큰 군 → 정기 균형 순. 갠트리의 내검 일정과 시간을 나눈다.
- **육아실 우선:** 저밀실 플랩 개도와 다음 조절 시각은 **육아실 예측 가드 (§2.4)** 가 정한다. 육아실 기준 회복이 목적인 조정은 저밀실 조정보다 먼저 처리한다.
- **최소 개도:** 모든 플랩은 최소 개도 이상을 유지한다. 챔버 쪽 총 유로가 막히지 않아 팬 실속 (서징) 이 생기지 않는다.

### 2.3 스캐닝 보정 — 유량 이중 추정

각 배기 라인의 **그릴 바로 뒤 (벌 공간 밖)** 에 측정점 하나를 둔다. 셀 블록 64 개 측정점을 솔밸브 매니폴드 또는 회전형 셀렉터로 차례로 차압 센서 1 개에 연결한다. 측정점 압력은 군 압력 (P 군) 의 근사값이다.

| 추정 | 계산 |
| :--- | :--- |
| **흡기 쪽 유량** | (P 실내 − P 군) 과 플랩 개도 |
| **배기 쪽 유량** | (P 군 − P 챔버) 와 라인 저항 DB |

**판정**

| 관측 | 판정 | 동작 |
| :--- | :--- | :--- |
| 소문 0 단계 (닫힘) 에서 두 추정이 일치 | 정상 | 저항 DB 를 느린 평균으로 갱신 |
| P 군이 **실내 쪽으로 붙음** (흡기 손실 거의 없음) | **배기 쪽 막힘** — 배기 그릴 프로폴리스, 역류 방지 플랩 고착 | 홀 값으로 구분. 그릴이면 Tender 청소 과제, 플랩이면 에어 퍼지 후 미회복 시 관리자 알림 (§1.3) |
| P 군이 **챔버 쪽으로 붙음** | **흡기 쪽 막힘** — 흡기 그릴 프로폴리스, 플랩 개도 이탈 | Tender 청소·플랩 재설정 |
| 소문 1 단계 이상에서 흡기 > 배기 | 정상. 차이가 **소문 유출량** (양압 페로몬풍) | 소문 유출 제어 입력, 소문 통기 계수 G_ 단계 갱신 (§2.5) |
| 소문 열림인데 흡기 ≤ 배기 | **소문으로 외기 유입** | 챔버 압력 상향 (§2.5), 반복되면 흡기 플랩 재배분 |
| 같은 소문 단계에서 유출량이 점점 감소 | 소문 프로폴리스 막힘 | Tender 청소 과제 |
| 같은 군 저밀실·육아실 측정점 차이 과다 | 실 사이 막힘 또는 한쪽 라인 이상 | 점검 |

- 소문이 0 단계면 흡기와 배기가 같아야 한다 (소초광 틈 누설은 작게 본다). 1 단계 (통풍 망) 는 열림으로 취급한다.
- **저항 DB 갱신과 야간 응답 시험은 그 군의 소문이 0 단계일 때만 한다.** 시각이 기준이 아니다. 열대야로 밤에도 열려 있으면 새벽 청소 시간대 (소문 닫힘) 나 비 오는 날로 보정 기회를 잡는다.
- 공조 문서 §1.6 의 **야간 응답 시험** (팬 PWM 한 단계 변경 후 응답) 과 함께 쓰면 판정이 더 확실하다.
- **판정 보류:** 선풍 음향 (격리판 센서) 이 높거나 출입 교통량 (Hive Gate IR 카운터) 이 많을 때, 소문 면 바람이 셀 때는 소문 유출 판정을 보류한다. 벌이 소문에서 공기를 직접 밀고 당기거나 바람이 압력을 덮기 때문이다.

**구현**

- 한 바퀴: 64 측정점 × 안정 시간 약 3~5 초 → 약 4~5 분.
- 센서: ±25~125 Pa 범위, 약 0.05 Pa 분해능 (Sensirion SDP8xx 급). 두 포트를 잇는 밸브로 주기적 자동 영점.
- 측정 튜브: 습한 배기라 물이 맺힌다. 배수 기울기 + 소수성 필터. 튜브 길이는 응답 시간에만 영향을 준다.
- 제어용 고정 센서 (실내↔외기 1 개, 챔버↔실내 블록당 1 개) 는 스캐닝과 별도다. 빠른 루프는 순차 측정으로 돌릴 수 없다.

### 2.4 육아실 예측 가드 — 다음 조절량과 다음 조절 시각

저밀실 플랩을 열어도 육아실은 **즉시 반응하지 않고**, 갠트리는 **실시간으로 조정할 수 없다.** 현재값이 기준을 넘은 뒤 대응하면 늦다. 따라서 **추이로 앞날을 예측해, 이번에 얼마나 조정할지와 다음에 언제 다시 조정할지를 함께 정한다** (단순화한 예측 제어).

**기준 재정의 — 고정값이 아니라 추이**

| 항목 | 내용 |
| :--- | :--- |
| **지표** | 육아실 **절대습도 (또는 이슬점)**. 상대습도는 온도 변화에 흔들리므로 쓰지 않는다 |
| **정상 범위** | 군마다 학습한 평소 육아실 값의 범위. 벌이 스스로 조절하므로 군마다 다르다 |
| **경고선 H_warn** | 정상 범위 하단 + 여유 |
| **판정** | 현재값이 아니라 **예측 궤적이 경고선에 닿는 시각**과 **하락 속도**로 판정한다 |

**변수 체계 — 조작 변수와 조건 변수**

예측에 들어가는 변수는 **직접 움직이는 조작 변수**와 **모델 계수·예측을 바꾸는 조건·외란 변수**로 나눈다.

| 조작 변수 | 범위 | 속도 | 장치 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **저밀실 흡기 플랩 개도 u_h** | 군별 | 느림 (갠트리, 시간 단위) | Tender Gantry | 가드의 주 조절 대상 |
| **육아실 흡기 플랩 개도 u_b** | 군별 | 느림 | Tender Gantry | CO₂ 와 건조 사이 균형 |
| **실내 − 챔버 압력차 ΔP** | 셀 블록 | 빠름 (초) | 급기팬·배기팬 PWM | 전체 환기량 (§2.1) |
| **실내 압력 수준 P 실내** | 유닛 | 빠름 | 급기팬 PWM | 군 양압 수준, 소문 열림 때의 소문 유출량 |
| **급기 온도·절대습도 T_s, w_s** | 유닛 | 중간 (분) | 급기 코일 (히트펌프·펠티어) | **육아실 습도에 가장 직접적인 변수** |
| **ERV 자유 냉방 바이패스** | 유닛 | 중간 | Fanner 유닛 댐퍼 | 급기 온도 |

- **팬 수량 × RPM 은 조작 변수가 아니라 결과값이다.** 압력 샌드위치에서 팬은 압력을 맞추도록 돌아가므로, 같은 RPM 이라도 필터 막힘·플랩 개도에 따라 실제 풍량이 달라진다. 제어는 압력으로 하고, 팬 수량 × RPM 은 팬 곡선과 함께 **총풍량 추정·필터 막힘 진단·팬 고장 감지·전력 추정**에 쓴다.
- 급기 상태는 지령값이 아니라 실측값을 쓴다. 군별 격리판 센서는 벌의 영향이 섞인 결과값이라 대신할 수 없다. 센서 두 곳의 정확한 위치는 공조 문서 §1.5 를 따른다.
  - **① 급기 출구** (블로어 뒤 덕트, 실내 토출구 바로 앞): 선행 신호. 급기 변화를 육아실보다 수십 분~수 시간 먼저 안다.
  - **② 실내 대표점** (셀 블록마다, 갠트리 쪽 흡기 플랩 높이): 군이 실제로 들이마시는 공기. **모델의 급기 상태 입력 T_s, w_s 는 이 값**을 쓴다.

| 조건·외란 변수 | 쓰는 방식 |
| :--- | :--- |
| **소문 단계** (군별, Hive Gate 0~4, §1.6) | **계수 세트 전환.** 공기 경로 자체가 달라져 θ·τ·K 가 크게 바뀐다. 시각 (낮·밤) 은 보조 정보다. 열대야처럼 밤에도 열릴 수 있다 |
| **출입 교통량** (Hive Gate IR 카운터) | 벌 몸이 소문을 막아 유효 개구가 줄어든다. 소문 통기 계수 보정, 선풍벌 판정 (§2.5) |
| **소문 면 풍속·풍향** | 바람 동압이 군 양압보다 클 수 있다. 외란 입력, 강풍 대응 (§2.5) |
| **계절·군 상태** (증식기·유밀기·월동, 육아권 크기, 세력) | 계수 세트 전환, 정상 범위 갱신 |
| **날씨** (외기 온도·이슬점, 비, 일사) | 대부분 **급기 상태를 거쳐** 들어오므로 급기 실측값으로 상당 부분 반영된다. 나머지 (소문 유입, 일사에 의한 외피 가열) 는 외란 입력으로 둔다. **예보**는 전역 운전 계획에 쓴다 |
| **유밀량** (꽃꿀 증발 수증기) | 외란 입력. 저밀실 무게 변화·배기 습도로 추정 |
| **이벤트** (내검, 청소, 방제, 주행) | 이후 일정 시간 예측 신뢰도를 낮추고 조절 간격을 줄인다 (운영 규칙 2) |

**2 층 구조 — 전역 층과 군별 층**

```text
[전역 층] ΔP · P실내 · 급기 코일 · ERV 바이패스    ← 날씨 예보 · 전체 군 상태
    │  모든 군에 동시에 작용. 계획된 변경은 미래 입력으로 미리 알린다
    ▼
[군별 층] 저밀실 · 육아실 플랩 + 육아실 예측 가드   ← 소문 단계 · 계절 계수 세트
```

- **전역 층은 유닛의 모든 군을 보고 정한다.** 기준은 **가장 빡빡한 육아실**이다. 예를 들어 야간 제습 강도는 가장 건조해지기 쉬운 군이 버틸 수 있는 범위에서 정한다.
- **계획된 전역 변경은 미리 알린다.** "22 시부터 제습 강화 " 같은 계획을 군별 예측식에 **미래 입력**으로 넣어, 군별 층이 미리 플랩을 조정할 시간을 준다. 리드 타임 L 보다 늦게 예고되는 전역 변경은 하지 않는다 (생명 제약 대응은 예외).
- **군별 층의 결과는 전역 층으로 올라간다.** 플랩만으로 경고선을 지킬 수 없는 군이 있으면 전역 층이 제습 완화·압력차 감소 같은 조정을 다시 계획한다.

**응답 모델 — 다입력**

\[
H_b(t) = H_{now} + s \cdot t + \sum_i K_i \, \Delta u_i \left(1 - e^{-(t - t_i - \theta_i)/\tau_i}\right) \quad (\text{각 항은 } t > t_i + \theta_i \text{ 일 때만})
\]

| 기호 | 뜻 |
| :--- | :--- |
| **Δu_i** | 입력 i 의 변화량. i = 저밀실 플랩, 육아실 플랩, ΔP, 급기 절대습도, 급기 온도 |
| **t_i** | 변화 시각. 이번 플랩 조정은 0, 전역 층이 예고한 변경은 미래 시각 |
| **θ_i (지연)** | 입력 i 가 바뀐 뒤 육아실이 움직이기 시작할 때까지의 시간 |
| **τ_i (시간상수)** | 반응이 대부분 끝날 때까지의 속도 |
| **K_i (이득)** | 입력 i 의 변화량당 육아실 절대습도 변화량 |
| **s (잔여 추세)** | 모델에 들어 있지 않은 외란이 남긴 최근 기울기 (유밀량, 일사 등) |

- 계수 세트는 조건 (소문 단계 × 계절·군 상태) 으로 고른다.
- 예측 구간 안에 예약된 소문 단계 변경 (개폐 시각) 이 있으면, 그 시각에 계수 세트를 바꿔 이어서 계산한다.

**학습 전략 — 군별 계수는 최소로**

| 계수 | 학습 단위 | 데이터 |
| :--- | :--- | :--- |
| 저밀실·육아실 플랩 계수 | **군별** | 갠트리의 플랩 조정 하나하나가 계단 응답 시험이다 |
| 전역 입력 계수 (ΔP, 급기 온습도) | **유닛 공유** (층·위치 보정만 군별) | 전역 변경은 모든 군에 동시에 작용하므로 모든 군의 데이터를 함께 쓴다 |
| 외란 계수 (외기, 유밀량) | 유닛 공유 → 데이터가 쌓이면 군별 보정 | 운영 기록 |

- 군별로 추정할 계수가 적어 첫 시즌 데이터로도 학습이 된다.
- 변수는 핵심 (플랩 2, ΔP, 급기 절대습도, 소문 단계) 부터 넣고, 데이터가 쌓이면 늘린다. 처음부터 변수를 많이 넣으면 과적합된다.
- 따로 시험하지 않고 운영 중 조정을 학습 데이터로 쓴다. 야간 응답 시험 (§2.3) 때의 팬 PWM 단계 변경은 ΔP 계수 학습을 겸한다.

**계산식**

| 결정 | 방법 |
| :--- | :--- |
| **저밀실 조절량 Δu_h** | 전역 층이 예고한 입력을 넣은 상태에서, 다음 조절 시각 T 까지 H_b(t) ≥ H_warn 을 만족하는 범위에서 저밀실 개도를 **가장 크게** 둔다. 숙성은 최대로, 육아실은 지킨다 |
| **육아실 조절량 Δu_b** | CO₂ 상승과 건조 사이 균형. 아래 확장 표의 CO₂ 가드와 함께 정한다 |
| **다음 조절 시각 T_next** | 예측 궤적이 H_warn 에 닿는 시각 − 리드 타임 L (갠트리 이동·대기). 최소·최대 간격 사이로 제한한다 |

- T 와 Δu 는 서로 얽혀 있다. 기본 간격 (값 미정) 으로 Δu 를 구하고, Δu 가 1 회 변경량 상한을 넘거나 추세가 계속 나쁘면 T 를 줄여 다시 계산한다.

**운영 규칙**

1. **비대칭:** 저밀실 플랩을 **줄이는 것은 과감히** (안전한 방향), **여는 것은 조금씩** (1 회 변경량 상한).
2. **불확실하면 짧게 본다.** 새 군, 내검 직후 (소초광 틈 밀봉 상태 변화), 날씨 급변, 예측 오차가 클 때는 T_next 를 줄이고 여유를 키운다. 안정되면 간격이 자연스럽게 늘어난다.
3. **갠트리 큐:** 군별 예약 시각이 작업 큐가 된다. **마감이 가까운 순서**로 처리하고, 이웃 군은 묶어 동선을 줄인다. 내검과 겹치면 마감이 임박한 조정이 먼저다.
4. **안전망:** 예측보다 빨리 떨어지면 (모델 오차) 빠른 레버를 쓴다 — 급기 코일 제습 완화, 전체 압력차 감소, 갠트리 긴급 호출 (내검 중단). 빠른 레버는 유닛 전체에 작용하므로 최후 수단이다.
5. **초기 운전:** 학습 데이터가 없으면 작은 변경량·짧은 간격으로 시작하고, 데이터가 쌓이면 간격을 늘린다.
6. **기록:** 예측값과 실제값의 차이를 남겨 모델 정확도를 추적한다 (Keeper 진단 화면).
7. **재계획 트리거:** 계획에 없던 전역 변경 (안전망 레버 사용 포함), 날씨 급변 (예보와 실측의 차이 과다), 소문 단계 변경, 계수 세트 전환이 생기면 **모든 군의 조절량과 다음 조절 시각을 다시 계산**하고 갠트리 큐를 다시 정렬한다.

**확장 — 같은 틀을 다른 변수에도**

| 변수 | 걱정하는 방향 | 원인이 되는 조정 |
| :--- | :--- | :--- |
| 육아실 절대습도 | 하락 (건조) | 저밀실 플랩 개방, 급기 코일 제습, 전체 압력차 증가 |
| 육아실 온도 (가장자리) | 하락 (냉각) | 냉방, 저밀실 환기 강화, 겨울 육아실 급기 |
| 육아실 CO₂ | 상승 | 육아실 플랩 축소 (건조 방지 조정의 부작용) |

- 셋을 **하나의 예측 가드**로 묶는다. 조절량과 다음 조절 시각은 세 변수 중 **가장 빡빡한 쪽**이 정한다.

### 2.5 소문 유출 제어 — 소문이 열렸을 때의 목표

소문이 열리면 (1~4 단계) 소문은 외기로 바로 통하는 큰 구멍이 되어 군 압력은 외기보다 조금 높은 수준에 묶인다. 이때 지킬 것은 압력이 아니라 **군별 유량 균형**이다. 이상적인 상태는 **소문으로 최소한의 양압 바람만 나가고, 나머지 환기는 배기 라인이 맡는 것**이다.

\[
Q_{소문} = Q_{흡기} - Q_{배기라인} > 0, \qquad Q_{소문} = G_{단계} \cdot \sqrt{\Delta P_{소문}}
\]

| 기호 | 뜻 |
| :--- | :--- |
| **Q_ 소문** | 소문 유출량. 스캐닝의 흡기 추정 − 배기 추정 (§2.3) 으로 구한다 |
| **G_ 단계** | 그 군·그 소문 단계의 통기 계수. 초기값은 설계 면적, 운영 데이터로 갱신. 교통량이 많으면 IR 카운터로 유효값을 낮춘다 |
| **ΔP_ 소문** | 군 압력 − 소문 앞 외기 압력 (바람 동압 포함) |

**목표와 조절**

| 항목 | 내용 |
| :--- | :--- |
| **목표** | 소문 최소 풍속 ≤ 소문 풍속 ≤ 소문 풍속 상한 (값 미정). 목표 유출량 = 목표 풍속 × 단계 면적. 여왕 귀소 지원 때는 상한까지 올린다 |
| **빠른 조절** | 셀 블록 챔버 압력 (배기팬). 챔버를 낮추면 배기 라인이 더 당겨 소문 유출이 줄고, 올리면 는다. **블록 안에서 유출이 가장 작은 군이 최소 풍속을 지키도록** 정한다 |
| **느린 조절** | 군별 흡기 플랩. 군 사이 유출 편차를 Aero 테이블로 재배분한다 |

**낮 배기 운전 — 배기팬은 끄지 않는다**

- 소문 유출은 군 환기량의 약 10~15% 수준이다 (§1.5). 더 빼려면 군 압력을 올려야 하고, 그러면 소문 풍속이 세져 착륙을 방해한다.
- 환기 수요가 가장 큰 때가 **여름 낮 (소문 열림)** 이다. 나머지 85~90% 는 배기 라인으로 빠져야 하므로 여름 낮 배기팬은 높게 돈다. 봄·가을 낮은 낮게 돈다.
- 배기팬을 끄면 챔버 압력이 군 압력까지 올라 배기 라인 흐름이 멈춘다. 모든 공기가 소문으로 몰려 풍속이 지나치게 세지고, 저밀실 상단 배기가 사라져 숙성 제습 흐름이 끊기며, 꿀의 습기·열이 육아실을 거쳐 소문으로 나간다.
- **배기 응축 코일은 줄이거나 끈다.** 소문 열린 군이 많을수록 공기 일부가 ERV·코일을 거치지 않아 포획 효율이 낮다. 포획은 소문이 닫힌 밤에 주력으로 한다.

**소문 면 바람**

| 풍속 | 동압 (약) | 의미 |
| :--- | :--- | :--- |
| 2 m/s | 2.4 Pa | 군 양압 (+1~4 Pa) 과 비슷 |
| 3 m/s | 5.4 Pa | 군 양압보다 크다. 바람받이 면 소문으로 외기가 밀려 든다 |
| 5 m/s | 15 Pa | 압력 샌드위치로 막을 수 없다 |

- **하드웨어:** 소문 앞 바람막이·미로형 소문으로 동압을 줄인다 (Hive Gate 설계).
- **센서:** 소문 면 풍속·풍향 센서. 차량 양면이 다르므로 면마다 둔다.
- **운전:** 강풍이면 실내 압력을 상한까지 올리고, 바람받이 면 군의 소문 축소 (2 단계) 를 Hive Gate 에 요청한다. 바람이 압력을 덮는 동안은 소문 유출 판정과 학습을 보류한다.

**선풍벌·교통량**

- 소문에서 선풍하는 벌은 공기를 직접 밀고 당겨 유량 균형 판정을 흔든다. 선풍 음향 (격리판 센서) 이 높을 때는 소문 유출 판정을 보류하고, 그 구간 데이터는 예측 모델 학습에서 가중치를 낮춘다.
- 교통량이 많으면 벌 몸이 소문을 막는다. IR 카운터로 G_ 단계 유효값을 보정한다.

## 3. 운전 상태 연동

| 상황 | Aero Profiler 동작 |
| :--- | :--- |
| **새벽 청소** | L2 배분 정지. 청소 경로 (푸시 - 풀 사양서 댐퍼 E·플랩 F) 는 별도 구동부다. 청소 중인 군은 챔버보다 낮은 압력이 되어 **그 군의 역류 방지 플랩이 닫히므로** 챔버 공기가 넘어오지 않는다. L1 은 실내 양압을 유지한다 |
| **자율 방제** | L2 정지. 방제 전 해당 복합군 흡기 플랩을 최소로 둔다 (공조 문서 §7.5). 방제 후 잔류 가스는 플랩 개도 증가로 뺀다 |
| **내검** | 시작 전 해당 군 흡기 플랩을 최소로 둔다. 인출 순간의 압력 변화는 L1 이 급기팬으로 보상한다 |
| **여왕 귀소 지원** | 해당 군 소문 4 단계 (전개) 요청, 소문 쪽 실 흡기 플랩을 최대로 연다 (공조 문서 §7.4). 소문 풍속 상한 준수 |
| **열대야** (밤에도 환기 필요) | 소문 1 단계 (통풍 망) 요청. 해당 블록 챔버 압력은 소문 유출 기준 (§2.5). 그 군의 저항 DB 보정은 다음 소문 닫힘 때로 미룬다 |
| **강풍** | 실내 압력 상한까지 상향, 바람받이 면 소문 2 단계 요청, 소문 유출 판정·학습 보류 (§2.5) |
| **플랩 닫힘 확인 시험** | 소문 0 단계에서 배기팬 수 초 정지 → 128 개 홀 값 일괄 판독 → 정상 운전 복귀 (§1.3) |
| **플랩 에어 퍼지** | 소문 0 단계, 정방향 흐름 유지. L1 이 퍼지 공기만큼 배기팬을 올려 챔버를 군보다 낮게 유지. 구역별 순차, 끝나면 닫힘 확인 시험 (§1.3) |
| **플랩 교체 모드** | 관리자가 Keeper 에서 시작. 해당 블록 배기팬을 조금 올려 챔버를 군보다 확실히 낮게 유지. 장착 후 닫힘 확인 시험으로 홀 기준값 등록 |
| **플랩 열림·이물 경보** | 해당 블록 역압 운전 금지 (청소 경로 사용 보류, 챔버 압력 상한 강화), 관리자 즉시 알림 |
| **출입문 개방** | L1 이 급기팬을 즉시 올린다. 흡기 플랩의 역류 방지 기능이 섞임을 막는다 |
| **배기팬 1 대 고장** | 역풍 방지 댐퍼가 닫히고, 남은 팬이 소프트 스타트로 올라가 챔버 압력을 유지한다 |
| **배기팬 2 대 정지** | 챔버 압력이 군 압력까지 올라 흐름이 멈추고 역류 방지 플랩이 닫힌다. **섞이지 않는다.** 급기는 계속 돌아 군은 실내 압력 쪽으로 붙는다. CO₂ 상승 → 경보·비상 운전. 격리 강제 사유가 없으면 **연동 모드**로 반대쪽 블록 팬이 거든다 (§1.7) |
| **배기팬 1 대 고장 (연동 가능 시)** | 연동 모드로 전환해 유닛 전체 팬이 나눠 맡는다. 손실이 한 블록에 몰리지 않는다 (§1.7) |

- 유닛 단위 댐퍼 (ERV 자유 냉방 바이패스, 외기 보충 흡입, 배기팬 역풍 방지, 챔버 연결 댐퍼) 는 Fanner 장치다. 챔버 연결 댐퍼의 개폐 판단은 Aero Profiler 가 하고 (§1.7), 구동은 Fanner 가 한다.

## 5. 확인 필요

1. **압력 예산 실측:** 복합군 1 개 목업으로 2.5~4 Pa 안에서 실제 유량, 굴뚝 효과, 역류 방지 플랩 열림 압력 확인
2. 배기 라인 굵기 확정과 셀 블록 안 배관 공간 (128 라인)
3. 역류 방지 플랩 재질·형상 (필름 + 자석 보조 vs 자석 척력형), 겹침 립 밀폐 구간 길이, 떨림·소음·습윤 부착·진동·내구 시험, 출고 전수 시험 지그와 합격 기준 (열림 압력·개방 손실·닫힘 누설)
4. 흡기 플랩 기구: 개도 조절·고정 홈·역류 방지·탈착 그릴, 저밀실·육아실 각각의 갠트리 접근 위치
5. 슬릿 카세트: 슬릿 높이·망 규격, 분배 상자 깊이, 실내 쪽 서랍식 탈착 구조, 바닥 띄움 높이, 조정부 - 출구 내부 채널 구조
6. **격리판·격왕판 급기구 융합 가능성** (검토 예정): 슬릿 카세트·분배 상자를 격리판 또는 격왕판에 통합할 수 있는지
7. 육아실 바닥 배기를 소문 쪽 끝에 둘지 (문지기벌 구역의 프로폴리스 막힘 가능성, 목업 비교)
8. 저밀실 하단 분배 공간: 격왕판과 소초광 하단 사이 간격 (벌 통로 약 8~10 mm) 이 좁아 분배가 제한되는지
9. 스캐닝 구성: 솔밸브 64 개 vs 회전형 셀렉터, 튜브 배수, 센서 사양
10. 챔버 압력 목표값·하한 (블록 소문 상태별: 모두 닫힘 / 열린 군 있음), 실내 압력 상한
11. ERV·배기 응축 코일을 셀 블록마다 둘지, 급기 계통 구성 (공통 실내로 1 계통 또는 2 계통)
12. 배기팬 사양 (1 대로 블록 배기 감당), 역풍 방지 댐퍼
13. Tender Gantry 작업 큐에서 플랩 조정과 내검의 시간 배분 (마감 순 처리, 이웃 군 묶음)
14. 상·하단 분배용 고정 오리피스 필요 여부와 교체 주기
15. 전력 예산 문서의 " 복합군 급배기 댐퍼 32 개 " 항목 갱신 (전력 예산 정리 때)
16. 육아실 예측 가드 (§2.4): 경고선 여유, 기본·최소·최대 조절 간격, 1 회 변경량 상한, 계수 세트 분할 단위 (소문 단계 × 계절·군 상태), 초기 운전 보수값
17. 육아실 절대습도 측정: Hive Wall 격리판 센서의 온습도로 계산할지, 정확도와 응답 속도
18. 급기 온습도 센서 (공조 문서 §1.5 ① 급기 출구·② 실내 대표점): 덕트 내 혼합 거리, 층별 추가 여부, 정확도. 팬 곡선 데이터 확보 (팬 수량 × RPM → 총풍량 추정)
19. 전역 변경 예고 리드 타임과 전역 층 결정 주기, 날씨 예보 연동 방식 (예보 소스, 급변 판정 기준)
20. Hive Gate 5 단계 (§1.6): 단계별 개구 면적·구멍 패턴, 벌 통로 높이, 통풍 망 규격, 톱니 턱 구조, 갠트리 맞물림 확인 방식 (힘 피드백·카메라)
21. 소문 유출 제어 (§2.5): 소문 최소 풍속·상한, 단계별 통기 계수 초기값, 소문 앞 바람막이·미로형 구조, 소문 면 풍속·풍향 센서 위치, 강풍 판정 기준
22. 급배기 팬 용량 비율 (§1.5): 소문 열림·닫힘 상태의 실측 유량으로 배기 = 급기의 85~95% 가정 검증
23. 플랩 홀 센서 (§1.3): 센서 형식·다중화 (스캐닝 MCU), 안전·경계 구역 임계값 실측 방법 (역압 5 Pa 누설 허용치), 온도 보정, 허용 추이 기준, 닫힘 확인 시험 주기
24. 플랩 에어 퍼지 (§1.3): Air Core 퍼지 라인 압력·노즐 형상·구역 크기, 램프 시간, 주기, 퍼지 중 맥동·진동·음향 한계, 챔버 출구 쪽 부스러기 포집, 목업 검증
25. 관리자 점검·교체 (§1.3): 개별 점검 도어, 스프링 셔터 슬롯, 휴대용 시험 지그, 카세트 QR 이력
26. 챔버 연결 (§1.7): 연결 덕트 경로 (천장·바닥, 갠트리 동선 회피) 와 크기, 연결 위치 (ERV 앞 권장, ERV 블록별 구성 여부와 함께 결정 — 항목 11), 연결 댐퍼 밀폐 등급·닫힘 확인 방식, 연동 전환 램프 시간·압력 차 허용값
