# 미아 벌 방지 및 교통 체증 극복 마스터 플랜

목적: **표류 (미아/드리프트) 감소** + **소문 앞 이착륙 체증·충돌 완화**.

## 평가 척도 — 기성 전통 = 100

| 항목           | 정의                                                                                                   |
| :------------- | :----------------------------------------------------------------------------------------------------- |
| **기준 (100)** | 기성 전통 양봉 (단상·밀집 다군, 단색/간이 표식, 수동 방풍·균세·방제) 에서 **미아·체증 목적 달성 수준** |
| **지수↑**      | 같은 목적 (미아↓·체증↓) 이 **더 잘** 달성됨. 150 = 전통 대비 약 **1.5 배** 잘함                        |
| **가산 Δ(안)** | 전통 (100) 위에 **해당 수단만** 추가했을 때 기대 상승폭. 예: Δ+20 → 단독 적용 시 **120**               |
| **통합 지수**  | 수단을 한꺼번에 쓸 때. **Δ 단순합 ≠ 통합** (효과 중복·상한 → 보정계수 적용)                            |

수치는 현장 계측 전 **설계 추정 (안)**. 시즌 KPI 로 재보정.

**통합 보정 (안):** `NEXA 통합 ≈ 100 + (ΣΔ) × 0.45`
(구조·소프트가 겹치는 개선을 중복 제거한 체감 상한)

- **ΣΔ(안) = +169** (가산 단순합)
- **NEXA 통합 지수 (안) = 100 + 169 × 0.45 ≈ 176**
  → 기성 전통 **100** 대비 목적 달성 **약 +76% (≈1.76 배)**
- **기여비중** 합계 100%: 플랜 내부에서 상대적 중요도 (통합 지수를 나누는 가중).

## 목적별 읽기 (안)

| 목적      | 전통 (100) 에서 주로 올리는 항목 | 통합에 대한 체감                                        |
| :-------- | :------------------------------- | :------------------------------------------------------ |
| 미아↓     | 2(+22), 9(+18), 11(+16)          | 랜드마크 + 냄새/기류 제어가 전통 페인트·감에 비해 큼    |
| 체증↓     | 3(+10), 5(+14), 7(+12), 10(+12)  | 기하·방풍·봉풍 제거                                     |
| 극한·예외 | 14~16, 12                        | 지수 가산은 작아도 풀스택 신뢰도 (실효 하한) 를 받쳐 줌 |

## 현장 재보정 KPI (전통=100 환산)

계측 후 `신지수 = 100 × (전통KPI / NEXA KPI)` 형태로 맞춘다. (사고·정체·오인 **낮을수록** 좋은 KPI 는 역수)

| KPI 예               | 전통 관측치 | NEXA 관측치 | 환산        |
| :------------------- | :---------- | :---------- | :---------- |
| 오인 입방률 (미아)   | A₀          | A₁          | 100 × A₀/A₁ |
| 문턱 체류시간 (체증) | T₀          | T₁          | 100 × T₀/T₁ |
| 이착륙 충돌·낙하     | C₀          | C₁          | 100 × C₀/C₁ |

세 KPI 평균 ≈ **실측 통합 지수**. 설계안 (176) 과 괴리면 Δ·보정계수 (0.45) 를 갱신한다.

## 2. 소프트웨어 / 공조 영역 (9 번 ~ 16 번) 재평가

" 미아 벌 방지 및 교통 체증 극복 마스터 플랜 " 문서에 제시된 16 개 항목에 대해, 문서에 기재된 기존 가산지수와 기여비중을 제외하고 **생태학적 특성 (꿀벌의 시각·후각·비행 행동) 과 공학적 실효성 (유체/동선 병목·비전 가공·유지보수성)** 관점에서 냉정하게 재평가한 결과입니다.

### 📊 평가 기준 (4 단계)

- **S 등급 (핵심 기여)**: 생태학적 근본 원인을 해결하거나 병목을 원천 제거하여 기여도가 극히 높은 기술
- **A 등급 (우수 기여)**: 실효성이 검증되었으며 체감 효과가 확실한 기술
- **B 등급 (보조 기여)**: 효과는 있으나 조건부이거나 간접적인 지원 기술
- **C 등급 (과평가/무의미)**: 개념은 좋으나 벌의 생태와 맞지 않거나, 유지보수/복잡도 대비 실효성이 떨어지는 기술

## 최적 LED

질문의 본질은 단순히 "LED 를 켜느냐 마느냐" 의 문제가 아니라, **"꿀벌의 생물학적 시각 파장에 맞춘 최적의 광원 (Spectrum) 을 어떻게 설계할 것인가"** 로 접근하는 것이다.
기대대로, **꿀벌이 자연계에서 꿀을 찾고 집을 찾을 때 사용하는 '특정 파장대' 를 정밀하게 타격하는 최적 파장의 LED 조합**이 실제로 존재한다.
이 아이디어를 부작용 (스트레스, 눈부심) 없이 극대화할 수 있는 **'생체 맞춤형 (Bio-Targeted) LED 마커 설계 방안'** 은 다음과 같다.

---

### 1. 꿀벌 시각 특성에 맞춘 최적 파장대 (Spectrum)

사람의 눈은 적색/녹색/청색 (RGB) 을 보지만, 꿀벌은 적색을 전혀 보지 못하고 **자외선 (UV) / 파란색 (Blue) / 녹색 (Green)** 3 가지 파장에 극도로 민감합니다.

- **최적 파장 1: 365nm ~ 385nm (근자외선 / Near-UV LED) 🌟**
  - **자연계의 원리**: 꽃들은 꿀벌을 유인하기 위해 꽃잎 중앙으로 들어가는 길에 자외선 패턴인 **' 꿀샘 가이드 (Nectar Guide)'**를 숨겨두고 있습니다.
  - **적용**: 소문 입구 테두리에 365nm UV LED 를 은은하게 유도선으로 배치하면, 꿀벌에게는 본능적으로 *" 여기가 입구다 "* 라고 알려주는 가장 강력한 자연주의 이정표가 됩니다.
- **최적 파장 2: 440nm ~ 450nm (Deep Blue LED)**
  - 꿀벌 시각 피크 중 하나로, 멀리서 날아올 때 방향을 잡는 **원거리 랜드마크 (Visual Landmark)** 역할을 합니다.
- **최적 파장 3: 520nm ~ 530nm (True Green LED)**
  - 근거리 소문 위치 정밀 안착 시 시각적 안정감을 주는 파장대입니다.

---

### 2. 스트레스 (역효과) 를 0 으로 만드는 3 가지 광학 기술

아이디어가 메모에서 그치지 않고 실전에서 성공하려면, 꿀벌을 자극하지 않는 **3 가지 드라이빙 기술**이 함께 적용되어야 합니다.

#### ① PWM 감광 금지 ➔ **DC 정전류 지속 발광 (Constant Current Drive)**

- 꿀벌이 느끼는 스트레스의 주원인은 빛의 색이 아니라 **' 초당 100~200Hz 로 깜빡이는 PWM 주파수 '**입니다.
- 회로를 PWM 방식이 아닌 **정전류 (DC) 지속 발광 회로**로 구성하면, 빛의 떨림 (Flicker) 이 0Hz 가 되어 꿀벌 눈에도 햇빛처럼 완전히 부드러운 연속광으로 인지됩니다.

#### ② 점발광 금지 ➔ **면발광 (Diffused Light) + 초저전력 (0.05W 급)**

- LED 직사광은 벌과 카메라 모두에게 눈부심 (Glare) 을 줍니다.
- 0.05W~0.1W 수준의 미세한 마이크로 LED 패키지 위에 **매트 아크릴 확산판**을 덮어, 은은하게 떠오르는 ' 파장 면발광 ' 으로 연출합니다.

#### ③ 꿀벌 가청/진동 대역 노이즈 차단

- LED 드라이버 스위칭 회로에서 발생하는 고주파 노이즈나 진동이 벌통에 전달되지 않도록 방수/절연 팟팅 (Potting) 처리를 적용합니다.

---

### 3. AI 비전 (OpenCV) 관점에서의 비약적인 이점

이 특정 파장 LED 마커는 꿀벌뿐만 아니라 **AI 비전 카메라의 성능을 비약적으로 상승**시킵니다.

- **특수 밴드패스 필터 (Bandpass Filter) 와의 결합**:
  - 카메라 렌즈 앞에 **'365nm 또는 450nm 파장만 통과시키는 광학 필터 '**를 씌우면, 야외의 강한 직사광선, 그림자, 복잡한 배경이 화면에서 거의 다 사라지고 **LED 마커 랜드마크만 칠흑 같은 어둠 속에서 밝게 빛나게 됩니다.**
  - 이렇게 되면 OpenCV 의 HSV 색상 추적이나 피듀셜 마커 검출 로직이 **연산 부하 0% 수준으로 0.001 초 만에 소문 위치를 칼같이 포착**할 수 있습니다.

---

### 💡 고도화 아이디어 요약

> **"365nm UV(근자외선) + 450nm Blue LED"**를 **"DC 정전류 회로 + 매트 확산판 "**과 결합하면:
>
> 1. 꿀벌에게는 자연계의 **' 꿀샘 길잡이 (Nectar Guide)'**처럼 본능적이고 편안한 귀소 이정표가 되고,
> 2. AI 카메라에게는 햇빛 노이즈를 100% 튕겨내는 **절대적인 비전 앵커 (Anchor)**로 작동하게 됩니다.

의도하셨던 최적 파장 접근법은 꿀벌 생태와 광학 비전을 동시에 만족시키는 매우 훌륭한 고도화 방향입니다!

---

**햇빛이 강한 대낮에 조도를 올리는 것은 랜드마크의 시각적 대비 (Contrast) 확보를 위해 매우 정확하고 필수적인 접근입니다!**

PWM 을 쓰지 않는다고 해서 조도를 조절할 수 없는 것은 아닙니다. **깜빡임 (Flicker) 을 유발하는 PWM 대신 ' 아날로그 디밍 (Analog Dimming / 직류 전류 크기 조절)'** 방식을 사용하면, 꿀벌에게 시각적 스트레스를 주지 않으면서 대낮과 일몰 시의 조도를 자유자재로 제어할 수 있습니다.

---

### 1. 핵심 원리: 아날로그 디밍 (Analog Dimming)

- **PWM 방식**: 빛을 초당 백~천 번 껐다 켰다 (ON/OFF) 하는 **시간 비율 (Duty Ratio)**로 밝기를 조절 ➔ **꿀벌 눈에 200Hz 대역의 극심한 깜빡임으로 인지됨**
- **아날로그 디밍 방식**: 전원은 끊김 없이 100% 지속 켜두되, LED 에 흐르는 **직류 전류의 크기 (mA)** 자체를 위아래로 조절 ➔ **깜빡임 0Hz (Pure DC) 상태를 유지하면서 조도만 자유롭게 변화**

---

### 2. 실전 조도 조절 구현 방안 3 가지

#### ① 아날로그 디밍 지원 전용 LED 드라이버 IC 활용 (가장 정석)

- **원리**: TI(Texas Instruments), Maxim 등의 정전류 LED 드라이버 IC 중 **'Analog Dimming' 또는 'CTRL / VREF' 핀**을 내장한 칩을 선택합니다.
- **구동**: 라즈베리 파이나 ESP32 의 DAC(디지털 - 아날로그 변환기) 핀에서 **0V ~ 3.3V 직류 제어 전압**을 이 핀에 전달합니다.
  - **대낮 (강한 햇빛)**: 3.3V 인가 ➔ 최대 직류 전류 (예: 350mA) 공급 ➔ **최대 조도 발광**
  - **흐린 날 / 일몰**: 1.0V 인가 ➔ 낮춘 직류 전류 (예: 100mA) 공급 ➔ **은은한 디밍 발광**

#### ② 대기 조도 센서 (BH1750 / CDS) 연동 자동 제어

- 스캐너 외부 모서리에 **대기 조도 센서**를 장착하여 태양광 밝기 (Lux) 를 실시간 측정합니다.
- 대낮 태양광이 강해질수록 가변 정전류 회로를 연동 제어하여 **LED 조도를 태양광 수준에 맞게 자동으로 최대 출력**으로 끌어올리고, 석양이나 어두워질 때는 꿀벌의 눈부심을 막기 위해 자동으로 조도를 낮춥니다.

#### ③ 다중 정전류 채널 스위칭 (그룹 뱅크 제어)

- 회로 제어를 보다 직관적으로 구성하고 싶다면, 고효율 LED 라인을 **2~3 개 그룹 (Bank)**으로 나눕니다.
- **대낮**: 3 개 그룹 모두에 직류 (DC) 전원 인가 (100% 최대 조도)
- **흐린 날**: 1~2 개 그룹에만 직류 전원 인가 (33%~66% 조도)
- 이 방식 역시 전원 공급 자체가 순수 직류이므로 깜빡임이 0% 입니다.

---

### 💡 대낮 조도 상승이 가져오는 시너지 (생태 + 비전)

아날로그 디밍으로 대낮 조도를 대폭 올리면 다음과 같은 2 가지 강력한 이점이 확보됩니다.

1. **꿀벌 귀소 유도력 극대화**: 어닝 차양막 그늘 속에서 **365nm UV / 450nm Blue 파장**이 태양 산란광을 뚫고 강렬한 대비 (Contrast) 로 떠올라, 먼 거리를 귀소하는 일벌들에게 명확한 Visual Landmark 가 됩니다.
2. **AI 비전 카메라 셔터 스피드 확보**: LED 조도가 밝아지면 카메라 렌즈의 노출 시간 (Shutter Speed) 을 1/1000 초 이하로 극단적으로 줄일 수 있어, **날아다니는 꿀벌/말벌의 모션 블러 (잔상) 가 완벽히 제거**된 선명한 스틸컷을 얻을 수 있습니다.

---

요약하자면, 대낮의 높은 조도 확보와 꿀벌의 시각 안전을 모두 잡는 해법은 **' 아날로그 전류 제어 방식 (Analog Dimming) 의 LED 드라이버 '**를 적용하는 것입니다.

이 아날로그 디밍 회로의 기본 제어 개념도와 조도 센서 연동 제어 로직은 후속 검토 대상이다.

## LED 운용 모드 — 평시 절제 / 무왕군 귀소 강조 (안)

**취지:** 평시에는 모든 소문 LED 를 **과하지 않게 (절제)** 유지한다. **무왕군이 발생하면 해당 여왕군 소문만 강조**하여 처녀왕의 교미 비행 후 **올바른 귀소**를 돕는다. **산란이 확인되면 평시 상태로 복귀**한다.

### 1. 타당성 검토

| 관점 | 판단 |
| :--- | :--- |
| **생태 근거** | 처녀왕은 출방 후 약 5~7 일부터 1~2 주간 정위·교미 비행을 수 회 반복한다. 이 기간의 **귀소 실패 (타군 오입방·실종)** 가 신왕 손실의 주원인이며 봉군 소멸 (Fatal) 로 직결된다. 관행적으로 교미군 소문을 색·형태로 구별 표시하는 이유와 같다. → **해당 소문만 시각 대비를 높이는 것은 타당.** |
| **평시 절제 근거** | 모든 소문을 강하게 밝히면 소문 간 **상대 대비가 사라져** 식별력↓, 비전 노출 백화↑, 전력↑. 평시가 절제되어 있어야 강조가 신호로서 의미를 가진다. |
| **복귀 근거** | 산란 개시 = 교미 성공. 산란왕은 분봉 외에는 재비행하지 않으므로 강조를 유지할 이유가 없다. |
| **리스크** | 강조 시점·방식이 잘못되면 오히려 귀소를 방해하거나 이웃 군 벌을 끌어당길 수 있음 → 아래 설계 원칙으로 보완. |

### 2. 설계 원칙 (보완 조건)

1. **처녀왕 첫 비행 전에 강조 진입** — 무왕 판정 (또는 왕대 확인) 즉시 강조로 전환한다. 처녀왕이 비행을 시작한 **뒤에** 소문 외형을 바꾸면, 기억한 랜드마크와 달라져 역효과가 난다.
2. **강조 기간 중 외형 불변** — 점멸·색 순환·깜빡임 금지 (PWM 금지 원칙과 동일). 밝기만 **아날로그 디밍**으로 올리고, 색·패턴은 해당 군 고유 `entrance_color_hsv` 를 그대로 유지한다.
3. **밝기보다 ' 고유성 ' 강조** — 밝기만 키우면 밝은 표적 쪽으로 **이웃 군 일벌·타 처녀왕이 드리프트**할 수 있다. 강조는 해당 군 고유 색의 채도 확보 + **365 nm UV 테두리 채널 추가 점등**처럼 " 그 군만의 표식 " 을 강화하는 방식으로 한다.
4. **이웃 소문은 평시 그대로** — 대비를 만들려고 이웃 소문을 어둡게 하면, 이웃 군이 기억한 랜드마크가 바뀐다. 이웃은 건드리지 않는다.
5. **동시 강조 제한** — 같은 복합군 안에서 **인접 소문 동시 강조 금지** (권장: 복합군당 1 개 또는 비인접). 불가피하면 강조 채널을 분리한다 (예: A 군 UV 테두리 / B 군 Blue 테두리).
6. **복귀는 점진 (Ramp-down)** — 산란 확인 후 **3~5 일**에 걸쳐 평시 밝기로 선형 감소. 일벌의 랜드마크 적응을 위해 급변을 피한다.
7. **야간 소등은 공통** — 강조 모드라도 일몰 후에는 소등 (벌 비행 없음, 야행성 곤충 유인 방지).

### 3. 상태 머신 (여왕군 소문 단위)

| 상태 | 진입 조건 | 해당 소문 LED | 연동 |
| :--- | :--- | :--- | :--- |
| `DEFAULT` | 초기값 / `RAMP_DOWN` 완료 | 주변광 추종, **상한 ~35%** (예: 최대 350 mA 중 ~120 mA) | — |
| `QUEENLESS_BEACON` | 무왕 판정 (내검 스캐너 · 관리자 입력 · 왕대 확인) | 주변광 추종, **상한 100%** + **UV 테두리 채널 ON**, 고유 색 유지 | **No. 9 교미 비행 인터록** (자군 페로몬·양압) 동시 활성 + 교미 창 **소문 차등 개방** (하단 소문 개도 운용) + **무왕군 집붕 관리** (하단 · 외부 스케너 출궁 감시) |
| `RAMP_DOWN` | 산란 (알) 확인 | 3~5 일에 걸쳐 `DEFAULT` 상한까지 선형 감소, UV 채널 마지막에 OFF | No. 9 인터록 해제 · **집붕 관리 해제** (해당 소문 우선 순찰 해제) |
| `ALERT` | 처녀왕 출방 후 **21 일** (출방일 미상 시 무왕 판정 후 **35 일**) 경과 + 산란 미확인 | 강조 유지 | 관리자 알림 (교미 실패·일벌 산란 위험 → 산란왕 투입 판단) · 집붕 감시 로그 첨부 |

- **산란왕 직접 투입** (교미 비행 불필요) 시: `QUEENLESS_BEACON` 을 생략하고 `DEFAULT` 유지. 집붕 관리도 기동하지 않는다.
- 산란 확인 경로: 내검 스캐너 비전 (알·유충 검출) 우선, 관리자 수동 확인으로 보완.
- 상한 % 와 램프 기간은 설계 추정 (안) — 시즌 계측으로 재보정.

### 4. 평가 반영

- **No. 1 (마커 LED 채널간판화)**: 상시 강발광 기준 **C** → 이벤트 연동 운용 시 **B (조건부)**. 적용 범위는 신왕 교미 기간으로 좁지만, 막는 사고가 봉군 소멸급이라 가치가 크다. No. 9 (여왕벌 교미 비행 인터록) 의 **시각 채널**로 묶어 운용한다.
- 가산 Δ(+12) 는 현장 계측 전까지 유지한다.
- **보조 KPI 추가 (안)**: 신왕 교미 귀소 실패율 — 전통 Q₀ / NEXA Q₁ → 환산 `100 × Q₀/Q₁`. 통합 지수 (3 KPI 평균) 에는 넣지 않고 No. 1·No. 9 의 Δ 재보정 근거로 쓴다.

## 무왕군 관리 — 외부 스케너 집붕 감시 · 여왕 출궁 확인 (안)

**취지:** 무왕군이 발생하면 LED 귀소 강조·교미 인터록만으로는 **실제 처녀왕이 출궁했는지** 알 수 없다. **외부 스케너 로봇 (GRC / 가드 레일캠)** 이 해당 봉군을 **집붕 관리** 대상으로 지정하고, 소문면 카메라로 **여왕 출궁 여부를 직접 확인**한다. 출궁이 확인된 뒤에야 교미 창·차등 개방·양압 상한을 **확정 활성**한다.

### 1. 집붕 관리 진입

| 항목 | 기준 (안) |
| :--- | :--- |
| **진입 조건** | `QUEENLESS_BEACON` 진입과 동일 — 무왕 판정 (내검 스캐너 · 관리자 입력 · 왕대 확인) |
| **대상** | 해당 여왕군 소문 **1 개** (복합군 ID + `entrance_color_hsv` 슬롯) |
| **주체** | 외부 스케너 로봇 (GRC). 평시 순찰·경비 루틴 위에 **해당 소문 우선 고정 감시** 를 얹는다 |
| **해제** | 산란 확인 → `RAMP_DOWN` / 산란왕 직접 투입 / 관리자 Override / `ALERT` 후 관리자 조치 완료 |

**산란왕 직접 투입** 군은 교미 비행이 없으므로 집붕 관리·출궁 감시를 기동하지 않는다.

### 2. 집붕 관리 동작 (외부 스케너)

1. **포지셔닝** — 무왕 판정 즉시 해당 복합군·소문 좌표로 이동 (복합군 ID 피듀셜 + 소문 HSV). 소문면이 화각에 들어오도록 정면·근거리 고정.
2. **스케줄** — 처녀왕 정위·교미 가능 시간대 (**통상 13~17 시**, 기온 ≥ 20 °C · 약풍 · 강우 없음) 에는 **해당 소문을 최우선 고정 감시**. 그 외 시간대는 평시 경비 순찰을 유지하되, 해당 소문 재방문 주기를 단축한다 (예: 순찰 1 바퀴당 1 회 → **2 회**).
3. **동시 집붕 제한** — 스케너 1 대가 동시에 집붕 관리할 수 있는 소문은 **권장 1~2 개**. 초과 시 교미 창이 가장 임박한 군·출방일령이 오래된 군부터 우선.
4. **경비 우선** — 말벌·침입체 (P0) 가 걸리면 집붕 고정을 **일시 중단**하고 요격·경비 개도로 전환. 위협 해제 후 즉시 해당 소문으로 복귀.

### 3. 여왕 출궁 카메라 확인

| 항목 | 기준 (안) |
| :--- | :--- |
| **목적** | "시간대가 맞다" 가 아니라 **"정말 여왕 (대형 개체 · 처녀왕 추정) 이 해당 소문에서 출궁했는지 "** 를 비전으로 확인 |
| **판정 입력** | 소문면 YOLO/트래킹 — 체장·복부 형태가 일벌 분포와 뚜렷이 다른 **대형 개체**, 출항 궤적 (소문 → 이륙), 필요 시 귀소 시 동일 개체 재검출 |
| **출궁 확정** | 해당 소문에서 대형 개체 출항 이벤트 ≥ 1 회 (신뢰도 임계 이상) → `queen_exit_confirmed = true` |
| **미확정** | 교미 가능 시간대가 지나도 출궁 미검출 → 그날은 **교미 창 확정 활성 보류**. LED 강조·평시 기준 개도는 유지. 관리자 알림 (왕대 미출방·실왕·내검 재요청) |
| **오탐 완화** | 수벌·대형 일벌과 혼동 가능 → 단독 프레임이 아니라 **궤적 + 체장 시계열** 로 판정. 확정은 로그·스틸컷을 Keeper 앱에 첨부 |

### 4. 교미 비행 로직과의 연동

| 단계 | LED / 소문 / 기류 | 외부 스케너 집붕 |
| :--- | :--- | :--- |
| 무왕 판정 | `QUEENLESS_BEACON` 진입 · No. 9 인터록 **준비** | 집붕 관리 기동 · 소문면 고정 감시 |
| 출궁 **미확인** | LED 강조 유지 · 소문은 **기준 개도** · 양압은 **평시 미세** (차등 개방·상한 양압은 대기) | 교미 창 시간대에 출궁 감시 지속 |
| 출궁 **확정** | 교미 창 **확정 활성** — 소문 완전 개방 · 교미군 양압 상한 · 인접 군 중립 (하단 §3) | 출궁 시각·궤적 로그. 귀소 예상 창까지 해당 소문 우선 유지 |
| 귀소 감지 (대형 개체 재진입) | 차등 개방·양압 유지 (당일 창 종료까지) | 귀소 이벤트 로그 · 타군 진입 시 P1 알림 (기존 §4) |
| 산란 확인 | `RAMP_DOWN` · 인터록 해제 | 집붕 관리 해제 · 평시 순찰 복귀 |

**한 줄:** 무왕군이면 외부 스케너가 그 소문을 **집붕 관리**하고, 카메라로 **여왕 출궁을 확인한 뒤에** 교미 귀소 차등 개방·양압 상한을 켠다.

## 소문 개도 운용 — 귀소 시간대 세력 평탄화 / 교미 귀소 차등 개방 (안)

**취지:** 소문 개폐 액추에이터 (전력 예산 A8) 로 **귀소 시간대에만** 소문 크기를 미세 조정한다.

1. **세력 평탄화 (No. 13 상세)** — 귀소 피크에 강군 소문을 조금 좁혀, 꿀·화분을 실은 귀소 일벌이 같은 복합군의 약군 소문으로 자연스럽게 들어가도록 유도한다.
2. **교미 귀소 차등 개방 (No. 9 연동)** — 교미 비행 시간대에는 LED 강조와 함께 해당 여왕군 소문을 **나머지 군보다 넓게** 연다.
3. **실시간 안전 대응** — 외부 경비 스캐너 (GRC) 와 내부 실시간 데이터로 이상을 감지하면 위 두 조정보다 **안전 대응이 우선**한다.

### 1. 개도 기준과 단계

차단율 = 소문 전체 폭 대비 닫힌 비율. **폭 방향으로만** 조절하고 **높이는 ≥ 8 mm 고정** (여왕 흉폭 약 4.5~5 mm, 격왕판 4.2 mm 기준 상회) → 어떤 단계에서도 여왕 통과를 막지 않는다.

| 단계 | 차단율 | 용도 / 조건 |
| :--- | ---: | :--- |
| **기준** | **20%** (개도 80%) | 평시 전 군 공통. 남겨 둔 20% 는 교미군 차등 개방·악천 전 귀소 러시 수용 여유분 |
| **완전 개방** | 0% | 평탄화 수용 약군, 교미 창 교미군, 악천 직전 전 군 |
| **L1 미세** | 30~40% | 평탄화 기본 단계 (경미한 편차) |
| **L2** | 40~50% | 편차가 2 일 이상 지속 시. 상한 = `다왕 복합군 농법의 위험 요소.md` 의 30~50% 기준 |
| **L3 슬릿** | 80~90% | `특허초안.md` 청구항 8 의 상한. 편차 큼 + 유밀기 + 체증 감시 정상일 때만, 귀소 피크 1 시간 이내 |
| **경비 개도** | 60~70% | 말벌·도봉 대응 (§4) |

### 2. 귀소 시간대 세력 평탄화 (No. 13 상세)

**원리:** 꿀·화분을 실은 귀소 일벌은 이웃 군 경비벌이 공격 없이 받아들이는 습성이 있다. 다왕 복합군은 상단 저밀실 공유로 냄새가 섞여 있어 같은 복합군 안에서는 이 효과가 더 확실하다.

| 항목 | 기준 (안) |
| :--- | :--- |
| **세력 산정** | 매일 1 회: 리프팅 잭 압력 변위 (중량) + 내부 열화상 봉구 부피 + 소문 출입 트래픽 (GRC) |
| **대상** | 복합군 평균 대비 **+15% 이상** 강군 → 축소 / **−15% 이하** 약군 → 완전 개방 (수용) |
| **시간 창** | 고정 시각이 아니라 **GRC 실측 귀소 피크** (귀소 수 > 출항 수, 당일 귀소율 상위 구간). 유밀기 통상 오후 |
| **조정 속도** | 1 단계 (10 %p) / **10 분 이상 간격**. 피크 종료 후 같은 속도로 기준 개도 복귀 |
| **수용 범위** | **같은 복합군 안의 인접 군만**. 복합군 간 유도 금지 (냄새 미공유 → 공격 위험) |
| **목표** | 복합군 내 세력 편차 ±10% 이내 도달 시 평탄화 종료 |

**적용 금지 조건:**

- **무밀기 (유밀 없음)** — 약군 소문 개방 + 강군 유도는 **도봉 (약군 털림)** 을 부른다.
- **응애·질병 이상** — 강군·약군 어느 쪽이든 내검 이상이면 금지 (표류는 응애·병원체 전파 경로).
- **교미 창 중 교미군 인접 강군** — 축소하면 넘친 교통이 교미군 소문으로 몰려 여왕 귀소를 방해한다. L1 까지만 허용하고, 교미군은 수용 대상에서 제외.
- 봉구 (여왕 공격)·분봉열·무왕 판정 군 — 해당 군은 평탄화 대상 제외.

### 3. 교미 귀소 차등 개방 (No. 9 연동)

LED `QUEENLESS_BEACON` 상태의 군에만 적용한다. **LED 차등 밝기 + 소문 차등 개도**를 같은 시간 창에서 함께 운용한다.  
**전제:** 상단 **무왕군 집붕 관리** 에서 `queen_exit_confirmed = true` (외부 스케너가 해당 소문 여왕 출궁을 카메라로 확정) 한 뒤에만 당일 교미 창을 **확정 활성**한다. 출궁 미확정이면 LED 강조만 유지하고 차등 개방·양압 상한은 대기한다.

| 항목 | 기준 (안) |
| :--- | :--- |
| **기간** | 처녀왕 출방 후 5 일 ~ 산란 확인 (LED `RAMP_DOWN` 진입 시 함께 종료) |
| **교미 창 (일일)** | 13~17 시 중 **기온 ≥ 20 °C · 약풍 · 강우 없음** (GRC `weather_state` + 기상 API). **집붕 감시 중** GRC 가 해당 소문에서 대형 개체 (처녀왕 추정) **출궁을 확정**하면 즉시 창 진입 |
| **교미군 소문** | **완전 개방 (차단 0%)** → 이웃 (기준 20%) 대비 **개도 +20 %p 차등** |
| **이웃 소문** | 기준 개도 유지. 차등을 만들려고 이웃을 추가로 좁히지 않는다 (이웃 교통 체증 방지) |
| **교미 창 밖** | 교미군도 기준 개도로 복귀 — 무왕 기간의 약해진 군은 소문이 좁아야 도봉·말벌 방어에 유리 |
| **최소 개도 보장** | 교미 창 중 교미군은 **어떤 대응에서도 개도 ≥ 50%** 유지 (처녀왕이 밖에 있을 수 있음) |
| **양압 기류** | 교미군 소문 기류를 **상한까지 상향** (아래 ' 교미 창 기류 배분 ') |

#### 교미 창 기류 배분 (No. 9 · No. 11 연동)

모든 군의 양압을 끄지 않는다. 처녀왕 오입방은 대부분 **바로 옆 소문**에서 일어나므로, 경쟁 냄새는 인접 군만 정리하고 나머지 군은 평시 페로몬 기류를 유지한다.

| 대상 | 교미 창 소문 기류 | 구현 (`시스템-지능형 공조 제어 알고리즘 Aero Profiler.md`) |
| :--- | :--- | :--- |
| **교미군** | **상한까지 상향** (자군 페로몬 기류 최대) | 여왕 귀소 지원: 소문 쪽 흡기 플랩 최대, 소문 풍속 상한 준수 |
| **인접 군** (같은 복합군의 좌우·상하 인접 소문) | **중립 — 소문 유출량 ≈ 0** | 군별 흡기 플랩을 줄여 흡기 ≈ 배기 라인 유량으로 맞춤 |
| **나머지 군** | **평시 미세 양압 유지** | 평시 소문 유출 제어 그대로 |

**인접 군을 음압으로 만들지 않는 이유:**

- **교미군 냄새를 이웃 소문으로 빨아들인다** — 음압 소문은 주변 공기를 흡입하므로 수 cm 옆 교미군 페로몬 기류가 이웃 소문 쪽으로 휘어, 이웃 소문 앞에 ' 집 냄새 ' 가 생긴다. 처녀왕을 이웃 군으로 안내하는 역효과.
- **외기 직유입** — 먼지·고온/저온 외기·농약 냄새가 소문을 통해 육아실로 들어온다.
- **공조 구조와 충돌** — 압력 샌드위치는 군 양압을 구조적으로 보장하는 설계이고, ' 소문 열림 + 흡기 ≤ 배기 ' 는 이상 상태로 보정 대상이다. 음압 시 배기 챔버 역류로 페로몬·질병이 섞일 위험이 있고, 압력 예산 (2.5~4 Pa) 에 음압 여유도 없다.
- **선풍벌 증가** — 소문으로 공기가 빨려 들면 벌들이 바깥쪽 선풍으로 대응해 문턱 체증이 생긴다.

**운용 조건:**

- 인접 군 중립은 **교미 창 동안만** 적용하고, 창 종료 시 평시 미세 양압으로 복귀한다. 이웃 군 일벌은 그 시간 기류 안내를 잃지만 LED·칼라 표식은 그대로이므로 영향은 작다.
- 인접 군 소문에서 **외기 유입 (흡기 < 배기)** 이 감지되면 즉시 미세 양압 쪽으로 보정한다 — 중립의 하한은 0 이며 음압으로 넘어가지 않는다.
- 인접 군이 내부 고온·CO₂ 상승 등 환기가 필요하면 배기 라인으로 환기량을 확보하고, 소문 기류는 중립을 유지한다. 배기만으로 부족하면 군 생존 우선 원칙 (§4) 에 따라 미세 양압으로 복귀한다.

### 4. 실시간 안전 대응 (GRC + 내부 데이터)

**입력:**

- **외부 — 경비 스캐너 (가드 레일캠, GRC):** 말벌·침입체 감지 (`Wasp`/`Intruder`), 소문 앞 격투·난비 (도봉), 문턱 체류시간·소문 앞 뭉침 (체증), 깃발 비전 기상 (`weather_state`), 대형 개체 (처녀왕 추정) 출입. **무왕군 집붕 관리** 시 해당 소문 고정 감시 · 여왕 출궁 확정 (`queen_exit_confirmed`).
- **내부 — 실시간 데이터:** 군별 온도·습도·CO₂, 리프팅 잭 압력 (중량 급변), 열화상 (봉구 38 °C 이상), 피에조 진동 (망실 울음·분봉음·공황).

**우선순위:** `안전 (말벌·도봉·기상)` > `군 생존 (내부 환경·봉구)` > `교미 귀소 지원` > `세력 평탄화`. 상위 대응이 걸려 있는 동안 하위 조정 명령은 차단된다.

| 등급 | 이벤트 (감지원) | 즉시 대응 | 해제 조건 |
| :--- | :--- | :--- | :--- |
| **P0 (수 초)** | 말벌 접근 (GRC) | 해당 구역 소문 **경비 개도**, 평탄화 중지, 말벌 요격 연동. 교미 창 교미군은 개도 ≥ 50% 유지 | 말벌 이탈 후 5 분 |
| **P0** | 도봉 (GRC 격투·난비 + 내부 중량 급감) | 피해 군 차단 70~80% (높이 8 mm 유지), **전 군 평탄화 중지**, 관리자 알림 | 격투 소멸 후 30 분 + 관리자 확인 |
| **P0** | 강풍·강우 임박 (GRC 기상 + 기상 API) | 평탄화 즉시 해제, **전 군 완전 개방** (귀소 러시 수용) → 귀소 완료 후 No. 16 출항 통제 | 기상 회복 |
| **P1 (분 단위)** | 소문 체증 (GRC 문턱 체류시간·뭉침 임계 초과) | 해당 소문 축소 **1 단계 해제** | 체류시간 정상 10 분 유지 |
| **P1** | 내부 고온·CO₂ 상승 (내부 센서) | 해당 군 축소 1 단계 해제 + 공조 보정 (No. 10) | 내부 환경 정상 |
| **P1** | 봉구·분봉열·망실 울음 (열화상·피에조) | 해당 군 평탄화 대상 제외, 관리자 알림 | 관리자 확인 |
| **P1** | 처녀왕 추정 개체의 타군 진입 (GRC) | 관리자 즉시 알림 (해당 군 내검 요청) | 관리자 확인 |
| **P1** | 교미 창 인접 군 소문 외기 유입 (흡기 < 배기, 공조 유량 판정) | 해당 군 흡기 상향 → 중립 또는 미세 양압으로 보정 | 소문 유출량 ≥ 0 유지 10 분 |

**조정 속도 원칙:** 안전 대응 (P0) 은 단계를 건너뛰어 **즉시** 실행하고, 평탄화·교미 차등은 **10 분 1 단계**로 느리게 움직인다 (벌의 적응 + 제어 진동 방지). 해제에는 히스테리시스 (위 해제 조건) 를 둔다.

**Fail-safe:**

- **GRC 또는 내부 센서 데이터 30 초 이상 단절** → 자동 조정 중지, 전 군 **기준 개도** (교미 창 중 교미군은 완전 개방), 인접 군 중립 해제 → **전 군 평시 미세 양압**, LED 는 현재 상태 유지.
- **액추에이터 이상** (서보 전류·위치 피드백 불일치, 프로폴리스 고착) → 해당 소문 정지 + 알림, 현장 확인 전 자동 조정 제외.
- **관리자 수동 우선 (Override)** 은 항상 가능하며 모든 개도 변경·대응 이력은 로그로 남긴다 (시즌 KPI 재보정 근거).
