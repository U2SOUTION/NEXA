# 허니웨건 리프팅 잭 및 하드웨어 시스템 설계서

목적: **정박·지면 수평용 순수 전동 스크루 잭** 사양·추력·안전율·기계 한계를 한곳에 정리한다.
전력·일일 Wh·버스 예산은 **「전력 계산.md」** 에만 요약하고, **본문이 상세 기준**이다.

---

## 1. 범위와 설계 전제

| 항목 | 내용 |
| :--- | :--- |
| 범위 | 코너 잭 ×4 · 감속·스크루·너트·스러스트·셀프락 · 수평 운용 |
| 비범위 | HVAC·블로어·공압 컴프레셔·레일/갠트리 (타 문서) |
| 구동 | **100% 전동** (공압 실린더·잭 에어 배제) |
| 차대 | 1 t 트럭용 샤시 → **화물 5 t 적재·운송이 아님** |
| 잭 역할 | 정박 시 **레벨링·짧은 승강**. 만차 질량이 코너에 실릴 수 있음 |
| 하중 자세 | 설계 상한 참고 **5.0 t**. 실무는 만차 추정 **4.3~4.7 t** · **운용 SF 1.5** 를 충분 기준으로 봄 |

---

## 2. 시스템 구성

- 수량: **4 코너**, 독립 제어 (대각·단축 레벨링)
- 1 잭: **NEMA17 롱바디 + 50:1 일체 감속 + TM20×3P + 청동 너트 (유효 길이 ≥ 35 mm) + 스러스트 베어링**
- 공압: **없음**

```json
[NEMA17] → [50:1 감속] → [커플링] → [스러스트 베어링] → [TM20×3P] → [청동 너트 / 풋]
                ↑
         축방향 하중은 감속기에 넣지 않음
```

---

## 3. 부품 스펙

| 구분 | 규격 | 비고 |
| :--- | :--- | :--- |
| 모터 | NEMA17 롱바디 (예: 42×42×48 mm), 클로즈드루프 권장 | 기준 **운전 토크 Tm = 0.55 N·m** (홀딩 0.45~0.65 대역, 기종표로 확정) |
| 감속 | **50:1** 다단 행성 일체형 | 다단 효율 **ηg ≈ 0.70~0.80**, 기준 **0.75**. 정격·피크 **≥ 25 N·m** 급 권장 |
| 스크루 | **TM20 × 3P** (외경 20 mm, 피치·리드 3 mm) | S45C 등. 가이드 컬럼과 병행 |
| 너트 | 인청동, **유효 물림 길이 L_nut ≥ 35 mm** | 면압·마모. Ø 외형 약 35 mm 급 |
| 스러스트 | 스크루 축방향 전용 베어링 | **감속기 출력축에 축방향 하중 금지** |
| 홀딩 | 사다리꼴 + 고감속 → **무통전 셀프락 지향** | §6 |

## 4. 만차 질량 (잭 하중 근거)

| 항목 | t | 비고 |
| :--- | ---: | :--- |
| 본체 (하한) | 0.3 | 작게 잡은 안 |
| 소초광 512 장 | **3.46** | 저밀 9 kg×256 + 육아 4.5 kg×256 |
| 소계 | ≈ 3.8 | 본체 + 소초광 |
| + 벌·배터리·물·장비 | +0.5~0.9 | |
| **만차 추정** | **≈ 4.3~4.7** | |
| 설계 상한 (참고) | **5.0** | 여유·피크 표기용. 일상 목표로 과하게 잡을 필요는 없음 |

소초광: 저밀 2,304 kg + 육아 1,152 kg = **3,456 kg**.

**운용 전제 (SF 1.5):** 수평은 대개 **짧은 스트로크·간헐**, 타이어/지반과 **하중 분담**이 있을 수 있음.
「만차 전량을 네 잭이 동시에 완전 부양」은 상한 시나리오로만 둔다.

## 5. 추력 산출

### 5.1 식

```json
F = (2π · Tm · i · ηg · ηs) / L
```

| 기호 | 기준값 |
| :--- | :--- |
| Tm | 0.55 N·m |
| i | 50 |
| ηg | **0.75** (다단 보수) |
| ηs | **0.35** (사다리꼴·윤활 가정) |
| L | **0.003 m** (3 mm) |

피치 2 mm → 3 mm: 추력 **×2/3**, 속도 **×3/2**.

### 5.2 결과 (기준안)

| 모터 Tm | 1 잭 이론 F | 4 잭 동시 | 비고 |
| ---: | ---: | ---: | :--- |
| 0.45 N·m | ≈ 1,260 kgf | ≈ **5.0 t** | 턱걸이 |
| **0.55 N·m** | ≈ **1,540 kgf** | ≈ **6.2 t** | **기준** |
| 0.65 N·m | ≈ 1,820 kgf | ≈ **7.3 t** | 여유 |

감속기 효율을 0.88 로 올리면 이론 ≈ **7.2 t** 까지 나오나, **다단 양산 감속은 0.75 기준**으로 설계한다. 데이터시트로 ηg 확정 시 재계산.

### 5.3 안전율 (SF = 이론 추력 / 적용 하중)

목표: **운용 SF ≈ 1.5** (사용자 판단: 충분).

| 적용 하중 | SF (@ 6.2 t) | 판정 |
| ---: | ---: | :--- |
| 4.0 t (실효·분담 가정) | ≈ **1.55** | 목표 부합 |
| 4.5 t (만차 중앙) | ≈ **1.38** | 약간 빠듯 · 분담·간헐이면 수용 가능 |
| 5.0 t (상한) | ≈ **1.24** | 상한만 · 일상 기준으로는 과대 |

| 이론 추력에 SF 역산 | 값 |
| :--- | ---: |
| 6.2 / 1.5 | ≈ **4.1 t** (SF 1.5 실효 상한) |
| 6.2 / 2.0 | ≈ **3.1 t** |

**판정:** 토크 식·기준 구성은 **타당**. 5 t 를 일상 목표로 두지 않고 **SF 1.5·만차 ~4.x t** 로 보면 구성과 맞음.
편중 하중 (한 코너 과다) 은 §7 에서 별도.

## 6. 속도 (참고)

스크루 rpm = 모터 rpm ÷ 50. 이송 속도 = 스크루 rpm × 3 mm.

| 모터 rpm (부하 운전) | 스크루 rpm | 상승 속도 | 300 mm 소요 |
| ---: | ---: | ---: | ---: |
| **600** (보수·연속) | 12 | ≈ **36 mm/min** (0.6 mm/s) | ≈ **8.3 min** |
| 1,000 | 20 | ≈ 60 mm/min | ≈ 5.0 min |
| 1,500 | 30 | ≈ 90 mm/min (1.5 mm/s) | ≈ 3.3 min |

수평 행정은 보통 수십 mm. **부하 시 600~1,000 rpm** 을 설계점으로 두고, 1,500 rpm 이상은 간헐·토크 여유 확인 후.

## 7. 셀프락

| 항목 | 값 |
| :--- | :--- |
| 평균 지름 (가정) | ≈ 18.5 mm |
| 리드각 λ | arctan(3 / (π×18.5)) ≈ **2.95°** |
| 정지 μ ≈ 0.10 → 등가 마찰각 ρ' | ≈ **5.9°** (사다리꼴 보정 포함) |
| 스크루만 | λ ≪ ρ' → **자체 잠금 성향** |
| 실무 | 윤활·진동·마모 시 여유 감소 → **50:1 감속이 실질 락** |

전원 차단 시 흘러내림 **위험 0%** 같은 단정은 하지 않는다.
목표: **무통전 홀딩 가능** (스크루 + 감속). 장기 정박은 풋 락·샤시 지지 병행 권장.

## 8. 기계적 안전성 (요약 판정)

| 요소 | 판정 | 요지 |
| :--- | :--- | :--- |
| 토크 식·ηg 0.75·ηs 0.35 | **타당** | ηs 는 윤활·마모에 민감 → 실측으로 SF 가 흡수 |
| TM20 축·나사 | **대체로 OK** | 코너당 ~1.5 t 급 축응력·전단 여유. **가이드 + 행정** 전제 좌굴 |
| 청동 너트 L ≥ 35 mm | **조건 OK** | 면압·윤활. 짧은 너트면 면압이 먼저 한계 |
| 50:1 감속기 | **최주의** | 출력 ~ **20 N·m** → 정격·피크 ≥ 25 N·m. **스러스트 분리 필수** |
| 코너 편중 | **운용 주의** | 레벨링 중 한 코너가 평균 (25%) 을 크게 초과할 수 있음 → 단축·대각 시퀀스 |
| 셀프락 | **감속기 포함 OK** | 스크루만으로 “완전”이라고 쓰지 않음 |

**한 줄:** 계산 (토크) 은 이 구성으로 맞다. 기계적으로 **큰 구멍은 스크루보다 감속기·축방향 경로**. 스펙·베어링만 막으면 SF 1.5 운용과 정합.

## 9. 전력 (본문 요약 · 상세는 전력 계산)

| 모드 | 전력 (4 코너) |
| :--- | ---: |
| 대기 / 셀프락 | ≈ **0 W** |
| 수평 가동 (동시) | **80~250 W** |
| 피크 (기동·동시) | **150~350 W** |

버스: DC 48V. 일일 Wh·동시 ON 합산 → **「전력 계산.md」** 산정순 **5b**.

---

## 10. 제어·운용 (최소)

- 4 축 독립 + 수평 센서 (또는 기울기) 폐루프
- 기동은 **순차/대각** 권장 (편중·돌입전류 완화)
- 과전류·스톨·스트로크 리미트 필수
- 정전 시: 셀프락 의존 + 가능하면 기계적 고정

---

## 11. 확정 전 체크리스트

- [ ] NEMA17 기종표: **운전 토크** ≥ 0.55 N·m (해당 rpm)
- [ ] 감속기: 정격·피크 토크, ηg, 백래시, **축방향 하중 0** 구조
- [ ] 스러스트 베어링 정격 ≥ 코너 설계 하중 × SF
- [ ] TM20 행정·가이드 길이 → 좌굴 검토
- [ ] 청동 너트 물림 ≥ 35 mm, 면압·그리스
- [ ] 실기: 1 잭 추력·전류·셀프락 (전원 OFF) 확인

## 12. 정리

|       |                                                                   |
| :---- | :---------------------------------------------------------------- |
| 구성    | NEMA17 롱 + **50:1** + **TM20×3P** + 청동 너트 (≥35 mm) + 스러스트 × **4**  |
| 이론 추력 | 기준 **≈ 6.2 t** (Tm 0.55, ηg 0.75, ηs 0.35)                        |
| 하중    | 만차 **≈ 4.3~4.7 t** · 상한 표기 5 t · **운용 SF 1.5**                    |
| 판정    | **토크·구성 타당** · 기계는 감속기·스러스트·편중만 관리하면 SF 1.5 안과 맞음                 |
| 전력    | 피크 **150~350 W** / 대기 ≈0 → 상세는 **전력 계산.md**                       |
