# 군별 내부 격리판 기능 명세서

가로 730mm × 높이 426mm 격리판 공간을, **두께를 누적하지 않는 범위에서** 양봉 관리·제어 기능에 활용한다.

## 설계 원칙

- **두께:** 각 기능은 정면·측두에 분산 배치하거나 필름/증착으로 두께 증가를 최소화. 목표 두께 **15mm**.
- **급기 — 배관 (덕트) 없음, 개구·밸브는 검토:** 실내 공간 자체가 **급기 플레넘**이므로 격리판까지 별도 **급기 배관은 두지 않는다**. 플레넘 공기는 격리판 **상·하 개구**(및 선택적 밸브·초박형 내부 채널) 로 군에 들어올 수 있다. 본체 흡기 플랩과의 역할 분담은 미결정·병행 가능. (상세는 §격리판 상하 급기 구조)
- **액추에이터 0 개:** 격리판 자체 전동기는 두지 않는다. 소문·페로몬 셔터·급기 개도 등 기계 변위는 **Tender Gantry**가 레버·링크로 직접 구동한다.
- **히팅 (보조):** 양면 히팅 패드는 **보조 열원**이다. 소문 링크·페로몬 셔터·버스·센서 등 P0 기구를 확정한 뒤, **잔여 공간**을 보고 방식·용량을 구체화한다. (현 단계: 후보·후순위)
- **검증 후 배제:** 두께·전자파·열해·생태 유해성은 별도 필터 단계에서 쳐낸다.

## 슬라이딩 (Front-in) 버스 트랙 & 무단 결합 인터페이스

격리판이 슬롯에 고정되지 않고 봉군 크기에 따라 **무단 이동**하거나 **완전 탈착**(내검/교체) 될 수 있도록, 유선 케이블을 배제하고 **전면 수평 삽입형 연속 버스 레일**을 적용한다.

### 1. 물리적 아키텍처 및 차폐

* **벌통 본체 (고정측) — 청정 버스 트랙 슬롯**
  * 연속 4 선: `[ RS485 A ]` `[ RS485 B ]` `[ VCC (+24V) ]` `[ GND ]` — 금도금 동합금 스트립.
  * **생태 차폐 듀얼 실링:** 고밀도 모헤어 + V 자 실리콘 립 → 프로폴리스·밀랍·벌 사체 유입 차단.
* **격리판 측두 (이동측) — 전면 진입형 접점 헤드**
  * 스키형 판스프링 접점 (15mm 두께 면).
  * Front-in 수평 삽입 시 어느 위치에서나 4 점 접촉.
  * Self-Wiping: 슬라이딩 마찰로 산화막 연마.
* **통합 EMI 차폐:** 버스 트랙 슬롯을 접지된 알루미늄 압출 프로파일 (차폐 터널) 로 구성하고, 입구에 **전도성 모헤어**를 적용하여 이물질 차단과 RF 누설 차단을 동시에 수행.

### 2. 통신·전원 운영

* **프로토콜:** RS485 Half-Duplex, Master-Slave.
* **30 초 Low-EMI 폴링:** 평시 대기, 마스터 폴링 시에만 응답.
* **Hot-Swap:** 인출 즉시 차단, 재삽입 후 1 초 이내 복구·노드 재등록.

## 슬라이딩형 버스 트랙 차폐 구조

```text
[벌통 내부 (벌 서식 영역)]
           │
           │  ◀── [1차 차폐: 전도성 모헤어 / 카본 도핑 실리콘 립]
┌──────────▼──────────────────────────────┐
│  슬롯 진입 유로 (알루미늄 압출 프로파일 홈) │  ◀── [2차 차폐: 금속 하우징 도파관 효과]
│  (전위 접지 : GND Shield Wall)         │
│                                         │
│    [RS485 A] [RS485 B] [VCC] [GND]      │  ◀── [3차 차폐: 레일 배면 절연 차폐층]
│    ════════  ════════  ═════ ═════      │
│       ▲         ▲        ▲     ▲        │
│       │         │        │     │        │
│    [스키형 판스프링 접점 (측면 쉴드 핀)]  │  ◀── [격리판 진입부]
└─────────────────────────────────────────┘
```

### 1. 1 차 물리·전자기 복합 차폐

* **메커니즘:** 은 도금 섬유 (Conductive Mohair) 또는 카본/니켈 도핑 전도성 실리콘 립.
* **효과:** 프로폴리스·벌 차단 + 슬롯 틈 RF 누설을 접지 (GND) 로 흡수.

### 2. 2 차 구조적 차폐 (차폐 터널)

* 알루미늄 압출 (또는 SUS 쉴드) 슬롯을 Earth GND 에 연결.
* Waveguide Below Cutoff: 좁고 깊은 금속 홈이 방사 노이즈를 감쇄.

### 3. 3 차 핀 레벨 차폐

* 권장 배열: `[ GND ]` — `[ RS485 A ]` — `[ RS485 B ]` — `[ VCC ]`
  또는 `GND` - `A` - `B` - `GND` - `VCC`.
* Make-First: 쉴드끼리 먼저 맞닿은 뒤 신호선 연결.

### 15mm 마진 관점

1. 슬롯은 벌통 벽면 내부 마감이므로 **격리판 두께를 잠식하지 않음**.
2. 전도성 모헤어·실리콘 립은 슬라이딩 저항이 낮아 Front-in 삽탈이 원활함.

## 향후 배제 (Filter) 체크포인트

1. **두께 15mm:** 액체 사양 탱크·대형 밸브 본체는 격리판 밖. 개구·초박형 채널·링크·노즐만 내부.
2. **전자파·열해:** 히팅을 후순위로 두더라도, 채택 시 쉴드 캔 단열 격벽 + 단일 존 차등 운영 필수.
3. **급기 치우침:** 격리판 측 급기 시 기류가 한쪽으로 몰릴 수 있음 → 배기구 위치·상하 개도·(선택) 내부 채널 토출점으로 보정. 시제품에서 실측 후 밸브 채택 여부 확정.
4. **밸브 4 개 / 15mm:** 양면 (A·B)×상하 독립 시 판당 최대 4 밸브. **구조 방향은 유지하되 기구 현실성은 별도 검토** (§격리판 상하 급기 · 현실성 검토 이슈).

## 유선 통신 설계

**Tender Gantry = CAN**, **봉군·격리판 = RS485** 계층 분할이 두께 15mm·Low-EMI·30 초 폴링 전제와 맞는다.

### 1. 프로토콜 역할

| 구성 요소 | 프로토콜 | 이유 |
| :--- | :--- | :--- |
| **Tender Gantry** | **CAN** | 로봇 구동·도킹·고신뢰성. 에러 검출·아비타션. 상위 인프라와 계층 통일. |
| **격리판 / 봉군** | **RS485** | 30 초 폴링 Master-Slave 에 적합. 온습도·CO₂·진동 멀티드롭. ≤2mm PCB. 저주파 차동으로 EMC 유리. |

### 2. 30 초 폴링 동작

1. **정상:** 마스터가 30 초마다 폴링 → 슬레이브가 온습도·CO₂·진동·플래그 일괄 응답.
2. **이벤트:** 임계 초과 시 내부 플래그 유지 → 다음 폴링에 이상 플래그와 함께 전달. (즉시 인터럽트 버스 불필요)
3. **도킹:** 갠트리 CAN 제어와 병행해 RS485 데이터 백업·캘리브레이션. 필요 시 포고핀 보조 포트.

### 3. 통신 항목 요약

| 대분류 | 세부 기능명 | 내용 |
| :--- | :--- | :--- |
| 통신·전력 | CAN (Tender Gantry) | 로봇 구동, docking, 고신뢰성 교환 |
| | RS485 (봉군·격리판) | 센서 네트워크, 30 초 폴링, 2 선, Low-EMI |
| | 포고핀 백업 | 도킹 시 데이터·전력 보조 |

## 격리판 상하 급기 구조 (플레넘 직결)

### 전제

* 실내 = **급기 플레넘** → 군까지 **별도 급기 배관 (덕트) 은 없음**.
* 플레넘 양압 공기가 **격리판 면의 개구**로 군에 유입되는 구조를 기본으로 검토한다.
* **밸브 채택 여부·본체 흡기 플랩과의 분담**은 미결정. 아래는 구조 방향 (의도) 이다.

### 상·하 역할 구분

| 위치 | 의도 | 비고 |
| :--- | :--- | :--- |
| **상단 개구** | 플레넘 공기를 **가장 위쪽에서 오픈** → 자연스럽게 **저밀실 쪽 공급**이 우선되도록 유도 | 육아실 쪽 격리판이라도 상단을 열어 저밀실 공급 경로를 만든다 |
| **하단 개구** | **가스 (CO₂ 등) 배출에 유리**한 높이·방향 | 배기 라인·소문 유출과 조합해 상향·하향 흐름을 잡음 |

```text
[실내 급기 플레넘 +양압]
        │  (배관 없음 · 면 개구로 직결)
        ▼
┌───────────────────────────┐
│ 격리판 상단 개구 (±밸브)   │ ──→ 저밀실 공급 유도
│         …                 │
│ 격리판 하단 개구 (±밸브)   │ ──→ 가스 배출에 유리한 기류
└───────────────────────────┘
        │
        ▼
   군 내부 → (배기구 배치로 횡방향 치우침 보정) → 배기 라인 / 소문
```

### 밸브 · 내부 유로 (선택지)

1. **개구만:** 고정 슬릿·메쉬. 개도는 없고 상하 면적비로만 분배. 가장 단순, 15mm 에 유리.
2. **밸브 on 격리판:** Tender Gantry 가 상·하 레버/셔터를 조작. **배관은 없고** 플레넘↔군 개구 면적만 조절.
3. **밸브 + 초박형 내부 채널:** 밸브는 격리판 (또는 플레넘 측 입구) 에 두되, 심재에 **얇은 내부 유로**를 두어 토출구만 저밀실·육아실 목표 지점으로 옮김. 외부 덕트는 여전히 없음.

> **현 절의 구조 방향은 유지한다.** 다만 아래 수량·두께 이슈는 **별도 현실성 검토** 전까지 채택 확정으로 보지 않는다.

### 현실성 검토 이슈 — 양면 × 상하 = 밸브 4 개 / 15mm

한 장의 격리판이 **양쪽 봉군 (A 면·B 면) 을 모두 제어**하고, 각 면에 **상·하 급기를 독립**한다고 보면:

| 구분 | 수량 |
| :--- | :---: |
| A 면 상단 | 1 |
| A 면 하단 | 1 |
| B 면 상단 | 1 |
| B 면 하단 | 1 |
| **합계 (최대)** | **4 밸브 / 격리판 1 장** |

**제약**

* 판 두께 **15mm** 안에 밸브 본체·실링·링크·갠트리 접속면·(선택) 내부 채널·리브·버스·센서가 겹친다.
* 전면 (갠트리 접근면) 에 레버 포트가 **최대 4 개** 필요 → 도킹 순서·간섭·오조작 리스크.
* 양면 독립이면 A/B 유로가 심재에서 교차하지 않아야 함 → 채널·격벽이 두께를 더 잠식.

**검토 시 따질 축소안 (아직 채택 아님)**

| 안 | 요지 | 밸브 수 (대략) |
| :--- | :--- | :---: |
| A | 개구만 (고정 상하비), 밸브 없음 | 0 |
| B | 면당 상하 **연동 1 레버**(한 슬라이드로 상·하 패턴 전환) | 2 (A·B) |
| C | A/B **대칭 공통** 개도 (양면 동일), 상하만 독립 | 2 |
| D | 상단만 밸브, 하단은 고정 슬릿 | 2 (A·B) |
| E | 밸브는 격리판 대신 **본체 흡기 플랩**에만 | 0 (판 기준) |
| F | 풀스펙 4 밸브 + 초박형 기구 — 목업으로 통과 여부 판정 | 4 |

→ **의도 (상하 구분·플레넘 직결) 는 유지**, **4 밸브 풀스펙의 기구·정비·15mm 성립 여부는 목업·적층 단면도 단계에서 별도 검토**.

### 단점과 보강

| 단점 | 보강 |
| :--- | :--- |
| 격리판 측에서 급기되어 **기류가 한쪽으로 치우침** | **배기구 위치**를 반대편·대각·실별로 두어 횡단 흐름을 만듦 |
| 상단만 열면 육아실 환기가 약해질 수 있음 | 하단 개구·배기 라인·소문 단계와 함께 균형. 필요 시 내부 채널로 육아실 토출점 추가 |
| **15mm × 양면 독립 × 상하 = 밸브 4 개** | 위 §현실성 검토. 축소안 A~E 또는 목업 후 확정 |
| 내검 시 소초광 인출면이 추가 대유로가 됨 | §대량 급기 덤프 대책 (1 슬롯 마스크 + SW 시퀀스) |

### 공조 문서와의 관계

* 기존 공조 매트릭스의 **본체 흡기 플랩** 방안과 **병행·대체·역할 분담**은 아직 닫지 않는다.
* 확정 시 Aero Profiler·사계절 매트릭스의 “급기구 배치” 절을 이 구조에 맞게 갱신한다.

## Hive Gate — 갠트리 직접 구동식 5 단계 소문

격리판 전동 액추에이터 **0 개**. 모든 변위는 Tender Gantry 엔드이펙터가 수행한다.
소문 단계 정의·공조 연동은 **Aero Profiler §1.6** 및 사계절 공조 매트릭스를 정본으로 한다.

### 1. 기구

* **구조:** 격리판 전면 (갠트리 접근면) → 심재 리브 채널 → 외벽 소문까지 **초박형 Invar/SUS 링크**. 전면 **상하 슬라이드 레버**.
* **고정:** **톱니 턱 5 단계**. 주행 진동에도 단계 유지. 연속 위치 제어·고정밀 서보는 불필요.
* **개구 방식:** 슬라이드 **높이 확대가 아니라**, 단계별 **구멍 패턴 (개수·폭)** 으로 면적만 변경. 벌 통로 높이는 일정 유지 (말벌·쥐 유입 방지). 1 단계 통풍 망도 동일 판에 포함.
* **확인:** 갠트리는 단계 번호로 지령. 톱니 걸림 힘 피드백 또는 카메라로 맞물림 확인.

### 2. 5 단계 정의 (0~4)

| 단계 | 상태 | 쓰임 |
| :---: | :--- | :--- |
| **0** | 닫힘 | 방제, 새벽 청소, 주행, **내검 (권장)** |
| **1** | 통풍 망 (벌 차단, 공기만) | 열대야, 주행 중 환기 |
| **2** | 최소 (벌 1~2 마리 통로) | 월동, 도봉·말벌 방어 |
| **3** | 축소 | 봄·가을 평시 |
| **4** | 전개 | 유밀기 강군, 여왕 귀소 지원 |

### 3. 공조와의 관계

* 소문 단계는 주로 **조건 변수**. 공조 (Aero) 는 단계를 입력으로 받고 흡기 플랩·챔버 압력으로 유량을 맞춘다.
* 공조가 소문 변경을 **요청**할 수 있는 예외: 강풍, 도봉, 월동, 열대야 (1), 여왕 귀소 (4). 최종 결정은 Hive Gate 운영 규칙.

## 소초광 인출 시 대량 급기 덤프 대책

### 문제

실내 = 급기 플레넘이므로, 평시 공기는 `플레넘 → 격리판 상·하 개구(±밸브) 및/또는 본체 흡기 플랩 → 군` 으로 들어간다.
소초광을 빼면 내검면이 열려 **저저항 대유로**가 생기고, 해당 군으로 대량 급기가 덤프된다. (격리판 정상 개구보다 훨씬 큼)

* 해당 군: 온·습도 쇼크, 과도 환기
* 실내: 양압 (+3~5 Pa) 붕괴 위험 → 이웃 군·페로몬 역류 리스크
* 기존 **인입형 에어커튼**(실내→군) 은 벌 탈출 억제에는 유효하나, **덤프 유량 자체는 줄이지 못함**

**외부 급기 배관은 두지 않는** 전제 하에, **개구 면적 제한 (물리) + 시퀀스·압력 보상 (소프트웨어)** 으로 대응한다.

### 1. 물리 장치

#### A. 개구 면적 제한 (1 순위)

| 장치 | 역할 |
| :--- | :--- |
| **이동식 1 슬롯 마스크 / 카세트** | Tender Gantry 가 내검면에 밀착. **인출 중인 1 장만** 개방, 나머지 슬롯 차폐 |
| **빈 슬롯 블랭크·셔터** | 이미 뺀 자리·미사용 슬롯을 판으로 메워 병렬 개구 축소 |
| **내검면 브러시·립 실** | 마스크·프레임 레일 틈 누설 축소 (프로폴리스 대응 재질) |

#### B. 기류 방향·경로

| 장치 | 역할 |
| :--- | :--- |
| **인입형 에어커튼 (면 가장자리 노즐)** | 열린 슬롯 둘레에서 실내→군 방향 기류막 → 벌 탈출 억제·난류 완화 |
| **격리판 상·하 급기 밸브 / 개구** | 내검 전 **닫힘 또는 최소** → 정상 급기 기여 축소 (채택 시) |
| **본체 흡기 플랩** (병행 시) | 내검 전 해당 군 **최소 개도** → 정상 흡기 경로 기여 축소 |
| **역류 방지 플랩** | 군→실내 역류·페로몬 역류 차단 |
| **군별 독립 배기 라인** | 덤프 공기를 `열린 면 → 군 → 배기 챔버` 로 배출. 평시에는 배기구 배치로 격리판 급기 치우침도 보정 |

#### C. 용량·격리

| 장치 | 역할 |
| :--- | :--- |
| **급기 팬 여유 (N+1)** | 1 군 내검면 개방 시에도 실내 +3~5 Pa 유지 |
| **블록 L/R 챔버 평시 분리** | 한쪽 내검 덤프가 반대 블록 압력까지 끌어내리지 않음 |
| **Hive Gate 0 단계 (닫힘)** | 내검 중 외기 제 3 출구 차단 → 덤프분을 배기 라인으로 유도 |

### 2. 소프트웨어 장치

#### A. 내검 시퀀스 (상태머신)

```text
내검 요청
  → Hive Gate 0단계 확인/요청 (야간 권장)
  → 해당 군 격리판 급기 개구/밸브 최소·닫힘 (채택 시) + 본체 흡기 플랩 최소 (병행 시)
  → 동시 내검 군 수 ≤ 1 (또는 블록당 상한)
  → 1슬롯 마스크 도킹·Open 확인
  → 소초광 인출 허용
  → 인출 중: 급기 PWM 보상 루프 ON
  → 복귀 · 마스크 Close
  → 급기 개도·플랩·압력 목표 복구
  → 내검 모드 종료
```

#### B. 빠른 제어 (초 단위, Aero L1)

| 기능 | 내용 |
| :--- | :--- |
| **실내압 홀드** | 인출 순간 ΔP 급락 → 급기 팬 PWM 즉시 증속, 목표 +3~5 Pa |
| **챔버압 재조정** | 해당 블록 소문·개방 면적 반영, 덤프분을 배기로 흡수 |
| **개방 면적 추정** | 마스크 상태 (1 슬롯) 또는 ΔP·풍량 잔차로 유효 누설 추정 → 보상량 스케일 |
| **인터록** | 마스크 미도킹 / 급기 개구·플랩 미최소 / 동시 내검 초과 / 급기 팬 고장 시 **인출 금지** |

#### C. 느린·운영 규칙 (분~시간, Aero L2)

| 기능 | 내용 |
| :--- | :--- |
| **내검 모드 프로파일** | 급기 온·습도 하한을 평시보다 타이트하게 (냉·건풍 쇼크 완화) |
| **시간 상한·쿨다운** | 슬롯당·군당 최대 개방 시간, 종료 후 안정화 대기 |
| **이웃 군 보호** | 동일 블록 타군 플랩 소폭 조임, 여왕 귀소 등 민감 작업과 스케줄 분리 |
| **센서 판정 보류** | 내검 중 CO₂·진동·소문 IR·유출량 학습 갱신 보류 (덤프 왜곡 방지) |
| **경보** | 실내압 하한 이하 N 초 지속 → 인출 중단·마스크 Close·Keeper 알림 |

#### D. 역할 분담

| 주체 | 담당 |
| :--- | :--- |
| Hive Gate / 내검 스케줄러 | 개방 시점, 동시 군 수, 마스크·소문 단계 |
| Aero L1 | 인출 순간 압력·팬 보상 |
| Aero L2 / Tender Gantry | 격리판 상·하 급기 밸브·본체 플랩 최소/복구, 이웃 군 배분, 마스크 도킹 |
| Hive Wall 노드 | 센서 텔레메트리·내검 플래그. 급기 밸브는 **기계식 (갠트리 구동)** — 판 자체 전동 없음 |

### 3. 적용 우선순위

1. **물리:** 1 슬롯 마스크 + Gate 0 + 격리판 급기 개구/밸브·흡기 플랩 최소
2. **SW:** 시퀀스 인터록 + 실내압 PWM 보상 + 동시 내검 1 군
3. **물리 보강:** 급기 여유 용량, 에어커튼 노즐, 배기구 대각 배치 (평시 치우침 보강과 공유)
4. **SW 보강:** 온습 프로파일, 시간 상한, 센서 학습 보류

마스크 없이 팬 보상만 하면 벌 탈출은 줄여도 해당 군 덤프 유량은 남는다.
마스크만 있고 인터록이 없으면 동시 개방·미도킹으로 덤프가 재발한다. **물리로 면적을 줄이고, SW 로 타이밍·압력을 묶는 것**이 한 세트다.
