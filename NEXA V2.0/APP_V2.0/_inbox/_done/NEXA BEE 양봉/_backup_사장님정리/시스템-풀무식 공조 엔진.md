# 시스템 - 풀무식 정압 공조 엔진 (뱅가드 렁)

허니 뱅가드의 공조는 **배기를 복동식 풀무 (뱅가드 렁, Vanguard Lung) 로, 급기를 EC 블로어로** 구동합니다. 풀무는 역압과 관계없이 정해진 체적을 빼내므로 **배기량을 정확히 아는 공조**가 되고, 그 정확성 덕분에 단순 환기·온습도 조절을 넘어 **군별 양압 관리라는 생태 제어**에 직접 쓰입니다. 급기는 설치 공간 제약으로 EC 블로어 (정풍량 제어 + 유량 측정) 가 맡고, 배기 풀무를 기준 유량계 삼아 매일 보정합니다. 배기 쪽 블로어는 **비상시 백업 장치**로만 둡니다.

## 0. 결정 요약

| 항목 | 결정 |
| :--- | :--- |
| **공조 방식** | **배기 = 풀무 (정압·정량), 급기 = EC 블로어.** 배기 설계 풍량 전체를 풀무가 맡고, 급기는 설치 공간 제약으로 EC 블로어가 맡습니다. 배기량이 정확해 급기 블로어가 얹는 여유와 회전수 (전력·소음) 가 줄어드는 간접 효과도 있습니다 (§1·§7) |
| **급기 EC 블로어** | **N+1** (1 대 고장 시 남은 블로어로 급기 설계 풍량 유지). L1 (약 10 Hz) 로 주간 (소문 열림) 에는 **정유량**, 야간 (소문 닫힘) 에는 **실내 압력**을 제어하고, 흡입 노즐 차압 (K-factor) 으로 급기량을 측정합니다. 소문이 닫힌 야간에 배기 풀무 기준으로 매일 보정합니다 (§2·§8.1·§10) |
| **배기 백업 블로어** | **비상 전용.** 평시에는 정지하고 자중 플랩이 닫혀 있습니다. 배기 풀무 용량 부족·구동 계통 이상·가스 정체 경보 등 정해진 조건에서만 기동합니다 (§11) |
| **급기 경로** | 외기 → 프리필터·방충망 → **급기 EC 블로어 (N+1)** → HEPA → ERV (급기 쪽) → 급기 코일 → 실내 가압 플레넘 (§8.1) |
| **배기 경로** | 실별 배기 챔버 → ERV (배기 쪽, 실별 구획) → 배기 응축 코일 → **실별 배기 풀무 그룹** → 배기탑 (§8.1) |
| **결로수 수집 (기본)** | 저밀실·육아실 두 흐름 모두 **ERV 배기 쪽과 배기탑 하부**를 기본 수집점으로 두고, 응축 코일·풀무 하부에서도 받습니다. 실별 트랩 → 실별 계량 → 저장조 (여과·소독) 순입니다 (§8.1) |
| **실별 배기 분리** | 배기 챔버를 **저밀실 챔버 (상단 배기 라인 64 개)** 와 **육아실 챔버 (하단 배기 라인 64 개)** 로 나누고, 각 챔버에 풀무 그룹을 따로 붙입니다. 두 흐름 모두 ERV (배기 쪽 실별 구획) 를 지나며, 풀무 출구 (배기탑) 에서만 합칩니다. 블록 저밀실·육아실 배기량을 각각 정확히 알아 실별 관리 (대사량·숙성 수분 추정) 가 정밀해집니다 (§2·§8.1) |
| **설계 풍량** | 배기 **블록 800 m³/h, 유닛 1,600 m³/h (안).** 급기는 여기에 소문 유출·누설·필터 여유를 더합니다. 수분·CO₂·열 기준의 최댓값, 증발 잠열 차감, 대사열 시나리오 B 기준입니다. 이전 산정 (최대 2,500 m³/h) 은 이중 계상으로 폐기합니다 (§7) |
| **구성 원칙** | 배기 풀무는 블록마다 **N+1**: 1 대가 고장 나도 나머지를 리미트 (15 CPM) 로 올려 블록 설계 풍량을 유지합니다 (§7.8). 실별로는 **같은 규격 풀무를 쓰되 저밀실에 대수를 더 주고**, **공용 대기 풀무** 1 대가 두 챔버에 **자중 역류 방지 플랩 2 개 (구동부 없음)** 로 연결되어, 운전하면 부족한 쪽에서 저절로 더 많이 빨아들입니다 (예: 400 × 400 기준 저밀실 2 + 육아실 1 + 공용 대기 1, §7.8). 평시 실별 미세 배분은 군별 흡기 플랩이 간접적으로 맡습니다 (§2). 급기 EC 블로어도 N+1 입니다 |
| **양산 규격** | **미확정.** 배기 풀무 보어·대수는 §7.8 후보 (300×300 ~ 500×500) 중 대사열 실측 후 확정합니다. 스트록 1,200 mm 는 유지합니다 |
| **기구 검증 규격** | 200 × 200 mm 사각 보어, 스트록 1,200 mm. §5·§6 의 수치는 이 규격 기준입니다 |
| **압력 제어** | 배기 유량은 **배기 풀무 연속 CPM** 으로 맞춥니다. **급기 EC 블로어**는 주간에 급기 = 배기 + 소문 유출 목표 + 보정값으로 정유량 제어 (실내 압력은 상·하한 감시), 야간에 실내 압력을 제어합니다. 렁 단계는 기준점이고 실제 CPM 은 피스톤 속도를 연속으로 바꿉니다 (§9·§10) |
| **운전 원칙** | 평시 배기는 풀무 단독, 백업 블로어 정지. 생태 제어는 정량 배기 + 야간 보정된 급기로 합니다 (§2) |
| **구동** | 볼스크루 직결 정속 구동. 고리드 (권장 리드 40 mm) + 양단 고정 (§5.4) |
| **기밀** | **피스톤 씰 (가죽 + 실리콘) 이 주 기밀이자 최종 방어선.** 타포린 주름관은 시각 피드백용 보조 수단입니다 (§5.2) |
| **비주얼** | 외부에서 동작이 보이는 **키네틱 아트** 수준으로 구성합니다 (§8.2) |
| **속도 단위** | 풀무 속도는 **CPM** 으로 통일합니다. RPM 은 모터·블로어에만 씁니다 (§3) |
| **연계 문서** | Aero Profiler 의 " 급기팬 " 은 **급기 EC 블로어** (그대로), " 배기팬 " 은 **배기 풀무**로 읽습니다 (해당 문서 개정 필요) |

## 1. 왜 배기는 풀무인가 — 급기·배기 역할 분리

허니 뱅가드의 공조는 환기·온습도 조절에 그치지 않고 **군별 양압 관리 (생태 제어)** 까지 맡습니다. 이 목적에서 팬과 풀무는 성격이 근본적으로 다릅니다.

| 비교 | 블로어 (팬) | 풀무 (용적식, 뱅가드 렁) |
| :--- | :--- | :--- |
| **유량 결정** | 회전수 + 역압 (팬 곡선). 같은 RPM 이라도 필터 오염·코일 결로·외풍에 따라 유량이 변합니다 | **CPM 으로 정해집니다.** 역압에 거의 영향받지 않습니다 |
| **유량 확인** | RPM 으로 알 수 없습니다. EC·BLDC 팬은 공기가 흐르지 않아도 RPM 을 유지합니다 (§11.3) | **사이클 수 = 유량.** 유량 센서 없이 계산됩니다 |
| **필터·코일 오염 영향** | 고정 회전수면 유로가 막힐수록 유량이 조용히 줄어듭니다 (EC 정풍량 제어로 보완) | 유량은 유지되고 피스톤 부하만 늘어납니다. 부하 전류로 오염을 압니다 |
| **정지 시** | 구멍이 되어 역류 경로가 됩니다 (자중 플랩 필요, §11) | 흡입·배출 체크밸브가 직렬로 막아 역류가 없습니다 |
| **저유량 운전** | 회전수가 낮을수록 차단 압력이 작아져 유량 0·역류 위험이 커집니다 (§11.4) | 저속에서도 정량을 유지합니다 |
| **음향** | 날개 순음 (약 300 Hz 대역) 이 벌과 음향 감시 마이크에 간섭합니다 | 저속 왕복이라 순음이 없습니다 |
| **풍량 규모** | 1 대로 대풍량을 냅니다 | 1 대 풍량이 작아 보어·대수로 확보합니다 (§7.8) |

**결론:** 생태 제어의 기준이 되는 **" 정확히 아는 배기량 "** 은 풀무만 만듭니다. 배기는 벌과 가장 가까운 자리이고 (128 개 유로 직결), 역압이 크며 (ERV·응축 코일), 정지 시 역류가 곧 군 간 섞임이 되는 자리이므로 풀무로 구동합니다. 배기 쪽 블로어는 풀무가 동작할 수 없는 비상 상황에만 쓰는 **백업 장치**로 둡니다 (§11).

**간접 효과 — 풀무 배기는 급기 블로어 회전수를 낮춘다**

낮에는 소문이 열려 있어 군 압력이 바깥 공기에 물리므로, 배기 풀무의 음압이 실내 양압을 직접 받쳐 주지는 못합니다 (§10). 그래도 급기 목표는 " 배기 + 소문 유출 목표 + 보정값 " 이라, **배기를 얼마나 정확히 아느냐가 급기 블로어가 얹어야 할 여유를 정합니다.**

| 구분 | 배기 = 팬 | 배기 = 풀무 |
| :--- | :--- | :--- |
| **배기량 불확실성** | ERV·코일 오염, 배기탑 바람, 팬 특성 편차로 약 ±10% (추정) | 사이클 수 × 체적 효율 (야간 보정) 로 약 ±2~3% (추정) |
| **소문 유출 안전 여유** | 배기가 예상보다 많아도 소문 유출이 음수가 되지 않도록 크게 잡음 | 작게 잡음 |
| **급기 블로어가 얹는 여유 (블록 800 m³/h 기준)** | 약 80 m³/h | 약 20 m³/h |
| **배기탑 바람** | 배기 팬 유량이 흔들려 급기가 따라 보상 | 풀무 유량은 그대로라 급기 보상 불필요 |

- **급기 유량 여유가 줄면 회전수가 낮아집니다.** 위 예시에서 블록 낮 급기 (약 900~1,000 m³/h) 가 약 60 m³/h (약 6%) 줄면, 팬 법칙상 소비 전력은 약 17%, 소음은 약 1.4 dB 줄어듭니다 (전력 ∝ 회전수³, 소음 ∝ 50 log 회전수 비).
- **급기 블로어는 급기 쪽 손실만 이기면 됩니다.** 배기 쪽 ERV·응축 코일·배기탑 손실 (약 200~300 Pa) 은 배기 풀무가 당겨서 감당하므로, 급기 블로어가 벌통을 지나 배기까지 밀어낼 압력을 낼 필요가 없습니다.
- **야간 보정의 기준도 풀무입니다.** 급기 측정 오차를 정확한 배기량으로 매일 보정하므로 (§2), 급기 측정 불확실성 때문에 얹는 여유도 함께 줄어듭니다.
- 위 불확실성·여유 값은 추정입니다. 실측 (§12) 으로 소문 유출 안전 여유를 확정합니다.

**급기를 EC 블로어로 두는 이유와 보완**

| 항목 | 내용 |
| :--- | :--- |
| **공간** | 급기까지 풀무로 하면 블록당 배기와 같은 수의 대형 실린더가 더 필요합니다 (§7.8). 뱅가드 내부에 들어가지 않습니다 |
| **벌과의 거리** | 급기 블로어는 외기 흡입부 (HEPA 앞) 에 있어 벌 공간과 멀고, HEPA·ERV·코일·플레넘을 지나며 날개 순음이 감쇠됩니다 |
| **필터 오염** | EC 블로어 **정풍량 제어**로 HEPA 가 막혀도 급기량을 유지합니다. 같은 급기량에서 소비 전력·회전수가 오르는 추이로 교체 시점을 압니다 |
| **유량 확인** | 흡입 노즐 차압 (K-factor) 으로 급기량을 측정합니다. RPM 만으로 판단하지 않습니다 |
| **정밀도 보완** | 소문이 닫힌 야간에 **배기 풀무를 기준 유량계**로 삼아 급기 측정값을 다점 보정합니다 (§2) |
| **고장 대비** | 급기 정지는 실내 양압 붕괴이므로 **N+1** 로 두고, 블로어마다 역풍 방지 자중 플랩을 둡니다 |

## 2. 생태 제어 응용 — 양압 관리

**원리:** 소문이 열려 있을 때 군의 양압 조건은 압력이 아니라 **유량 균형**입니다. 군별 소문 유출량은 Q_ 소문 = Q_ 흡기 − Q_ 배기라인 입니다 (Aero Profiler §2.5). 블록 단위로는 다음이 성립합니다.

> **블록 소문 유출 합계 = Q_ 급기 (EC 블로어 측정값) − Q_ 배기 (풀무) − 보정값**

배기량은 사이클 수로 정확히 알고, 급기 측정 오차와 누설은 야간 보정값 하나로 묶어 매일 갱신합니다. 군별 배분은 흡기 플랩 (Tender Gantry) 이 하고, 풀무는 그 기준이 되는 **블록 총 배기량**을 정합니다.

| 생태 제어 | 목표 | 풀무가 기여하는 점 | 연계 문서 |
| :--- | :--- | :--- | :--- |
| **평시 소문 미세 양압** (페로몬풍) | 자군 냄새 기류로 귀소 유도, 외기 유입 0 | 배기 기준이 정확하고 급기가 보정되어 최소 풍속 마진을 작게 잡을 수 있습니다. 과환기 없이 양압을 유지합니다 | 미아 벌 방지 No. 11 |
| **교미 귀소 지원** | 교미군 상한 / 인접 군 중립 (유출 ≈ 0) / 나머지 미세 양압 | 중립 (≈ 0) 은 허용 오차가 가장 작은 목표입니다. 정량 배기와 보정된 급기가 있어야 음압으로 넘어가지 않게 맞출 수 있습니다 | 미아 벌 방지 ' 교미 창 기류 배분 ' |
| **세력 평탄화·소문 개도 변경** | 개도를 바꿔도 소문 유출 유지 | 개도 변화에 따른 유출 변화를 기준 유량으로 바로 재계산합니다 | 미아 벌 방지 ' 소문 개도 운용 ' |
| **군 간 섞임 방지** | 챔버를 항상 군보다 낮게 유지 | 정지 시 역류 경로가 없고, 운전 중 유량이 정확해 역류 방지 플랩이 닫히는 상황을 예측할 수 있습니다 | Aero Profiler §1.2 |
| **음향 생태 감시** | 망실 울음·분봉음·공황 진동 검출 | 날개 순음이 없어 마이크·피에조 신호 대 잡음비가 높습니다. 반전 순간은 반전 시점 신호로 제외합니다 | §12 소음 |
| **내검·청소·플랩 시험** | 작업 중에도 군 간 섞임 0 | 작업에 필요한 배기 증감을 CPM 으로 미리 계산할 수 있습니다 | Aero Profiler §1.3 |

- **야간 다점 보정:** 소문이 모두 닫힌 야간에는 블록 소문 유출이 0 이므로, Q_ 급기 (측정) − Q_ 배기 (풀무) 가 곧 보정값 (급기 측정 오차 + 누설) 입니다. 배기 풀무 CPM 을 몇 단계로 바꿔 가며 재면 유량별 보정 곡선이 나옵니다. 이 곡선을 매일 갱신해 주간 소문 유출 계산에 씁니다.
- **보정이 중요한 이유:** 소문 유출은 큰 두 값 (급기 대 배기, 각각 블록 수백 m³/h) 의 작은 차이입니다. 급기 측정 오차가 몇 % 만 돼도 소문 유출 계산이 크게 틀어지므로, 보정 없이 EC 블로어 측정값을 그대로 쓰지 않습니다.
- **실별 배기 분리로 얻는 관리 정확도 (§8.1):** 블록의 저밀실 배기 합계와 육아실 배기 합계를 각각 사이클 수로 압니다. 육아실 흐름의 CO₂ 농도 × 유량으로 군 대사량 (§7.3) 을, 저밀실 흐름의 절대습도 차 × 유량으로 꿀 숙성 수분 (채밀 시점 판단) 을 따로 계산합니다. 군 하나하나의 실별 배분은 여전히 흡기 플랩이 정하며, 정확해지는 것은 블록 단위의 실별 합계입니다.
- **두 챔버 압력 차 제한:** 두 챔버의 압력 차가 크면 격왕판을 통해 실 사이로 공기가 흐릅니다. 두 챔버 모두 군 압력보다 낮게 유지하고, 서로의 차이는 수 Pa 이내 (값 미정) 로 묶습니다.
- **배기 백업 블로어 운전 중에는 정밀도가 떨어집니다.** 블로어 유량은 자중 플랩 각도로 추정하므로 (§11.3) 오차가 섞입니다. 이때는 정밀 생태 제어 (교미 창 인접 군 중립 등) 를 멈추고 **전 군 평시 미세 양압**으로 되돌립니다 (§11.1).

## 4. 풀무 기구 분류 (Bellows Master Classification)

> **본 문서 채택: 피스톤형 (§4.2).** 현 규격은 볼스크루 관통 구동 + 사각 보어 회전 방지입니다 (§5). 피벗·로타리 항목의 수치와 역할은 초기 구상 기록이며 현 규격이 아닙니다.

### 4.1 피벗 벨로우즈 (Pivoted Bellows)

- 물리적 정의: 한쪽 끝단에 고정된 회전축 (Pivot/Hinge) 을 두고, 반대편 판재가 부채꼴이나 호 (Arc) 를 그리며 비대칭 왕복 운동을 하는 풀무 구조입니다.
- 특징: 기하학적 형태 유지가 단순하고 경첩 (힌지) 하나로 가이드라인이 끝나므로 자작 가공성이 가장 뛰어납니다.
- 프로젝트 내 역할: 실내 본체 기계실 내부의 공간 절약형 서브 펌프나, 100m 너머 외부에 노출될 ' 잠자는 곰 ' 조형물의 옆구리 들썩임 (유기체적 아날로그 미학) 을 패시브하게 연출할 때 독보적인 시각적 가치를 가집니다.

### 4.2 피스톤 벨로우즈 (Piston Bellows)

- 물리적 정의: 주머니 원판이 중심선을 따라 어떠한 각도 꺾임도 없이 오직 수평·수직으로만 일직선 왕복 운동 (Linear Sliding) 을 하며 체적을 쥐어짜는 구조입니다.
- 특징: 유저님이 수많은 논박 끝에 [대구경 가이드 연마봉 직결 축 + 오일리스 슬리브] 를 대입하여 완성하신 최종 정밀 기구 형태입니다. 주머니 원단이 한쪽으로 쏠리거나 비틀리는 아코디언 현상이 전 구간에서 0% 로 완벽히 차단됩니다.
- 프로젝트 내 역할: 가죽 주머니의 스트레스 (피로도) 를 최하한선으로 낮춰 정확한 수명 예측 (Predictable Lifespan) 을 달성하고, 50% 의 최대 압축 행정 거리를 온전히 뽑아내는 메인 정압 펌프의 핵심 코어 뼈대입니다.

### 4.3 로타리 벨로우즈 (Rotary Bellows)

- 물리적 정의: 구동축 자체가 왕복하지 않고, 360 도 무한 정회전 (Continuous Rotation) 하는 캠이나 크랭크 드럼 롤러가 순차적으로 벨로우즈의 격벽 면을 밀어붙여 연속적인 맥동 없는 기류를 만드는 성형 방사형 구조입니다.
- 특징: 모터가 행정마다 멈춰 서서 정·역회전을 반복해야 하는 S- 커브 가·감속 제어 연산 스트레스를 소프트웨어 (ESP32) 에서 완벽히 덜어내 줍니다.
- 프로젝트 내 역할: 단 1 개의 BLDC 모터가 정속 주행 (7~10 RPM) 하는 힘을 받아 시간당 무려 40.3 CMH(672 LPM) 의 초대용량 무맥동 연속 정압을 완성하고, 86mm 중공 내벽을 관통하는 천연 음압 흡기풍으로 모터를 상시 서늘하게 식혀주는 허니 뱅가드 전체 공조계의 마스터 엔진 카트리지입니다.

배기 풀무의 기구 규격입니다. 양산 보어는 §7.8 에서 확정하며, 아래 구성 원칙은 보어와 관계없이 유지합니다.

### 5.1 구성

| 구분 | 구성 요소 | 설계 사양 | 비고 |
| :--- | :--- | :--- | :--- |
| 실린더 바디 | 사각 투명 PC 파이프 | 200 × 200 mm 정방형 보어, 모서리 R 처리 | 내부 동작 확인 (키네틱 아트). 사각 보어가 피스톤 회전을 막아 별도 회전 방지 장치가 필요 없습니다 |

| 시각 보조 | 타포린 주름관 | 외경 Ø180 mm 내외, 피스톤 상·하 각 1 기 | 압력을 받지 않는 시각 피드백용 (§5.2) |

| 체크밸브 | 실리콘 드롭 플랩 | 상·하 끝판에 흡입·배출 각 1 조 (실린더당 4 조) | 금속 스프링 없는 유연 판막으로 타격음을 줄입니다 |

- **나사 격리 구조:** 고정된 격리관 안에 나사를 두면 관 벽을 뚫지 않고는 너트와 피스톤을 연결할 수 없습니다. 그래서 나사가 피스톤을 관통하게 하고, 피스톤 위·아래 나사부만 밀봉 부트로 감싸는 구조로 정합니다. 로드가 실린더 밖으로 나오지 않으므로 높이도 줄어듭니다.
- **개략 높이:** 스트록 1,200 mm + 피스톤 + 주름관·부트 압축 길이 (상·하) + 끝판·밸브 헤드 + 모터 = **약 1.9~2.1 m** 입니다. 주름관 압축비에 따라 달라지므로 실물로 확정합니다.

### 5.2 기밀 구조 — 피스톤 씰이 주 기밀, 주름관은 시각 보조

- **토출 체적은 피스톤 씰이 정합니다.** 피스톤 씰이 사각 보어 전체를 밀봉하므로, 토출량은 보어 단면적 기준으로 계산합니다.
- **주름관은 압력을 받지 않게 합니다.** 주름관 안팎에 균압 구멍을 두어 같은 공간으로 만듭니다. 주름관이 압력을 받지 않으므로 수명이 길어지고, 터지더라도 풀무 기능에는 영향이 없습니다.
- **주름관의 역할은 시각 피드백입니다.** 주름이 접히고 펴지는 모습으로 풀무의 호흡을 강하게 보여 줍니다. 주름관이 손상되면 눈으로 바로 보이므로 관리자가 교체합니다.
- **피스톤 씰 상태는 모터 전류로 감시합니다.** 씰 마모로 누설이 늘면 같은 CPM 에서 부하 전류와 압력 응답이 달라집니다. 추이가 허용 범위를 넘으면 관리자에게 알립니다. 씰 누설은 정량성 (§1·§2) 을 직접 깎으므로 생태 제어 정밀도 관리 항목이기도 합니다.
- **배기 경로 오염도 전류로 봅니다.** ERV·응축 코일이 막히면 같은 CPM 에서 피스톤 부하가 늘어납니다. 씰 마모 (부하 감소·누설 증가) 와 방향이 반대이므로 구분할 수 있습니다.

### 5.4 볼스크루 리드와 위험 속도

모터 회전수 (RPM) = CPM × 2 × 1,200 mm ÷ 리드 (mm) 입니다. 스트록이 같으므로 이 표는 보어와 관계없이 적용됩니다.

| CPM | 리드 10 mm | 리드 20 mm | **리드 40 mm (권장)** | 피스톤 평균 속도 |
| :--- | :--- | :--- | :--- | :--- |
| 1.0 | 240 RPM | 120 RPM | **60 RPM** | 0.04 m/s |
| 6.0 | 1,440 RPM | 720 RPM | **360 RPM** | 0.24 m/s |
| 9.4 | 2,256 RPM | 1,128 RPM | **564 RPM** | 0.38 m/s |
| 12.0 | 2,880 RPM | 1,440 RPM | **720 RPM** | 0.48 m/s |
| 15.0 | 3,600 RPM | 1,800 RPM | **900 RPM** | 0.60 m/s |

- **위험 속도 (개략):** Ø20 나사 (골지름 약 17 mm), 나사 길이 1.4~1.5 m 기준으로 허용 회전수 (위험 속도의 80%) 는 다음과 같습니다.
    - 한쪽 고정·한쪽 지지: 약 900~1,050 RPM
    - **양단 고정: 약 1,300~1,500 RPM**
- **리드 10 mm 는 쓰지 않습니다.** 약 4 CPM 이상에서 위험 속도를 넘습니다. 15 CPM (3,600 RPM) 에서는 DN 값 (20 × 3,600 = 72,000) 도 일반 전조 볼스크루 허용치 근처이거나 넘습니다.
- **리드 40 mm + 양단 고정을 권장합니다.** 최대 15 CPM 에서도 900 RPM 이라 여유가 있습니다. 나사가 피스톤을 관통하고 양 끝판에 지지되므로 양단 고정이 자연스럽습니다.
- **토크:** 피스톤 힘 F = 차압 × 보어 면적 + 씰 마찰, 모터 토크 ≈ F × 리드 ÷ (2π × 효율) 입니다. 200 × 200 에서 약 100 N 이면 약 0.7 N·m 입니다. 배기 쪽은 ERV·응축 코일 손실 (약 200~300 Pa) 을 이겨야 하고 보어가 커지면 면적과 씰 둘레만큼 힘이 늘어나므로, 양산 보어 확정 때 재계산합니다 (§12).
- 위 위험 속도는 개략식으로 낸 값입니다. 최종값은 제조사 계산으로 확정합니다.

## 6. 토출량 산출 (CPM 기준)

### 6.1 계산식

- 편도 토출량 = 보어 단면적 × 행정 1.2 m
- 1 사이클 (왕복) 토출량 = 편도 × 2
- 1 대 풍량 (m³/h) = 1 사이클 토출량 (L) × CPM × 60 ÷ 1,000
- 기구 검증 규격 (200 × 200): 편도 **48 L**, 1 사이클 **96 L**, 1 대 풍량 **5.76 × CPM** (m³/h)
- 호흡 주기 (초) = 60 ÷ CPM

### 6.2 모드별 토출량 (기구 검증 규격 200 × 200, 이론값)

| 뱅가드 렁 모드 | CPM | 호흡 주기 (편도) | 1 대 | 2 대 | 4 대 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 수면 (Sleep) | 6.0 | 10.0 초 (5.0 초) | 34.6 m³/h | 69.1 m³/h | 138.2 m³/h |
| 표준 (Normal) | 9.4 | 6.4 초 (3.2 초) | 54.1 m³/h | 108.3 m³/h | 216.6 m³/h |
| 활성 (Active) | 12.0 | 5.0 초 (2.5 초) | 69.1 m³/h | 138.2 m³/h | 276.5 m³/h |
| 리미트 (Max) | 15.0 | 4.0 초 (2.0 초) | 86.4 m³/h | 172.8 m³/h | 345.6 m³/h |

- 양산 보어별 1 대 풍량은 §7.8 표를 따릅니다.
- **이론값입니다.** 실제 토출량은 다음만큼 줄어들며, 체적 효율 η 로 묶어 실측 보정합니다.
    - 나사 보호 부트 단면적: 예를 들어 유효 Ø45 이면 편도 약 1.9 L (200 × 200 기준 약 4%)
    - 체크밸브가 닫히는 순간의 역류
    - 피스톤 씰 누설
- **총 유량은 CPM 으로 직접 정해집니다.** 용적식이므로 팬처럼 관 저항이나 역압에 따라 유량이 크게 변하지 않습니다. 다만 총 유량이 128 개 유로로 어떻게 나뉘는지는 각 유로의 저항에 따라 달라지므로, 균등 분배는 급기구 조절로 따로 맞춥니다.

### 6.3 맥동

- **볼스크루 정속 구동이므로 반전 순간 외에는 유량이 일정합니다.** 크랭크 사인 구동처럼 유량이 계속 출렁이지 않습니다.
- **반전 시점을 엇갈립니다.** 배기 풀무 n 대의 반전 시점을 편도 시간 ÷ n 간격으로 엇갈리면, 한 대가 반전하는 순간에도 합계 유량은 약 (n − 1)/n 이상을 유지합니다.
- **배기 맥동은 챔버 압력에 나타납니다.** 반전 직전·직후 속도를 연속 CPM 제어 (§10) 로 보상해 줄이고, 실내 압력은 급기 EC 블로어가 연속으로 잡으므로 맥동이 실내까지 전달되지 않습니다.
- 소문 유출 판정은 반전 순간을 제외하거나 몇 호흡 평균으로 합니다.

## 7. 요구 풍량과 용량 산정

### 7.1 산정 원칙 — 세 기준의 최댓값, 증발 몫 차감

필요 풍량은 **수분·CO₂·열** 세 기준으로 각각 계산하고, 그중 **가장 큰 값**으로 정합니다.

| 기준 | 계산식 |
| :--- | :--- |
| **수분** | 수증기 부하 (g/h) = 1.2 × Q (m³/h) × Δw (배기 − 급기 절대습도, g/kg) |
| **CO₂** | Q (m³/h) = CO₂ 발생량 (L/h) ÷ [(목표 농도 − 외기 농도) × 1,000] |
| **열 (현열)** | 현열 (W) = 0.335 × Q × ΔT (배기 − 급기 온도) |
| **증발 잠열** | 잠열 (W) ≈ 수증기 부하 (g/h) × 0.68 (증발열 2,450 kJ/kg) |
| **대사열 ↔ CO₂** | 당 대사 (호흡률 1) 기준 CO₂ 1 L ≈ 21 kJ → 대사열 1 W 당 CO₂ 약 0.17 L/h |
| **대사수** | CO₂ 1 L 당 물 약 0.8 g 이 함께 생깁니다 |

- **증발 몫을 차감합니다.** 꿀 수분을 증발시키는 에너지는 벌의 대사열에서 나옵니다. 대사열 중 증발 잠열만큼은 수증기와 함께 이미 빠져나가므로, **환기가 온도 상승으로 빼야 할 열은 ' 대사열 − 증발 잠열 '** 입니다 (엔탈피 기준).
- **이전 산정 (평시 1,200~2,200 / 최대 2,500 m³/h) 은 폐기합니다.** 공조 구동 방식 문서 §9 를 따른 이전 값은 대사열 전체를 현열로 빼면서 수분을 따로 또 빼는 **이중 계상**이었습니다. 같은 대사열 가정 (시나리오 A) 에서 바로잡으면 유닛 평시 약 245 m³/h 로, 이전 값의 약 1/5 입니다 (§7.5).
- **벽체 방열은 0 으로 둡니다** (보수적). 실측으로 확인되면 열 기준 풍량이 그만큼 줄어듭니다.
- 열이 남으면 벌 공간 온도가 올라가고 (육아권 34~35°C 유지, 40°C 이상 위험), 벌이 선풍과 물 증발로 버티면서 채밀 일벌이 줄어듭니다. 수분이 남으면 이슬점이 올라 차가운 벽·덕트·소초광 테두리에 결로가 생기고, 꿀 숙성이 늦어집니다.

### 7.2 설계 조건

| 항목 | 값 | 근거 |
| :--- | :--- | :--- |
| **1 군 마릿수** | 4 만 마리 (평시 256 만 ÷ 64 군). 최대 8 만 마리 (512 만) | 기존 문서 기준 |
| **급기 (코일 통과 후)** | 22°C, 절대습도 약 8 g/kg (RH 약 50%) | 급기 코일 냉각·제습 |
| **배기 (벌통 공기)** | 34°C·RH 65%, 절대습도 약 22 g/kg | 육아권 34~35°C, 숙성 구역 다습. **습도는 수분 기준 풍량 계산용 가정**이며, 실제 벌통 습도는 풍량의 결과로 정해집니다 (§7.4) |
| **ΔT / Δw** | **12 K / 14 g/kg** | 위 두 값의 차. Δw 14 는 제습을 가장 깊게 했을 때로, 수분 기준 풍량의 최솟값을 줍니다 |
| **CO₂ 목표** | **0.6%** (상한 1.0%), 외기 0.04% | 자연 벌통 관측 범위 |
| **증발량** | 군당 **1.3 L/일 (약 55 g/h)** | 이전 산정의 꿀 숙성 수분 3.5 L/h ÷ 64 군. 표준 벌통 1 L/일 (3 만 마리) 의 4 만 마리 환산과 일치 |
| **벽체 방열** | 0 | 보수적 가정 |

### 7.3 대사열 시나리오

필요 풍량을 가장 크게 좌우하는 값은 **군당 대사열**이며, 아직 실측값이 없습니다. 그래서 세 시나리오로 계산합니다.

| 시나리오 | 마리당 | 군당 (4 만 마리) | 군당 CO₂ | 근거 |
| :--- | ---: | ---: | ---: | :--- |
| **A (하한)** | 1.45 mW | 58 W | 9.9 L/h | 기존 문서 가정 (안정 시 대사) |
| **B (중간, 설계)** | 2.4 mW | 96 W | 16.3 L/h | A 와 C 의 중간 |
| **C (상한)** | 3.4 mW | 136 W | 23.1 L/h | 여름 활동기 CO₂ 15~20 L/h (3 만 마리) 의 4 만 마리 환산 |

- 시나리오 A 는 증발 잠열 (약 43 W) 이 대사열 (58 W) 의 약 73% 를 차지합니다. 숙성이 몰리는 밤에는 대사열이 증발을 감당하기 어려우므로, A 는 **하한 가정**으로 봅니다.

### 7.4 군당 필요 풍량 (4 만 마리, 설계 조건)

| 항목 | A (58 W) | B (96 W) | C (136 W) |
| :--- | ---: | ---: | ---: |
| 수증기 부하 (증발 55 g/h + 대사수) | 62.6 g/h | 67.7 g/h | 73.2 g/h |
| 증발 잠열 | 42.6 W | 46.1 W | 49.8 W |
| 현열 (대사열 − 잠열) | 15.4 W | 49.9 W | 86.2 W |
| **수분 기준 풍량** (Δw 14) | 3.7 m³/h | 4.0 m³/h | 4.4 m³/h |
| **CO₂ 기준 풍량** (0.6% / 1.0%) | 1.8 / 1.0 m³/h | 2.9 / 1.7 m³/h | 4.1 / 2.4 m³/h |
| **열 기준 풍량** (ΔT 12) | 3.8 m³/h | 12.4 m³/h | 21.4 m³/h |
| **군당 필요 풍량 (최댓값)** | **3.8 m³/h** | **12.4 m³/h** | **21.4 m³/h** |
| 지배 기준 | 열 ≈ 수분 | 열 | 열 |

- **열이 풍량을 정합니다.** CO₂ 는 어느 시나리오에서도 지배 기준이 아니고, 수분은 A 에서만 열과 비슷합니다.
- **풍량을 줄이는 것은 제습이 아니라 냉각입니다.** 같은 A 라도 외기를 그대로 넣으면 (30°C·RH 60%, ΔT 4 K·Δw 6 g/kg) 수분 기준 8.7, 열 기준 11.5 m³/h 로 약 3 배가 됩니다. 제습만 하고 냉각하지 않으면 열 기준 11.5 m³/h 가 그대로 남습니다. B·C 는 열이 지배하므로 제습을 더 깊게 해도 필요 풍량은 줄지 않고, 급기 온도를 낮춰야 줄어듭니다 (예: B 에서 급기 18°C, ΔT 16 K → 약 9.3 m³/h. 벌에 닿는 찬 기류·덕트 결로 확인 필요).

**벌통 습도는 결과값 — 급기 이슬점은 벌통 습도로 정한다**

설계 풍량으로 운전하면 벌통 습도는 " 급기 절대습도 + 수증기 부하 ÷ (1.2 × 풍량)" 으로 정해집니다. 급기를 8 g/kg 까지 제습한 상태로 계산하면 다음과 같습니다.

| 시나리오 | 풍량 | 벌통 절대습도 | 34°C 상대습도 |
| :--- | ---: | ---: | ---: |
| A | 3.8 m³/h | 약 21.7 g/kg | 약 63% (§7.2 가정과 일치) |
| B | 12.4 m³/h | 약 12.6 g/kg | **약 37%** |
| C | 21.4 m³/h | 약 10.9 g/kg | **약 32%** |

- **B·C 에서는 깊은 제습이 육아권을 지나치게 말립니다.** 알은 상대습도 50% 아래에서 부화율이 떨어진다고 알려져 있습니다 (문헌 재확인 필요). 벌이 물을 날라 가습하면 채밀 일벌이 줄어듭니다.
- **제습 목표는 " 최대 " 가 아니라 벌통 상대습도 50~60% 유지입니다.** 급기 이슬점을 고정하지 않고 벌통 습도 피드백으로 정합니다.
    - 열이 큰 상태 (B): 급기 절대습도 약 12~14 g/kg (22°C 기준 이슬점 약 17~19°C) 이면 충분합니다.
    - 열이 작은 상태 (A): 풍량이 작아 습기가 쌓이므로 8 g/kg 수준까지 제습합니다.
- **펠티어·히트펌프의 주 역할은 냉각 (현열) 입니다.** 필요 이상 제습은 잠열 부하만 늘려 전력을 낭비합니다. 공조 구동 방식 문서의 용량 검토도 이 기준으로 다시 봅니다 (§12).

| 항목 | A (44 W) | B (72 W) | C (102 W) |

- **문헌값과 비교:** Peters et al., *Collective ventilation in honeybee nests* ([PMC6364655](https://pmc.ncbi.nlm.nih.gov/articles/PMC6364655/)) 는 랑스트로스 벌통 (2~4 만 마리, 소문 2 × 36 cm) 에서 선풍 벌이 만드는 풍속을 약 1 m/s 로 잡았고, 소문에서 배출·유입 구역이 나뉜다고 보고했습니다. 소문 절반 면적 × 1 m/s 로 추정한 자연 벌통 환기량은 **약 13 m³/h** 로, 외기 직도입 조건의 A (8.6) ~ B (27.5) 사이입니다. 자연 벌통은 나무 벽으로 열 일부가 빠지므로 B 와도 모순되지 않습니다. 대사열은 A 보다 크다고 보고 **B 를 설계값**으로 씁니다.
- **근거 ① (수분 증발량) 검토:** 1 L/일 ÷ 흡수 여유 10 g/m³ ÷ 24 h = **4.2 m³/h** 는 맞습니다. 다만 하루 평균이므로, 피크를 고려한 최소값이 이보다 낮은 1.5~2.5 m³/h 가 될 수는 없습니다. 제습 급기 (흡수 여유 약 19 g/m³) 라면 약 2.2 m³/h 입니다. 어느 경우든 수분은 지배 기준이 아닙니다.
- **근거 ② (CO₂) 검토:** 15~20 L/h ÷ (0.6% − 0.04%) = **2.7~3.6 m³/h** 입니다 (1.2~1.8 m³/h 는 계산 오류). 또한 CO₂ 15~20 L/h 는 대사열 약 90~120 W 에 해당하므로, 이 값을 쓰면 열 기준 풍량 (시나리오 C) 도 함께 받아들여야 합니다.
- **" 군당 1.5~2.5 m³/h" 가 성립하는 조건:** 대사열이 A 이하이고, 급기를 냉각·제습하고, CO₂ 1% 가까이를 허용할 때입니다. 설계값으로는 쓰지 않습니다.
- **기타 추정치:** SNS 문구 " 선풍 분당 50~60 L" (3.6 m³/h) 는 출처가 불명이라 근거로 쓰지 않습니다. 소문 전체 면적 × 2 m/s (50.4 m³/h) 는 소문에서 나가는 쪽과 들어오는 쪽이 상쇄되는 점을 무시한 과대값입니다.
- **건조 공기의 "3.5 배 " 는 틀립니다.** 수분 흡수 능력은 상대습도가 아니라 절대습도 차이로 정해집니다. 벌통 배기를 33°C·RH 60% (약 19.3 g/kg) 로 두면 다음과 같습니다.
    - 자연 야간 공기 (20°C·RH 80%, 약 11.7 g/kg): 흡수 여유 7.6 g/kg
    - 건조 급기 (24°C·RH 40%, 약 7.5 g/kg): 흡수 여유 11.8 g/kg
    - 비율은 **약 1.5 배** 입니다. 또한 건조해도 빼야 할 열은 줄지 않습니다.
- **군당 1 m³/h 수준은 월동기 최소 환기에서만** 성립할 수 있습니다. 이 경우에도 CO₂ 가 약 1% 올라 자연 범위의 상한에 닿습니다. 이 값 (블록 약 32 m³/h) 이 풀무 저유량 운전의 설계 하한입니다 (§7.8).

### 7.7 역할 분담 기준

| 구분 | 기준 | 담당 |
| :--- | :--- | :--- |
| **생태 제어 기준** | 군 양압·소문 유출 계산의 기준 배기량 (§2) | **배기 풀무** (급기 EC 블로어는 야간 보정) |
| **평온 호흡** | 표준 벌통이 선풍하지 않는 평온한 상태의 자연 환기량 × 64 군 (봉판 매수로 세력 환산) | **풀무** (수면·표준 단계) |
| **선풍 피크** | 유밀기 밤·더운 날 집단 선풍 풍량 × 64 군 | **풀무** (활성 단계, 필요 시 운전 대수 증가) |
| **비상** | 배기 풀무 용량 부족·구동 계통 이상·가스 정체 (§11.1) | **배기 백업 블로어** (급기는 EC 블로어 N+1) |
| **상한 확인** | 소문 최대 열림 통과 풍량 | 검증용 |

**실측 방법 (표준 벌통, 세력을 아는 군)**

1. 열선 풍속계로 소문 폭 방향 여러 점의 풍속과 방향 (유입·배출) 을 1~5 분 평균해, 면적을 곱한 순배출량을 구합니다.
2. 소문 바깥과 벌통 안의 온습도를 함께 재서 현열 제거량 (0.335 × Q × ΔT) 과 수분 제거량·잠열을 계산하고, §7.4 와 맞춰 봅니다.
3. 평온한 밤, 유밀기 밤, 더운 낮으로 나눠 잽니다.
4. 같은 군의 봉판 매수를 기록해 프레임당 풍량으로 정규화합니다.
5. **대사열 확정 (최우선):** 소문을 수 분간 닫고 벌통 안 CO₂ 농도 상승 속도로 군 CO₂ 발생량을 재면 대사열이 정해집니다 (§7.3). 중량 변화로 하루 증발량도 함께 잽니다. 이 두 값으로 시나리오 A·B·C 중 하나를 확정합니다.

### 7.8 양산 용량 산정 기준과 후보 (미확정)

**산정 기준 (배기 풀무, 블록 단위):**

1. **평시 최대:** 블록 설계 풍량 **800 m³/h** (§7.5) 를 **활성 12 CPM 이하**로 감당합니다.
2. **N+1:** 1 대가 고장 나면 나머지를 **리미트 15 CPM** 으로 올려 블록 설계 풍량을 유지합니다. 블록은 분리·격리 모드로 따로 운전할 수 있으므로 블록마다 이 조건을 만족해야 합니다.
3. **저유량:** 월동기 최소 (블록 약 32 m³/h) 는 운전 대수를 줄이고 연속 CPM 하한 (예: 1.0 CPM) 으로 맞춥니다.
4. **급기 EC 블로어 용량:** 급기 = 배기 + 소문 유출 + 누설이므로, 급기 블로어는 배기 설계 풍량에 소문 유출·누설·필터 오염 여유를 더한 값을 N+1 로 감당합니다.
5. **실별 배분:** 같은 규격 풀무를 저밀실·육아실 그룹으로 나누고, 저밀실에 대수를 더 줍니다. 자중 플랩 2 개로 두 챔버에 연결한 공용 대기 풀무 1 대가 N+1 을 맡습니다 (아래 ' 실별 배분 ').

| 시기 | 전체 풍량 | 비중이 큰 쪽 |
| :--- | :--- | :--- |
| 여름 유밀기 | 최대 | 저밀실 (숙성 수분 + 위로 오르는 열) |
| 이른 봄·가을 육아기 | 작음 | 육아실 |

- 육아실 비중이 커지는 시기에는 전체 풍량이 작으므로, 육아실 쪽은 **절대량 기준 여름 최대치**만 감당하면 됩니다. 기존 실별 비율 (저밀실 약 25 : 육아실 약 15, Aero Profiler) 로 보면 블록 설계 800 m³/h 의 약 40%, **약 300~350 m³/h** 입니다. 저밀실 쪽은 약 500~560 m³/h 입니다.

- **전환 댐퍼 (구동식) 는 두지 않습니다.** 모터·링크 고착 위험을 없애기 위해, 공용 대기 풀무 흡입 쪽에 두 챔버에서 각각 들어오는 **자중 역류 방지 플랩 2 개 (각도 센서)** 만 둡니다. 128 개 배기 라인의 역류 방지 플랩과 같은 방식이며, 군별 배기 댐퍼 모터를 없앤 Aero Profiler 원칙과도 맞습니다.

    - **대기 풀무 운전 시:** 고장·과부하로 빨아내는 힘이 약해진 챔버는 압력이 덜 음압이 되어, 대기 풀무가 그쪽에서 더 많이 빨아들입니다. 실별 챔버 압력 제어 (§10) 가 목표를 맞추면서 부족분 배분이 저절로 정해집니다. 어느 쪽에 붙일지 판단하는 소프트웨어가 필요 없습니다.
    - **대가:** 대기 풀무 운전 중에는 그 유량이 두 챔버에 어떻게 나뉘는지를 플랩 각도로 추정합니다 (백업 블로어 §11.3 과 같은 방식). 이 동안은 실별 계측 (대사량·숙성 수분) 을 보수 운전으로 바꿉니다. 실별 합계 (블록 총 배기량) 는 계속 정확합니다.
    - **고착 감시:** 128 개 플랩 닫힘 확인 시험 (Aero Profiler §1.3) 과 함께 두 플랩의 닫힘을 정기 판정합니다. 대기 풀무 정지 중 플랩이 열려 있으면 챔버 간 누설 경로이므로 경보를 냅니다.
- **평시 실별 미세 배분은 흡기 플랩이 간접적으로 맡습니다.** 실별 배기 합계는 각 그룹 풀무 유량으로 고정되지만, 군별 육아실·저밀실 흡기 플랩 비율을 바꾸면 신선 공기가 들어가는 실이 바뀝니다. 육아실 흡기를 키우면 그 공기가 격왕판을 지나 저밀실 배기로 나가므로 육아실 환기량이 간접적으로 늘어납니다. 다만 바닥 CO₂ 를 빼는 하단 배기 자체는 대신하지 못하고, 군별 흡기 변경은 소문 유출 (§2 양압 관리) 과 함께 계산해야 합니다.
- 육아실 1 대로 약 300~350 m³/h 를 내려면 평시 상한 (12 CPM) 을 조금 넘는 약 13 CPM 이 필요합니다. 실측 결과에 따라 **육아실을 작은 보어 2 대로 나눌지** 정합니다.
- 위 숫자는 기존 실별 비율을 가져온 추정입니다. 목업에서 계절별 실별 풍량을 실측해 확정합니다 (§12).

## 8. 배치와 키네틱 아트

### 8.1 급기·배기 배치

**급기 EC 블로어 — HEPA·ERV·코일 앞에서 밀어 넣는다**

- 외기 → 방충망·프리필터 → **급기 EC 블로어 (N+1, 각 역풍 방지 자중 플랩)** → HEPA → ERV (급기 쪽) → 급기 코일 → 실내 가압 플레넘.
- 급기 블로어가 밀고 배기 풀무가 당기므로 ERV 안에서 급기 쪽 압력이 배기 쪽보다 높게 유지됩니다 (ERV 교차 누설 규칙). 오염된 배기가 급기로 새지 않습니다.
- **제어:** L1 (약 10 Hz) 로 주간에는 정유량 (급기 = 배기 + 소문 유출 목표 + 보정값), 야간에는 실내 압력을 맞춥니다 (§10). 급기량은 흡입 노즐 차압 (K-factor) 으로 측정하고, 야간에 배기 풀무 기준으로 보정합니다 (§2).
- **용량·정압:** 유량은 주간 기준 (배기 설계 + 소문 유출 블록 약 100~190 m³/h + 누설·필터 여유), 정압은 소문 면 바람 여유 (약 30~60 Pa, 안) 를 더해 N+1 로 정합니다 (§10).
- **필터 오염:** 정풍량 제어로 HEPA 가 막혀도 급기량을 유지합니다. 같은 급기량에서 소비 전력·회전수가 오르는 추이로 교체 시점을 알리고, 회전수 상한에 닿으면 경보를 냅니다.
- **소음:** 외기 흡입부에 두어 HEPA·ERV·코일·플레넘을 지나며 감쇠되게 하고, 방진 마운트와 흡음 덕트로 마감해 날개 순음이 벌 공간과 음향 감시 마이크에 닿지 않게 합니다.
- **N+1:** 1 대가 멈추면 역풍 방지 플랩이 닫히고 남은 블로어가 소프트 스타트로 올라가 실내 압력을 유지합니다.

**배기 풀무 — ERV·응축 코일 뒤에서 당긴다**

- 셀 블록 배기 챔버 → ERV (배기 쪽) → 배기 응축 코일 → **배기 풀무** → 배기탑.
- **고압이 필요한 자리입니다.** 배기 유로는 좁고 (22 × 40 mm 등), ERV·코일 손실이 큽니다. 풀무는 관 저항과 역압에 따라 유량이 크게 변하지 않습니다.
- **벌과 가장 가까운 자리입니다.** 챔버는 128 개 유로로 벌통과 직결됩니다. 저속 풀무는 팬의 날개 순음 (약 300 Hz 대역) 이 없어, 벌과 음향 감시 마이크에 유리합니다.
- **배기 유량을 정확히 알 수 있습니다.** 소문 배출량 (Q_ 소문 = Q_ 흡기 − Q_ 배기라인) 의 계산 정확도가 올라갑니다. 이것이 생태 제어 (§2) 의 출발점입니다.
- 포화에 가까운 공기가 배기 풀무를 지나므로 내부 결로 배수가 필요합니다 (아래 ' 결로수 수집 ', §12).

**실별 배기 챔버 — 저밀실과 육아실을 따로 당긴다**

```text
[저밀실] 상단 배기 라인 64 → 역류 방지 플랩 → 저밀실 챔버 → ERV 저밀실 구획 → 응축 코일 → 저밀실 풀무 그룹 → 배기탑
[육아실] 하단 배기 라인 64 → 역류 방지 플랩 → 육아실 챔버 → ERV 육아실 구획 → 응축 코일 → 육아실 풀무 그룹 → 배기탑
[공용]   저밀실 쪽 자중 플랩 + 육아실 쪽 자중 플랩 (코일 뒤, 구동부 없음, 각도 센서) → 공용 대기 풀무 → 배기탑
결로수:  ERV 각 구획 · 응축 코일 · 풀무 하부 · 배기탑 하부 → 실별 트랩 → 실별 계량 → 결로수 저장조 (§8.1 '결로수 수집')
```

- **두 흐름은 풀무 출구에서만 합칩니다.** 풀무 앞에서 합치면 실별 유량을 알 수 없게 됩니다.
- **챔버 분리:** 128 개 라인이 이미 상단·하단으로 나뉘어 챔버 입구에 닿으므로, 챔버 안에 칸막이를 두어 나눕니다. 칸막이 누설은 두 챔버 압력 차 (수 Pa) 가 작아 영향이 작지만 실측으로 확인합니다.
- **두 흐름 모두 ERV 를 지납니다 (기본).** 배기 전량의 열을 회수하고 결로수도 두 흐름 모두에서 받습니다. 흐름을 풀무까지 나눠 두어야 하므로 **ERV 배기 쪽을 저밀실·육아실 두 구획**으로 나누거나 ERV 를 실별 2 모듈로 둡니다. 급기 쪽은 하나로 둡니다. 자유 냉방 바이패스 (공조 구동 방식 문서) 도 실별 구획마다 둡니다.
- **ERV 를 풀무 뒤로 옮겨 하나로 합치지 않습니다.** 풀무가 밀어 넣으면 ERV 배기 쪽 압력이 급기 쪽보다 높아져, 오염된 배기가 급기로 새는 쪽으로 교차 누설 규칙이 뒤집힙니다.
- **실별 측정:** 각 챔버 (또는 각 그룹 풀무 앞) 에 온습도·CO₂ 센서를 둡니다. 유량은 풀무 사이클 수로 이미 알고 있으므로, 농도만 재면 실별 제거량이 나옵니다 (§2).
- **챔버 연동:** 셀 블록 L·R 챔버 연결 댐퍼 (Aero Profiler §1.7) 는 같은 실끼리만 잇습니다 (저밀실 L ↔ 저밀실 R, 육아실 L ↔ 육아실 R).

**결로수 수집 — ERV 와 배기탑이 기본 수집점**

결로수 수집은 저밀실·육아실 두 흐름 모두에서 **기본 기능**으로 둡니다. 물 확보 (공조 구동 방식 문서: 겨울 ERV 자연 결로가 기본) 와 결로수 재활용 (양봉 방재 문서) 의 출발점입니다.

| 수집점 | 주로 생기는 때 | 비고 |
| :--- | :--- | :--- |
| **ERV 배기 쪽 (실별 구획)** | 외기가 차가운 계절·밤 (주 수집점) | 외기가 영하 근처면 소자 결빙 위험. 예열·부분 바이패스로 해빙 운전 |
| **배기 응축 코일** | 히트펌프 운전 시 (냉방·제습·배기 열원 난방) | 용량은 공조 구동 방식 문서 |
| **배기 풀무 하부** | 포화 공기가 실린더 안에서 식을 때 | 실린더 바닥 배수구 (§12) |
| **배기탑 하부** | 사계절, 특히 밤·겨울 (탑 벽이 외기에 식음) | 탑 벽을 타고 흘러내린 물이 풀무 쪽으로 되돌아가지 않게 탑 하부에서 받음 |

- **ERV 소자 재질이 수집량을 정합니다.** 알루미늄 판 (현열 전용) 은 습기를 배기에 남겨 배기 쪽 결로가 많습니다. 습기까지 옮기는 막·종이 소자 (전열) 는 결로가 적고, 여름에는 습기를 급기로 되돌려 급기 코일 부하를 늘립니다. 결로수 수집을 기본으로 삼으면 **현열 소자가 유리**합니다 (공조 구동 방식 문서와 함께 확정, §12).
- **실별로 따로 받고 따로 잽니다.** 실별 트랩을 거친 뒤에 합쳐 실 사이 공기가 배수관으로 섞이지 않게 하고, 합치기 전에 실별로 수량을 계량합니다 (전도식 계량 등). 저밀실 결로수량은 숙성 수분 추정 (§2) 을 습도 계산과 별도로 검증하는 값이 됩니다.
- **음압 쪽 배수는 트랩 봉수 높이가 핵심입니다.** ERV·코일·풀무 흡입 쪽은 음압 (최대 약 −200~−300 Pa ≈ 20~30 mmAq, 추정) 이라, 봉수가 낮으면 배수가 안 되고 공기가 배수관으로 빨려 듭니다. 봉수 높이는 최대 흡입 음압의 약 1.5 배 이상 (값 미정) 으로 하고, 봉수 마름 (여름)·동결 (겨울) 을 막습니다 (보충 급수 또는 볼 체크식 트랩 검토). 배기탑 쪽은 양압이므로 일반 트랩으로 충분합니다.
- **위생:** 결로수에는 먼지·CO₂·암모니아·밀랍 성분 등이 섞일 수 있으므로 저장 전 여과·소독합니다 (양봉 방재 문서). 저장조는 배수관을 통해 벌 공간 쪽으로 냄새·세균이 역류하지 않게 트랩 뒤에 둡니다.

### 8.2 키네틱 아트 구성

- **외부 투시창:** 타포린 주름관과 피스톤 동작이 밖에서 보이도록 합니다. 자외선 안정화 폴리카보네이트나 강화유리를 쓰고, 겨울 김서림을 막기 위해 이중창으로 합니다.
- **실린더 내부 김서림:** 포화에 가까운 배기가 투명 PC 실린더 안을 지나면 내벽에 김이 서려 주름관이 안 보일 수 있습니다. 내벽 방담 코팅과 주름관 색상 대비로 대응하고, 실물로 확인합니다.
- **배기 풀무 열 연출:** 배기 풀무를 한 열로 나란히 두어, 벌집의 숨을 내쉬는 폐처럼 보이게 합니다.
- **동작 연동 조명:** CPM 에 맞춰 간접 조명의 밝기나 색을 바꿔, 공조 부하를 시각적으로 보여 줍니다. 조명이 벌 공간으로 새지 않게 차광합니다.
- **위상 연출:** 반전 시점을 엇갈려 돌리므로 (§10), 파도처럼 순차적으로 움직이는 모습이 자연스럽게 연출됩니다. 맥동을 줄이는 기능이기도 합니다.
- **안전:** 끼임 방지 가드를 두고, 점검 도어가 열리면 해당 풀무를 정지합니다. 정지한 만큼 남은 풀무가 보상합니다 (§10).
- **원칙:** 시각 연출은 공조 제어보다 우선하지 않습니다. 보여 주기 위해 필요 이상으로 빠르게 돌리지 않습니다.

## 9. 뱅가드 렁 (Vanguard Lung) 모드별 심장 CPM 기준

렁 단계는 운영과 연출의 **기준점**입니다. 사람이 보기에 거대한 생명체가 숨 쉬는 듯한 일정한 리듬을 유지하기 위해, 실제 CPM 은 기준 단계 근처에서만 연속으로 미세 조정합니다. 1 회 호흡은 1 사이클 (들숨 = 한 방향 행정, 날숨 = 반대 방향 행정) 이며, 복동식이므로 들숨·날숨 모두 토출합니다.

| 구동 모드 | 기준 CPM | 1 회 호흡 주기 (들숨 + 날숨) | 적용 조건 | 시각적·생태적 연출 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 수면 (Sleep)** | 6.0 | 10.0 초 (5 초 / 5 초) | 야간, 월동기, 저부하 | 사람의 깊은 명상·수면 호흡 (분당 6~8 회) 과 같은 리듬입니다. 거대한 생명체가 가장 깊고 평온하게 잠들어 숨 쉬는 듯한 정적을 연출합니다 |
| **2. 표준 (Normal)** | 9.4 | 6.4 초 (3.2 초 / 3.2 초) | 평시 공조 | 기본 리듬입니다. 장비가 살아 움직이며 실내·챔버 압력을 안정적으로 유지하고 있다는 신뢰감을 줍니다 |
| **3. 활성 (Active)** | 12.0 | 5.0 초 (2.5 초 / 2.5 초) | 유밀기 주간·밤, 외기 고온 | 외기가 따뜻하면 배기와 급기의 온도차가 작아져 같은 열을 빼는 데 풍량이 더 필요합니다. 심장이 약간 빠르게 뛰는 느낌으로 " 벌들과 함께 열심히 일하고 있다 " 는 생동감을 보여 줍니다 |
| **4. 리미트 (Max)** | 15.0 | 4.0 초 (2.0 초 / 2.0 초) | 비상 전용: 배기 풀무 1 대 고장 보상 (N+1), CO₂ 또는 가스 정체 경보 | 소프트웨어 한계선입니다. 이보다 빠르면 기계가 " 헐떡인다 " 는 불안감을 주므로, 아무리 급해도 15 CPM 에서 제한합니다. 그래도 부족하면 백업 블로어가 기동합니다 (§11) |

- **연속 미세 조정:** 실제 CPM 은 기준 CPM ± 15% 안에서 연속으로 바뀝니다. 이 정도 변화는 눈으로 리듬 차이를 거의 느끼지 못합니다. 범위를 벗어나면 기준 단계를 바꾸거나 운전 대수를 바꿉니다 (§10).
- **저유량:** 수면 단계보다 적은 수요는 운전 대수를 줄이고, 그래도 많으면 CPM 을 하한 (예: 1.0 CPM) 까지 연속으로 낮춥니다. 배기 풀무가 멈추면 챔버 압력이 군 압력까지 올라 소문 유출이 크게 출렁이므로 **간헐 정지 운전은 하지 않습니다.**
- **모드 전환 연출:** 기준 단계는 호흡 끝 (피스톤이 끝점에 멈추는 순간) 에서만 바꾸고, 한 단계씩 2~3 호흡에 걸쳐 부드럽게 바꿉니다.
- **풍량을 정하는 것은 열과 수분입니다.** 배기 풀무 CPM 은 열·수분 제거에 필요한 배기량으로, 급기 EC 블로어 회전수는 실내 압력으로 정해집니다 (§10).

## 10. 공조 운전 로직 (배기 풀무 + 급기 EC 블로어)

블록마다 아래 순서를 실행합니다. 배기 풀무는 **실별 그룹 (저밀실·육아실) 마다** 따로 계산합니다. 챔버 연동 모드에서는 유닛 전체의 같은 실 그룹을 한 그룹으로, 분리·격리 강제 모드에서는 블록별로 계산합니다.

```text
입력:
  Q_배기_목표  = 챔버 압력 제어기가 요구하는 배기 유량 (Aero Profiler §2.1·§2.5)
                 = Q_저밀_목표 + Q_육아_목표 (실별 챔버 압력 제어기가 각각 요구)
  ΔP_챔버_허용 = 두 챔버 압력 차 상한 (수 Pa, 값 미정)
  P_실내_목표  = 실내 가압 플레넘 목표 압력 (Aero Profiler §1.2, +3~5 Pa)
  Q_소문_목표  = 블록 소문 유출 합계 목표 (소문 상태별, Aero Profiler §2.5)
  Q_보정(Q)    = 야간 다점 보정 곡선 (급기 측정 오차 + 누설, §2)
  Q_급기_측정  = 급기 EC 블로어 흡입 노즐 차압 (K-factor) 측정값
  n_배기       = 정상 동작 중인 배기 풀무 대수
  V_사이클     = 보어 면적 × 1.2 m × 2 (양산 보어 확정 후 값)
  η            = 체적 효율 (실측 보정값)
  Q(n, CPM)    = n × V_사이클 × η × CPM × 60 / 1000
  CPM 범위     = 1.0 (하한) ~ 12.0 (평시 상한) ~ 15.0 (비상 리미트)

1) 배기 풀무 — 실별 유량 기준 (L2, 수 초~분)
   실별 그룹 g ∈ {저밀실, 육아실} 마다:
     운전 대수 m_g = CPM 이 렁 단계 ±15% 안에 들어오는 최소 대수
     CPM_g = Q_g_목표 ÷ Q(m_g, 1)   (연속값)
   공용 대기 풀무 기동 = 그룹 풀무 고장, 또는 어느 CPM_g 가 평시 상한 (12) 을 넘을 때
     최저 CPM 에서 소프트 스타트 → 두 챔버 압력이 목표에 들도록 대기 풀무 CPM 을 올리고
     그룹 CPM 을 함께 재조정 (배분은 자중 플랩 2 개가 압력 차로 저절로 정함)
     실별 유량 = 그룹 풀무 유량 + 대기 풀무 유량 × 플랩 각도 추정 비율 (보수 운전 표시)
   평시 실별 미세 배분 = 군별 육아실·저밀실 흡기 플랩 비율 (간접, 소문 유출 함께 계산)
   두 챔버 압력 차 > ΔP_챔버_허용 → 압력이 더 낮은 (더 음압인) 챔버의 그룹 CPM 을 줄여 차이를 좁히고 경보
   기준 단계 변경 = 호흡 끝에서만, 한 단계씩, 최소 10 호흡 유지 후
   Q_배기 = Q_저밀 + Q_육아 (급기·소문 유출 계산에 사용)

2) 급기 EC 블로어 (L1, 약 10 Hz) — 소문 상태에 따라 제어 방식을 바꾼다
   주간 (소문 열림) — 정유량 제어
     Q_급기_목표 = Q_배기 + Q_소문_목표 + Q_보정(Q)
     회전수 = Q_급기_목표 에 해당하는 회전수 + PI(Q_급기_목표 − Q_급기_측정)
     실내 압력은 상·하한 감시만 한다
       P_실내 < 하한 (출입문 개방·내검 인출 등 실내 누설) → 부족분만큼 Q_급기_목표 를 올림
       P_실내 > 상한 (소문 면 강풍) → 정유량 유지, 바람받이 면 소문 단계 축소 요청·경보
   야간 (소문 닫힘) — 실내 압력 제어 + 저소음 모드
     P_실내_목표 = 야간값 +1~2 Pa (외기 유입만 막는 최소 양압, 주간 +3~5 Pa)
     회전수 = (Q_배기 + Q_보정) 에 해당하는 회전수 + PI(P_실내_목표 − P_실내)
     급기 블로어는 정지하지 않는다 (아래 '야간 저소음 모드' 참조)
   전환 = 블록 소문 상태 신호로, 목표값을 몇 초에 걸쳐 이어 붙여 출렁임 없이 바꾼다
   소문 유출 추정 = Q_급기_측정 − Q_배기 − Q_보정(Q)

3) 반전 시점 배치
   실별 그룹마다 풀무 m_g 대의 반전 시점을 편도 시간 ÷ m_g 간격으로 엇갈리고,
   두 그룹의 반전 시점도 서로 겹치지 않게 어긋나게 둔다

4) 대수 제어
   CPM 이 하한 근처로 내려가면 운전 대수를 줄이고, 평시 상한을 넘으면 늘린다
   쉬는 풀무는 순번을 돌려 마모를 고르게 한다
   대수 변경은 호흡 끝에서, 들어오는 풀무를 먼저 올리고 나가는 풀무를 내린다

5) 고장·비상
   배기 풀무 이상 (모터 전류·엔코더 위치) → 해당 풀무 제외, 공용 대기 풀무 기동,
   반전 시점 재배치, 해당 그룹 남은 풀무를 리미트 (15.0 CPM) 까지 허용
   대기 풀무 정지 중 자중 플랩 열림 (각도 센서) → 챔버 간 누설 경보, 실별 계측 보수 운전
   대기 풀무 운전 중 한쪽 플랩이 열리지 않음 → 해당 그룹 리미트로 대응, 경보
   남은 풀무 리미트로도 목표 미달 → 배기 백업 블로어 기동 (§11.1)
   급기 EC 블로어 1 대 정지 → 역풍 방지 플랩 닫힘, 남은 블로어로 급기 목표 유지
   CO₂·가스 정체 경보 → 배기 리미트 단계, 해소 안 되면 배기 백업 블로어
   비상 조건이 해제되면 한 단계씩 원래 단계로 복귀

6) 야간 다점 보정 (블록 소문 전부 닫힘)
   배기 풀무 CPM 을 몇 단계로 바꾸며 각 단계에서 Q_급기_측정 − Q_배기 를 기록
   → Q_보정(Q) 곡선 갱신. 전날 대비 급변하면 노즐·필터·누설 점검 경보
```

- ±15%, 10 호흡, 10 Hz 는 초기값입니다. 실측 후 조정합니다.
- **급기가 배기에 따라붙는 이유:** Aero Profiler 의 압력 샌드위치에서 실내 쪽은 급기가, 챔버 압력은 배기가 맡습니다. 배기 풀무가 정한 유량에 급기 EC 블로어가 따라붙는 구조라 급기·배기 차이 (소문 유출 + 누설) 가 항상 양수로 유지됩니다.
- **주간에 정유량 제어를 쓰는 이유:** 소문이 열리면 군 압력은 바깥 공기에 물려, 배기 음압이 실내 양압을 받쳐 주지 못합니다. 이때 실내 압력을 일정하게 맞추면, 소문 면에 바람이 불어 바깥 압력이 오를 때 (풍속 3 m/s 동압 약 5 Pa, 5 m/s 약 15 Pa) 소문 유출이 줄거나 역류합니다. 반대로 급기·배기 유량 차이를 고정하면 질량 보존에 따라 소문 유출이 유지되고, 실내·군 압력은 바람만큼 저절로 올라갑니다. 급기·배기가 모두 풀무일 때 얻는 이 성질을 EC 블로어의 정유량 제어로 대신합니다.
- **야간 저소음 모드:** 소문이 모두 닫힌 밤에는 외기 유입만 막으면 되므로 소음을 최소로 낮춥니다.
    - **실내 목표 압력을 +1~2 Pa 로 낮춥니다.** 급기 블로어는 급기 경로 손실을 상쇄하는 최저 회전수 부근에서 돕니다. 팬 소음은 회전수의 약 5 제곱에 비례해 회전수 1/2 에서 약 15 dB, 1/3 에서 약 24 dB 줄어듭니다 (기종 확정 후 실측).
    - **배기 풀무는 필요 풍량이 허락하는 가장 낮은 단계로 운전**하고, 대수 제어로 쉬는 풀무를 늘립니다. 숙성 수분이 몰리는 밤이라 풍량 하한은 CO₂·벌통 습도로 지킵니다.
    - **급기 블로어를 멈추고 배기 풀무만 돌리는 방식은 쓰지 않습니다.** 정량 배기가 실내를 음압 (급기 경로 손실만큼, 약 150~250 Pa 추정) 으로 만들어, 닫힌 소문 틈·외벽 틈으로 거르지 않은 외기가 벌 공간에 직접 들어옵니다. 배기 풀무가 급기 쪽 손실까지 이겨야 해 토크 기준 (§5.4) 을 넘고, 야간 다점 보정 (6 단계) 도 할 수 없습니다.
    - 벌은 공기 중 소리보다 벌통을 타고 오는 진동에 민감하므로, 회전수보다 블로어·풀무의 방진 마운트 (§8.1·§11.5) 가 더 중요합니다.
- **급기 블로어 압력 여유:** 바람에 따라 압력이 올라가도 유량이 유지되도록, 블로어 정압 사양은 "HEPA 오염 말기 + ERV + 코일 + 덕트 손실 + 실내 목표 압력 + 바람 여유 (약 30~60 Pa, 안)" 로 정합니다.
- **연속 CPM 은 정량성을 해치지 않습니다.** 유량은 피스톤 속도 (엔코더) 로 정확히 계산되므로, 압력을 맞추느라 CPM 이 바뀌어도 급기량·배기량은 계속 알 수 있습니다. 바이패스 댐퍼로 유량을 깎는 방식은 바이패스 유량을 추정해야 하므로 쓰지 않습니다.

## 11. 배기 비상 백업 블로어

배기 쪽 블로어는 공조 장치가 아니라 **비상 백업 장치**입니다. 배기 풀무와 병렬로 두고, 평시에는 정지 + 자중 플랩 닫힘 상태로 대기합니다. 급기 쪽은 EC 블로어 N+1 이 주 장치이자 서로의 백업이므로 별도 백업을 두지 않습니다 (§8.1).

실별 배기 챔버로 나눈 경우, 백업 블로어는 **두 챔버 각각에 자중 플랩을 거쳐** 연결합니다 (실별 1 대씩 또는 1 대 + 실별 플랩, 안). 백업 운전 중에는 실별 유량을 정확히 알 수 없으므로 실별 관리도 보수 운전으로 바꿉니다 (§12).

```text
[배기]  챔버 → ERV → 코일 ─┬─ [배기 풀무 (체크밸브 내장)] ──────────────┬─ 배기탑
                           └─ [백업 블로어] ─ [자중 플랩 + 각도 센서] ──┘
```

- **풀무 경로:** 풀무가 멈춰도 흡입·배출 체크밸브가 직렬로 역류를 막으므로 별도 댐퍼가 필요 없습니다.
- **블로어 경로:** 정지한 블로어는 구멍과 같아서 배기탑 공기가 챔버로 들어오는 역류 경로가 됩니다. 이를 막기 위해 합류부보다 블로어 쪽에 **자중 플랩**을 둡니다.

### 11.1 기동·운전·복귀 규정

| 구분 | 내용 |
| :--- | :--- |
| **기동 조건** | ① 배기 풀무를 리미트 (15 CPM) 로 올려도 목표 유량 미달 (예: 블록 배기 풀무 2 대 이상 고장) ② 풀무 구동 계통 이상 (48 V 버스·모터 드라이버 공통 고장) ③ CO₂·가스 정체 경보가 풀무 리미트로 해소되지 않음 ④ 계획 정비 (씰 교체 등) 로 가용 풀무가 N+1 미만 |
| **운전 중** | 블로어는 **부족분만** 채웁니다 (풀무는 가용 대수로 계속 운전). 정밀 생태 제어를 멈추고 **전 군 평시 미세 양압**으로 되돌립니다 (교미 창 인접 군 중립 해제 포함). 관리자에게 알립니다 |
| **복귀 조건** | 풀무 가용 대수 회복 → 풀무 CPM 을 올리며 블로어를 감속 → 블로어 정지 → 자중 플랩 닫힘 확인 → 생태 제어 재개 |
| **정기 기동 시험** | 주 1 회 (값 미정) 단시간 기동해 RPM·플랩 열림 각도를 확인합니다. 소문이 닫힌 야간에 실행해 생태 영향을 없앱니다 |
| **전원** | 풀무 48 V 버스와 **다른 전원 계통**에서 받습니다 (기동 조건 ② 대비, 안) |

### 11.2 자중 플랩 설치 조건

1. **방향:** 경첩을 위에 두어 블로어가 멈추면 자중으로 시트에 내려앉게 합니다. 역압이 플랩을 시트 쪽으로 누르도록 배치해, 역압이 클수록 더 꽉 닫히는 자기 밀봉 구조로 만듭니다.
2. **밀봉:** 역류 방지 플랩과 같은 겹침 립을 씁니다. 역압 상태의 누설은 실측으로 확인합니다. 평시 내내 닫혀 있는 플랩이므로 이 누설이 곧 정량성 오차입니다.
3. **떨림 방지:** 블로어 저유량 운전 중에는 반쯤 열린 플랩이 풀무 반전 순간의 유량 변동에 흔들릴 수 있습니다. 경첩에 약한 마찰이나 자석 댐핑을 주고, 각도 신호는 몇 호흡 평균으로 판정합니다.
4. **개방 저항:** 플랩 무게만큼의 개방 저항 (수 Pa 수준) 은 블로어 능력에 비해 작으므로 허용합니다.

### 11.3 판정 — RPM 은 기계 고장, 플랩 각도는 유량

- **블로어 RPM 만으로는 부족합니다.** EC·BLDC 팬은 컨트롤러가 회전수를 유지하므로 공기가 흐르지 않아도 RPM 이 유지됩니다. 원심 블로어는 유량이 줄면 부하가 가벼워져 회전수가 오히려 오르기 쉽습니다. 따라서 RPM 은 고착·모터 고장만 판정합니다.
- **플랩 각도가 유량을 알려 줍니다.** 열림 각도는 유량에 따라 커집니다. 목업에서 각도 - 유량 관계를 실측해 두면 블로어 유량을 추정할 수 있고, 풀무 유량 (사이클 수) 과 더하면 총 유량이 됩니다. 이 추정 오차 때문에 백업 운전 중에는 정밀 생태 제어를 멈춥니다 (§2).

| 블로어 명령 | 블로어 RPM | 플랩 각도 | 판정 | 대응 |
| :--- | :--- | :--- | :--- | :--- |
| 정지 | 0 | 닫힘 | 정상 (평시 풀무 단독 운전) | — |
| 정지 | 0 | 열림 | 플랩 걸림·이물질 (누설 경로) | 관리자 경보, 정량성 오차로 생태 제어 보수 운전 |
| 운전 | 기대값 | 기대 각도 | 정상 (백업 운전) | — |
| 운전 | 기대값 | 기대보다 작음 | 유량 부족 (막힘 또는 역류 직전) | 블로어 회전수 올림 또는 풀무 단계 낮춤 |
| 운전 | 기대값 | 닫힘 | 유량 0, 역류 시작 | 즉시 위와 같이 대응, 반복되면 경보 |
| 운전 | 크게 낮음 또는 0 | 닫힘 | 블로어 고장 | 풀무 리미트 유지, 최우선 경보 (백업 상실) |

### 11.4 백업 병렬 운전 규칙

풀무는 압력과 상관없이 정해진 유량을 밀어내므로 압력을 크게 만들 수 있습니다. 반면 블로어가 낼 수 있는 최대 압력 (차단 압력) 은 회전수가 낮을수록 작아집니다. 풀무가 만든 압력이 블로어 차단 압력을 넘으면 블로어 유량이 0 이 되고 이어서 역류합니다. 부족분이 작아 블로어를 저속으로 돌릴 때가 가장 위험합니다.

| 규칙 | 내용 |
| :--- | :--- |
| ① 블로어 최소 회전수 | 블로어는 차단 압력이 걸리는 압력의 약 1.3 배 이상인 회전수 (RPM_ 블로어 _ 최소) 아래로 돌리지 않습니다 |
| ② 풀무 단계 낮춤 | 블로어가 최소 회전수로 돌아도 부족분보다 많이 낼 때는 풀무를 한 단계 낮춥니다 |
| ③ 백업 운전 중 | 풀무는 가용 대수로 운전을 유지하고, 블로어 회전수로 남은 부족분을 맞춥니다 |
| ④ 역류 감시 | 블로어 운전 중 플랩이 닫히려 하면 역류가 시작된 것입니다. 블로어 회전수를 올리거나 풀무 단계를 낮추고, 반복되면 경보를 냅니다 |

- 역류하려는 순간에는 자중 플랩이 닫혀 역류를 막습니다. 플랩은 규칙 ④ 의 감지 수단이자 안전장치입니다.

### 11.5 기계 구조 보강

- **챔버·플레넘 벽:** 풀무 반전 순간의 유량 변동에 벽이 떨지 않도록 리브로 보강합니다.
- **풀무 마운트:** 피스톤 반전 때 반력이 주기적으로 걸리므로 방진 마운트로 벌통 구조와 떼어 놓습니다. 같은 열 풀무의 반전 시점을 엇갈려 반력도 분산합니다.
- **플랩 위치:** 자중 플랩은 반드시 합류부보다 블로어 쪽에 둡니다. 그래야 평시 풀무 단독 운전 때 블로어 경로를 완전히 끊을 수 있습니다.
