# 스마트 무선 양봉 관리기 및 검진 시스템 기획서

측정 대상 홈에 **지렛대를 끼워 넣고 손으로 눌러** 하중을 읽는 **NEXA 스마트 양봉 검진 스틱** 종합 기획서.
스트레인 게이지·비틀림 추론은 폐기하고, **소형 로드셀 + 지렛대 배율**로 절대 하중을 계측한다.
**차량 지붕 자이로**가 약 1mm 리프트에 해당하는 기울기 변화를 감지하면, 메인 컴퓨터가 그 순간의 휴대 측정기 데이터를 **기준값으로 래치**한다.
손잡이 쪽 **슬라이딩·고정형 리미트 블록**이 물리적으로 더 이상 눌리지 않게 막아, 전자 (Δθ) 와 기구 (리미트) 의 **복합 검증**이 가능하다.

## 1. 프로젝트 개요

| 항목 | 내용 |
| :--- | :--- |
| 제품명 | NEXA 스마트 양봉 검진 스틱 (Smart Beekeeping Diagnostic Stick) |
| 목적 | 대상 홈에 지렛대를 삽입·수동 가압하여 소형 로드셀로 하중을 직접 계측하고, 비전·환경·운영 이력과 융합해 봉군 상태를 진단하는 휴대형 맥락 연결 장치 |
| 적용 범위 | 벌통·아우트리거 등 매립 홈 하중 측정, 개체 식별·내검, 저밀량 데이터 자산화 |

### 핵심 가치

1. **지렛대 배율 로드셀 계측** — 로드셀을 지렛대 뒤쪽 (손잡이 측) 에 배치해 센서 용량을 줄이고, 배율 상수로 실제 팁 하중을 환산.
2. **지붕 자이로 래치** — 아래에서 약 1mm 만 올려도 지붕 IMU 가 Δθ를 캐치. **항상 동일한 기울기 조건**에서 메인 컴퓨터가 스틱 데이터를 포착·기준으로 삼음.
3. **슬라이딩 리미트 블록 + 복합 검증** — 손잡이 행정에 물리 스톱을 걸어 과가압을 차단하고, `Δθ_target` 도달과 `리미트 ON` 을 교차해 측정 신뢰도를 이중 확인.
4. **상향식 (Bottom-up) 저밀 데이터** — 소초광 관리기 누적 무게와 검진 스틱 측정값을 교차해 꿀 무게를 자산화.
5. **핸즈프리에 가까운 현장 자동화** — QR 스캔 → 자이로·리미트 게이트된 로드셀 패킷 → BLE 프린터 출력.
6. **비전 AI 데이터 소스** — 고정 거리·각도·조명 정형 이미지가 서버 AI 학습·진단 입력이 됨.

## 2. 시스템 아키텍처

화면·버튼을 제거하고 50mm 슬림 프레임에 맞춘 센서 융합형 디바이스.

```json
       [ 차량 지붕 IMU / 자이로 ] ── Δθ(≈1mm 리프트) ──┐
                                                       │ 래치 트리거
       [ 야외 봉군 / 아우트리거 현장 ]                   ▼
  ┌──────────────────────────────────────┐    [ 메인 컴퓨터 ]
  │  NEXA 스마트 검진 스틱 (ESP32-CAM)    │──► │ 동일 Δθ에서 F_lc 포착
  │  - 지렛대 암 + 피벗(지점)             │    │ = 기준 측정값
  │  - 후방 소형 로드셀 + HX711           │──┐ │ + 리미트 블록 복합검증
  │  - 손잡이 슬라이딩 리미트 블록        │  │ └──────────┬──────────┘
  │  - 24핀 0.5mm 피치 내시경 카메라      │  │            │
  │  - IR 온도 / 디지털 마이크            │  │            ▼
  └──────────────────────────────────────┘  │   [ PostgreSQL ] → [ 비전 AI ]
           │ BLE 양방향                      ▼
           ▼                      [ 휴대용 열전사 프린터 ]
  [ 스마트폰 (Vue.js 앱) ]         - 58mm 스티커 / ESC/POS
```

### 2.1 하드웨어 구성

| 계통 | 사양 | 비고 |
| :--- | :--- | :--- |
| 메인 제어 | ESP32-CAM (Wi-Fi + BLE) | 비전·무선·센서 게이트웨이. 연속 `F_lc` 스트림 송신 |
| 지붕 IMU | 고정밀 자이로 (+ 가속도) | 차량 지붕 설치. ≈1mm 하부 리프트의 Δθ 감지 → **샘플 래치 게이트** |
| 메인 컴퓨터 | 차량/현장 호스트 | `Δθ ∧ limit` 동시 충족 시 스틱 패킷을 기준값으로 확정 |
| 내시경 | OV2640, Ø5.5~8mm, 24 핀 0.5mm FFC/FPC | 15~30cm 연장 시 FPC 보드 + 구리 차폐로 모터 EMI 차단 |
| 하중 | 소형 로드셀 + HX711 | 지렛대 **후방** 배치. 스트레인 게이지 단독 부착 방식은 미사용 |
| 지렛대 | 팁 — 피벗 — 후방 로드셀 — 그립 | 손으로 그립을 눌러 팁을 들어 올림 |
| 리미트 블록 | 손잡이 행정상 **슬라이딩 후 고정** 스톱 | ≈1mm 팁 리프트에 해당하는 그립 각도에서 물리 정지. 과가압 차단 |
| 리미트 감지 | 마이크로스위치 / 홀센서 (선택) | `limit_engaged` 플래그를 메인 컴퓨터에 송신 → 복합 검증 |
| 온도 | MLX90614 (비접촉 IR) | 소문 접근 시 육아실 33~35°C 추정 |
| 음향 | INMP441 | 날갯짓 주파수 → 무왕군·분봉열 예측 |
| 전원 | 18650 1 셀 (~3,000mAh) + Type-C, 그립 매립 | 터치/진입 트리거 **스마트 웨이크업**으로 대기 방전 억제 |

### 2.2 지렛대·로드셀 배치 (소형화)

측정 대상 홈에 팁을 끼운 뒤, 피벗을 지점으로 그립을 손으로 누르면 팁에 상향 하중이 걸린다.
로드셀은 팁이 아니라 **피벗 기준 뒤쪽 (손잡이 쪽)** 에 두어, 센서가 받는 힘을 줄이고 용량·부피를 축소한다.

```json
  [대상 홈]          [피벗]              [손 가압]
      │                │                    │
   팁 F_tip ───────────┼─────────── 로드셀 F_lc ── 그립
      ←──── L_tip ────→←──── L_lc ────→
```

- `L_tip`: 피벗 → 팁 (하중점) 거리
- `L_lc`: 피벗 → 로드셀 거리 (`L_lc` > `L_tip` 이 되도록 후방 배치)
- **지렛대 배율** `k = L_lc / L_tip` (> 1)
  → 같은 팁 하중일 때 로드셀 하중은 `1/k` 로 줄어 소용량 셀 사용 가능.

### 2.3 손잡이 슬라이딩 리미트 블록

그립 행정에 **슬라이드→고정** 가능한 물리 스톱 블록을 둔다. 목표 리프트 (≈1mm) 에 해당하는 그립 각도에 블록을 맞춰 잠그면, 그 이상 손이 누르지 못한다.

```json
  [그립 가압 방향]
       │
  그립 ─┬─► 슬라이딩 블록 ──(잠금)──► 스톱면(프레임)
       │         ▲
       │    위치 조절 후 클램프/핀 고정
       │
  행정 끝 = 팁 ≈1mm 리프트 (교정으로 맞춤)
```

| 기능 | 효과 |
| :--- | :--- |
| 과가압 차단 | 리미트 이후 추가 변위·충격 하중이 로드셀·홈에 전달되지 않음 |
| 행정 재현 | 매번 같은 끝점에서 정지 → 손 가압 “깊이” 편차의 기구적 상한 |
| 복합 검증 | 지붕 `Δθ_target` 과 `limit_engaged` 가 **동시에** 맞을 때만 측정을 Valid 로 채택 |
| 현장 튜닝 | 홈·차체마다 1mm 대응 각도가 다르면 블록을 슬라이드해 재고정 |

### 2.4 내구성·유지관리

- **프로폴리스/밀랍 오염**: 팁·내시경 끝 나사산 교체형 강화유리 보호 캡 (Window Protect Cap).
- **방수**: IP67 목표. 로드셀은 실란트·커버로 습기·염분 차단.
- **렌즈 자가 청소 (연동)**: Closed-loop 공압 배기 라인의 미세 에어 블로우를 내검 시 렌즈단에 선택 연결 (별도 문서: 공압 Closed-loop 시스템 융합).
- **홈·피벗 부식 방지**: 측정 대상 측은 외부 돌출 나사산 없이 `1/2″`(≈12.8mm) 급 사각 타공 홈만 노출. 스틱 피벗·로드셀 시트는 스테인리스 또는 방청 코팅.

## 3. 하중 계측 및 환산

### 3.1 기본 환산식

모멘트 평형 (`F_tip · L_tip = F_lc · L_lc`) 에서:

```json
F_tip = F_lc × (L_lc / L_tip) = F_lc × k
```

| 기호 | 의미 |
| :--- | :--- |
| `F_lc` | 로드셀이 읽은 힘 (N 또는 kgf) |
| `F_tip` | 홈에 작용하는 실제 측정 하중 |
| `k` | 지렛대 배율 `L_lc / L_tip` (펌웨어 상수, 캘리브레이션으로 확정) |

중량 표기:

```json
m_tip = F_tip / g    (또는 kgf 단위면 m_tip ≈ F_tip)
```

**설계 예**: `L_tip = 40mm`, `L_lc = 160mm` → `k = 4`.
팁 40kgf 를 잴 때 로드셀은 약 10kgf 만 부담 → 소형·저용량 셀로 커버.

### 3.2 측정 절차 (수동 가압 + 자이로 래치 + 리미트)

1. 팁을 대상 **홈에 완전 삽입** (내시경으로 QR·안착 확인).
2. 리미트 블록이 **교정된 위치에서 잠금**되어 있는지 확인.
3. 메인 컴퓨터가 지붕 IMU 를 **θ₀**로 태어링.
4. 그립을 **천천히 손 가압** → 팁 ≈1mm 리프트 방향.
5. 스틱은 `F_lc`·`limit_engaged` 를 **연속 스트림** 송신 (미확정).
6. 그립이 리미트 블록에 **물리 접촉·정지** (`limit_engaged = true`).
7. 허용 시간창 안에서 지붕 `|θ − θ₀| ≥ Δθ_target` → 메인 컴퓨터 **래치**.
8. **복합 검증 통과** 시에만 기준값 확정: `F_tip = F_lc_latched × k`.
9. 확정값만 DB·스티커·앱 출력. 리미트 이후 추가 가압은 기구적으로 불가.

### 3.3 지붕 자이로 래치 — 손 가압량 오차 보정

손으로 지렛대를 “얼마나 눌렀는지”가 매번 달라지면, 임의 시점의 `F_lc` 는 비교 불가하다.
지붕 IMU 는 **구조물이 실제로 동일하게 들린 기하 상태**를 공통 기준으로 제공한다.

| 항목 | 내용 |
| :--- | :--- |
| 센서 위치 | 차량 **지붕** 고정 |
| 감지 목표 | 하부 약 **1mm** 리프트 → 미소 `Δθ` |
| 게이트 조건 | `Δθ = Δθ_target` (θ₀ 대비) |
| 확정 주체 | **메인 컴퓨터** — 조건 충족 시 스틱 샘플 포착 |
| 보정 효과 | 동일 변위 조건의 하중만 채택 |

### 3.4 복합 검증 (자이로 × 리미트 블록)

전자 게이트와 기구 스톱을 묶어 **이중 기준**으로 Valid 판정한다.

```json
가압 시작 ──► F_lc 스트림 (미확정)
                │
        ┌───────┴───────┐
        ▼               ▼
  Δθ → Δθ_target?   리미트 블록 접촉?
        │               │
        └───────┬───────┘
                ▼
         둘 다 Yes? ──No──► Reject / 재측정 안내
                │ Yes
                ▼
     메인 PC 래치: F_lc → F_tip 기준값 (Valid)
```

| 판정 | 조건 | 의미 |
| :--- | :--- | :--- |
| **Valid** | `Δθ_target` ∧ `limit_engaged` | 구조 들림과 손잡이 행정이 동시에 목표 도달 |
| **Reject-A** | 리미트만 ON, Δθ 미달 | 블록 과소·홈 슬립·연약 지반 → 리미트 재슬라이드 |
| **Reject-B** | Δθ만 도달, 리미트 미접촉 | 블록이 너무 뒤쪽 → 행정 재고정 |
| **Reject-C** | 둘 다 미달/타임아웃 | 가압 부족 또는 세션 오류 |

**운용 주의**
- `Δθ_target` 과 리미트 위치는 다이얼게이지 1mm 기준으로 **한 세트**로 교정.
- 측정 세션 ON 구간·짧은 시간창·리프트 축 필터로 바람·서스펜션 노이즈 분리.
- 고정형 모듈만 측정 시 모듈 상단 IMU 로 지붕 IMU 대체 가능.

### 3.5 캘리브레이션·오차 관리

- **제로**: 비가압 `F_lc` 오프셋 + `θ₀` 태어링.
- **스팬**: 기지 중량으로 `k`·HX711 확정.
- **Δθ_target + 리미트 위치**: 1mm 리프트에 맞춰 동시 고정.
- **피벗 마찰**: 필요 시 `F_tip = α · F_lc × k + β`.
- **과부하 보호**: 리미트 기구 1 차 차단 + `F_lc`/Δθ 상한 알림.

### 3.6 양봉카 아우트리거 (별도 축)

차량 장박용 오토 레벨링·공압 파워어시스트는 검진 스틱과 **분리된 구동축**이다. 지붕 IMU 는 장박 수평 제어와 **측정 래치**에 겸용할 수 있다.

1. **공압 선개방** — 드롭 레그 핀 고정 후 실린더 4 개 가압 (6bar ≈118kgf/기둥). `Tr14x2` 오버슈트 차단.
2. **모터 동기화** — `NEMA 11 + 50:1`. 공압이 속도 댐퍼.
3. **10% 선제 차단** — 자이로 + TMC `SG_RESULT` 10~15% 에서 밸브 차단.
4. **장박 모드** — 모터 전류 0, `Tr14x2` 셀프 락킹.

아우트리거 하중 검증도 **동일 스틱 + Δθ × 리미트 복합 검증**으로 수행한다.

| 기능           | 동작                                                             |
| :----------- | :------------------------------------------------------------- |
| QVGA 초고속 ID  | 320×240 흑백 + `quirc` 로 ≈0.1 초 QR 인식                              |
| 정형 촬영        | 홈 안착 시 거리·각도·LED 고정 → 벌 밀도·봉판·해충 분석에 유리                        |
| 하이브리드 패킷     | `[F_tip @ (Δθ_latch ∧ limit) + 온도 + 음향 Hz + 이미지]` 메타데이터로 DB 저장 |
| 수동 내검 아카이브   | 소비를 꺼내 스틱으로 찍어도 ID 와 타임라인 매핑                                    |
| 잼 예방 자가진단    | 홈 내부 이미지로 프로폴리스·이물질 축적 감지                                      |
| 기계적 인터록      | 팁 완전 삽입 + 측정 세션 ON + **리미트 프리셋 잠금** 시에만 래치 허용                  |
| 소문 심층 내검 (선택) | 소문 삽입 시 스마트폰 거치 화면으로 실시간 암실 스트리밍                               |

**교차 활용**: 소문 시스템의 CO₂·온도·전쟁상태 신호, 소초광 관리기 무게 추이와 결합하면 채밀 타이밍·분봉·도봉 예측 신뢰도를 높일 수 있다.

## 5. 현장 자동화 시퀀스

```json
[1] 팁 홈 삽입 → QR 스캔 → 리미트 블록 잠금 확인 → 측정 세션 ON
        ↓
[2] 메인 컴퓨터: 지붕 IMU θ₀ 태어링 / "○번 수집 모드" 통지
        ↓
[3] 그립 손 가압 → F_lc·limit 스트림 (미확정)
        ↓
[4] 리미트 블록 물리 정지(limit_engaged) ∧ Δθ_target 도달
        ↓
[5] 복합 검증 Valid → F_lc 래치 → F_tip = F_lc × k 확정
        ├─► PostgreSQL INSERT + 소초광 연동
        └─► 58mm 스티커 출력 → 벌통 뚜껑 부착
```

**오프라인 우선**: 서버 단절 시에도 메인 컴퓨터 로컬에 래치값·프린터 출력·큐 적재 후, 복구 시 일괄 동기화.

## 7. 데이터·앱 연동 요약

- **앱**: Vue.js — `F_lc`/`F_tip`/`k`/`Δθ`/`limit_engaged`·Valid·Reject 코드 표시.
- **DB**: PostgreSQL — (`F_lc`, `k`, `F_tip`, `θ₀`, `Δθ_latch`, `limit_engaged`, 판정코드, 시각).
- **AI**: 비전 + 물리 메타 → 채밀·분봉·무왕 판정.
- **프린터**: ESC/POS — 개체 ID, 시각, `F_tip`, Valid 마크, QR.
