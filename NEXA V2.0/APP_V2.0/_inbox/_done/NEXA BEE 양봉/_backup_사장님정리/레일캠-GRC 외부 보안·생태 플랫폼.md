# 가드 레일캠 (GRC) — 외부 보안·생태 센싱 플랫폼 참고서

벌통·양봉차 **외부 전면**을 담당하는 **가드 레일캠(GRC)** 플랫폼 참고서다.

헤드의 **다채널 이펙터·센서**로  
**현장 보안 + 소문 전면 생태 음향 감시 + 현장 기상 파악**을 다룬다.  
**말벌 고출력 레이저(M140) 운용·`FIRE_OK`·인터록은 본 문서에 두지 않는다** → 전략서로 이관.

**피에조는 필수 탑재**(TX/RX 양방향).  
**비전 + 기상 깃발(+윈드삭) + 피에조**로 **실시간 현장 기상**을 추정하고,  
캠 헤드 **자이로/IMU**로 흔들림·충격을 읽어 조준 게이트·기상·보안과 연동한다.

말벌 **레이저 요격 원본** →  
[`레일캠-허니왜건 말벌 레이저 요격 전략.md`](<레일캠-허니왜건 말벌 레이저 요격 전략.md>)

주파수·생태 신호 원표 →  
[`꿀벌의 사운드 및 진동 신호 매핑 테이블.md`](<꿀벌의 사운드 및 진동 신호 매핑 테이블.md>)

## 1. 시스템 개요 — 외부 보안·생태 센싱 헤드

| 항목   | 내용                                                                |
| :----- | :------------------------------------------------------------------ |
| 명칭   | 가드 레일캠 / GRC                                                   |
| 1차    | 전방 **보안·감시·경고**                                             |
| 2차    | 소문 근접 **말벌 억제**(레이저 상세는 전략서)                       |
| 3차    | 소문 전면 **피에조 생태·위협 음향 센싱**                            |
| 4차    | **비전·깃발·피에조 퓨전 현장 기상**                                 |
| 5차    | **헤드 자이로/IMU** — 흔들림·충격·자세                              |
| 비임무 | 벌통 **내부** 공조·세력·약제 (기상·흔들림 추정값은 내부에 **제공**) |

### 다채널 이펙터·센서 (헤드 내장 · 필수 포함)

| 채널                         | 역할                                                          | 위험도(상대) |
| :--------------------------- | :------------------------------------------------------------ | :----------- |
| **카메라(+순찰 스틸)**       | 시각 인지·기록·**기상(하늘·깃발·시정)** ·원격 판정            | 낮음         |
| **기상 깃발 / 윈드삭**       | 차체·부지 **고정 배치**, 비전으로 풍향·풍속 대용 추정         | — (패시브)   |
| **LED 조명**                 | 야간·역광, 순찰·깃발 시인성                                   | 낮음         |
| **LED 위협**                 | 점멸·지향 경고                                                | 낮음~중      |
| **ARM 적색 LED**             | 레이저 마스터 SW ON 시 점멸 — **배선·시인만** (정책은 전략서) | 시인         |
| **사이렌**                   | 청각 경고·퇴치·알림                                           | 중           |
| **520nm 라인 레이저**        | 지면 **가상 경계선** (보안용, 고출력 타격 아님)               | 중           |
| **피에조 (필수)**            | **TX:** 초음파·생태 모사 / **RX:** 벌·위협·**기상** 센싱      | 중           |
| **자이로 / IMU (필수 권장)** | 헤드 **각속도·가속도** — 흔들림·충격·자세·settle              | 낮음         |
| **445nm M140 2W**            | **말벌 단펄스 전용 슬롯** — 운용·게이트는 **전략서 §0**       | **고**       |

**원칙:** 위협↑ → 이펙터 단계↑. **고출력 블루는 전략서 `FIRE_OK`만.**  
피에조는 보안·바이오 **상시 인프라**로, **센싱과 발신을 시분할**한다.

### 플랫폼 제어 철학

1. **순찰:** 스틸 + 조명 LED + **피에조 RX** + **IMU 샘플**.
2. **분류:** 사람 / 꿀벌 / 말벌 / 조수 / 미확인 / **기상** / **흔들림·충격**.
3. **에스컬레이션** 또는 **기상·안정성 연동 정책** 후 이송·짐벌.
4. **`D_work`** 설치 고정.
5. **말벌 레이저** — 전략서 `FIRE_OK`. 사람·아군·과도 흔들림·비지향 시 금지.

## 3. 보안 에스컬레이션

```text
[순찰: 스틸 + 피에조 RX + IMU]
    │
    ▼
분류: Clear | 미확인 | 조수 | 말벌 | 사람·사람유사·침입 | (생태 알람)
    │
    ├─ Clear ──► Sleep/대기 · 조명 LED · 피에조 RX
    │
    ├─ 생태 알람 ──► 알림 · (선택) 유도 TX  · M140 금지
    │
    ├─ 미확인 ──► 조명↑ + 위협 LED · 재스틸 · M140 금지
    │
    ├─ 조수 ──► 위협 LED + 사이렌 + 피에조 초음파  · M140 금지
    │
    ├─ 말벌 ──► 전략서 FIRE_OK ?
    │              (유도 TX)→ keepout → OK면 M140 단펄스
    │            : 아니면 Lockout / 소문면 재조준
    │
    └─ 사람·사람유사·침입 ──► M140 즉시 Lockout
                              → LED + 사이렌 + 520nm 라인 → 알림
```

| 단계   | 이름       | 이펙터                    | M140     |
| :----- | :--------- | :------------------------ | :------- |
| S0     | 순찰       | 스틸, 조명 LED, 피에조 RX | 금지     |
| S1     | 주의       | 위협 LED                  | 금지     |
| S2     | 경고       | 사이렌 + 피에조 TX        | 금지     |
| S3     | 경계       | 520nm 라인                | **금지** |
| **S4** | **말벌만** | → **전략서 `FIRE_OK`**    | 전략서   |

| 모드               | 경로                               |
| :----------------- | :--------------------------------- |
| 보안·침입·사람유사 | S0→S1→S2→S3 (**레이저 경로 없음**) |
| 유해조수           | S0→S1→S2 (**레이저 경로 없음**)    |
| 말벌               | S0→S4 (전략서)                     |
| 생태 감시          | S0 RX · 알람 (레이저 없음)         |

**구 S4b(조수용 450nm PWM)는 폐기.** 상세는 전략서.

## 4. 이펙터·센서 상세

### 4.1 LED — 조명 / 위협

| 구분     | 용도                                                     |
| :------- | :------------------------------------------------------- |
| 조명 LED | 야간 노출·기록 품질. 벌 유인 최소화(지향·디밍)           |
| 위협 LED | S1+ 존재 과시·퇴치                                       |
| ARM 적색 | 마스터 SW ON 점멸 — **전략서 §0.4.2** (본 문서는 배선만) |

광학·드라이버 **분리**. ARM은 위협/조명과 **채널 공유 금지**.

### 4.2 사이렌

침입·조수·수동. 민가·심야 프로파일. 말벌 단펄스와 **기본 비동시**.

### 4.3 520nm 라인 레이저

지면 가상 경계. 사람·침입 주력. M140 Lockout 후 보안 경계용.

### 4.4 445nm M140 — 슬롯만 (운용은 전략서)

| 항목     | 본 문서                                                                                           |
| :------- | :------------------------------------------------------------------------------------------------ |
| 모듈     | 니치아 M140 445nm 2W (헤드 슬롯)                                                                  |
| 용도     | **말벌 단펄스 전용**                                                                              |
| **원본** | [`레일캠-허니왜건 말벌 레이저 요격 전략.md`](<레일캠-허니왜건 말벌 레이저 요격 전략.md>) **§0** |

방열·펄스·물리 SW·`FIRE_OK`·소문 지향은 **전략서에만** 기술한다.

### 4.5 피에조 — 필수 · 양방향 (핵심)

하드웨어 설계도에 **필수 포함**. 디스크/어레이를 헤드(또는 소문 전면 지향 마운트)에 두고,

| 모드          | 동작                                   | 용도                                             |
| :------------ | :------------------------------------- | :----------------------------------------------- |
| **RX (센싱)** | 음향·진동 → ADC/호스트 스펙트럼·이벤트 | 소문 전면 **벌 생태** + **위협(말벌 비행음 등)** |
| **TX (발신)** | PWM/드라이브를 통한 진동·초음파        | 조수 퇴치, 벌 **유도·대피·진정** 모사            |

**시분할:** `piezo_sense_ms` 동안 RX → 필요 시 `piezo_emit_*` TX → 잔향 대기 → 다시 RX.  
TX 중 RX 데이터는 폐기하거나 게이트 OFF.

장착 팁: 가능하면 **구조물(착륙판·가드·프레임)과 고체 전달**이 되게 본딩. 벌은 공기음보다 **기질 진동**에 민감한 경우가 많다.  
상세 주파수표는 [`꿀벌의 사운드 및 진동 신호 매핑 테이블.md`](<꿀벌의 사운드 및 진동 신호 매핑 테이블.md>).

## 5. 피에조로 외부에서 파악 가능한 벌 생태

레일캠은 **소문·전면 외부**에 있다. 내부 소초광에 붙인 피에조와 **관측 범위가 다르다.**  
아래는 **외부 헤드에서 현실적으로 노릴 수 있는 신호**와 **한계**다.

### 5.1 외부(소문 전면)에서 잘 잡히는 편

| 생태·상태                                    | 대략 대역 (참고)                | 해석·활용                                                        |
| :------------------------------------------- | :------------------------------ | :--------------------------------------------------------------- |
| **일반 비행·선풍(환기) 활동**                | ~190–260 Hz                     | 소문 활력·출입 밀도. 과다/과소 활동 알람                         |
| **외역 피크·혼잡**                           | 활동 버즈 + 충돌성 펄스         | 출입 폭주, 소문 병목. 시차 소문·공조와 연동 힌트                 |
| **훕/범프 (Whoop)**                          | ~300–600 Hz 단펄스              | 충격·급접근·통로 충돌 → **돌발 스트레스**                        |
| **정지 신호 (Stop)**                         | ~300–400 Hz, 0.1–0.2 s          | 포식·위험 경고가 소문 앞으로 전파될 때. **말벌 경계와 교차검증** |
| **일벌 파이핑·분봉 전조** (외부로 새는 경우) | ~100–550 Hz, 고조 시 500 Hz↑    | 분봉열·동요. 내부 센서와 **교차 확인** 권장                      |
| **무왕·거친 웅웅** (입구로 유출 시)          | ~300–400 Hz 거친 변조           | 무왕 의심 → 내부 검진·하중·비전과 융합                           |
| **말벌·포식자 비행음**                       | 예: 장수말벌 ~100–150 Hz (참고) | **보안+바이오**. 레이저 Engage 전 음향 트리거                    |

### 5.2 외부에서는 제한적 · 내부 피에조가 유리

| 생태·상태                    | 이유                      | 레일캠 역할                             |
| :--------------------------- | :------------------------ | :-------------------------------------- |
| **여왕 튜팅 / 콰킹**         | 왕대·소초 고체 전달 중심  | 약신호면 참고만. **내부 센서 우선**     |
| **꼬리춤(Waggle) 기하 진동** | 소초 위 12–15 Hz 등 내부  | 외부는 날개 맥동(~250–300 Hz) 힌트 정도 |
| **봉군 전체 미세 활력**      | SNR·바람·레일 기구 노이즈 | 장기 추세는 내부+외부 **퓨전**          |

### 5.3 센싱 → 시스템 행동 (활용)

| 감지 태그                | GRC·상위 반응 예                                       |
| :----------------------- | :----------------------------------------------------- |
| 활동 과다/과소           | UI·디지털 트윈, 소문·공조 힌트                         |
| Stop / Whoop + 비전 말벌 | **각성**, 말벌 모드, (선택) 대피 TX 후 레이저          |
| 분봉 전조 의심           | 알림, 내부 파이핑 센서와 교차, 분봉 억제 시나리오      |
| 무왕 의심                | 검진 스틱·내부 음향 우선 점검 트리거                   |
| 말벌 비행음              | S0→말벌/조수 경로, 순찰 주기 일시 단축                 |
| 기구·바람 노이즈         | HPF/대역 제한 (예: 관심 150–600 Hz + 초음파 밴드 분리) |

### 5.4 피에조 TX — 발신으로 쓰는 생태·보안 모사

| 목적                    | 모사 예 (참고 Hz)            | 반응 기대                            |
| :---------------------- | :--------------------------- | :----------------------------------- |
| **조수 퇴치**           | 20–35 kHz 초음파 스윕/펄스   | 조수 청각 자극 (S2)                  |
| **야간·위험 대피 유도** | 말벌 비행음 모사 ~100–150 Hz | 소문 앞 벌을 안쪽으로                |
| **출항 억제**           | Stop 유사 단펄스 ~320–550 Hz | 외역 이륙 일시 억제 (도어·레이저 전) |
| **안정·유인**           | Healthy hum ~190–250 Hz      | 안착·귀가 유도 (과사용 주의)         |
| **방제 전 클리어**      | 고주파 경고 파이프 ~2–4 kHz  | 소문 주변 대피 후 레이저/작업        |

단일 톤 고정은 **습관화**되므로 스윕·펄스 권장.  
상세 패턴은 매핑 테이블 문서의 **모사 음파** 절을 따른다.

### 5.5 내부 피에조와의 역할 분담

|      | 레일캠 피에조 (외부)             | 하이브/오리가미 바닥 피에조 (내부) |
| :--- | :------------------------------- | :--------------------------------- |
| 위치 | 소문 전면·헤드                   | 소초·바닥·착륙 구조                |
| 강점 | 출입·위협·말벌음·외부 스트레스   | 여왕음·분봉·무왕·춤 진동           |
| 융합 | 동일 타임라인에 태그 병합 → NEXA | 동일                               |

## 6. 실시간 현장 기상 — 비전 · 깃발 · 피에조 퓨전

기상청 API만으로는 **차체 바로 앞 소문 미기후**(국지 돌풍·빗줄기·역광)를 놓치기 쉽다.  
GRC는 **이미 있는 비전·피에조**에 **기상 깃발(또는 윈드삭)을 시야에 배치**해, 순찰 루프에서 **현장 기상을 실시간 추정**한다.

### 6.1 배치

| 요소                    | 배치                                                                  | 역할                                         |
| :---------------------- | :-------------------------------------------------------------------- | :------------------------------------------- |
| **기상 깃발 / 윈드삭**  | 차체·가드·폴대 등 **카메라 시야 안 고정점** (가능하면 2점: 직교 방향) | 풍향·풍속 **시각 대용 센서**                 |
| **레퍼런스 마커(선택)** | 깃발 근처 고정 색·길이 스케일                                         | 픽셀→각도·처짐량 환산                        |
| **비전(헤드 카메라)**   | 순찰 스틸에 **하늘 ROI + 깃발 ROI + 소문면**                          | 운량·강수·시정·조도·깃발 기하                |
| **피에조 RX**           | 헤드 필수                                                             | 우적 타격음, 풍진(구조 진동), 천둥·돌풍 펄스 |
| **조명 LED**            | 야간 깃발 시인                                                        | 기상 ROI 노출 확보 (위협 패턴과 분리)        |

깃발은 **이펙터가 아니라 패시브 타깃**이다. 유지보수는 엉킴·퇴색·결빙 점검.

### 6.2 비전으로 읽는 기상

| 관측              | 방법 (요지)                               | 산출 예                                      |
| :---------------- | :---------------------------------------- | :------------------------------------------- |
| **풍향**          | 깃발/윈드삭 기울기 방위각 (차체 좌표계)   | `wind_dir_deg`                               |
| **풍속(대용)**    | 처짐각·펄럭임 주파수·진폭 (캘리브 테이블) | `wind_speed_class` (calm/breeze/strong/gale) |
| **돌풍**          | 짧은 시간 처짐·펄럭임 급증                | `gust_flag`                                  |
| **운량·맑음**     | 하늘 ROI 밝기·색·텍스처                   | `sky_class`                                  |
| **강수·눈**       | 스트릭/노이즈·소문면 젖음·반사            | `precip_class` (none/rain/snow/unknown)      |
| **시정·안개**     | 원거리 대비·깃발 윤곽 선명도              | `visibility_class`                           |
| **조도·역광**     | 노출·히스토그램, 태양 방위 대략           | `illum_class` → LED·레이저 정책              |
| **결로·성에(창)** | 렌즈/창 헤이즈 (장비 상태이기도 함)       | 퍼지·파킹 트리거                             |

풍속은 절대 m/s보다 **등급 + 현장 캘리브**가 우선이다. 정밀 풍속이 필요하면 별도 풍속계를 붙이되, GRC 기본은 **깃발 비전**.

### 6.3 피에조가 기상에서 협력하는 방법

비전만으로는 **미세 이슬비·야간 강수·돌풍 시작**이 늦을 수 있다. 피에조 RX가 보완한다.

| 기상 현상            | 피에조 단서 (요지)                                      | 비전·깃발과 융합                        |
| :------------------- | :------------------------------------------------------ | :-------------------------------------- |
| **강수(비·우박)**    | 하우징·깃발 폴·가드에 떨어지는 **불규칙 충격 스펙트럼** | 비전 스트릭과 AND/OR → `precip` 신뢰도↑ |
| **바람·돌풍**        | 구조 **저주파 진동·공력 잡음** 증가 (벌 대역과 분리)    | 깃발 처짐과 동시 ↑ → `gust` 확정        |
| **천둥·원거리 폭풍** | 저주파 충격·럼블                                        | 하늘 어두움과 결합 → 조기 경계          |
| **우박 vs 비**       | 충격 에너지·펄스 밀도 차이 (휴리스틱)                   | 비전 입자 크기와 교차                   |
| **건조 강풍**        | 진동↑ · 우적 패턴 없음                                  | 깃발만 크게 움직임 → 강수 아님          |

**대역 분리 (권장)**

- **벌 생태:** 관심 ~150–600 Hz (기존 §5).
- **기상·구조:** 더 낮은 풍진·우적 광대역, 천둥 저역 — `piezo_weather_band`로 **별도 특징** 추출.
- 벌 Stop/Whoop과 우적 펄스를 혼동하지 않도록 **주기성·지속시간·비전 동시성**으로 게이트.

**TX와의 관계:** 기상 판정용 RX 구간에는 피에조 TX(초음파·유도)를 끈다. 조수 퇴치 TX 직후에는 잔향 대기 후 기상 RX.

### 6.4 퓨전 상태머신 (요지)

```text
[순찰 스틸]
  ├─ 깃발 ROI → 풍향/풍속등급/돌풍
  ├─ 하늘·소문면 ROI → 운량/강수/시정/조도
  └─ 피에조 RX → 우적/풍진/천둥 특징
         │
         ▼
  weather_fuse() → weather_state
         │
         ├─ OK ──► 정상 순찰·말벌·보안 정책
         ├─ WIND_HIGH / GUST ──► 레이저 보류·헤드 파킹 검토·소문 방풍
         ├─ RAIN / STORM ──► 450nm·라인 제한, 퍼지 주기↑, 내부 공조·소문 시나리오
         └─ LOW_VIS / NIGHT ──► 조명 LED, 순찰 노출·신뢰도 가중치 조정
```

외부 기상 API가 있으면 **보조**로만 쓰고, **현장 fuse 결과가 소문 직전 미기후에 우선**한다.

### 6.5 기상 → 운용 연동

| `weather_state` | GRC                                              | 양봉카/내부 (연동 예)           |
| :-------------- | :----------------------------------------------- | :------------------------------ |
| 강풍·돌풍       | 이송 가속 제한, 말벌 레이저 **보류/ABORT**, 파킹 | 업라이트·방풍·소문 슬릿         |
| 강수·폭풍       | 고출력·라인 사용 제한, 창 퍼지, 순찰만           | 소문·단열 시나리오, Closed-loop |
| 저시정·안개     | 조명 LED, 검출 임계 완화/강화 정책               | 출항 지연 힌트                  |
| 고온·강광       | 노출·열 부하, 주간 말벌 순찰 가중                | 공조                            |
| 평온            | 정상 Engage·보안 에스컬레이션                    | 정상                            |

벌 생태 해석 시: 강풍·우천이면 **비행 버즈 감소는 기상 효과**일 수 있으므로, 무왕·분봉 알람 전에 **weather_state를 공변량**으로 넣는다.

### 6.6 설정 키 (기상)

| 키 개념                    | 의미                              |
| :------------------------- | :-------------------------------- |
| `flag_roi[]` / `sky_roi`   | 깃발·하늘 픽셀 영역 (설치 캘리브) |
| `flag_calib`               | 처짐각↔풍속 등급 테이블           |
| `weather_fuse_w_*`         | 비전 vs 피에조 가중               |
| `piezo_weather_band`       | 기상용 스펙트럼 밴드              |
| `wind_laser_lockout_class` | 이 등급 이상이면 450nm 금지       |
| `weather_publish_hz`       | 내부/NEXA로 기상 상태 발행 주기   |

강풍 판정 시 **깃발 비전 + 피에조 풍진 + 헤드 자이로 RMS**를 같이 보면 오탐이 줄어든다 (§7).

## 7. 캠 헤드 자이로 / IMU — 흔들림과 응용

헤드(카메라·짐벌 블록)에 **자이로(+가속도) IMU**를 둔다.  
차체 지붕 IMU(검진 스틱 래치 등)와 **별개**로, **레일캠 로컬 동역학**을 읽는다.

### 7.1 측정량

| 신호                  | 용도                                |
| :-------------------- | :---------------------------------- |
| 각속도 ω (자이로)     | 흔들림·펄럭임·짐벌 잔진동           |
| 가속도 a              | 충격·충돌·이송 가감속·기울기 추정   |
| 자세(추정)            | 라인 레이저 지면 각도, 도킹 기울기  |
| RMS / 피크 / 스펙트럼 | 등급화 (`shake_class`), 이벤트 검출 |

### 7.2 응용 방법

| 응용                       | 방법 (요지)                                                              | 연동                       |
| :------------------------- | :----------------------------------------------------------------------- | :------------------------- |
| **레이저·조준 게이트**     | `\|\omega\|`, `\|a\|`가 `imu_fire_ok_*` 미만일 때만 450nm·정밀 서보 허용 | settle 완료와 **AND**      |
| **스틸 품질**              | 촬영 직전·직중 흔들림 크면 프레임 **폐기·재촬영**                        | 순찰·기상 ROI 신뢰도       |
| **짐벌 안정화**            | 각속도 피드포워드/댐핑, 바람 외란 억제                                   | 이미지 서보와 병행         |
| **이송 settle 판정**       | 이동 명령 후 ω·a가 임계 이하로 N ms 유지 → settle                        | 와이어/레일 장력 진동 포함 |
| **강풍·돌풍 퓨전**         | 헤드 흔들림 ↑ + 깃발 처짐 ↑ + 피에조 풍진 ↑ → `GUST`/`WIND_HIGH`         | §6 기상                    |
| **우천·우박 보조**         | 단발 충격 a 피크와 피에조 우적 동시 → 강수 신뢰도↑                       | 비전 스트릭과 3중 확인     |
| **충돌·파손·침입**         | 급가속 피크(타격·차량 접촉) → 보안 알람, 450nm Lockout, 로그             | 사이렌·LED·원격 알림       |
| **레일/와이어 이상**       | 주행 중 이상 고주파 진동·주기 떨림 → 정비 알람                           | 장력·베어링·이물           |
| **외팔보·공진 감시**       | 특정 대역 공진 지속 시 속도·가속도 제한                                  | S-커브·vmax 자동 완화      |
| **슬립/웨이크**            | 충격·지속 흔들림으로 Light Sleep 웨이크                                  | `patrol` 외 이벤트 각성    |
| **라인 레이저 지향**       | 자세로 지면 투영 각도 보정                                               | 침입 경계 모드             |
| **도킹·파킹**              | 홈 접근 시 기울기·잔진동으로 안착 판정                                   | 충전 접점·퍼지 타이밍      |
| **차체 vs 국소 외란 분리** | (선택) 차체 IMU와 차동 → “차량 흔들림” vs “헤드만 바람”                  | 오보 감소                  |
| **생태 해석 보정**         | 강흔들림 구간 피에조 벌 신호는 **저신뢰** 처리                           | 무왕/분봉 오탐 방지        |

### 7.3 레이저 게이트와의 관계

IMU는 **`imu_settle_ok`** 를 전략서 `FIRE_OK`에 제공한다.  
발사 AND 조건·소문 지향·물리 SW는 **전략서 §0** — 본 문서는 흔들림 샘플·임계만 정의.

흔들림 중 발사 금지(IMU). 사람유사·비지향 시 금지(전략서).

### 7.4 피에조·깃발과의 역할

| 센서       | 잘 보는 것           | 자이로와의 협력                                 |
| :--------- | :------------------- | :---------------------------------------------- |
| 깃발 비전  | 풍향·평균 바람(시각) | 자이로는 **헤드가 실제로 얼마나 흔들리는지**    |
| 피에조     | 우적·공기/구조 음향  | 자이로는 **강체 운동**, 음향과 분리해 원인 추정 |
| 자이로/IMU | 헤드 각운동·충격     | 레이저·짐벌·settle의 **직접 게이트**            |

예: 깃발만 흔들리고 헤드 ω는 낮음 → 바람은 있으나 조준 가능.  
헤드 ω만 높고 깃발 약함 → 레일/와이어/충돌 쪽 점검.

### 7.5 설정 키 (IMU)

| 키 개념                | 의미                    |
| :--------------------- | :---------------------- |
| `imu_sample_hz`        | 샘플링                  |
| `imu_fire_ok_gyro_dps` | 발사 허용 각속도 상한   |
| `imu_fire_ok_acc_g`    | 발사 허용 가속도 상한   |
| `settle_hold_ms`       | 임계 이하 유지 시간     |
| `imu_gust_rms`         | 돌풍·강풍 등급용 RMS    |
| `imu_impact_g`         | 충돌 이벤트 임계        |
| `imu_discard_still`    | 스틸 폐기 흔들림 임계   |
| `imu_vs_vehicle`       | 차체 IMU 차동 사용 여부 |

## 9. 순찰 · 인지

## 11. 양봉카(내부) vs 레일캠(외부)

|             | 내부              | 레일캠                            |
| :---------- | :---------------- | :-------------------------------- |
| 보안        | 밀폐·농약 모드 등 | 침입·조수·말벌·**충격**           |
| 음향        | 내부 생태 정밀    | 소문 전면 생태+위협+기상          |
| 기상·동역학 | 연동 소비         | 미기후 + **헤드 흔들림** 발행     |
| 액션        | 소문·공조·약제    | LED·사이렌·라인·피에조·450nm·파킹 |

## 12. 컴퓨트·통신

헤드: ESP32 + 이펙터·피에조·**IMU**.  
원격: RPi — YOLO + 스펙트럼 + 기상 fuse + **imu_settle_ok**.  
`weather_state` / `shake_class` / impact 이벤트 → 내부·NEXA.
