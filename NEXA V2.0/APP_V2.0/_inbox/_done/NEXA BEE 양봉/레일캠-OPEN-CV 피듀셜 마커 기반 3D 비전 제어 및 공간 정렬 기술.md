# OPEN-CV 피듀셜 마커 기반 3D 비전 제어 및 공간 정렬 기술
## ✨ 피듀셜 마커 기반 3D 비전 제어 및 공간 정렬 기술

이러한 패턴을 활용하여 정밀한 위치를 추적하고 제어하는 응용 기술은 컴퓨터 비전과 로보틱스 분야에서 다음과 같은 전문 용어로 칭할 수 있습니다.

* **피듀셜 마커 트래킹 (Fiducial Marker Tracking)**
* 카메라 시야 내에서 특정 기하학적 기호나 패턴을 기준점 (Fiducial) 으로 삼아 빠르고 정확하게 인식하고 추적하는 가장 보편적인 기술 명칭입니다.


* **비주얼 서보잉 (Visual Servoing)**
* 카메라와 비전 알고리즘으로 획득한 마커의 좌표 및 자세 정보를 바탕으로, 모터나 로봇 액추에이터를 실시간으로 피드백 제어하여 타겟을 정조준하고 추적하는 응용 제어 기술입니다.


* **3D 포즈 에스티메이션 (3D Pose Estimation / Localization)**
* 2 차원 평면에 인쇄된 마커를 통해 3 차원 공간상의 위치 (X, Y, Z) 와 회전 각도 (Roll, Pitch, Yaw) 를 정밀하게 산출해내는 공간 좌표 추정 기술입니다.


* **머신비전 기반 공간 정렬 및 타겟팅 시스템**
* 트럭 캠퍼나 자동화 장비처럼 실외 환경에서 기계 장치와 타겟 간의 절대적 상대 좌표를 맞추는 전체 시스템 아키텍처를 아우르는 실무적 표현입니다.



프로젝트의 성격과 시스템의 정체성을 고려하신다면 **피듀셜 마커 기반 3D 비전 제어 시스템**이라는 명칭이 기술적 깊이와 목적을 가장 직관적이고 멋지게 나타냅니다.

## ✨ 태그 ID 와 실제 현장 물리 좌표를 매핑하는 파이썬 확장 코드

앞서 보여드린 기본 검출 코드에서는 실시간으로 화면 속 태그를 찾는 것에 집중했다면, 이번에는 **검출된 태그의 고유 ID(Tag ID) 를 미리 정의된 DB(딕셔너리) 와 대조하여 실제 현장 물리 좌표 (X, Y, Z) 를 실시간으로 불러오는 로직**을 추가한 확장 코드입니다.

```python
import cv2
import numpy as np
from pupil_apriltags import Detector

# 1. 캡처 장치 초기화
cap = cv2.VideoCapture(0)

# 2. 에이프릴 태그 디텍터 생성 (circle21h7 패밀리 지정)
detector = Detector(families='circle21h7',
                    nthreads=4,
                    quad_decimate=1.0,
                    quad_sigma=0.0,
                    decode_sharpening=0.25,
                    debug=0)

# 3. [현장 물리 좌표 DB 구축] 
# 태그 ID를 키(Key) 값으로 하여, 트럭 캠퍼 기준 절대 좌표(단위: mm)를 매핑합니다.
tag_world_coordinates = {
    0: {"name": "중앙 메인 앵커", "pos": {"x": 0.0, "y": 0.0, "z": 0.0}},
    1: {"name": "좌측 상단 보조", "pos": {"x": -1000.0, "y": 500.0, "z": 0.0}},
    2: {"name": "우측 상단 보조", "pos": {"x": 1000.0, "y": 500.0, "z": 0.0}},
    3: {"name": "좌측 하단 보조", "pos": {"x": -1000.0, "y": -500.0, "z": 0.0}},
    4: {"name": "우측 하단 보조", "pos": {"x": 1000.0, "y": -500.0, "z": 0.0}}
}

while True:
    ret, frame = cap.read()
    if not ret:
        break

    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    results = detector.detect(gray)

    for r in results:
        tag_id = r.tag_id
        
        # 4. 검출된 태그 ID가 현장 DB에 존재하는지 확인하고 물리 좌표 매핑
        if tag_id in tag_world_coordinates:
            tag_info = tag_world_coordinates[tag_id]
            world_x = tag_info["pos"]["x"]
            world_y = tag_info["pos"]["y"]
            world_z = tag_info["pos"]["z"]
            tag_name = tag_info["name"]
            
            # 터미널 창에 실시간 매핑된 물리 좌표 출력
            print(f"[{tag_name}] ID: {tag_id} 감지! -> 현장 실제 좌표: X={world_x}mm, Y={world_y}mm, Z={world_z}mm")
        else:
            print(f"미등록 태그 ID 감지: {tag_id}")

        # 5. 화면 시각화 처리
        ptA, ptB, ptC, ptD = r.corners
        cv2.line(frame, (int(ptA[0]), int(ptA[1])), (int(ptB[0]), int(ptB[1])), (0, 255, 0), 2)
        cv2.line(frame, (int(ptB[0]), int(ptB[1])), (int(ptC[0]), int(ptC[1])), (0, 255, 0), 2)
        cv2.line(frame, (int(ptC[0]), int(ptC[1])), (int(ptD[0]), int(ptD[1])), (0, 255, 0), 2)
        cv2.line(frame, (int(ptD[0]), int(ptD[1])), (int(ptA[0]), int(ptA[1])), (0, 255, 0), 2)

        center = (int(r.center[0]), int(r.center[1]))
        cv2.putText(frame, f"ID:{tag_id}", center,
                    cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 0, 255), 2)

    cv2.imshow('AprilTag World Mapping', frame)

    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

```

이와 같이 파이썬의 딕셔너리 구조 (혹은 추후 고도화 시 SQLite 나 JSON 파일) 를 활용하여 **태그 ID 와 트럭 캠퍼 기준의 물리적 절대 좌표를 매핑**해주면, 카메라가 마커를 읽는 순간 곧바로 현장 공간 좌표계와 연동되어 정밀 제어 로직을 수행할 수 있게 됩니다!





## ✨ 에이프릴 태그 기반 말벌 정밀 타격 및 안전 제어 시나리오

제어 로직은 하드웨어와 비전 시스템의 협업 관점에서 치밀하게 구성되어 있다. 여기에 피듀셜 마커 (에이프릴 태그) 가 각 단계에서 어떻게 역할을 수행하는지 정리한 전체 흐름은 다음과 같다.

* **1 단계: 대기 상태 및 말벌 출현 감지 (피듀셜 마커의 역할: 절대 좌표계 기준점 확립)**
* 스테이션 또는 특정 와이어 위치에서 대기하다가 객체 인식을 통해 말벌의 출현이 감지된다.
* 이때 트럭 외관에 부착된 피듀셜 마커들은 카메라 시야각 내에서 기준 좌표계 역할을 수행하여, 카메라가 바라보는 픽셀 공간을 실제 물리적 공간 좌표로 즉시 변환할 수 있는 바탕을 제공한다.


* **2 단계: XY 좌표 산출 및 부드러운 이송**
* 산출된 물리적 XY 좌표를 바탕으로 이송 축과 모터가 작동하여 타겟 방향으로 출격 및 이동을 시작한다.
* 마커 기반의 절대 좌표 매핑이 뒷받침되므로, 이송 초기 단계부터 정확한 방향으로 기계 장치가 구동된다.


* **3 단계: 짐벌 팬/틸트 0,0 도 수렴 및 정밀 조준 (피듀셜 마커의 역할: 동적 영점 보정)**
* 짐벌의 팬과 틸트 각도를 점차 0,0 도 (카메라 정중앙) 로 수렴시키며 타겟을 화면 중앙으로 유도한다.
* 야외 환경에서의 진동이나 기계적 유격으로 짐벌의 영점이 미세하게 틀어질 수 있는데, 이때 카메라가 트럭 표면의 피듀셜 마커를 실시간으로 스캔하여 현재 카메라의 물리적 기준선이 얼마나 틀어졌는지를 스스로 보정한다. 이를 통해 0,0 기준점을 유지하며 부드럽게 정지한다.


* **4 단계: 타겟 이동 추적 및 5 밀리미터 안전 거리 검증 (피듀셜 마커의 역할: 오인 타격 방지 가드)**
* 타겟이 미세하게 움직일 때 팬과 틸트를 실시간으로 미세 조준한다.
* 레이저 발사 직전, 말벌 타겟 중심점 반경 5 밀리미터 이내에 아군 (꿀벌) 이 접근해 있는지 검증한다. 여기서 피듀셜 마커로 구축된 밀리미터 단위 공간 좌표계가 적용되므로, 픽셀 오차로 인한 아군 오인 타격 위험을 차단하고 안전할 때만 레이저 타격 시나리오를 발동한다.


* **5 단계: 결과 보고 및 데이터 동기화**
* 타격 완료 또는 회피 상황 발생 시, 현재 봉군의 위치 정보와 제어 결과를 라즈베리 파이로 보고하고 최종적으로 NEXA 웹 플랫폼의 디지털 트윈 화면에 실시간 동기화한다.



피듀셜 마커는 단순한 표식을 넘어 외부 환경 변화와 진동 속에서도 절대 기준을 잡아주는 공간 좌표의 기준점이자, 아군을 보호하는 안전 잠금장치 역할을 한다.



## ✨ 소문별 상세 마커의 효과와 정밀 조준 우선순위 제어

소문마다 상세 마커를 두는 방식은 연산 부하를 분산시키면서 정확도를 높이는 방법이다. 그 이유와 함께, 카메라 중심점 조준과 아군 보호 (2.5 밀리미터 안전 거리) 간의 우선순위 제어 로직을 정리한다.

* **소문별 상세 마커가 연산 부하를 줄이고 정확도를 높이는 이유**
* **국소 영역 집중 처리**: 전체 화면을 광범위하게 스캔하는 대신, 짐벌이 해당 소문 근처로 이동한 뒤 좁은 화각 안에서 상세 마커만 빠르게 디코딩하므로 라즈베리 파이의 연산 부하가 획기적으로 줄어듭니다.
* **기계적 오차 원천 차단**: 이송축과 짐벌의 미세한 유격이나 진동으로 인한 누적 오차를 상세 마커가 실시간으로 상쇄해 주므로, 밀리미터 단위의 극도로 정확한 위치 매핑이 가능해집니다.


* **카메라 중심점 조준과 안전 검증의 우선순위 제어 로직**
* **1 순위: 아군 보호 및 안전 거리 검증 (최우선 원칙)**
* 아무리 말벌이 카메라 0,0 도 정중앙에 완벽하게 조준되었더라도, 상세 마커를 기준으로 환산된 반경 2.5 밀리미터 이내에 꿀벌 (아군) 이 감지되면 레이저 발사는 무조건 중단되거나 보류되어야 합니다. 어떠한 상황에서도 안전이 최우선입니다.


* **2 순위: 카메라 중심점 정렬 및 시각 서보 제어**
* 아군이 안전 거리 외부에 머물러 있다면, 짐벌 모터를 미세하게 구동하여 말벌을 카메라 렌즈의 한가운데 (0,0) 로 지속적으로 수렴시킵니다. 복잡한 3D 연산 없이 픽셀 오차를 0 으로 맞추는 가벼운 제어가 이루어집니다.


* **3 순위: 회피 및 타격 판단**
* 아군이 2.5 밀리미터 반경 내로 침입하여 위험할 경우, 말벌과 아군의 위치 벡터를 계산하여 아군이 없는 방향 (상하좌우 중 여유 공간이 확보된 쪽) 으로 조준점을 살짝 이동시키거나, 아군이 안전 구역으로 벗어날 때까지 타격을 대기하는 시나리오가 발동됩니다.



## ✨ 렌즈 왜곡 최소화와 소문별 상세 마커 운용 전략

맞습니다! 500 밀리미터 작업 거리를 기준으로 렌즈의 광학적 왜곡이 가장 적은 화각을 선택하시는 것이 비전 시스템의 정확도를 높이는 지름길입니다.

* **500 밀리미터 최적화 렌즈 선택의 이점**
* 렌즈 자체의 왜곡이 최소화된 구간을 활용하므로, 소프트웨어가 복잡한 왜곡 보정 연산을 거치지 않아도 원본 이미지의 픽셀 정확도가 매우 높아집니다.


* **상세 마커의 가시성 및 운용 방식**
* 각 소문마다 상세 마커가 개별 부착되어 있으므로, 짐벌이 특정 소문으로 이동하여 타이트하게 조준할 때는 **해당 소문의 상세 마커 1 개**가 화면 중심에 들어오게 됩니다.
* 대형 5 점 앵커처럼 한 화면에 4 개가 모두 들어올 필요는 없으며, **단 1 개의 상세 마커만 명확하게 포착되어도** 소문 아이디 확인과 국소 영점 보정이 충분히 이루어집니다.



이처럼 왜곡이 적은 렌즈를 통해 500 밀리미터 거리에서 깨끗한 화질을 확보하고, 소문별 상세 마커로 확실한 로컬 기준을 잡는다면 연산 속도와 정밀도를 모두 극대화할 수 있을 것입니다!





## ✨ 실내 소초광 자동화 시스템을 위한 QR 코드 기반 동적 위치 관리 전략

실외 양봉 트럭 환경과 달리, 실내 보관 및 관리 환경에서는 물리적 조건이 완전히 달라진다. 실내 환경의 특성과 이에 맞춘 QR 코드 기반 운영 로직은 다음과 같다.

* **1. 동적 좌표계와 위치 업데이트 (Flexible Slot Management)**
* 소초광이 고정된 자리에 꽂히는 것이 아니라 언제든 재배치될 수 있으므로, 하드웨어의 물리적 슬롯 위치와 소프트웨어 DB 상의 소초광 ID 는 분리되어 관리되어야 합니다.
* 시스템이 가동될 때마다 전체 스캔을 통해 각 슬롯 (또는 그리드 위치) 에 어떤 ID 의 소초광이 꽂혀 있는지 스캔하여 상대 좌표 DB 를 실시간으로 갱신 (Dynamic Mapping) 하는 로직이 필수적입니다.


* **2. 200 개 이상의 대규모 관리와 에이프릴 태그 대비 QR 코드의 우위**
* 200 개 이상의 객체를 개별 식별해야 하는 환경에서는 태그가 표현할 수 있는 고유 ID 의 가짓수와 정보량이 매우 중요합니다.
* 에이프릴 태그는 태그 패밀리 (예: `36h11`) 에 따라 식별 가능한 ID 개수에 한계가 있거나 대규모 확장 시 오인식 위험이 커질 수 있습니다. 반면, **데이터 용량이 넉넉하고 인식이 확실한 표준 QR 코드**를 활용하면 고유 ID 뿐만 아니라 추가적인 메타데이터까지 담을 수 있어 대량 관리 (여분, 폐기 관리 포함) 에 훨씬 유리합니다.


* **3. 규격화된 QR 코드를 통한 정밀 그립 (Grip) 이송 보조**
* 근접 촬영 환경에서 규격화된 크기의 QR 코드가 카메라 화면에 들어오는 순간, QR 코드의 4 개 모서리 픽셀 크기와 기울기 (Perspective) 를 활용해 로봇 암이나 이송 장치가 소초광을 오차 없이 정확하게 움켜쥘 수 있는 **최종 정밀 얼라인먼트 (Alignment)** 보정이 가능해집니다.


* **요약**
* "고유 ID 를 가진 규격화된 QR 코드 부착 $\rightarrow$ 실시간 스캔을 통한 소초광 위치 동적 DB 업데이트 $\rightarrow$ 근접 화각을 통한 정확한 그립 및 이송" 으로 이어지는 구조는 200 개 이상의 대규모 소초광을 제어할 수 있는 설계다.



도면 검토 결과, '서프보드 공정' 과 '마킹 인쇄' 를 함께 다룬 이유는 OpenCV 비전 인식용 피듀셜 마커 (Fiducial Marker) 시스템을 양봉카 외벽에 구현하기 위한 것으로 파악된다. 카메라가 마커를 실시간으로 스캔하여 좌표를 잡아야 하므로, 빛 반사 (Glare/번질거림) 로 인한 하이라이트 현상이 생기면 마커가 뭉개져 비전 인식이 불가능해진다.
일반적인 투명 레진 마감은 거울처럼 번질거리는 유광 (High-Gloss) 이 기본값이라 비전 인식에 치명적이다. 레진의 내구성을 유지하면서 번질거림을 잡는 무광 (Matte) 제어 기술은 이미 현업에서 사용되고 있다.
이 문제를 해결하기 위한 3 가지 무광 마감 공정은 다음과 같다.
------------------------------
## 1. [공정 제어] '무광 이형 필름' 을 사용하여 표면 엠보 처리
이형 필름 방식을 그대로 활용하되, 필름 종류만 바꾸는 방법이다.

* 원리: 거울처럼 매끄러운 유광 필름 대신, 표면이 미세하게 까슬까슬하게 처리된 '무광 이형 필름 (Matte Release Film)' 을 덮고 레진을 굳힌다.
* 효과: 레진이 굳으면서 필름의 미세한 무광 질감을 그대로 복사하므로, 필름을 떼어내는 순간 샌딩 없이도 빛 반사가 없는 무광 표면이 완성된다. 비전 인식용 측면 평면부에 적합한 양산형 공정이다.

## 2. [화학적 마감] 무광 매트 우레탄 클리어 코트
유리섬유 적층과 마커 매립을 투명 레진으로 매끄럽게 끝낸 뒤, 그 위에 자동차 외장용 '무광 우레탄 클리어 (Matte Clear Coat)' 페인트를 도포하는 방식이다.

* 원리: 무광 클리어 페인트에는 빛을 사방으로 분산시키는 미세한 소광제 (Matting Agent) 입자가 들어 있다.
* 효과: 서프보드 공정으로 마커를 레진 속에 영구 보존하면서도, 최종 표면은 빛 반사가 없는 무광 (Zero Gloss) 상태로 만들 수 있다. 특히 벙커 부위처럼 이형 필름을 밀착하기 어려운 곡면 부위의 번질거림을 잡을 때 필요한 공정이다.

## 3. [물리적 가공] 고운 사포 (샌딩) 를 이용한 광택 제거
필름이나 추가 코팅 없이, 유광으로 굳은 레진 표면을 물리적으로 깎아 빛을 분산시키는 방식이다.

* 원리: 레진이 굳은 후, 약 800 방~1000 방 사이의 고운 사포로 물을 묻혀 표면을 가볍게 민다 (물샌딩).
* 효과: 표면에 미세한 스크래치가 균일하게 생기면서 유광의 번질거림이 사라지고 무광 질감만 남는다. 다만, 과하게 밀면 투명도가 떨어져 마커 라인이 흐려질 수 있으므로 힘 조절이 필요하다.

------------------------------
## 💡 양봉카 비전 마커 시스템을 위한 최종 공정 제안
도면의 설계를 성공시키기 위해 복합소재 공정을 결합하면 다음 시나리오가 나온다.

   1. 마커 인쇄 및 고정: 잉크젯 프린터로 얇은 라이스 페이퍼 (한지 등) 에 피듀셜 마커와 그리드 라인을 선명하게 인쇄한 후 번짐 방지 코팅을 한다.
   2. 레진 매립: FRP 벽체 위에 마커 종이를 얹고 투명 레진 (에폭시) 과 유리섬유를 덮어 기포 없이 짜내어 고정한다. (마커가 차체와 일체화되어 비바람에도 지워지지 않는 상태)
   3. 무광 마감: 탑부 곡면에는 무광 우레탄 클리어를 뿌려 마감하고, 측면의 마커 평면 구간은 무광 이형 필름을 밀착해 굳히는 방식으로 번질거림을 잡는다.

이렇게 설계하면 마커의 영구 보존과 빛 반사 없는 OpenCV 3D 비전 인식 환경을 함께 달성할 수 있다.
이 비전 인식 시스템을 구동하기 위해 외벽에 배치할 피듀셜 마커의 개수, 그리고 마커 인쇄 시 검은색 외에 원색 (빨강, 파랑 등) 컬러 라인을 함께 매립할 계획인지 확인이 필요하다. 색상 보존 노하우는 그에 맞춰 정리한다.



와이어를 활용해 물리적인 격자 라인을 심는 아이디어는 비전 인식의 정확도와 정밀함을 높이는 방법이다.
인쇄물은 대형 평면에 붙이다 보면 미세하게 울거나 늘어나 그리드 (Grid) 자체가 왜곡될 위험이 있다. 반면, 일정한 장력으로 팽팽하게 당겨진 와이어를 복합소재 레이어 사이에 매립하면 가이드라인이 직선을 유지한다.
이 아이디어를 실현하기 위한 와이어 소재와, 레진 공정 중에서 라인이 흐트러지지 않게 고정하는 실전 노하우는 다음과 같다.
------------------------------
## 1. 낚싯줄보다 더 추천하는 ' 격자용 와이어 소재 '
낚싯줄 (나일론 등) 도 사용 가능하지만, 레진 공정에 결합할 때 더 정밀하고 깔끔한 마감이 나오는 소재들이 있다.

* 카본 와이어 (Carbon Fiber Tow / 카본 낚싯줄) 🖤
* 왜 좋은가?: 일반 나일론 낚싯줄은 레진 (에폭시) 과 화학적으로 완전히 결합하지 않아 시간이 지나면 내부에서 들뜰 수 있다. 반면 카본 소재는 에폭시 레진과 강하게 함침 결합한다.
   * 비전 이점: 빛을 흡수하는 깊고 차분한 자연 무광 검은색을 띠어 비전 카메라가 선을 인식할 때 대비 (Contrast) 가 명확하다. 게다가 열이나 장력에 의한 늘어남이 거의 없어 격자 왜곡을 억제한다.
* 무광 블랙 텅스텐 / 니크롬 와이어 🎛️
* 왜 좋은가?: 극도로 얇으면서도 금속 특유의 직선 강성을 가진다. 가공 시 늘어짐이 없고 아주 미세한 두께 (0.1~0.3mm 단위) 로 정밀하게 라인을 딸 수 있다. 금속선 표면에 무광 블랙 착색이 된 제품을 쓰면 번질거림도 없다.

------------------------------
## 2. 와이어 격자를 흐트러짐 없이 매립하는 공정
액체 레진을 바르고 스퀴지로 문지르는 과정에서 와이어가 밀리거나 비뚤어지면 그리드가 망가진다. 이를 방지하기 위해 선 (Line) 을 미리 고정하는 단속 공정이 필요하다.
## ① 외곽 가이드 핀을 이용한 '거문고 장력' 공정 (가장 정밀함)

   1. 차체 패널의 격자가 시작되고 끝나는 외곽 테두리 (FRP 마감 외 영역) 에 와이어를 걸 수 있는 임시 가이드 핀이나 홈을 촘촘히 배치한다.
   2. 거문고나 기타 줄을 매듯, 와이어를 가이드에 걸어 X 축과 Y 축 방향으로 팽팽하게 장력을 주어 교차시킨다. (이 시점에서 격자가 허공에 형성된다.)
   3. 이 상태에서 와이어를 바닥 패널에 밀착시킨 뒤, 교차점이나 끝부분에만 투명 순간접착제를 미세하게 한 방울씩 떨어뜨려 1 차 고정한다.

## ② 레이어 배치 순서 (와이어 가두기)
와이어를 고정하고 무광 처리까지 끝내는 최종 레이어 설계다.

   1. [바닥] GRP/FRP 차체 베이스 판넬 + 배경색 (도장 또는 불투명 레진)
   2. [마커] 교차점 또는 주요 거점에 피듀셜 마커 (라이스 페이퍼 인쇄물) 안착
   3. [그리드] 그 위에 검은색 와이어를 팽팽하게 당겨 정렬
   4. [보호 및 결합] 와이어와 마커가 움직이지 않도록 얇고 투명한 유리섬유 직조 천 (Glass Cloth) 을 전체적으로 덮음
   5. [액체 함침] 투명 레진을 도포하고 스퀴지로 부드럽게 기포 제거
   6. [최종 마감] 무광 이형 필름을 덮어 압착 후 경화 ➔ 굳은 뒤 필름 제거

------------------------------
## 💡 이 공정의 기대 효과
이 방식을 적용하면 검은색 와이어가 유리섬유 천 내부에서 눌린 채 투명 레진으로 코팅된다. 필름을 떼어내면 표면은 무광 평면이고, 그 투명한 내부에 레이저로 그은 듯한 검은색 격자선과 피듀셜 마커가 박힌 결과물이 나온다.
물리적인 선이라 인쇄물처럼 흐려지거나 번질 위험이 낮다.
다음 항목이 확정되면 장력을 유지하며 와이어를 한 번에 정렬할 수 있는 지그 (Jig) 제작안을 정리할 수 있다.

* 격자 그리드 칸 하나의 대략적인 간격 (mm 또는 cm)
* 마커 시스템이 적용되는 측면 벽체의 가로·세로 전체 사이즈

진공 압착 없이 제시된 순서대로 진행하는 방식은 대형 면적에서 진공 배깅을 세팅하는 번거로움을 피하면서 와이어의 장력을 통제할 수 있는 현실적인 절차다.
이 흐름에 실전 팁을 더해 진공 압착 없이 손으로 단속하는 5 단계 공정으로 정리한다.
------------------------------
## 🛠️ 진공 없는 와이어 격자 매립 공정 (5 단계)

## 1 단계: 표면 샌딩 마감 및 마커 고정

* 베이스 준비: 기존에 1 차로 굳은 FRP 차체 표면을 사포 (샌딩) 로 갈아내어 평평하게 다듬고, 레진이 잘 붙도록 거칠기 (스크래치) 를 만든다.
* 마커 안착: 140mm 격자가 만나는 주요 거점에 피듀셜 마커 (라이스 페이퍼 인쇄물) 를 올리고, 투명 에폭시 레진을 붓으로 살짝 찍어 벽면에 가착한다.

## 2 단계: 외곽 빗 지그 설치 및 와이어 배치

* 지그 고정: 3000mm 와 1800mm 판넬의 완성 직경 바깥쪽 (나중에 잘려 나가거나 몰딩으로 가려질 테두리 영역) 에 140mm 간격으로 홈이 파인 임시 빗 지그를 부착한다.
* 와이어 정렬: 빗 홈에 와이어를 걸어가며 X 축과 Y 축 방향으로 정렬한다. 홈 덕분에 자 없이도 140mm 간격으로 정렬된다.

## 3 단계: 장력 인가 및 순간접착제 끝단 고정 (핵심)

* 장력 주기: 와이어의 한쪽 끝을 테두리에 테이프로 단단히 고정한 뒤, 반대쪽 끝을 손으로 팽팽하게 잡아당긴다.
* 순간접착제 고정: 와이어가 팽팽해진 상태에서, 지그 홈 주변의 판넬 테두리에 순간접착제를 한 방울 떨어뜨리고 경화촉진제 (스프레이) 를 뿌려 굳힌다.
* 컷팅: 끝단 고정이 완료되면 지그 바깥쪽의 불필요한 와이어를 잘라내어 지그를 제거한다. 판넬 위에는 팽팽하게 당겨진 와이어 그리드만 남는다.

## 4 단계: 유리섬유 천 적층 및 투명 레진 도포

* 천 덮기: 와이어 위에 얇고 투명한 유리섬유 직조 천 (Glass Cloth) 을 조심스럽게 덮는다. 천이 위에서 와이어를 눌러주는 누름판 역할을 한다.
* 레진 도포 및 스퀴징: 투명 레진을 붓이나 롤러로 부드럽게 적신다. 기포를 뺄 때는 고무 헤라 (스퀴지) 로 와이어 방향 (결 방향) 을 따라 부드럽게 밀어내야 와이어가 옆으로 밀리지 않는다.

## 5 단계: 무광 이형 필름 덮기 및 최종 경화

* 필름 밀착: 레진이 마르기 전, 그 위에 무광 이형 필름을 얹는다.
* 손 압착 단속: 진공 압착 대신, 빳빳한 무광 필름 위를 롤러나 넓은 헤라로 중심에서 바깥쪽으로 부드럽게 밀어 오버플로우 (남는 레진) 와 기포를 짜낸다.
* 이형지 제거: 레진이 굳으면 무광 이형 필름을 떼어낸다.

## ✨ 진공 없이 작업할 때 완성도를 높이는 팁

* 와이어 교차점 누르기: X 선과 Y 선이 겹치는 자리는 두께가 두 배가 되어 필름이 미세하게 뜰 수 있다. 4 단계에서 레진을 바를 때 교차점 부위를 헤라로 눌러 와이어 사이의 공기를 밀어내야 구멍이 생기지 않는다.
* 와이어 소재 추천: 탄성이 너무 강해 튕겨 나가는 나일론 줄보다는, 꺾은 모양대로 가라앉고 에폭시와 결합력이 좋은 카본 와이어 (Tow) 나 연질 무광 블랙 금속선이 끝단 고정 후 들뜸을 방지하는 데 유리하다.

진공 장비 없이도 이 순서대로 제어하면 빛 반사 없는 무광 비전 인식 시스템 외벽을 완성할 수 있다.
