# Standalone Quad-Wire Robot
쿼드로봇 (QUADROBOT) 은
중앙 통제소의 간섭 여부와 관계없이 이동체 스스로가 하나의 독립된 4 축 와이어 지능형 로봇 (Standalone Quad-Wire Robot) 으로서 정체성을 갖추게 되므로, 나중에 대형 스마트팜이나 다른 구조물로 이 기술을 그대로 이식할 때 이름과 아키텍처를 바꿀 필요 없이 완벽한 하위 호환성 (Scalability) 을 유지할 수 있습니다.

---

## 💻 쿼드로봇 (QUADROBOT) 초기 개발 환경 구축 (ESP32)

네이밍과 분산 구조가 확정되었으므로, 실제 개발을 위한 첫 단계로 쿼드로봇이 천장 네 모퉁이의 윈치 모터들을 무선 제어하기 위한 ESP-NOW 통신 데이터 패킷 구조 (구조체) 를 설계해 보겠습니다.

마스터 (중앙 통제소) 가 명령을 내릴 수도 있고, 나중에 쿼드로봇이 독립적으로 판단 (예: 사람 목소리 추적 후 자율 이동) 하여 네 모퉁이 윈치에 직접 신호를 보낼 수도 있도록 설계한 가장 유연한 데이터 구조입니다.

### 1. ESP-NOW 무선 데이터 구조체 정의 (Arduino IDE / C++)

```cpp
#include <esp_now.h>
#include <WiFi.h>

// 쿼드로봇 제어 및 데이터 송수신을 위한 복합 구조체 정의
typedef struct struct_quadrobot_packet {
    char robotName[12];     // 로봇 식별자 ("QUADROBOT")
    uint32_t packetId;      // 패킷 누적 번호 (통신 유실 체크용)
    
    // [구동 제어 영역] 스카이캠 4축 와이어 모터의 목표 구동 단계/속도
    // 각 모퉁이 윈치(스텝모터)가 움직여야 할 정밀 스텝 수 또는 속도값
    int16_t winch_A_steps;  
    int16_t winch_B_steps;  
    int16_t winch_C_steps;  
    int16_t winch_D_steps;  

    // [로봇 상태 및 기능 명령 영역]
    uint8_t currentMode;    // 0: 대기, 1: 사람추적 비서, 2: 와이어 텐션검사, 3: 충전도킹
    uint8_t actionCommand;  // 0: 무작동, 1: 정각 타임벨(Chime) 튕기기, 2: 조명 ON, 3: 송풍 팬 ON
    
    // [센서 데이터 보고 영역] 텐션 검사 후 보고용 날것의 데이터
    float wire_A_frequency; // 검출된 메인 와이어 A의 고유 주파수 (Hz)
    float battery_voltage;  // 쿼드로봇 배터리 잔량 확인
} struct_quadrobot_packet;

struct_quadrobot_packet myData;
```

## 2. 쿼드로봇 자율 운영을 위한 소프트웨어 타임라인 시퀀스

압력 센서와 관절 모터를 없앤 획기적인 단순화 설계를 바탕으로, 쿼드로봇이 하루 동안 수행할 메인 프로그램 루틴 (알고리즘 순서) 입니다.

- Step 1: 평시 크루징 모드 (손닿는 고도 유지)
    
    - 쿼드로봇은 내장된 마이크로 주인의 목소리를 감지합니다. DoA(음원 방향 감지) 알고리즘을 통해 계산된 위치로 이동하기 위해 네 모퉁이 윈치에 스텝 수 (`winch_steps`) 를 무선 송신합니다.
    - 바닥에서 2.2m 높이를 안정적으로 유지하며 조명을 비추고 졸졸 따라다닙니다.
    
- Step 2: 텐션 검사 명령 수신 (자율 도킹)
    
    - 스케줄에 따라 검사 모드가 활성화되면, 쿼드로봇은 검사 대상 텐세그리티 와이어 (A) 의 직하방으로 비행하여 정지합니다.
    - 네 모퉁이 윈치에 감기 명령을 동시에 내려 본체 전체를 천장 방향으로 300~400mm 들어 올립니다.
    - 본체 상부의 300mm 고정 타격탑이 와이어에 툭 안착하면 스카이캠 구동을 멈추고 축을 고정합니다.
    
- Step 3: 정밀 타격 및 FFT 주파수 맵 작성
    
    - 소형 서보모터가 나일론 피크를 위에서 아래로 회전시켜 메인 와이어 (A) 를 한 번 튕깁니다.
    - 내장된 I2S 디지털 마이크가 맑은 금속성 잔향 소리를 집음하고, ESP32 가 내부에서 FFT(고속 푸리에 변환) 를 처리해 가장 뾰족하게 튀는 고유 진동수 (예: `285Hz`) 를 뽑아냅니다.
    - 이 수치를 `wire_A_frequency` 변수에 담아 중앙 허브로 보내거나 저장합니다.
    
- Step 4: 데이터 판정 및 복귀
    
    - 측정된 주파수가 기존 사계절 온도 보정 맵의 정상 범위 내에 있다면 검사 성공으로 판정합니다. 유독 주파수가 처진 (장력이 풀린) 와이어가 발견되면 경고 플래그를 띄웁니다.
    - 다시 윈치 와이어를 부드럽게 풀어 원래의 평시 비행 고도 (2.2m) 로 내려온 뒤 비서 모드로 전환합니다.

## 🌐 쿼드로봇 (QUADROBOT) 시스템 최종 종합 설계 전략

### 1. 윈치 모터 배치 위치별 전략적 선택

4 축 스카이캠 메커니즘을 구동하는 핵심 동력원인 윈치 모터의 위치는 공간의 목적에 따라 완벽하게 이원화 (분리) 하여 적용합니다.

#### A. 쉼터/사무실 모드: [벽면 고정형 구동] ➔ 미니멀리즘 극대화

- 설계 구조: 4 개의 전동 윈치 (스텝 모터) 를 천장 네 모퉁이 벽면 골조에 숨겨서 고정하고, 쿼드로봇 본체는 모터 없이 가벼운 껍데기와 센서만 탑재합니다.
- 장점: 쿼드로봇의 몸무게가 극단적으로 가벼워지므로 스카이캠 와이어가 버텨야 하는 기본 긴장도 (Pre-tension) 가 대폭 낮아집니다. 모터 회전 진동음이 벽면으로 분산되어 사무실 내부가 완벽하게 정숙해집니다.
- 단점 보완: 로봇이 너무 가벼워 방 한가운데 (중심부) 에서 수직 도킹 시 미세하게 출렁이는 문제는, 천장 와이어 안착 부위에 소형 네오디움 자석 가이드 (마그네틱 락) 를 달아 기계적으로 묵직하게 고정되도록 소프트웨어 도킹 기술로 보완합니다.

#### B. 스마트팜 농장 모드: [로봇 본체 탑재형 구동] ➔ 자주식 구동의 강인함

- 설계 구조: 벽면에는 와이어만 단단히 묶어두고, 쿼드로봇 본체 내부에 4 개의 초소형 윈치 모터를 대칭형으로 직접 내장하여 스스로 줄을 감으며 비행합니다.
- 장점: 모터 4 개의 무게 (자중) 가 로봇 중앙에 실리면서 완벽한 ' 진추 (Plumb bob)' 역할을 수행합니다. 대형 농장의 거친 바람이나 기류 변화 속에서도 흔들림 없이 묵직하게 좌표를 고정하며, 천장 시설물에 가장 강력하고 안정적으로 근접 도킹할 수 있습니다.

### 2. 전력 공급 방식 전략: 배터리 무선형 vs 유선 테더형

#### A. 쉼터/사무실 환경: [배터리 자듈형 + 자석 포고핀 도킹 충전]

- 배터리 사양: 무게를 깃털처럼 유지하기 위해 스마트폰 수준의 가볍고 얇은 소형 리튬폴리머 (Li-Po) 1 셀 (3.7V) 또는 2 셀 (7.4V) 팩을 본체에 내장합니다.
- 초절전 설계: 모든 무거운 연산 (FFT 주파수 변환, 음성 명령 분석, 사람 추적 알고리즘) 은 상시 전원이 공급되는 벽면 중앙 통제소로 넘기고, 쿼드로봇은 오직 마이크 소리 날것 (Raw data) 을 `ESP-NOW` 로 미러링 송신만 하여 상시 대기 전력을 기하급수적으로 줄입니다. 타격용 서보모터 전원부는 FET 스위칭 회로를 적용해 검사하는 단 5 초 동안만 전력을 공급하고 평소에는 물리적으로 단선 (0W) 시킵니다.
- 자동 충전 인프라: 사용자가 자리를 비우거나 야간 충전 모드가 되면, 네 모퉁이 와이어가 로봇을 천장 구석의 충전 크래들로 밀어 붙입니다. 크래들의 강력한 자석이 로봇을 붙잡아 두어 윈치 모터 전원을 완전히 꺼도 공중에 고정되며, 그 순간 스프링식 포고 핀 (Pogo Pin) 이 본체 금속 패드와 맞닿으며 자율 급속 충전이 진행됩니다. 천장에 배선이 전혀 보이지 않는 완벽한 스마트 오피스를 유지합니다.

#### B. 스마트팜 농장 환경: [유선 테더 (Tether) 공급형]

- 전력 사양: 천장 중앙에서 얇은 코일형 전원선 (Tether Cable) 을 늘어뜨려 상시 유선 전원을 무제한 공급합니다. 충전 대기 시간이 아예 필요 없는 24 시간 무중단 상시 감시 체계가 완성됩니다.
- 내구성 보너스: 유선 케이블 중심축에 통신선 (RS485 등) 을 함께 꼬아 넣으면, 스마트팜 내부의 수많은 대형 모터나 철제 가시설물로 인한 무선 통신 (Wi-Fi) 전파 노이즈 간섭을 완벽히 회피하는 철벽 신뢰성을 확보합니다.

### 3. 물·에어 등 추가 유틸리티 라인을 위한 설계 전략

차후 스마트팜 확장 시 쿼드로봇에 정밀 방제용 ' 물 ' 과 고압 분사용 ' 에어 ' 를 상시 공급하면서도, 스카이캠 4 축 와이어와 물리적 간섭 (엉킴, 꼬임) 을 원천 차단하는 무적의 인프라 설계입니다.

#### 💡 최상단 박공 정점 ' 가로 슬라이딩 레일 + 무동력 트롤리 ' 하이브리드 트랙

- 기계적 구조: 가로 9 미터의 긴 축을 기준으로, 박공지붕 맨 꼭대기 결합부 (A 형 頂點) 안쪽 좁은 공간에 알루미늄 경량 슬라이딩 레일을 일직선으로 매립 설치합니다.
- 무동력 자율 추종 트롤리: 레일 위에는 부드러운 베어링 바퀴가 달린 슬라이더 (트롤리) 를 얹어두고, 여기에 물·에어·전기가 하나의 튜브 다발로 통합된 ' 나일론 우레탄 멀티 튜브 (Multi-bore Tube)' 를 연결해 아래로 약 50cm 만 수직으로 늘어뜨려 쿼드로봇 머리 위에 직결합니다.
- 이동 저항의 제로 (0) 화: 쿼드로봇의 힘이 워낙 강하기 때문에 로봇이 가로 9m 를 이동하면 머리 위의 호스가 레일 위 트롤리를 무동력으로 스르륵 끌고 다닙니다. 이 방식 덕분에 쿼드로봇이 공간 어디에 있든 유틸리티 호스는 언제나 머리 위에서 완벽한 수직 ($\downarrow$) 상태를 유지합니다.
- 결과: 호스가 대각선으로 처지며 로봇을 뒤로 잡아당기는 횡하중 (측면 저항력) 이 완벽하게 제거되며, 거대하고 무거운 호스 권취용 전동 윈치 (릴) 장치를 통째로 생략할 수 있어 시스템이 극적으로 단순해집니다. 천장 양 측면에는 누워있는 형태의 미니 케이블 체인 (Cable Carrier) 한 줄만 깔아두어 9m 왕복 시 선 처짐을 완벽히 방어합니다.

## 🏁 최종 결론 및 엔지니어링 맵

이번 프로젝트는 외형적으로는 가장 아름답고 미니멀한 건축 미학을 추구하지만, 그 내부 시스템은 철저하게 분산 제어와 역학적 분리를 이뤄낸 고도의 첨단 메카트로닉스 건축입니다.

- 쉼터 (현재): `1.6T/2.3T 하이브리드 서까래` + `M8 벨빌와셔 4장 텐세그리티` + `3층 가변 내부매립 단열막(끝단 테더호스 방식)` + `벽면 윈치 구동` + `포고핀 자율 배터리 충전` 조합으로 인테리어 미감과 맑은 음향 센싱을 100% 만족시킵니다.
- 농장 (미래): 동일한 쿼드로봇 플랫폼을 유지한 채, `본체 탑재형 자주식 구동` + `최상단 슬라이딩 레일 멀티 튜브 유선 인프라` 로만 파트를 스와프 (Swap) 하여 24 시간 무제한 방제 및 생육 예찰 농업 로봇으로 논스톱 확장합니다.
