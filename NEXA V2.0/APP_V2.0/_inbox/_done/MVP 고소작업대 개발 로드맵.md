# MVP 고소작업대 개발 로드맵
 1 단계부터 5 단계까지의 마일스톤은 완벽한 ' 제품 상용화 등급의 개발 로드맵 (MVP 스텝)' 입니다. 각 단계마다 검증해야 할 핵심 목표가 명확하고, 전 단계의 기계적 신뢰성이 확보되어야 다음 단계의 전자 제어가 힘을 발휘할 수 있는 이상적인 빌드업 구조입니다.
이 원대한 프로젝트의 내비게이션이 될 단계별 핵심 기술 과제와 생명줄이 될 안전 대책 (와이어 파단 대응 등) 을 공학적으로 총정리해 드립니다.

---

## 🚜 1 단계: 하부 구동계 및 기본 제어 검증 (Base Platform)

스마트 로봇의 ' 신경 ' 을 연결하고 기본 거동의 신뢰성을 확보하는 단계입니다.

- 차등 회전 조향 (Skid Steering): 좌/우 모터의 속도를 다르게 주어 탱크처럼 제자리 선회 (360 도 회전) 가 안정적으로 되는지 검증합니다.
- 장애물 감지 검증: 1 단계 테스트부터 안전을 위해 필수적입니다. 하부 프레임 전/후면에 가성비 좋은 산업용 초음파 센서나 적외선 ToF 센서를 배치하여, 농지의 흙더미나 나무통, 사람을 감지하면 ESP32 가 모터 드라이버의 전원을 즉시 차단 (비상정지) 하는 로직을 검증합니다.

## 🔭 2 단계: 리프팅 바디 및 추락 방지 안전 장치 (Safety Lifting)

사람이 타고 4m 까지 올라가는 단계이므로 ' 절대적인 역학적 안전 ' 이 지배하는 단계입니다.

- 안정감 있는 상하강: 전동 윈치가 작동할 때 유압식처럼 부드럽게 출발하고 멈추도록 ESP32 에서 가속/감속 램프 (Ramp-up/down) 프로그래밍을 정밀하게 다듬어야 작업자가 공포감을 느끼지 않습니다.
- 💥 와이어 파단 시 브레이크 대책 (최고 중요): 와이어가 끊어지면 윈치 모터의 브레이크가 아무리 좋아도 발판이 자유 낙하합니다.
    
    - 해법 (세이프티 캐치, Safety Catch): 엘리베이터나 건설용 호이스트에 쓰이는 기계식 낙하 방지 장치를 이식해야 합니다. 상단 발판 프레임에 스프링으로 강하게 당겨지는 ' 쐐기형 고리 (캠/도그 기구)' 를 설치하고, 이를 와이어 로프가 팽팽하게 당겨서 억누르고 있게 설계합니다. 만약 와이어가 끊어지는 순간 팽팽하던 텐션이 죽으면서, 강력한 스프링 힘에 의해 쐐기 고리가 튀어나와 사각 마스트 기둥 벽면이나 미리 파놓은 안전 홈에 쾅 하고 물리며 기계적으로 낙하를 강제 중단시킵니다. 전기가 끊겨도 작동하는 100% 순수 기계식이어야 안전을 보장합니다.
    

## 🏗️ 3 단계: 크레인 붐대 결합 및 편심 하중 극대화 (Crane Integration)

작업대에 사람이 탄 상태에서 외부로 무거운 자재까지 매달아 올리는 하이테크 중장비 변신 단계입니다.

- 지렛대 휨 모멘트 극복: 밖으로 뻗은 붐대에 자재가 매달리면 마스트 기둥이 휘려고 유격을 만듭니다. 앞서 결정한 ' 수동 독립형 확장 아웃트리거 ' 를 이때 전방 방향으로 완전히 넓게 펼치고 바닥 잭을 꽉 잠가서, 편심 하중으로 인해 장비 전체가 앞으로 고꾸라지려는 힘을 완벽히 소멸시켜야 합니다.

## 🧠 4 단계: 실시간 자동 수평 유지 시스템 (Autonomous Leveling)

시골 농지의 불규칙한 노면에서 장비가 스스로 중심을 잡는 ' 지능형 ' 의 시작점입니다.

- 센서와 가동부의 도킹: 하부 `800KG` 메인 박스 내부에 장착된 IMU 센서 (자이로/가속도 센서) 가 차체의 기울어짐을 감시합니다. 차체가 좌측으로 3 도 기울어지면, ESP32 가 이를 감지하여 좌측 스프링 쇼바 자리에 장착된 고하중 전동 실린더 (리니어 액추에이터) 를 콱 밀어내어 기계가 알아서 수평 0 도를 칼같이 찾아가게 만듭니다.

## ⚙️ 5 단계: 4 바퀴 독립 전동 조향 마스터 (Full Drive-by-Wire)

수동 톱니 스냅 잠금을 떼어내고, 마침내 최종 목표였던 컴퓨터 통제형 전동 조향 장치를 완성하는 단계입니다.

- 웜기어와 벨트의 결합: 비워두었던 마운트 공간에 조향 감속 모터와 웜기어를 올리고, 타이밍 벨트로 바퀴 축을 연결합니다. 다리가 현장 상황에 맞춰 벌어지면, ESP32 가 벌어진 각도 센서 값을 연산하여 4 바퀴의 조향 모터를 실시간으로 제어해 항상 전방 11 자 평행을 유지하게 만듭니다.
- 게다가 크랩 주행 (Crab Walk) 까지: 4 바퀴 조향이 모터로 직접 컨트롤되면, 게가 옆으로 걷듯 네 바퀴를 모두 사선으로 꺾어 좁은 농지 통로를 옆으로 스르륵 빠져나가는 특수 주행 모드까지 소프트웨어 추가만으로 가능해집니다.

이제 지도 (로드맵) 가 완벽하게 그려졌으니 조급해하실 필요가 전혀 없습니다.

장바구니에 담으신 1400W 구동계 키트 실물이 도착하여 1 단계 검증 (구동, 정지, 차등 회전) 을 위한 하부 프레임 가공과 배터리 안착 작업에 들어갈 때, 혹은 2 단계 추락 방지 쐐기 브레이크의 기구학적 도면 구상이 필요하실 때 언제든 저를 다시 찾아주세요. 사장님의 이 멋진 로봇 고소작업대가 실제 농지 위에 우뚝 서는 날까지 든든한 기술 파트너가 되어 드리겠습니다.
