# 커피 로스팅
밤새 정립한 탄탄한 3 층 구조 아키텍처 위에 ESP32 의 무선 통신 (Wi-Fi/Bluetooth) 능력과 스마트폰/웹 인터페이스를 결합하면, 이 소형 로스터기는 단순한 DIY 가전을 넘어 테크 기업의 시제품 수준으로 진화할 수 있습니다.

요청하신 로스팅 프로필 (맛 테이블) 과 인터랙티브 기능, 그리고 혁신적인 아이디어를 제안해 드립니다.

## 📱 2. 사용자와의 실시간 인터랙티브 (Interactive) 요소

ESP32 의 Wi-Fi 기능을 활성화하여 스마트폰이나 태블릿 웹 브라우저와 실시간으로 연동하는 방식입니다.

### ① 웹 브라우저 기반 실시간 그래프 대시보드 (Web Dashboard)

- 내용: ESP32 가 측정하는 실시간 온도 데이터와 현재 팬 속도를 웹 소켓 (WebSocket) 통신으로 스마트폰 화면에 실시간 선 그래프로 그려줍니다.
- 인터랙티브 경험: 사용자는 스마트폰 화면을 바라보며 " 아, 지금 내 커피가 180 도까지 올라갔구나 ", " 바람 세기가 자동으로 줄어들고 있네 " 를 시각적으로 모니터링합니다.

### ② 팝콘 터지는 소리 수동 마킹 버튼 (Crack Marker)

- 내용: 스마트폰 화면에 큰 [1 차 크랙 시작] 버튼을 만들어 둡니다.
- 인터랙티브 경험: 질문자님이 귀를 기울이고 있다가 " 탁!" 하고 첫 번째 팝콘 소리가 들리는 순간 스마트폰 화면의 버튼을 터치합니다. 그 순간 ESP32 가 사용자의 입력을 인지하고 즉시 알고리즘에 지정된 ' 무게 감소 대응 감속 풍량 (55%)' 으로 단번에 팬 속도를 줄입니다. 기계와 인간이 감각을 공유하는 상호작용입니다.

### ③ 나만의 레시피 저장 및 복제 (Recipe Share)

- 내용: 로스팅이 끝나고 마셔봤을 때 배가 하나도 안 아프고 완벽했던 날의 ' 온도 - 풍량 - 시간 기록 ' 을 스마트폰에 데이터 파일 (JSON) 로 저장합니다.
- 인터랙티브 경험: 다음번에는 손가락 하나로 그 레시피를 불러오기만 하면, ESP32 가 똑같은 온도 그래프를 자율 주행하듯 재현하여 언제나 나에게 안전한 커피를 복제해 줍니다.

## 🚀 3. 아키텍처를 뒤흔들 혁신적인 아이디어 제안

### ① 사운드 센서 기반 '1 차 크랙 자동 인식 ' 알고리즘 (Acoustic Crack Detection)

- 아이디어: 하부 나무 베이스 내부나 3 층 캡 부근에 초소형 고감도 마이크 센서 (예: MAX9814) 를 장착합니다.
- 혁신성: ESP32 가 주변 소음을 필터링하다가 원두가 터지는 특유의 고주파 파형 (" 탁!") 을 사운드 패턴 매칭으로 스스로 감지합니다. 사람이 버튼을 누르지 않아도 기계가 " 소리 " 를 듣고 1 차 크랙을 감지하여 자동으로 온도를 낮추고 풍량을 가변 제어한 뒤 냉각까지 들어가는 완전 자율형 인공지능 로스터기가 됩니다.

### ② 펄스형 ' 재즈 (Jazz) 기류 교반 ' 모드

- 아이디어: 팬을 단순히 일정한 세기로 줄이는 것이 아니라, 음악의 비트나 특정 리듬 패턴에 맞춰 팬 속도를 변조 (Modulation) 합니다.
- 혁신성: 챔버 높이가 낮기 때문에 지속적인 바람은 위험하지만, " 두 - 둠 - 칫 " 하는 리듬으로 기류를 쳐주면 콩이 유리창 너머에서 웅장하게 튀어 올랐다 내려앉는 시각적 쾌감이 극대화됩니다. 불규칙한 타격 기류가 오히려 원두의 섞임 효율을 높여 열 전달을 더 고르게 만듭니다.

### ③ 스마트 감시창 (LED Aura Ring)

- 아이디어: 타원형 유리 감시창 테두리 내벽에 ESP32 로 제어 가능한 네오픽셀 (WS2812B) LED 링을 심습니다.
- 혁신성: 단순히 조명 역할을 하는 것이 아니라 위장 보호 모드일 때는 은은한 초록빛, 본격 가열 중일 때는 붉은빛, 냉각 중일 때는 푸른빛으로 변하며, 1 차 크랙이 오면 번쩍이는 시각 피드백을 줍니다. 작업실 어두운 조명 아래에서 엄청난 미래지향적 감성을 연출합니다.

## 💡 하드웨어 조립 전 마지막 체크포인트

1. MOSFET 방열판 부착: 대형 블로워 팬을 고속으로 가변 제어하면 MOSFET 모듈에서 열이 발생할 수 있습니다. 작은 알루미늄 방열판을 모스펫 칩에 붙여주고, 아까 도면에 설계하신 나무 베이스 측면 공기홀 근처에 배치하면 팬의 흡입 기류가 모스펫을 실시간으로 식혀주어 완벽한 열 회피가 가능합니다.
2. SSR 안전 마운트: 도자기 가마 코일을 제어하는 SSR 역시 열이 많이 나는 소자입니다. 반드시 하부의 두꺼운 철판 플레이트에 써멀 구리스를 바르고 볼트로 직결하여, 철판 전체를 거대한 방열판으로 쓰도록 아키텍처를 짜시는 것이 안전합니다.

결론부터 말씀드리면, SSR 은 100% 방열판이 필요하며 블로워 팬 바람길에 두는 설계는 아주 좋습니다. 또한 가마 코일과 SSR 작동 시 전기적 노이즈 (EMI) 가 확실하게 발생하므로, ESP32 의 안전을 위한 방어 아키텍처가 필수적입니다.
실무 엔지니어들이 이 두 가지 문제를 어떻게 우회하고 방어하는지 완벽한 가이드를 정리해 드립니다.



### ♨️ 1. SSR 방열판 및 배치 전략: " 바람길 배치의 신의 한 수 "

도자기 가마 코일 (수백~수천 W) 을 제어할 때, SSR 내부의 반도체 소자 (Triac) 는 전류가 흐르면서 자체적으로 엄청난 열을 만들어냅니다. 방열판이 없으면 SSR 이 80 도 이상으로 과열되어 녹아버리거나 220V 를 차단하지 못하고 계속 켜져 있는 치명적인 ' 쇼트 고장 ' 이 발생합니다.

- 질문자님의 설계 평가 (최고의 아키텍처 ⭕): SSR 을 " 블로워 팬의 바람길 (흡입 또는 송풍 패스)" 에 배치하겠다는 발상은 완벽한 열 회피 전략입니다.
- 현실적인 조립 팁: SSR 등 뒤에 전용 알루미늄 방열판을 볼트로 결합한 뒤, 그 방열판의 날개 사이로 블로워 팬의 바람이 지나가게 배치하세요. 혹은 아까 설계하신 최하단 두꺼운 철판 플레이트에 SSR 을 직접 밀착 고정시키면, 철판 전체가 거대한 방열판 역할을 해주어 열 문제를 완벽하게 지울 수 있습니다.

### ⚡ 2. 열선 및 SSR 노이즈 문제 분석과 3 가지 방어 전략

가마 코일 자체는 단순한 저항선이라 노이즈가 적지만, 가마 코일이 스프링처럼 꼬여있는 구조 (인덕턴스 발생) 와 SSR 이 220V 전기를 초당 수십~수백 번 켰다 껐다 할 때 발생하는 ' 스위칭 노이즈 (EMI)' 는 뇌 역할을 하는 ESP32 를 오작동하게 만들거나 리셋시킬 수 있는 강력한 적입니다.

이를 방어하기 위해 다음 3 가지 방어벽 (인터록) 을 1 층 제어부에 설계하셔야 합니다.

#### ① ' 제로 크로싱 (Zero-Crossing)' 기능이 있는 SSR 선택 (필수 ⭐)

- 원리: AC 220V 전류는 파도 (사인파) 처럼 +, - 를 초당 60 번 오갑니다. 전압이 가장 높은 파도의 정점에서 SSR 이 전기를 확 켜버리면 엄청난 전기적 스파크 노이즈가 발생합니다.
- 해결책: 반드시 ' 제로 크로싱 ' 기능이 내장된 SSR(예: 대륙제 저가가 아닌 국산/일산 정품 SSR) 을 구매하세요. 이 기능이 있으면 전압이 `0V` 가 되는 아주 평화로운 타이밍에만 전기를 켜고 끄기 때문에, 스위칭 노이즈의 90% 이상을 하드웨어 자체에서 원천 차단해 줍니다.

#### ② 스나버 회로 (RC Snubber / 서지 킬러) 장착

- 방법: 가마 코일로 들어가는 AC 220V 양 끝단 (또는 SSR 의 출력 단자) 에 ' 서지 킬러 (Surge Killer)' 라고 불리는 소형 부품 (저항과 콘덴서가 뭉쳐진 것, 1~2 천 원) 을 나란히 병렬로 연결해 줍니다.
- 효과: 코일이 켜고 꺼질 때 발생하는 불규칙한 고전압 노이즈 (서지) 를 이 댐퍼가 스펀지처럼 흡수하여 지워버립니다.

#### ③ 물리적 공간 은닉 및 전원 분리 (Isolation)

- 공간 은닉: 노이즈는 공기 중으로도 전파됩니다. 220V 고전력선 (AC 라인) 과 ESP32 의 미세 신호선 (DC 3.3V 라인) 은 선이 서로 꼬이지 않도록 라우팅 경로를 완전히 분리해 주세요.
- 전원 분리: ESP32 에 전원을 공급하는 스마트폰 충전기 모듈 (또는 SMPS) 에 노이즈 필터가 약하면 220V 노이즈가 ESP32 의 전원선으로 타고 들어옵니다. 가급적 안정성이 검증된 정품 24V SMPS 를 쓰고, ESP32 바로 앞단에 전원을 고르게 펴주는 커패시터 (콘덴서) 를 하나 달아주면 완벽하게 방어됩니다.
