# Mechanical Specifications

핫 블레이드 터닝 머신의 물리적 구조, 축별 구동 방식 및 하드웨어 구성 요소를 정의합니다.

> 관련 모듈: [01 Hardware & Motion](01-Hardware-Motion.md) (전기·StallGuard) · [02 Thermal Engine](02-Thermal-Engine-Sensing.md) (열선) · [05 G-code CAM](05-GCode-CAM-Pipeline.md) (Z·Kerf)

## 구동계 개요 · Motion Architecture

본 장비는 알루미늄 프로파일 프레임을 기반으로 하며, 총 4 개의 **NEMA17** 모터를 사용하여 공간 효율적인 4 축 제어를 구현합니다.

### Axis_Drive_Matrix 축별 구동 방식

| 축 | 역할 | 구동 방식 | 가이드 시스템 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **X 축** | 길이 방향 이송 | **타이밍 벨트 (GT2)** | 프로파일 + 베어링 휠 | 고속 이송 최적화 |
| **Y 축** | 폭 방향 이송 | **타이밍 벨트 (GT2)** | 프로파일 + 베어링 휠 | 경량화 및 응답성 |
| **Z 축** | 절삭 깊이 (높이) | **리드 스크류 (T8)** | **LM 가이드** | 고정밀·하중 지지 |
| **A 축** | 모재 회전 | **커플러 직결** | 모터 샤프트 직결 | 백래시 최소화 |

## 축별 상세 명세 · Detailed Specs

### Z 축: 고정밀 수직 제어
Z 축은 열선의 높이와 절삭 깊이를 결정하므로 가장 높은 기계적 강성이 요구됩니다.
- **가이드**: **LM 가이드 (Linear Motion Guide)**를 사용하여 유격을 방지하고 선형 운동의 반복 정밀도를 확보합니다.
- **전달**: **리드 스크류**를 채택하여 전원 차단 시 자중에 의한 낙하를 방지하고 미세 이송 (Resolution) 을 극대화합니다.

### X·Y 축: 고속 경로 추종
대형 모재 가공을 위해 빠른 이동이 필요한 X, Y 축은 벨트 구동 방식을 사용합니다.
- **전달**: **GT2 타이밍 벨트** 및 풀리 조합.
- **이송**: 알루미늄 프로파일 홈을 따라 주행하는 **V-Slot 베어링 휠** 시스템을 통해 진동을 흡수하고 부드러운 주행을 구현합니다.

### A 축: 회전 대칭 가공
모재를 직접 회전시키는 A 축은 동력 손실과 오차를 줄이기 위해 직결 방식을 사용합니다.
- **연결**: 스테퍼 모터 샤프트와 회전축을 **플렉시블 커플러**로 직접 연결.
- **지지**: 대형 모재의 경우 하단에 **베어링 블록 (UCP 시리즈)**을 추가하여 모터 샤프트에 가해지는 반경 방향 하중을 분산합니다.

## Mechanical Alignment — 하드웨어 정렬 및 물리적 교정 `[MVP v0.1 필수]` {#mechanical-alignment-- 하드웨어 - 정렬 - 및 - 물리적 - 교정 -mvp-v01- 필수}

**회전 중심 (A 축)** 과 **열선 절삭점 (Z·X·Y)** 의 물리적 영점이 어긋나면, 소프트웨어 보정만으로는 **Ø 누적 오차·단면 타원화·StallGuard 오검출** 을 막을 수 없습니다.
조립·정기 점검 시 아래 **3 축 정렬**(A↔Z, 심압대 수평, 벨트 장력) 을 수행합니다.

```text
[정렬 체인]

A축 회전 중심 (C_A)
    ║  ← Run-out · coaxial
    ╠══ 모재 (아이소핑크 / 볼트)
    ║
UCP204 심압 중심 (C_T)     ← 높이·수평 (ΔZ_tail)
    ║
Z/X/Y 갠트리 ──► ㄷ자 열선 헤드 중심 (C_W)  ← A축과 동축
```

| 불량 | 현상 | 소프트웨어 증상 |
| :--- | :--- | :--- |
| A↔Z 중심 어긋남 | Ø 절삭 **타원** · 누적 Z 오차 | `wire_temp_c` 불균일 · Kerf 편차 |
| 심압대 높이 편차 | 모재 **휨** · Run-out | A 축 `a_load_pct` 상승 · **S10** |
| 벨트 장력 부적절 | X/Y **진동·탈조** | StallGuard **오검출** · 리플링 |

### 1. A 축–Z 축 (열선) 중심 정렬 `[MVP v0.1 필수]` {#a 축 -z 축열선 - 중심 - 정렬}

**목표**: ㄷ자 열선 헤드의 **절삭 중심**이 A 축 회전 중심선과 **동축 (coaxial)** — 허용 **≤0.05mm (TIR)** @ 자재 표면.

#### 기준면 정의

| 기호 | 의미 |
| :--- | :--- |
| **C_A** | A 축 모터·커플러·모재 회전축 (수평) |
| **C_W** | ㄷ자 헤드 **니크롬 접촉 중심** (열선 두 줄 중앙) |
| **Z_ref** | C_W 의 Z 높이 — [05 Kerf Z_final](05-GCode-CAM-Pipeline.md) 기준 |

```text
        Z ↑
          │    ┌─ ㄷ자 열선 헤드 ─┐  ← X/Y/Z 갠트리
          │    │   C_W ●        │
          │    └────────────────┘
    ══════╪══════● C_A ═══════════  ← 모재·A축
          │
     [UCP204 심압]
```

#### 교정 절차 (5 단계)

| 단계 | 작업 | 합격 |
| :---: | :--- | :--- |
| **1** | `$H` / `G28 A0` · A 축 홈 · 모재 **미장착** | A 홈 반복 ≤0.02° |
| **2** | 다이얼 게이지를 **Z 캐리지**에 고정 · A 축 샤프트 (또는 테스트 mandrel Ø8) 에 터치 | — |
| **3** | A 축 **수동 360°** 회전 (`M210` 저속 또는 손돌림) | TIR **≤0.05mm** |
| **4** | 어긋남 시: **Y/Z 브래킷** 셔임 (0.05~0.2mm 알루미늄) · ㄷ자 헤드 마운트 볼트 재조임 | TIR 합격 |
| **5** | **live 저출력** 시험: Ø34 원통 1 회전 · `device_dry` | 단면 **원형** 육안 · telemetry ΔZ <0.1mm |

**ㄷ자 헤드 전용 체크** (열선 장착 후):

1. 열선 **OFF** (`M5`) · A 축 90°×4 정지 (`A_POS`)
2. 각 각도에서 **C_W → 모재 표면** 간극을 필러 게이지 (0.05/0.10mm) 로 측정
3. 4 점 간극 차 **≤0.10mm** — 초과 시 Y 미세 조정

```gcode
; A-Z coaxial check — device_dry, no PWM
G90
G28 A0
G01 A0   F60
G01 A90  F60
G01 A180 F60
G01 A270 F60
; 각 정지점에서 현장 간극 기록 → maintenance log
```

> CAM `Z_nominal` 은 **C_W 정렬 완료 후** [05 Profile/Kerf](05-GCode-CAM-Pipeline.md) 로 산출합니다.  
> **4점 간극** 측정값 → CAM `e_mount` (장착 편심, 패스 전 구간 상수).  
> Scan·형상 비대칭 → `e_shape` (대칭 수렴 시 감쇠) — [05 이원화 편심](05-GCode-CAM-Pipeline.md#편심eccentricity--lead-in-거리-보정) · 기계 정렬 **1차** / CAM **2차**.

### 2. 심압대 (Tailstock) 수평도 — UCP204 `[MVP v0.1 필수]` {#심압대 tailstock- 수평도 --ucp204}

A 축 **모터측** 과 **UCP204 심압대** 베어링 중심의 **높이 (Z)·수평 (Y)** 편차를 제거합니다.
편차가 있으면 장축 모재가 **휘어** A 축 모터에 **추가 토크** → [01 StallGuard S10](01-Hardware-Motion.md#stallguard--모재-지름-동적-부하-임계-a_vel-mvp-v01-필수) 오검출.

#### 측정

| 항목 | 방법 | 허용 |
| :--- | :--- | :---: |
| **ΔZ_height** | 동일 X 위치에서 모터 샤프트 중심 vs UCP204 내경 중심 (다이얼·높이 게이지) | **≤0.10mm** |
| **ΔY_lateral** | 정면에서 두 중심 연결선 vs 수평 (각도계·연필선) | **≤0.15mm / 200mm** |
| **Run-out @ 심압** | mandrel Ø8 · A 360° · 심압만 지지 | TIR **≤0.08mm** |

```text
[측면 — 높이 정렬]

  A 모터 ●━━━━━━━━━━━━● UCP204 (심압)
         ↑            ↑
         Z_motor      Z_tail
         |←── ΔZ ────→|  ≤0.10mm

[정면 — 수평]

  ● C_A ───────────── ● C_T
        ←── 200mm ──→
        ΔY ≤0.15mm
```

#### 보정 방법

| ΔZ | 보정 |
| :--- | :--- |
| 심압 **낮음** | UCP204 마운트 하부 **셔임 팩** (0.05·0.10·0.20mm) 적층 |
| 심압 **높음** | 마운트 볼트 풀고 브래킷 1~2mm 깎기 · 또는 A 측 모터 브래킷 셔임 |
| ΔY | 심압 **Y 슬롯 홀** (장공) 으로 전후 미세 이동 · 좌우는 프로파일 정사각 |

**조립 순서 (권장)**:

1. A 축 모터·커플러 고정 → 홈
2. **레벨 게이지**로 A 축 샤프트 수평 확인
3. UCP204 브래킷 **슬롯** 조임 (완전 체결 전)
4. 테스트 mandrel 장착 · ΔZ·ΔY 측정 → 셔임
5. 최종 토크 · Run-out 재측정

| 부품 | 사양 |
| :--- | :--- |
| **UCP204** | 내경 **20mm** (Ø20 샤프트) 또는 **12mm** 어댑터 + Ø8 mandrel |
| 마운트 | 2040 프로파일 + **슬롯** 6.5×15mm (미세 Y) |
| 셔임 | 0.05 / 0.10 / 0.20mm 알루미늄 박판 |

### 3. GT2 벨트 장력 정량화 `[MVP v0.1 필수]` {#gt2- 벨트 - 장력 - 정량화}

X/Y 축 **GT2 (6mm 폭)** 벨트 장력이 너무 느슨하면 **탈조·위치 오차**, 너무 팽팽하면 **베어링 마모·고주파 진동** → TMC **StallGuard** 가 실제 stall 없이 트리거됩니다.

#### 권장 측정법 — 중점 변위 (Deflection)

텐셔너에서 **벨트 스팬 중앙**에 표준 힘을 가하고 **처짐량**을 측정합니다.

```text
        Motor ●───────────────● Idler
                    │
              ← L_span →
                    │
                 ↓ F_test (표준)
                    ●  δ (처짐)

권장: L_span ≈ 200~350mm (프레임별 측정 후 고정)
```

| 파라미터 | X 축 MVP | Y 축 MVP |
| :--- | :---: | :---: |
| `L_span` | 프레임 실측 (예: **280mm**) | 실측 (예: **220mm**) |
| `F_test` | **3.0 N** (약 300gf) | **3.0 N** |
| **목표 처짐 δ** | **2.0~2.5 mm** | **1.8~2.3 mm** |
| 허용 범위 | **1.7~2.8 mm** | **1.5~2.6 mm** |

**측정 절차**

1. 가공 **OFF** · X/Y `device_dry` 홈
2. 텐셔너 볼트 **현 상태** 마킹
3. 스팬 중앙에 **디지털 푸시게이지** 3N 힘 · 처짐 δ 읽기
4. δ **> 상한** → 텐셔너 1/4 턴씩 조이기 · 재측정
5. δ **< 하한** → 1/4 턴 풀기
6. 좌·우 (또는 상·하) **양쪽 스팬** 각각 기록 — 편차 **≤0.3mm**

```text
[텐션 체크리스트 — 현장 기록]

날짜: ______  장비: turning-01
        L_span   F_test   δ_meas   판정
X축:    280mm    3N       2.2mm    OK
Y축:    220mm    3N       2.0mm    OK
A축 벨트: N/A (직결)
```

#### StallGuard 연동

| 벨트 상태 | `a_load_pct` (공회전) | X/Y Stall (모터측) |
| :--- | :--- | :--- |
| **최적 δ** | 15–25% (Ø34 기준) | 정상 |
| **느슨함** | 불규칙 스파이크 | `d_pct/dt` 급등 → 오검출 |
| **과장력** | 30%+ 정상 가공 | 모터 베어링 소음 |

**가공 전 필수** ([04 일일 기동 체크리스트](04-Data-Operations.md)):

- [ ] X/Y δ **허용 범위**
- [ ] `device_dry` `G01 X100 F600` 왕복 — 이상 소음 없음
- [ ] `a_load_pct` baseline — [01 드라이런 캘리브](01-Hardware-Motion.md#stallguard--모재-지름-동적-부하-임계-a_vel-mvp-v01-필수)

#### Tension_Adjustment_System (구조)

- **구조**: X/Y 프로파일 끝단 **나사식 수동 텐셔너**
- **Creep 대응**: 월 1 회 δ 재측정 · 마킹 위치 drift 시 1/4 턴 보정
- **균형**: δ 목표 **중앙값** 유지 — 과장력 NEMA17 수명 ↓

### Mechanical Alignment 검증 체크리스트

- [ ] A 축 TIR (mandrel) **≤0.05mm**
- [ ] ㄷ자 헤드 4 점 간극 **≤0.10mm**
- [ ] UCP204 ΔZ **≤0.10mm** · ΔY **≤0.15mm/200mm**
- [ ] 심압 Run-out **≤0.08mm**
- [ ] GT2 X/Y δ **허용 범위** · 양 스팬 편차 **≤0.3mm**
- [ ] 정렬 후 Ø34 시험가공 — 단면 타원 **없음**
- [ ] `a_load_pct` baseline 재기록 · `cmd_stall_policy` 갱신

> **수석 아키텍트 비평**: 벨트 (X/Y) 신속성 + 스크류 (Z) 정밀의 하이브리드는 핫 블레이드에 적합합니다. **A 축 직결** 은 부하 집중 → **UCP204 심압** 필수. **A↔Z 동축** 미달 시 CAM·HFS 를 아무리 맞춰도 **Ø 누적 오차** 가 남습니다.

| 주기 | 항목 |

## SD 외부 슬롯 · AP 스위치 장착 `[MVP v0.1 필수]` {#sd-외부-슬롯--ap-스위치-장착-mvp-v01-필수}

오프라인 운영·G-code 수동 교체를 위해 **측면 패널**에 SD 외부 슬롯과 **전면**에 AP 전환 스위치를 배치합니다.

### 장착 위치

| 부품 | 위치 | 이유 |
| :--- | :--- | :--- |
| **SD 외부 슬롯** | **우측면** 하단 (운영자 스탠드) | PC 복사 후 **전원 OFF** 탈착 · 내부 배선 FFC 20cm |
| **AP 스위치** | **전면 상단** (E-Stop 인접·시야 확보) | 긴급 시 CLOUD↔LOCAL **즉시** 판별 |
| **모드 LED** | 스위치 양측 | CLOUD=파랑 · LOCAL=초록 |

```text
[전면]

  E-STOP    [CLOUD ● LOCAL]    START
                 ↑
            AP 토글 + LED

[우측면]

       ┌─ SD ─┐  ← 푸시-푸시 · 화살표 ↓ 삽입
       └──────┘
```

### SD 연장 브래킷

- **재질**: 2mm 알루미늄 L 브래킷 · 2040 프로파일 볼트 고정
- **FFC 경로**: 내부 **최대 굴곡 R≥15mm** · 모터·벨트와 **분리** (EMI·마모)
- **덮개**: 자석 플랩 · 가공 중 **닫힘** (분진 유입 방지)

### AP 스위치 브래킷

- **5mm PETG** 또는 알루미늄 전면 플레이트 개구
- 라벨 **실크스크린**: `CLOUD` = 인터넷 · `LOCAL` = 장비 Wi-Fi
- 배선: ESP32 `GPIO_LINK_MODE` — [01 연결 하드웨어](01-Hardware-Motion.md#연결-하드웨어--ap-스위치--sd-연장-가이드-mvp-v01-필수)

### 오프라인 운영 체크 (조립 후)

- [ ] SD 외부 삽입·인식 (`/sd/nexa/manifest.json`)
- [ ] AP 스위치 CLOUD/LOCAL LED · `connectivity_mode` telemetry 일치
- [ ] LOCAL: 스마트폰 `NEXA-TURNING-01` 접속 · Portal 로드
- [ ] SD 탈착 시 **전원 OFF** 라벨 부착

## 정밀도 및 안전 보조 장치 · Precision & Safety

### Limit_Switch_Layout 리미트 스위치 구성
- **유형**: 기계식 마이크로 스위치 또는 비접촉 홀 센서.
- **위치**:
  - **X/Y Min**: 하우징 끝단 (Homing 용).
  - **Z Max**: 열선 상승 한계점 (충돌 방지).
- **로직**: 하드웨어 단에서 **Hard Limit** 활성화하여 스테퍼 모터의 탈조 및 기구부 파손 방지.

### Workpiece_Support 모재 지지 구조
- **심압대 (Tailstock)**: A 축 모터 맞은편에 **UCP204 베어링** 기반의 회전 지지대 설치.
- **효과**: 장축 모재 가공 시 Run-out 억제 — **ΔZ·ΔY 정렬**은 [Mechanical Alignment §2](#심압대tailstock-수평도--ucp204) 참조.

### Thermal_Barrier 열 차단 설계
- **절연 소재**: 핫 블레이드 홀더와 Z 축 캐리지 사이에 10mm 두께의 **PEEK** 또는 **세라믹 판재** 적용.
- **방열판**: 필요 시 Z 축 모터 보호를 위해 알루미늄 방열 핀 (Heatsink) 을 마운트에 추가.

## SHB-Lathe Head 열선 헤드 설계

### 물리 구조 설계 (Mechanical Structure)

ㄷ자 형태의 가이드 칼날이 별도의 지지판 없이 자체적인 자립 강성을 지니면서 열을 전달할 수 있도록 [샌드위치 적층 가공 방식] 을 채택한다.

```unset
       [ 가공 진행 방향 ➔ ]
               │
       ┌───────▼───────┐
       │ 스텐레스 1T   │  ◀── 1단계: 앞날 각(면취)을 세운 단단한 ㄷ자 뼈대
       └───────┬───────┘
               ├── 2단계: [테프론 테이프 랩핑] (전기 쇼트 원천 차단)
               ├── 3단계: [니크롬 열선 2줄 배치] (발열원, 직렬 연결)
       ┌───────┴───────┐
       │ 알루미늄 테이프│  ◀── 4단계: 열을 칼날 전체로 강제 확산 및 밀착 고정
       └───────────────┘
```

### 뼈대 자재 선정 및 가공

- 소재: 스텐레스 스틸 (SUS 304 또는 SUS 316) 판재 두께 1.0T(1mm) 또는 폐 회로기판 (FR-4) 1.2T~1.6T 활용.
- 규격: 최종 가공 폭 20mm 구현을 위해 [가로 20mm × 좌우 기둥 높이 각 20mm] 의 ㄷ자 형태로 드레멜 다이아몬드 날을 이용하여 정밀 커팅한다. (총 펼친 길이 60mm)
- 모서리 면취 가공 (★필수): 열선이 감길 금속의 날카로운 모든 모서리는 사포나 그라인더를 이용해 부드럽고 둥글게 (R 값 라운딩) 가공한다. 모서리가 날카로우면 조립 시 절연 테이프가 찢어져 쇼트가 발생한다.
- 날 각 세우기: 아이소핑크와 먼저 만나는 앞날 전면부는 칼날처럼 사선으로 날을 살짝 세워둔다. (열선을 껐을 때 순수 물리 대패 역할을 겸하기 위함)

---

### 전기 및 절연 설계 (Electrical & Insulation)

열선 전력이 스텐레스 뼈대 및 기계 프레임 전체로 누전되는 것을 차단하고, 열에너지를 칼날 전면으로 집중시키는 구조이다.

### 구조적 절연 및 밀착 조립 순서

1. 1 차 절연층 (테프론 랩핑): 가공된 스텐레스 ㄷ자 뼈대 표면에 구매한 ‘테프론 (PTFE) 유리섬유 원단 테이프 (두께 0.18mm)’를 타이트하게 1~2 바퀴 감싸 뼈대 전체를 절연한다.
2. 발열선 매립 (투 라인 직렬 배치): 지름 0.5mm(24AWG) 니크롬선을 사용한다. ㄷ자 프레임 뒷면 (칼날 등) 을 따라 ‘갔다가 돌아오는 한 선 구조 (직렬, Series Connection)’로 두 줄을 팽팽하게 밀착 배치한다.
    
    - _이유_: 직렬로 연결해야 전체 저항이 2 배로 늘어나 소모 전류 (A) 가 줄어들며, 보유한 DC 파워 서플라이와 MKS 보드에 무리를 주지 않는다.
    
3. 열 가둠 및 고정 마감 (알루미늄 샌드위치): 열선 두 줄 위에 ‘알루미늄 테이프’를 덮고 꾹꾹 눌러 강하게 압착한다. 열전도율이 극도로 높은 알루미늄이 열선에서 발생한 열을 흡수하여 스텐레스 칼날 전체를 150℃ 이상으로 신속하고 균일하게 달구어 준니다.

### 센서 인터페이스 설계 (Sensor Telemetry)

열선의 건강 상태와 실제 가공 부하를 실시간으로 계측하기 위해 이중 센서 감시 체계를 구축한다.

```unset
 [MKS 보드 LASER 단자 (+)] ───▶ [INA219 전류 센서 Vin+] 
                                         │ (내부 전력/노화 계측)
 [하이브리드 ㄷ자 칼날 열선]   ◀─── [INA219 전류 센서 Vin-]

 [MKS 보드 I2C 단자]         ◀───▶ [INA219 데이터선 (SDA/SCL)]
 [MKS 보드 SPI 단자]         ◀─── [MAX6675 모듈] ◀── [K-타입 열전대 센서]
```

#### 열전대 (Thermocouple) 간접 온도 측정

- 센서 유형: 지름 1mm 내외의 끝단 구슬형 K- 타입 열전대 (Thermocouple) 선 활용.
- 거치 위치: 스텐레스 판 뒷단, 직렬로 배치된 열선과 열선 사이의 중심 공간에 센서 끝단 접점을 밀착시킨 후 알루미늄 테이프로 함께 밀봉한다.
- 신호 변환: MAX6675 모듈에 센서를 물린 후, MKS 보드의 확장 `SPI` 통신 단자에 직결하여 ESP32 가 디지털 온도 값을 상시 읽도록 한다.

#### INA219 전류 센서를 통한 노화 및 쇼트 감지

- 거치 위치: MKS 보드의 `LASER (+)` 출력 단자와 열선 플러스 입력 단자 사이에 INA219 센서 모듈을 직렬로 연결한다. 센서의 통신선 (`SDA`, `SCL`) 은 MKS 보드의 `I2C` 단자에 꽂는다.
- 노화 (수명) 감지 공식: 열선이 오래되어 가늘어지면 저항 (R) 이 커져 전류 (A) 가 감소한다. Next.js 백엔드에서 아래 공식을 실시간 연산하여 사용자 UI 에 열선 수명을 퍼센트 (%) 로 표시한다.
    $$\text{열선 수명 잔여율(\%)} = \left( \frac{\text{현재 계측 전류(A)}}{\text{최초 가공시 정상 전류(A)}} \right) \times 100$$
- 초고속 쇼트 차단: 가공 중 테프론 테이프가 찢어져 전류가 5A 이상으로 치솟는 순간, ESP32 가 하드웨어 레벨에서 0.001 초 만에 전원을 차단하는 인터록 (Interlock) 루틴을 실행한다.


### 펌웨어 (FluidNC) 및 G- 코드 매칭 설계

#### 독립적 구동 제어 매커니즘
보드 내부에서 4 개 모터 구동 회로와 열선 전력 제어 회로는 완벽히 분리되어 동시 실행됩니다.

- **모터 4 축 매핑**: 4 개의 모터 슬롯에 **X**(좌우), **Y**(앞뒤), **Z**(높이/깊이), **A**(자재 회전) 모터선을 직결합니다. (TMC2209 드라이버 기반)
- **열선 인터페이스**: 보드의 내장 모스펫 (MOSFET) 과 연결된 **LASER** 2 핀 터미널 단자에 열선 전원선을 연결하여 PWM 제어를 수행합니다.

#### G-Code_Protocol G- 코드 표준 지시어 약속
Next.js 서버가 생성하고 ESP32 가 실행할 프로콜 규격입니다. 열선의 세기는 **S 값 (0~1000)**을 이용하며, 이는 향후 하드웨어 확장 시 스핀들 RPM 과 1:1 호환됩니다.

- **M3 S{value}**: 열선 전력 공급 시작 (예: `M3 S1000` 은 100% 출력).
  - **S1000**: 가공 초기 예열 및 고속 이송 구간.
  - **S600~800**: 감속 구간 또는 얇은 단면 가공 시 온도 과열 방지.
- **M5**: 열선 전력 즉시 차단 (가공 완료 및 긴급 정지 시 실행).
- **G01 X.. Y.. Z.. A.. F..**: 4 축 동기 보간 이송 명령.
